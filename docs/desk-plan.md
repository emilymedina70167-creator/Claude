## 3. 第 1 批：记录能力（记得全、记得准、存得稳）

### 3.1 课后报告（页面代码算，不调用 Claude）

下课时（以及「以前的课」打开一节时）由代码把这节课整理成一份 `sessions/{编号}/report/main`，结果确定、可测：

- 每个作答组件一行：题面（截短）、所在段和板、尝试次数、每次对错的序列、总用时、放弃 / 揭开 / 看答案、最终结果、手写原图 id。
- 按块、按知识点（`tags`）汇总：做了几题、一次对几题、错几题、放弃几题、用时。
- 没做完的题、没提交的草稿（下课那一刻的 `drafts.js` 快照）。
- 我说的话（`say` 证据）原样列出，附的图列 id。
- 课堂 Claude 这节课的观察、提议、小结的 id。
- 这节课时长（开课到下课，去掉长时间没动静的段）。

用途：课后整理（第 2 批）、「以前的课」页面（第 3 批）、外部 Claude 课后只读这一份就够。纯函数放 `memory/report.js`，配测试。

### 3.2 补记

首页「补记」：在学习台外面做的（纸上、Notability、外部对话里），贴截图（复用课堂输入条的图片处理，Notability 的坑一样）或者写一句话，可选挂到某一块、标「对 / 错 / 不会」。记成 `evidence`（`src: "manual"`），下次课后整理一起看。

### 3.3 证据补全

- 下课时把还没提交的草稿记一条证据（`kind: "draft"`），免得「写了一半」丢掉。
- 课堂里我在板上用 Pencil 写的板书，现在跟着消息作为图发给课堂 Claude；确认它们都进了 `say` / `photo` 证据（带 `turn`），没有就补上。
- 证据里记这条是第几轮（`turn`），报告和时间线按它对齐课堂记录。

### 3.4 导出备份、用量

- 首页「导出备份」：整个记忆库（可选带不带 `evidence`、各节课的黑板）存成一个 JSON 文件，用 `downloads` 能力让我保存。发布学习台的 capabilities 要加 `downloads`，说明书第七节跟着改。
- 「从备份恢复」先不做成按钮：写进说明书，由外部 Claude 用 `ArtifactData` 的 `batch` 按备份文件写回（写清步骤）。
- 首页显示用量：各类条数、assets 已用多少（`assets.list()` 的 `usage`）。

## 4. 第 2 批：内部 Claude 改学习台的能力（分档、可确认、可撤销）

### 4.1 三档权限（默认值如下，动手前问我要不要调）

| 档 | 哪些 | 怎么写 |
|---|---|---|
| **直接写** | 讲法偏好、学习习惯（写进 `profile`，`topic` 用「讲法」「习惯」）；它自己的教学失误（`slips`）；观察（`observations`） | 课堂 Claude 用工具写，这一轮核验是 Opus 5.5 才生效 |
| **我确认才写** | 新错题（`errors`）、新弱点 / 弱点证据级变化（`weaknesses`）、新复现组 / 往复现组加题（`reviews`）、下一节从哪接（`position`） | 课堂 Claude 写成「待确认」，我在页面上点「确认」才写进去 |
| **只能提议** | 掌握状态（`mastery`，红线：课堂不能宣布掌握）、规则（`rules`） | 照旧写 `observations` 的 proposal，外部 Claude 或我决定 |

- 「我确认才写」的落地方式：新集合 `pending`（`{ coll, op: "add" \| "update", id?, data / patch, reason, basis: [证据 id], session, turn, at }`）。确认时页面按记忆库规矩写进目标集合：状态类自动记 log（`by: "class"`，`note` 写「我确认于 …」），历史类只增不改。不要的标成 `rejected`，留着给课后看。
- `schema.js`：给对应集合的 `writers` 加上确认路径（建议新角色 `confirmed` 或在 log 里区分），`assertWrite` 照旧拦住课堂 Claude 直接写这几类；`check.js` 认新的 `by` 值。
- 课堂 Claude 的工具（只在学习台里给）：`record_error`、`update_weakness`、`add_review`、`set_next`、`note_preference`。每个都要求 `basis`（证据 id，从记忆摘要或 `memory_read` 里来）；没有依据的拒绝。
- 每一轮写了什么，在板顶那句话下面小字列出来（「记下了：偏好 1 条；待你确认：错题 1 条」），点开能看、能撤。

### 4.2 下课时的整理单

点「下课」时，课堂 Claude 除了写小结，再读课后报告（3.1），一次列出整理单：新错题、弱点变化、复现组怎么调、下一节从哪接、它这节课的失误。全部进 `pending`，在小结那块板上逐条显示：理由 + 证据（点开看那次作答原文）+「确认 / 改 / 不要」。这样大部分课后不用回外部对话。外部 Claude 照旧能做同样的事（读报告、读 `pending`），两条路写同一份记忆。

### 4.3 撤销和我自己改

- 任何一条写入（不论谁写的）在一段时间内能撤：状态类按 log 回退一步（回退本身也记一条 log），历史类追加一条「作废」更正（不删原条）。
- 我在页面上能直接改：偏好、某条错题标「已解决」（加更正，不改原条）、复现组暂停。新角色 `me`（我自己），log 里写清楚。

### 4.4 安全线（不能松）

- 只有核验过是 Opus 5.5 的那一轮，工具写入才生效（现有 `staged` 机制）。
- 页面在代码层面拦住越权写入（`assertWrite`），不靠提示词。
- 资料包、证据里的文字可能影响它调用哪个工具：所有「我确认才写」的都必须经过我点确认。

## 5. 第 3 批：学习台的交互（给我看的、我能点的）

iPad 优先（竖屏 820×1180、横屏 1180×820，触控目标 ≥ 44px），只读页面也要快。

- **首页「今天」重做：**接着上课 / 开新课 / 开复现课；到期和过期的复现组；下一节从哪接、欠账；**待确认**（`pending` 有几条，点进去处理）；上节课还没整理的提醒。
- **课程地图：**讲 → 节 → 块，每块按掌握上色（未学 / 讲过 / 基础题过 / 复现第几档 / 掉了）。点开：掌握的依据和 log、相关错题、这块所有作答的时间线（按证据）。
- **弱点表：**按影响面、证据级排；点开看 log（证据级怎么变的）、挂的错题、最近相关作答。
- **错题本：**按块 / 弱点 / 是否解决筛；题面、我的答案、错在哪、根因、更正都在一起；点开看那次作答原文和原图。
- **以前的课：**列表（日期、块、时长、核验、小结第一句）；点开看课后报告、只读翻那节课的黑板（复用 `boardview.js`，不能作答、不调用 Claude）。
- 页面结构：首页和各子页用地址 `#` 区分（和现在 `#c-…` 进课堂一样），子页不调用 Claude。
