# 外部 Claude 能力测试（2026-11-17）

学生说「多去测一下，看看外部有哪些潜力可以挖掘」。方向：外部 Claude 当主教（claude.ai 的记忆、项目知识），学习台负责呈现、即时判分、记录，内部 Claude 当助教。动手之前先量外部的上限，不等碰壁。

用法：在 claude.ai 的学习项目里开一个新对话，把下面整段粘进去。结果写进学习台 `meta/probe-external`，开发那边 `ArtifactData get meta/probe-external` 读。第 4 步写库时有没有弹「允许」、能不能一直允许，只有学生看得到，要问学生。

```text
这是一次能力测试，不是上课。请照下面一项一项真的去试，试不出来的照实写「不行」和卡在哪，不要猜、不要省步骤。除了 probe/ 下面的文档和 meta/probe-external 这一条，学习台里的数据一条都不要改。

学习台：https://claude.ai/artifact/BCAMUUkMWc2rt5hSS1ULHo

1. 工具：列出你这个对话里现在能用的全部工具（名字 + 一句话用途）。特别说清楚有没有：读写 artifact 数据库的、读 artifact 里的文件或图片的、搜以前对话的、搜项目知识的、网页搜索、能跑代码的。
2. 读：读学习台数据库里的 meta/instructions 和 meta/project 两条；再列一下 sessions（只报条数和最新三条的编号）。
3. 连着调工具：在同一条回复里，连着读 meta/project 20 次（每次都真的调，不要合并），数你实际调成了几次、在第几次被停下、停下时平台说了什么。
4. 写：写一条 probe/p1 = {"n": 1}，再用 update 改成 {"n": 2}，再删掉它。每一步成没成都记下。
5. 读大的：找最近一节课，把 sessions/{编号}/class_turns 整类读完（要分页就分页），报一共几条、大约多少字，中间有没有被截断或报错。
6. 看图：学习台的教材页存过原页图（books/{书}/pages/{页} 里记着 asset 的编号）。试着取一张来看，看得到就说上面写了什么；取不到说卡在哪一步。
7. 记忆：你现在对我有没有记忆？有的话列三条你记得的。能不能搜以前的对话？试搜一次「黑板」。
8. 项目知识：这个项目的知识库里有哪些文件？能不能按意思搜？试搜一次「被动语态的用法」，看找回来的是不是相关的。
9. 计时：能跑代码的话，第 3 步前后各取一次当前时间，算出连着调工具平均一次多少秒。
10. 你是哪个模型、这次有没有用扩展思考。

最后把结果写成一条 meta/probe-external（先 get，没有就新建）：
{ "at": 现在的时间, "model": ..., "tools": [...], "reads": {...}, "chain": { "calls": ..., "stoppedAt": ..., "message": ..., "secPer": ... }, "write": {...}, "bigRead": {...}, "image": {...}, "memory": {...}, "knowledge": {...}, "notes": "其他你发现的、能用在教学上的能力" }
写完在对话里用几行字汇报，然后问我：第 4 步写数据库时有没有弹出「允许」，能不能选「一直允许」。
```
