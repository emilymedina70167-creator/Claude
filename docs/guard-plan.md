# 学习台后方的守卫（2026-11-05）

## 我要的

学习台里有用的东西（错题、弱点、复现组、复盘、要记的、守则、教案）都是 Claude 写的：课堂里的 Claude 当场写，首页后台的复盘、归类，以后的云端教研室。我要的是**一个很强的代码系统把关**，保证写进来的东西是真的、对的、不重复、不越权、过时了会被发现——**不改 Claude 写的话**，也**不碰上课回话的速度**。我愿意为它付出开发成本；它做好以后日常不该再花额度。

这和「体检」（`health.js`）分工：体检修页面自己留下的机械数据；守卫管所有**写内容**的入口。

## 三层

1. **守卫（法律）**：每一条要写进记忆库的内容先过它，不管谁写的（课堂 Claude 的 memo 和下课整理单、首页后台的复盘和归类、云端教研室）。我自己在页面上改的不拦。
2. **调度（大脑）**：纯代码每天算出后方该做什么（没收尾的课、待重判的结论、薄弱点缺新题、明天要备的课），按价值排好，写明大概花多少。
3. **云端教研室（手）**：照工作单写内容；写出来的先在云端跑同一套守卫，再进学习台的收件箱，学习台并进来时再跑一遍。

这份文档先管第 1、2 层；教研室另起一份。

## 守卫的六道（`kit/src/memory/guard.js`，纯函数）

一条待写的内容（候选）：哪一类、哪一条、写成什么样（改之前、改之后）、谁写的（`class` / `page` / `lab` / `chat`）、哪节课。

| 道 | 查什么 | 不过时 |
|---|---|---|
| 格式 | `schema.js` 的必填、编号、取值、日期（`writer.js` 的 `validateWrite`） | 拒收 |
| 证据 | basis 里的编号都在；写着是这节课的，证据也得是这节课的（或以前真有的）；**引的原话**（「…」、"…"）能在这节课的记录里逐字找到（学生说的、写的、作答、老师写的板书都算，不管空格、全角半角）；`#43`、`第 43 轮` 这样指的轮次真有；`b12`、`ps-b26r` 这样指的组件真有；错题的「我写的」（`mine`）要对得上它挂的那条作答 | 编号找不到：拒收；原话、轮次、组件对不上：挂提醒（教研室写的：先暂存） |
| 计算 | 新题、答案：渲染、取数自检、精确重算（教研室出题那一批接上） | 拒收 |
| 归属 | 课堂里的 Claude 当场写的、我自己改过的内容，别的作者（教研室、页面）**不能改它的话**，只能挂「有疑问」附依据；事后替没下课的课写的要标 `backfill` | 拒收 |
| 一致 | 和已有的几乎一样（同一类、同一科）；和已有结论矛盾（弱点标「修好了」但之后还在错、复现组记「过」但这节课那几块的题没做对、掌握升档时最近在错） | 重复：拒收；矛盾：挂提醒 |
| 时效 | 已经收下的结论被后来的证据推翻（「消了」的误解又出现、「修好了」的弱点又错）：标「可能过时」，排进待重判 | 只标（第 3 步） |

结果四种：**收下**、**收下但挂提醒**（记在那一条的 `guard` 字段，页面和下一次写内容的 Claude 看得到）、**先暂存**（`pending` 的 `status: held`，带对照，我或下一次的 Claude 处理）、**拒收**（写明原因）。每一个决定记进审计日志 `guard_log`，都能撤销（照旧走 `undoPending`）。

**宽严**：课堂里的 Claude 上课最准，它当场写的原话对不上只挂提醒；教研室（事后写的）对不上先暂存。数字照真数据量过再定（第 1 步）。

**被拒了怎么办（不多花额度）**：上课时的 memo 块被拒，照旧在下一轮告诉课堂 Claude（`classroom.js` 已经这么做）；下课整理单被拒的，记进 `meta/guard` 的 `carry`，下一节同一科开课时资料包里带一行「上次整理单里没收的几条和原因」，让它顺带补。不为重写单独调用。

**不碰上课的速度**：守卫在写进记忆库那一刻跑（memo 块执行时、下课以后、首页、云端），是几毫秒的纯函数，不在调用 Claude 的路上，不往发给 Claude 的说明里加东西（只在下一节开课的资料包里多一行）。

## 第 3 步：回头复查和调度（`kit/src/memory/sentry.js`，纯函数）

- **复查**：每次首页自检后跑。按「这条结论说的是哪几块、哪几种错」去看它之后的证据，被推翻的标 `guard.stale`，进待重判的清单（重判交给下一次本来就有的下课整理、复盘，不单独调用）。
- **调度**：算出工作单 `meta/workorder`：没收尾的课、待重判的结论、到期却没有新题的复现组、薄弱点、明天大概上哪块要备课；每项写来源、为什么、预计花多少。首页「管理 → 后方」能看。教研室按它干活，不自己挑。

## 分步

1. **只记不拦地量**（`tools/guard-audit.mjs`）：拿真实学习台的全部数据（6 节课、153 道错题、37 个弱点、47 条观察、84 条失误、12 条守则、21 个复现组、2 份复盘），把已经写进去的每一条当成候选重跑一遍守卫，看会拒哪些、提醒哪些、是不是冤枉，调准规则。
2. **接上入口、开始真拦**：memo 块和下课整理单（`memops.js` 的 `applyMemo`）、首页后台的复盘（`fixDebriefs`）和归类（`fixSkills`）、备课（`planview.js`）；审计日志、暂存、`carry`；管理页「守卫」一段。e2e 加一段：故意写一条编原话的、一条重复的、一条越权的。
3. **复查和调度**。
4. （另起）云端教研室，输出走守卫。
