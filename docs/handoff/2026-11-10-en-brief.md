## 背景

课在「舞台」上上（`kit/src/stage/`）：老师（Claude）每一轮写几行镜头指令，页面画、动、让学生直接上手、算事实、判对错，把学生做了什么整理好发回给老师。句子（`types/sentence.js`、`sentence.rules.js`）已经能拆成分、折、挪、拉线，照老师给的 `key=` / `links=` 判。**缺的是词形和时态**：页面不知道动词有几种形式，不会照「时间 × 状态 × 主语」拼出谓语；`{式子}` 只算数，句子里的词、贴的字、话都跟不了拨盘；老师想让学生拨时态，只能一种状态写一个挑战、做到时整句 `rewrite`，学生拨回去以后句子和拨盘就对不上了。用户在学考研英语语法（眼下是时态：一般过去、进行、完成；后面是非谓语 doing / done / to do）。

## 原则（不许违反）

- 页面不做教学决定；事实以页面算的为准；不说假话（认不准就不说）；不静默失效（老师写错当场报，报的话要让老师照着改得对）。预写只收做对 / 做完，没有 `.wrong`。
- **页面照旧不自己分析任意英语句子**（成分还是照老师的 `key=`）。这一轮加的是机械的词形：一个动词的几种形式、照指定的时间 / 状态 / 语态 / 主语的人称和数拼出谓语。主语是几个词的名词词组时，单复数由老师写明，页面不猜；代词（I you he she it we they）页面认得。
- 旧课照 log 放回要和以前一样（重放的行带 lenient，新规矩只管新写的行）。没用新写法的句子行为一字不变。
- iPad：触控目标 44px，输入框 16px。不用 confirm / alert / prompt。纯函数配 `node --test`。

## 要做的

**1. 动词词形的纯函数 `kit/src/enverb.js`**（配 `tests/enverb.test.js`，测试要多）：
- 一个动词的五种形式（原形、三单、过去式、过去分词、现在分词）：规则变化的拼写（双写、去 e、y 变 i、加 es、ie 变 y）加一张不规则动词表（考研常见的要全：be / have / do、go、write、take、begin、rise、lie / lay……至少 150 个），be 的人称变化（am / is / are / was / were）。
- 照「时间（过去 / 现在 / 将来 / 过去将来）× 状态（一般 / 进行 / 完成 / 完成进行）× 语态（主动 / 被动）× 主语的人称和数」拼出谓语的几个词（has been laughing、was being written、will have gone）；否定和疑问这一轮不做。
- 非谓语的几种形：to do、to be done、to have done、doing、being done、having done、done。
- 反过来读：给一串词（has been laughing），认出是哪个动词的哪种时间 × 状态 × 语态；认不出、有两种读法（read、put 这类原形和过去式一样的）时说清楚或给 null。
- 每种形式的中文叫法照考研语法书（一般过去时、现在完成进行时、过去分词……）。

**2. 字跟着拨盘变（舞台的通用件）**：
- **能拨字的拨盘**：现在 `dial` 只有数。加一种拨的是几个词 / 几个选项的（写法你照现有 dial 的风格定，比如 `dial t = 过去 options="过去 现在 将来"`，或者另起一个指令名；学生拨它 / 点它）。它的值能写进 `{式子}`、挑战的条件（`when="t = 过去"`）、预写。
- **`{…}` 能算出字**：句子里（`sentence s = "He {…} at me."`）、贴的字、话、题卡里的 `{…}` 能是字的式子，跟着它用到的拨盘当场变。要有的函数（名字你定，说明里一行一个）：照拨盘拼谓语（动词、时间、状态、语态、主语）；非谓语的某种形；照拨盘的值从几个写好的词里挑一个（这是通用的，不只英语用）。
- 句子里的 `{…}` 一变，句子当场重排（照 `rewrite` 的画法：同样的词滑到新位置、新的淡进来），学生拉好的括号、老师的标记尽量跟着（跟不了的照实写进现状）。`key=` 里要能指这个会变的位置（它可能是 1～4 个词），页面照现在的词判；`s.3` 这种部件写法在词数变了以后指谁，要定清楚并写进说明。
- 主语也能是拨盘（He / They / The boys），谓语跟着主语的人称和数变（代词页面认；名词词组要老师标单复数，写法你定，没标又认不出时当场报）。
- 现状（发给老师的「舞台现在」）里写清每个会变的位置：现在是什么词、是哪种时间 × 状态（比如「s 的谓语 {…}：过去 × 完成 → had laughed（过去完成时）」）。学生拨的路照现有拨数的路写。

**3. 判学生写的词形**：`ask value … type=en` 的答案能写成跟着算的（`answer={…}`）；学生写错时，页面用「反过来读」认出学生写的是哪种形式，写给老师（「学生写的 has laughed 是现在完成时，要的是过去完成时 had laughed」）；认不出就只说对错。

**4. 顺手修 E1 那张「页面的毛病」单子里的两条**（先写会红的测试）：
- 提问以后句子被换过，学生点的词报成另一个编号（第 3 条，`stage.js` 里 ask tap 记的 slot）；
- 给中文句子写 key 报「[V …] 里面没有词」（第 4 条）：报错说清 key 只认英文的词，或者让中文也能写，你定。

**5. 给老师的说明**（`types/sentence.js` 的 `doc`、`doc.js` 共用那一段）：每条新写法一行，例子照抄能演（`tests/stage-doc.test.js` 守着）。「句子里留空位让学生填词：现在没有写法」那一行跟着改。长度硬上限：`STAGE_TEACH + stageDoc(科目)` 每门课 ≤ 24 KiB，英语现在约 18.3 KiB；能拨字的拨盘和「挑一个」是共用的写法，会加到每门课上，而操作系统、线代只剩约 1.9 KiB（如果前一个任务已经用掉一些会更少）——共用的那一行要极省，或者只在英语的那一节里写。量法：

## 不做

时间轴（小人、事件条）；能放字的表（图鉴）；把词拖进句子里的空位；否定、疑问、情态动词的各种搭配；页面自己判一句话是什么时态（只认老师写成 `{…}` 的那个位置和学生在 `ask value` 里写的那几个词）。
