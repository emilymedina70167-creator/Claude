# 真 iPad 走查清单

页面检查脚本（`tools/check-lesson.mjs`）和组件画廊（`tools/gallery.mjs`）在云端的 Chromium 里替我看过：写法错误、报错、冲出版面、叠字、五种风格。它们看不了的是**真机上的手感**：Apple Pencil、软键盘、从 Notability 粘贴、横竖屏转来转去、claude.ai 的 iPad App 里嵌着的样子。这份清单就是走这些。

怎么走：在 claude.ai 的 iPad App 里打开（Safari 里有不一样的，单独记）。每一条照着做，看到的和「应该」不一样就截个图，记下条目编号、横屏还是竖屏、用的哪个风格，发给 Claude。

## 0. 开始前

- [ ] 0.1 打开组件库（https://claude.ai/artifact/5ZUhFR5T5i1wMysQmthoAF），页面能出来、没有一整页红字。
- [ ] 0.2 记下版本：实时黑板或课堂的「⋯」菜单最下面写着「组件库 2026-10-xx」，和 `CLAUDE-PROJECT.md` 开头的版本号一样（引导模式的单元不显示版本）。

## 1. 引导模式（示范单元「矩阵乘向量」）

- [ ] 1.1 「热身」那题：点格子，**软键盘弹出来，页面不放大**（输入框 16px），输完点「检查」有对错。
- [ ] 1.2 「让 Ax 命中目标」：**手指拖** x 的点，跟手、不卡；**Apple Pencil 拖**也一样；拖的时候页面不跟着滚。
- [ ] 1.3 「两种算法，同一个结果」：两个滑块用手指拖得动，滑块的圆点够大（不会总是点不中）。
- [ ] 1.4 「你发现了什么？」：在文本框里打一段话，提交以后有批改（要联网，「问 Claude」）。
- [ ] 1.5 「练习」：点「换一题」能出新题；写错会标出哪一格。
- [ ] 1.6 做完一节才出现下一节；最后「复制学习记录」能粘贴到对话框里。

## 2. 写答案的几种输入框

在 `408-demo` 或者一节有这些题的课里试：

- [ ] 2.1 含 n 的式子（`formula: n`）：点输入框出现**符号小键盘**（不弹系统键盘）；**用 Apple Pencil 点进去**是系统的随手写，写 `3^(n-1)` 能认出来；上面的公式预览跟着变。
- [ ] 2.2 二进制 / 十六进制答案（`fadd`、`mul`、`bits` 的先猜）：写 `11.0101` 带不带小数点、括号都判对；系统键盘是数字的那种。
- [ ] 2.3 序列答案（遍历序列、出栈序列）：用空格、逗号隔开都认；写错时标出从第几个开始不对。
- [ ] 2.4 软键盘弹出时，正在写的输入框**不被键盘挡住**（横屏、竖屏各试一次）；收起键盘页面回到原位。

## 3. 演示组件（`408-demo.html`、`la-demo.html`）

- [ ] 3.1 「上一步 / 下一步 / 播放」按钮好点（≥ 44px），连点不会跳两步。
- [ ] 3.2 拖进度条：能拖到想去的那一步；有没答的「先猜」时停在那一步前面。
- [ ] 3.3 在图上点（`sort` 的枢轴落在哪、`tree` 下一个访问谁、`paging` 换出哪一页）：手指点得中，点错有提示。
- [ ] 3.4 按顺序点（`net` 的 BFS）：一个个点下去，点错一个时前面对的留着。
- [ ] 3.5 步与步之间的动画：结点、格子滑过去，不闪、不卡；转屏以后图重新排好。
- [ ] 3.6 自己填表（`mode: fill`，比如页面置换）：点格子能打字，「✓」格子点一下切换，「照抄」能抄上一列；填错标出第一处。
- [ ] 3.7 `trace` 的先猜（「执行完第 7 行，j 是多少」）：键盘弹出，答完接着走；代码那一栏能上下滑。
- [ ] 3.8 `code` 写代码题：框里打字**软键盘不收起**；下面那排符号点了直接插进去、键盘还在；Tab、回车自动缩进；「运行测试」有结果。
- [ ] 3.9 `elim` 的 `mode: do`（自己做行变换）：写 `r2 - 2r1` 这类，矩阵跟着变；撤销一步能用。
- [ ] 3.10 长页面（`408-demo` 整页）上下滑得顺，不会一卡一卡。

## 4. 板书（Apple Pencil）

- [ ] 4.1 打开板书（「⋯」或者左下角的笔），**用 Pencil 写字**不延迟、线条跟笔尖；手掌放在屏幕上不会画出线。
- [ ] 4.2 **手指在板书开着的时候还能滚动页面**（只有 Pencil 画线）。
- [ ] 4.3 橡皮、换颜色能用；笔的颜色在浅色风格（纸本、白板）里看得清。
- [ ] 4.4 转屏、滚动以后，写过的字还在原来那段内容旁边，没有错位。

## 5. 截图作答（粘贴图片）

- [ ] 5.1 **Notability 圈选 →「拷贝」**，回到页面在粘贴框里**长按 → 粘贴**：图出现在框里，能交上去（这条最容易坏：Notability 的粘贴不带文件，靠页面从插进来的图里取）。
- [ ] 5.2 系统截图（截完点缩略图「拷贝并删除」）粘贴：一样能出来。
- [ ] 5.3 透明底、浅色笔迹的图交上去以后，Claude 看到的是白底黑字（不会一片空白）。

## 6. 课堂模式（一节 `mode: class` 的课）

- [ ] 6.1 点「开始上课」，板顶出现老师说的话，后面标着核验过的模型。
- [ ] 6.2 底部输入框：点进去软键盘弹出，**输入框抬到键盘上面**；发送以后老师接着讲。
- [ ] 6.3 老师换新板时自动翻过去；翻回旧板看，「回到当前板」会闪。
- [ ] 6.4 在当前板上用 Pencil 写一笔，输入框空着也能发（发出去的是板书的图）。
- [ ] 6.5 一块板一屏放得下，不用上下滑（横屏、竖屏都看）；放不下时老师下一轮会知道。
- [ ] 6.6 板上有题很久没做，老师会轻轻问一句；「⋯」里能关掉这个提醒。
- [ ] 6.7 刷新页面以后，板、作答、板书标注都恢复。

## 7. 实时黑板（`mode: live`）

- [ ] 7.1 对话里的 Claude 写一段，黑板上几秒内出现；连接状态是「已连接」。
- [ ] 7.2 「交截图」：选一张图交上去，对话里的 Claude 说「好了」后能看到。

## 8. 横竖屏和风格

- [ ] 8.1 每种模式都转一次屏：没有横向滚动条，图和表重新排好，正在写的输入框没丢字。
- [ ] 8.2 五种风格（默认、墨绿黑板 `chalk`、纸本 `paper`、深蓝 `midnight`、白板 `white`）：字在白天的光线下都看得清；浅色风格里的黄色、粉色不发虚。
- [ ] 8.3 小字号的按钮、提示都是正文字体（不是手写体），一眼认得出。
