# 云端教研室（2026-11-05）

`docs/guard-plan.md` 的第 3 层：守卫管「写进来的对不对」、调度（`sentry.js`）管「后方该做什么」，教研室是做这些活的手。

## 我要的

学习台后方有一堆该做却没人做的活：直接下课、挂着没下课的课没有小结和整理单；复现组到期了题库里只有原题（原题不算复现通过）；弱点好久没测；下一节还没备课。这些都要 Claude 写——但不能挤在上课那条路上（不碰回话速度），也不该等我打开学习台时才在 iPad 上跑。教研室是**每天夜里在云端自己开一个会话**做这些活的 Claude，做完的东西照样过守卫，第二天我打开学习台时并进来。

## 怎么分工

- **学习台（页面）出单子**：首页每次自检后算工作单 `meta/workorder`，挑教研室能做的几种、每种几张（`lab.js` 的 `labPicks`、`LAB_CAPS`：补收尾 2、出新题 3、探题 2、备课每科 1），每张拼成一份**自带全部材料**的单子 `lab_brief/{种类-编号}`：
  - 补收尾：这节课的每一轮（`transcriptText`）、课后报告、课堂带的同一份记忆（`memoryDigest`）、下课时课堂 Claude 收到的同一份要求（`closingPrompt`，含没归纳的失误）；
  - 出新题 / 探题：这几块讲什么（课程地图）、挂着的错题原文（复现组看它挂的弱点上的错题）、题库里的原题、学生的情况、要用的组件的完整写法（`componentDoc`）；
  - 备课：首页「让 Claude 备课」发的那一份（`planview.js` 的 `prepInput`，同一个函数）。
  拼材料的函数都是学习台里本来就有的，教研室看到的和课堂、首页看到的是同一份东西；材料没变（`srcOf` 指纹）就不重拼，平时打开首页什么都不写。
- **教研室（云端）只做题**：定时任务开一个新会话（提示词在 `docs/lab-prompt.md`），用 ArtifactData 读 `lab_brief`、看上一次的回执 `lab_inbox_log`，一张张做（有命令行，每个数自己算一遍），回答写进 `lab_inbox/{单子-日期}`：`{ brief, key, kind, text, by: 'lab', model, at }`。它不用懂学习台的代码，不用仓库，除了 `lab_inbox` 什么都不写。
- **学习台收回答**（`labdesk.js`，一直订阅着收件箱）：先核单子还在、指纹对得上（`checkReply`，材料变了的作废），再用课堂同一套读法读：
  - 补收尾：小结（`parseOutput` 去掉 memo 块）过守卫（`author: lab`：引的原话对不上 → 先暂存成 held 的改动单）；整理单走 `memops.applyMemo({ author: 'lab' })`：新加的记成 `by: lab`、标 `backfill`，守卫照 lab 的规矩（对不上先暂存、不能改课堂和我写的话）；
  - 出新题：一道题一个组件，编号换成 `d-lab-{单子}-{第几题}`；先 `problemLint`（数学、408 手写数字答案又没有 let / `\calc` 的不收）、`twinOf`（和题库里几乎一样的不收），再在页面上藏着画一遍（写法错误、取数自检不过都不收），过了才进题库 `drills`（`src: lab`，挂 `review` / `weakness`）；
  - 备课：这一科这期间我自己备好了就不盖；否则 `planview.js` 的 `prepFinish` 写进资料包（`by: lab`），照常后台预演。
  每份回答写一条回执 `lab_inbox_log/{同一个编号}`（收了几条、暂存几条、哪几条没收和原因），删掉收件箱那条；做完的单子撤掉。管理页「后方的工作单」里能看教研室等着做的单子、最近交回来的几份。
- **不多花额度**：学习台这边不调用 Claude；教研室一晚一个会话，没单子就直接结束。

## 安全线

- 我课后的学习内容不变成机械提取：教研室写的是 Claude 读完整节课写的话，学习台一个字不改，只决定收不收。
- 上课不变慢：教研室在云端、夜里；学习台这边拼单子、收回答都在首页，不在调用 Claude 的路上，不往课堂的说明里加东西。
- 写进去的都能撤：整理单走改动单（「管理」里能撤销），暂存的在「管理 → 自检 → 守卫」里放行或不要。

## 工具

- `node tools/lab.mjs briefs <存数据的目录>`：照真数据拼单子（不含备课），存成 JSON，能直接 `ArtifactData batch` 写进 `lab_brief`（学习台没打开过、想先让教研室做一晚时用）。
- `node tools/lab.mjs check <存数据的目录> <回答的目录>`：教研室交回来的回答按学习台并进来的同一条路先走一遍（替身数据库装上真数据），看会收、暂存、拒哪些。
- e2e 的 `lab` 一段：模拟教研室交补收尾（一条对得上、一条编原话）、出新题（一道好的、一道写坏的）、备课、一份对不上单子的，看收下 / 暂存 / 不收、回执、做完的单子撤掉。
