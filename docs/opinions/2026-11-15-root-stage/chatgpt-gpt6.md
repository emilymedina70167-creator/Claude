# ChatGPT（GPT-6）对第十二轮「教学回到根」的独立评审

**写的人：ChatGPT（OpenAI GPT-6），不是 Claude。** 我没有参与这座学习台的开发，也没有亲自作为学生完整体验课堂。以下判断基于仓库的第十二轮设计、舞台代码、历轮开发记录、教学评测，以及与使用者关于真实课堂体验的讨论。**这是外部评审意见，不代表 Claude 开发者的意见；设计意图和已实现效果必须分开。**

**对照设计**：`claude/friendly-ride-l2f31n` 分支的 `docs/superpowers/specs/2026-11-15-root-design.md` 和 `2026-11-15-root-rules-map.md`。

## 结论

**高度支持第十二轮纠正教学原则；有条件支持把连续黑板作为课堂底座；不赞成把“退出舞台唯一模式”理解为“让交互可视化退回到偶尔插入的辅助图”。**

我理解使用者最初的目标不是“画面替代文字”，而是**一位能够因材施教的一对一考研教师，拥有一个文字、公式、图形、解题过程都能在原处持续改变的实时工作空间**。学生可以在教师讲解尚未结束时随时介入，而不是只能读完一段文字再回答，或者被强制每走一步停下来交互。

旧黑板把“带着学”做成大段内容后验；舞台又把它做成“少说话、先动手、每轮提问”。这两者都是把有价值的教学要求固化成形式。第十二轮发现并拆掉这个根本错误，方向是对的。

## 我明确支持的部分

1. **Q1 终点、Q2 差距、Q3 动作**。让教师从考研目标与学生真实产出决定当下动作，而不是从固定课型决定动作。这比继续增加舞台指令更重要。尤其支持“一道题做对不等于掌握”。
2. **取消固定互动密度**。取消“先做后说”“每轮必须以 ask/挑战结束”“最多三句、每句四十字”，很必要。正确的一对一不是高频提问，而是**适时诊断、连续解释、随时打断、逐步交接到学生独立完成**。
3. **作答过程成为正式证据**。数学证明、推导、英语长难句分析、408 解题过程，不能被压成点选和拖动。支持 `work`、`board judge` 及对理由和具体断点的判断。
4. **以未见过的题验证迁移和延迟保持**。课堂看起来顺、学生操作成功、老师说懂了，都不足以证明真正学会。第十二轮终于把验证放到了学习结果上。
5. **原处改写、原处展开**。这比在底部另起长段更接近使用者最初的“文字也能变化”；支持留下修改前后的痕迹。

## 我的主要保留意见（按优先级）

### 1. “随时介入”不能只是一条提示词（最大缺口）

J11 写“学生随时叫停、改方向”，并不等于产品真的能在任何位置介入。需要验证至少四个行为：

- 教师正在逐字输出、播放板书或动画时，学生可以直接提问；后续内容不继续覆盖学生刚指的对象；
- 提问自动携带**学生所指的原句、公式步骤、当前图形状态**，不是把整份板书丢给教师让它猜；
- 教师能在原处解释、修改，再从适当位置继续，而不是重讲整节或跳过刚才的疑问；
- 用户正在手写、选择、阅读旧段时，不被自动滚动和新的输出抢走视线。

设计中的 `askhere` 与 `board expand` 是部分基础，但**尚不足以证明完整实时介入已经做成**。这一点应单独列入验收，而不只作为 J11 的一句话。

### 2. 别把“舞台不是课堂底座”变成“动态表达不再重要”

支持使用滚动黑板容纳长证明和完整推导：单屏不滚动确实与成段内容相冲突。但使用者并不是要求“回归以静态文字为主”。

理想的同一块板上，句子的主干可以被标注、替换，公式的条件改变可以驱动结果变化，矩阵可以操作，两个推导可以并排对照；文字、图、公式应该都是**可持续修改的教学对象**。第十二轮的 `patch`/`expand` 只覆盖一部分，`live` 被排在最后一批也有合理的开发成本考虑，但不应让教师重新形成“动态图只是偶尔插图”的偏好。

建议把 J7 表述为：**文字、公式、静态图、动态图和学生操作均为可选表达；教师按当前理解难点和效率选择，不强制使用，也不因文字方便而默认不用实时交互。**

### 3. 排版不能只验“不重叠”和“能滚动”

旧舞台第八至第十轮大量投入解决位置、缩放、重叠，却不等于排版真正符合教学。换成黑板能降低单屏拥挤，但仍可能出现重点被淹没、前提和结论相隔太远、对照对象无法同时看到、证明层级不清晰。

我建议教师只负责**教学语义**：什么是重点、哪些要对照、哪些需要长驻、哪些可折叠；布局引擎负责坐标、字号、断行和避让。以教师指定的教学意图是否真正呈现、学生是否能定位关键依据来评价，而不是让 Opus 兼职反复搬坐标。

### 4. 要防止从“频繁打断”反弹到“大段文字后再问”

J1 的“讲就讲完整”是对的，但不是“讲到一个完整小节才让学生参与”。教学中的“完整意思”大小应随概念、学生表现变化。

应按**实际分钟和有效学生产出**测量，而不是按模型轮数：开课到首次实质参与的时间；最长连续被动接收时间；没有获得新信息的停顿次数；自主提问被接住的比例；学生首次独立解题的时间。既不奖励“每十秒互动”，也不奖励“连续说完很多字”。

设计对比的“旧黑板约 245 字/分钟、舞台约 45 字/分钟”来自不同内容的两节课，只能说明表达密度差异，**不能当作哪种课堂更会教的证据**。

### 5. 教师判 + 第二个模型复判仍可能一起判错

两个模型一致不必然代表数学上正确。尤其是开放证明、等价变形、英语解释，应尽可能结合可计算部分的规则校验、参考解法、多种合法解法，以及带出处的复核；无法核实的标“待核”，不因一致就自动提升掌握。

课后新题检验也不能只看总正确率：要区分课堂中见过的同构题、真正迁移题、隔日保持和隔数日保持。

## 我建议对第十二轮做的三项调整

1. **第一批同时加入最小的学习效果闭环**：一份短课目标、独立作答证据、至少一道未见过的延迟检验；不必等所有首页、复核和自动出题系统完成后才开始验证。否则“根本规则改好了吗”只能靠主观印象。
2. **单列“实时介入与活内容”验收场景**：线性代数证明中途指向第二步追问；英语长难句原句被改写后保留主干标记；408 算法过程改一个条件，图、数字与解释一致更新。测试应覆盖生成中打断、原处补讲、继续讲、草稿不丢，而不是仅检查按钮存在。
3. **将教法 A/B 评价和界面 A/B 评价分开**：先在尽可能相同内容和学生基础下比较旧规则、新规则，再比较原黑板与可嵌互动黑板。否则同时换规则、记忆库和界面，效果改善或退化都难归因。模拟课是行为测试，真实的延迟独立作答才是学习结果证据。

## 一句话

**第十二轮最应该“回到根”的，不是黑板，也不是舞台，而是教师根据学生真实理解状态作判断的自由。** 保留舞台创造的实时操作能力，解除它对课堂形式的束缚；保留黑板承载完整推理的能力，解除它对学生被动阅读的束缚。不要第三次以一种固定形式替代另一种固定形式。

—— **ChatGPT（GPT-6），独立评审，2026-11-15**
