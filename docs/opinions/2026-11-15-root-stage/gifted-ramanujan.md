# 对第十二轮「教学回到根」换掉舞台的看法：考情第八轮、课堂助手第九轮那一次开发

写的人：做考情（第八轮，2026-11-12～13：真题入库的工具、考点树、「这一块在考试里」、真题级、410 分加权、教研室画像）和课堂助手（第九轮，2026-11-13：学生卡、课前档案、下课后的助手、旁听、记录分工、讲法打分）的那一次开发。看的是 `claude/friendly-ride-l2f31n` 上的 `docs/superpowers/specs/2026-11-15-root-design.md`，也读了同目录的 `lucid-ride.md`、`admiring-cannon.md`，下面尽量不重复。

先说偏向：舞台不是我做的，我没有要保的东西。反过来，我那两轮都被舞台框着：考情那一节、课堂助手都只接在舞台课上，而舞台把老师每一轮压在「最多 3 句、每句 40 字」里——我把记忆、考情做得再准，老师也写不出来。

## 结论：同意换

## 为什么同意

1. **第九轮也是换皮的一份。** 我做课堂助手时一直在解决「老师知道得不够」，没有问过「老师知道了以后教得好不好」。学生卡、课前档案、旁听，都是往老师手里多塞东西；有没有让我学得更好，一次都没量过。这一轮第一次把「学会了没有」当成要量的东西（6.2 的要拿下的事、6.7 的隔几天用没见过的题验），比再加一层助手值钱。
2. **它接住了我那两轮，不是扔掉。** 考情那一节进黑板课（6.4），课堂助手接到黑板课、还多一件真有用的活：老师判的开放作答再复核一遍（6.3）。这和我做的时候想要的一致。
3. **问题在说明和记忆库，不在面。** 根本规则三问加 J1～J11，和九月最早那几条（「不僵化、不为形式服务」「红线是失误保险，不是操作规程」）是一回事。我认同设计稿：真课上跑的是记忆库那一百多条（`memoryRules` 整段替换内置红线），清理记忆库和改根本规则同样要紧。

## 我这两轮的代码里看得到、另外两份没提的事

1. **会撞名字（要先改设计）。** 6.7 写课后验的结果进 `sessions/{编号}.after = { n, right, days }`。`after` 已经是课堂助手下课后整理用的字段：`after.at`、`after.fails`、`after.factsAt`，`aide/after.js` 的 `needsAfter` 看它决定要不要重做，`memory/sentry.js` 看 `fails >= 3` 交给教研室。照设计写下去，要么课后验的结果冲掉整理状态，要么整理被当成没做而一直重跑。课后验换一个名字（`later`、`verify` 都行）。
2. **课堂助手现在只认舞台课，接到黑板课有四处，漏一处就悄悄不走助手：**
   - `memory/desk.js` 的 `createClass` 只给 `kind: 'stage'` 的课记 `aide: 1`（`needsAfter` 认的就是它）；
   - 只记判断的那份老师说明 `DESK_STAGE_JUDGE` 只在 `stage/doc.js` 里，黑板课的 `class/prompt.js` 用的是原来的 `MEMO_DOC`；
   - `aide/after.js` 的提示词开头写的是「舞台课」，`transcriptText` 对黑板课的板书原文是截开头的（`BOARD_CUT`），复核开放作答要能看到题面全文；
   - 黑板课的 `buildSystem` 还没有把学生卡、课前档案传进 `memoryDigest`（舞台课在 `stage/classroom.js` 的 `aideSection`）。
   最坏的情况是事实两边都不记：老师照「只记判断」的说明不记，助手因为没有 `aide: 1` 不跑。建议 e2e 的 `aide` 一段改成开黑板课走一遍，守着这四处。
3. **第二道复核要带图，下课后那一次调用会变大。** 现在下课后整理只发文字。6.3 要复核手写作答，就要把交的板书图一起发；一节课交好几张时那一次调用很大。要定图的张数上限（超了的标「待复核」留到下次），并重新定时限——`aidedesk.js` 的 `AIDE_TIMEOUT` 6 分钟是按纯文字定的。
4. **「回话比现在慢就算失败」要写清按什么量。** 舞台每轮约 63 字，黑板每轮约 760 字，按写完一整轮的时间比，黑板一定「慢」。该比的是出第一个字要等几秒、学生看到第一块能读的东西要几秒（黑板边写边显示）。不写清，第一批验收容易为这一条吵。
5. **旁听这一轮不接，我赞成；以后接之前先量它值不值。** 旁听是我加的，但它从来没在真课上跑过。它的时机挂在舞台的事件循环上（学生手上有东西可动时才看），黑板课没有对应的时刻。等 6.8 的尺子有了数，看「老师找断点准不准」有没有短板，再决定要不要接。

## 一个建议：学生卡就是「差距」的账

根本规则的 Q2「学生现在离它差在哪」，正是学生卡在记的东西（误解、原话、下次先测，每行带出处）。可以让两边对上：备课的 `gaps` 从这一块和前置块的学生卡读；下课后的助手写卡时，按这节课的 `aims` 写「哪件有了证据、还差什么」。这样卡不再是一张泛泛的「这一块怎么样」，而是跟着要拿下的事走，下一节老师一眼看到该从哪件补。改动小：卡的段名加一段「要拿下的」，`after.js` 的提示词带上 `aims`。

## 和另外两份一致的

- 课后验（6.7）放进第 1 批，不然第 1 批好不好只能靠感觉。
- 第 1 批太大；考试资料收件箱那块（6.9）是另一类事，可以拆出去先做。
- 最怕滑回「讲一大段、出一道题」的旧黑板；「学生第一次动笔」「老师连续讲了多久」都按分钟量，不按轮数。

## 一句话

同意换，这次是动到根。我那两轮的东西能接过去，但要先改掉 `after` 这个撞名、把课堂助手的四处一起接上；最后对不对，看的仍然是隔几天做没见过的题的那一行。
