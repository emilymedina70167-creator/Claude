2026-11-16 写。接的是第十二轮的交接：那一份里「先等学生上一节真课」已经发生了，结论把方向改了。读完这一份和 `CLAUDE.md` 里「把 claude.ai 项目搬进学习台（第十三轮）」那一条就能接上。

## 一句话

学生要的是：**学习台 = claude.ai 项目 + 更强的呈现 + 后台的教学团队**。老师把内容讲透、学生来学，老师在分析学生的作答上多下功夫；不钉死老师怎么教。这一批做了两件事：记忆换成一份会重写的摘要（照 claude.ai），老师每一轮看得见板的截图。**已经发布。下一步是等学生上一节真课，读记录。**

## 学生定的做法（不要再问、不要改）

1. 每批发布以后停下来等学生上一节真课，上完先读那节课的记录，再定下一步。
2. 你自己一件一件做，不拆给一群助手；不跑模拟课（学生说了才跑）。
3. 汇报要短，先说主线；一次别摆一堆问题（上一个对话一口气摆了十几个，学生说脑子快炸了）。
4. 合进 `main`、重新发布学习台不用问。
5. **不要限制老师**：往老师的说明、往记忆摘要里加任何一句话之前先问——这是事实、学生的原话，还是替学生推广出来的规矩？是规矩就不加。
6. 记忆这一块和以前的做法冲突时，以第十三轮的为准。
7. 数学一真题入库不要主动提。

## 那节真课说了什么（2026-11-16，英语黑板课，23 分钟）

数据在 `.superpowers/root-next/`（私人数据，不进 git；没有了就照下面「读真课」重新取）。

- 老师每分钟写 577 字，学生第 8 分钟才第一次动笔；讲完一节甩一组题（9 句每句写三样），学生两次叫停。
- 出第一个字平均 13 秒，开课那一轮 49 秒（教材 8 秒没读完，老师自己取了 5 次工具）。
- 14 轮里 4 轮只写了一条位置记录、对学生一个字没说。
- 「要拿下的事」一节课被老师整份换了 3 次（讲到下一节就换），最后剩的是只讲了一块板的被动语态。
- 做得好的：学生做错以后找断在哪找得准、只补那一处。

找到的三个原因：老师看不见自己写的板；板的样子被记忆里的规则定成了模板；学生随口的建议被记成永久的规矩、优先级还最高。这一批对着这三个做的。

## 你的第一件事：读学生的下一节真课

1. 开工先读学习台的 `meta/errors`、`meta/health`。
2. `ArtifactData list`（带 `out_dir`，放 `.superpowers/` 下面）：`sessions`、`summary`、那节课的 `sessions/{课号}/class_turns`、`evidence`（按 `session` 查）。
3. `node tools/lesson-audit.mjs <那个目录>`。数先核再说（「产出花了多少分钟」那一项修过了）。
4. **读老师每一轮写的原文**，看这几件：
   - 板的样子变没变：还是不是每块板一个模板？重点突不突出？有没有因为看见了图而改上一轮排坏的地方（`replace`）？把那节课的板照 `tools/check-lesson.mjs` 放回页面截图自己看（上一个对话的做法：把 `class_turns` 拼成 `.class.json`，`theme: ink`）。
   - 每一轮 `cost.img` 有没有（带没带板的图）、`cost.eyeMs` 多大（iPad 上拍一次多久）、出第一个字是不是比 13 秒慢了。
   - 老师写没写 `know`、写的是不是「这一次的事实」；有没有照老习惯写 `ask`。
   - 还是不是甩一大段再测一堆；学生有没有叫停。
5. **读重写出来的摘要**（`summary/{科}` 的 `text` 和 `history`）：有没有丢事实、有没有把一句话推广成规矩、有没有流水账。不对就改 `summary.js` 的 `rewritePrompt`。
6. 把看到的告诉学生（短），再和学生定下一步。

## 上一个对话踩过的坑

- 估字节别按字数估：汉字 3 字节。
- 后台跑 `npm run e2e`（十来分钟）的时候不要 `npm run build`：它读的就是构建产物。
- 模拟老师看到调用带图就回「图收到了」：板的图不算学生附的图（`devteacher.js` 的 `eyeImages`）。

- 课堂页的 `.class-stage` 跟着整页滚，它的高就是整块板的高，不是一屏。
