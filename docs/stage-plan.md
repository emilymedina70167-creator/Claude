# 舞台：用画面讲课的一对一

2026-11-05 我看了一问一答的真课（希尔排序），说离预想差很多。问题出在三处：
- 图是摆设，老师从头到尾在写字（「位置：1:49 2:38…」「从第 1 位往后跳 5 格，到第 6 位」）；
- 我只能填空；
- 概念还是一点点摆出来的。

「一问一答」也不是核心，它只是这种教法带来的样子。

**我要的**：像一个会停下来等我的科普视频。
- 视觉交互是教学的主力：老师对图做事（跳格、连线、染色、出列、交换、播一趟），话和字也是画面里的东西，能贴到图上、能改、能飞过去。
- 讲到关键处停下来，等我在画面上动手（点、拖、排、拨）。看我怎么做，再决定下一个镜头怎么拍。
- 要做题也把题拿到同一个画面里。

**为什么黑板要换成舞台。** 黑板是一页往下长的文档，组件是嵌在里面的一张张小图，老师碰不到图里面的东西，最后只能写字。舞台是一个一直在的场景：
- 东西有名字，老师随时能操作；
- 镜头移到讲的地方；
- 画面质量由引擎保证。这像游戏不像 CG：不能提前做好，只能实时渲染，所以动作曲线、布局、镜头都在引擎里。

## 技术路线

都是浏览器自带的 SVG / HTML + Web Animations，打包进 la-kit.js，不从外面加载。

| 层 | 文件 | 做什么 |
|---|---|---|
| 动作 | `kit/src/stage/motion.js`（纯函数） | 动作曲线 `EASE`、弧线 `arcPoints` / `arcPath`、时长 `moveDuration`、错开 `stagger`、出字 `revealDelays`、留读的时间 `readHold` |
| 排版和镜头 | `kit/src/stage/layout.js`（纯函数） | 一排格子 `rowSlots`、镜头 `fitCamera`（竖着空时往上提，话贴在图上方）、贴字 `placeLabel`（先试上面，压着东西就往外让）、按「隔 d 个」分组 `strideGroups` |
| 镜头指令 | `kit/src/stage/script.js`（纯函数） | 一行一个动作：`parseScript`，部件 `parseRef`（`a`、`a.3`、`a.2-5`、`a#8` 跟着走的那一个），话里的 `parseRich`（`{a.2}` 图上的东西、`{d}` 拨的数、`$d$` 字母、`[词]` 能飞走） |
| 舞台 | `kit/src/stage/stage.js` + `stage.css` | 场景、镜头、话（一个字一个字写出来，`{a.2}` 画成和图上同色的小块）、贴着的字、连线、拨数、等学生点 / 拖 / 接着；一排格子 `ArrayObj`（跳格、交换走弧线、分组染色、出列成几排、合回去） |

### 镜头指令（A 段的写法，B 段让 Opus 写之前再定）

```
array a = 49 38 65 97 76 13 27 49′ 55 04
say "从 {a.1} 往后数 5 个，落在 {a.6}。它俩算一组。"
glow a.1 a.8 / unglow
lift a.2 / drop
hop a.1 -> a.6 color=g1 label="隔 5 个"
link a.2 a.7 g2 / unlink a
paint a.2 a.7 g2 / unpaint
& paint …                  行首 & ：和上一行一起演
dial d = 5 range=1-5 at=a  能拨的数
group a stride=d           按拨的数分组（拨了跟着重新分）
set d 5
split a / merge a          每组下到自己的一排 / 合回去
swap a#3 a#8
label flip a#1 a#8 "一样大，先后却换了" side=below tone=note
retext n "…" / unlabel n
fly say.1 -> key a#8 a#1   话里的 [词] 飞到图上
camera a / camera a.1-7 / camera all
ask tap a "…" / ask tap a#1 a#8 / ask drag a#1 a#6 / ask next "…" button="接着"
wait 600
```

## 分四段，每段我在 iPad 上看过才往下走

- **A. 引擎骨架 + 剧本演示**（做完了，等我看）：舞台、镜头、格子、字、连线、拨数、点和拖，希尔排序那一段按剧本演，不调用 Claude。
  - 样子页 `proto/stage/`：`demo.js` 是剧本，一轮一轮写成镜头指令。
  - `node proto/stage/build.mjs` 打包到 `proto/stage/dist/`，`index.html` 用来发布，`local.html` 用来本地看。
  - 发布成单独的 artifact，带 `stage-demo.js`。
  - 地址带 `?dev&blank` 是一块空舞台，检查脚本往上写镜头用。
  - 验的是画面讲解的感觉。
- **B. Opus 当导演**：定下镜头写法；边写边演；写错了退回重写（照一问一答的那一套）；舞台现状报给老师。在测试页上让 Opus 实时拍希尔排序和另一个内容，量第一个镜头多久出来、拍得好不好。不过关先改引擎和说明，不往下做。
- **C. 补齐对象**：树、图、矩阵行变换、向量平面、句子；公式一项一项变形（同名项滑过去）；题目上舞台（用现有的判分）。算步骤用现有的演示组件（`engines/`），舞台负责演。
- **D. 接进学习台**：作为新的上课方式替换一问一答的活板，接记忆、教材、证据、刷新放回、e2e。黑板课一直能用。
