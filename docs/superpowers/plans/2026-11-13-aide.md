# 第九轮：课堂助手 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 舞台课的老师身边多几个助手（同一个 Opus 5.5）：学生卡 + 课前档案替换按编号挑的记忆、上课时旁听、下课后对着整节课写事实，讲法按学生下一次的表现打分。

**Architecture:** 新目录 `kit/src/aide/`：判断全在纯函数里（卡、档案、下课后、旁听、讲法），数据库和调用只在 `aidedesk.js`（首页）、`watcher.js`（课上）两处。卡和档案是派生的一层，照考试资料的做法另立集合、按需读；写进记忆的事实走现有的 `applyMemo` + 守卫，作者 `aide`。所有调用 `lane: 'bg'`（开课那一份档案除外），出错、超时、不是 Opus 一律不用结果、课照常。

**Tech Stack:** 原生 ES 模块、`node --test`、esbuild 打包（`npm run build`）、Playwright e2e（`npm run e2e`）。

**Spec:** `docs/superpowers/specs/2026-11-13-aide-design.md`（第 9 节是审查后定的六件事，和正文冲突时以第 9 节为准）

## Global Constraints

- 助手的模型 `claude-opus-5-5`，`modelApplied` 不是它整次作废；课前、课后 `effort: 'high'`，旁听先 `'high'`。讲课的 `TEACH` 不动。
- 除开课那一份档案外，助手的调用一律 `lane: 'bg'`（`kit/src/ai.js` 的 `laned`）。
- 老师每一轮的说明不变长：`STAGE_SYSTEM_MAX` 150 KiB、记忆那一节 ≤ 28 KiB 不变；`[助手看到的]` ≤ 1.5 KiB、最多 5 行；`DESK_STAGE` 字节数不许比现在多。
- 学生卡每张 ≤ 2 KiB（`CARD_MAX = 2048`），整张重写不追加；课前档案 ≤ 6 KiB（`BRIEF_MAX_BYTES = 6144`）。
- 每一行带出处；出处对不上的**不挂起**：事实那一条不收、卡和旁听那一行删掉，其余照收，记 `guard_log` / `meta/guard.counts`。
- 发给 Claude 的提示词里提到学生不用「他」「她」（每个新提示词的测试里断言）。
- 只接舞台课（`kind: stage`），而且只接这一轮上线以后开的课（`sessions` 上 `aide: 1`）；旧课的复盘、知识点归类照旧，版本号不升。
- 注释、界面文字、提交说明用中文；不用 `window.confirm/alert/prompt`；`la-kit.js` 自包含。
- 提交说明末尾两行：`Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`、`Claude-Session: https://claude.ai/code/session_014f77bFHL5Go3Bnv2G9mHdw`。

## Review Focus

1. 课前档案是给别的块写的、依据的卡变了、这节课中途改了块 → 不带档案，退回代码挑的那一套（T5、T9 的测试）。
2. 助手的调用抛错、超时、回的不是 Opus、回的格式看不懂 → 结果不用、不写，课照常，下次再做（T8、T13 的测试）。
3. 助手引了不存在的轮次、编号、原话 → 那一行 / 那一条丢掉、不挂起，其余照收（T2、T3、T12 的测试）。
4. 卡写超 2 KiB、或者把旧卡原样贴一遍再加几行 → 新卡不收、旧卡留着（T2 的测试）。
5. 学生事件来了、旁听还在跑 → 老师马上叫、不等；旁听的结果晚于两轮就扔；提前想在跑时旁听不开（T12、T13 的测试）。
