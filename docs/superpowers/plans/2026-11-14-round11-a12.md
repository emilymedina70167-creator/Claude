# 第十一轮 A1 + A2：账记准（话的账、我的要求、当场生效）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 我在课上打的每一句话都有去处；要求、纠正、期望单独记成「我的要求」（`asks`），原话由页面抄、删课不丢；课上说的从下一次调用起就钉在老师的说明里。

**Architecture:** 判断全在纯函数里（`memory/said.js`：拼提示词、读回、核对、算出要写什么），数据库那一层在 `memory/saiddesk.js`（首页给有新话的课过账、课上隔 20 秒过账、删课前过账），写进去走 `memops.js` 和守卫（作者 `said`）。说明里「学生的要求」由 `digest.js` 每次调用重拼。尺子 `tools/memory-ruler.mjs` 用页面同一套函数重放 8 节真课。

**Tech Stack:** 纯 JS（ES 模块）、`node --test`、esbuild 打包（`npm run build`）、Playwright e2e（`npm run e2e`）。

**Spec:** `docs/superpowers/specs/2026-11-14-round11-design.md`（第六节 6.0–6.3、6.6，第九节，第十节 A1、A2，第十二节）

之后的几份计划（各自另写）：B1 总 Claude 第一版（先给我看样子）、A3 + A4（记忆放大、守没守、「你说过的」）、B2 总教练、C1 408 坑表（开发这边的资料活，不改页面代码，可以和这一份同时做）。

## Global Constraints

- 注释、界面文字、提交说明用中文；注释写「为什么」。
- 话的账、助手的调用只认 Opus 5.5（`modelApplied === 'claude-opus-5-5'`，不是就当没回、不写），一律 `lane: 'bg'`；effort 先 `medium`。
- 讲课的老师只能是 Opus 5.5 high，不碰它的调用、不让它等任何后台调用。
- 发给 Claude 的提示词里提到学生不用「他」「她」（`tests/` 里有测试守着，新提示词也要过）。
- 不用 `window.confirm / alert / prompt`；要问用 `kit/src/dialog.js`。
- 不加任何「要我确认」的东西。
- 原话一律由页面从 `evidence` 抄（`text` 字段），不让 Claude 重打。
- 一句 = 一条 `src: 'say'` 的证据；一条可以有几个去处。只有图（`kind: 'photo'`、或文字只剩「（在画面上用 Pencil 写了字）」「（附了 N 张图）」这种页面加的尾巴）的不调用，记 `图，没读`。
- 数据库总共 25000 条文档：话的账每节课一份 `sessions/{编号}/said/main`，不一句一条。
- 改了 `kit/src/` 要 `npm run build` 并提交 `kit/dist/`；合进 main 之前 `npm test`、`npm run e2e` 全过，舞台改动跑 `npm run check:stage`。

## Review Focus

1. 20 秒内连打两句：只过一次账，两句都在；第一次还在跑时又打了一句，跑完再跑一次补上（不丢、不重）。
2. 过账跑到一半整页刷新（我点进别的课、回首页）：水位线没前进，下次照样过这几句，不会重复建两条一样的要求。
3. 一条消息既有打的字又带「（在画面上用 Pencil 写了字）」尾巴：照文字那部分过账，不当成只有图。
4. 回的不是 Opus、超时、回答看不懂：什么都不写、水位线不动；首页试满 2 次交教研室。
5. 删一节还没过账的课、过账又失败：这节课 `src: say` 的证据留着（`keptWords`），别的照删；`asks` 一条不少。
