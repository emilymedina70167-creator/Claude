# 舞台主线第十轮：交给学生之前，老师先看一眼自己摆的画面

> 执行：我在这个会话里自己做（inline），一项一项 TDD；做完整条分支一次审查，再合、再发。
> 设计和计划写在一处（这一轮小而深：一个闭环，五样东西）。

## 0. 为什么有这一轮（2026-11-14 情态那一节真课）

我在 26 轮里说了五次排版（「你先优化好你的交互」「我的天，你这是什么排版」「让你做到排版不重叠……有那么难吗」「你重叠这件事情要犯几次？」）。
老师每次都认错、记了三条失误、一条偏好「画面上任何两样东西都不能重叠」，下一轮照样压着。

查下来（`evals/stage-sight/modal-lesson.txt`：那节课老师的每一轮原样，按我那台 iPad 当时的屏幕 1180×734 重演）：

1. **不是记性**：Claude 每一轮读整节课的对话，它记得，也想改。
2. **它看不到自己这一轮摆出来的样子**：一轮写完、页面画出来，学生先看到；它要等学生下一次动作，才看到这一轮的截图。每一次都是盲交。
3. **版面报告和屏幕对不上**：现状里的「版面 / 压着」用的是排版时分给每样东西的格子，不是画出来的样子（后来加的那一问、字变大以后长高的卡都不重量）。第 24、26 轮屏幕上压着，报告写「没压着」；老师照说明「看版面报告」，信了。
4. **放不下时页面照画、叠在一起**（这一回的屏幕比试验时矮：Safari 的地址栏占掉一截），只在报告里一句「还是挤」。

真实测量（`tools/stage-measure.mjs`，量每个节点在屏幕上真画在哪）在重演里把我说过的每一个画面都量出来了：第 7 轮 g 压着 a、话压着 c；第 18 轮 k 压着 q；第 24 轮 q 压着 tl；第 26 轮 q 压着 tl、r 压着 p。这把尺子一直只在测试工具里用，课堂里没有。

## 1. 质变在哪

以前：老师写 → 学生看到 → （下一次学生动了）老师才看到。
这一轮：老师写 → **页面量真实的样子** → 没问题交给学生；有问题**盖一层「老师在调画面」，把截图和量到的问题马上交回给同一个老师改**，改好才揭开 → 学生看到的永远是老师看过、没压着的画面。

放在哪、多大、留什么、拿掉什么都还是老师定（第九轮「画面归老师」不退）；页面只做两件事：**量得准**、**没量过不交给学生**。

不做的：
- 页面不替老师挪东西、不分块、不自己重排（那就回到了老路）。
- 不在每一轮都多叫一次老师：画面没问题时一次都不多叫，只多一次量（几十毫秒）。

## 2. 五样东西

### A. 真实测量进课堂：`kit/src/stage/sight.js`

- 把 `tools/stage-measure.mjs` 的 `measure` 搬进组件库，变成两半：
  - `collectSight(stage)`（碰 DOM）：每样东西、贴的字、拨盘、话的每一行（包括这一问那一行）、挑战、底下那一条、页面自己的按钮（说过的、撤一步、Pencil 那一条）在屏幕上真画在哪。
  - `sightIssues(items, view)`（纯函数，`node --test`）：两两比「压着」（同一样东西的部件、同一处的几行话不算；系在一起的东西不算），「出了屏幕」，「字太小」。结果用老师认得的名字：`q`、`话`、`这一问`、`拨盘 m`、`贴的字 lm`、`挑战`、`底下的输入框`、`页面的按钮「说过的」`。
- `stage.sight()` 返回 `{ issues, must }`（`must`：压着、出了屏幕；字太小只提醒）。
- 工具也用这一份：`tools/stage-measure.mjs` 改成在页面里调 `window.LAStage.sight()`（以前那份复制品删掉：尺子只有一把）。

### B. 现状里的「版面」照真的写

- `compose/report.js` 的 `layoutLines` 改吃量出来的框：「版面」那一行每样东西占哪几格是**画出来的**范围；「压着」「出了屏幕」直接是 `sight` 的结果。
- 排版时用的格子照旧给求解器用，不再写给老师。截图和文字说的是同一个画面。

### C. 交卷前自查（核心）：`kit/src/stage/loop.js`

- 老师一轮演完（`turn.armed`）、动画停下（`stage.settled()`）以后，`stage.sight()`。
- `must` 为空：照旧交给学生（和现在一样快）。
- `must` 不空、这一轮自查次数 < `SIGHT_MAX`（2）：
  1. 舞台盖一层「老师在调画面」（毛玻璃 + 三个点，挡住点和拖，`stage.veil(true)`）。
  2. 记一条事件 `{ kind: 'sight', now: true, text }`，马上叫老师（`events.js` 的 `triggers` 认它）。截图本来就跟着每一条走（`eyeFor`），是这一刻、量过的这张。
  3. 发给老师的那一段（`events.js` 写成文字）：
     `[画面自查] 你这一轮摆完、交给学生之前，页面量了屏幕（附的图就是现在，学生还没看到）：q 压着 tl（重叠 120×40）；…。只改画面：挪（place / at=）、缩小（look text= / scale）、拿掉用完的（remove）、或者换一幕（scene）。这一问不用重写（还挂着）；不要说话。`
  4. 老师这一轮（改画面的一轮）演完再量；干净了揭开；还有问题再给一次；`SIGHT_MAX` 次还不行就揭开，现状里照实写「还压着：…」，不卡住课。
- 改画面的那一轮：花费记 `why: 'sight'`；不算学生的一问（`scene.waiting` 留着上一问，老师不重写）；说了话照演（不拦，但说明里写不要说）。
- 提前想（spec）、旁听在盖着的时候不跑；学生在盖着的时候点、打字都挡住（输入框也在盖层下面）。
- 只读回看、练一练里嵌的舞台（没有老师）不自查。

### D. 少出问题（让 C 少叫）

- 一轮演完，话那一块（这一问加在后面、长高了）、挑战那一块按量出来的高重排一次没钉住的东西（`composeOnce` 收尾再跑一遍；钉住的照旧不挪，压着交给 C）。
- 页面右上角「说过的」按钮在窄处折成竖排（截图里）：不折行。

### E. 老师的说明（`doc.js`，每门课 ≤ 24576 字节，数据结构只剩 111：先压别的）

- 「画面」那一节改：去掉「先看版面报告」的意思（报告不再是它的事）；加一句「交给学生之前页面会量；压着、出了屏幕就把图交回给你改，只改画面」。
- 加几条排版的依据（研究里稳的几条，老师当场判断用不用）：正在讲的最大、放在视线中间；从上往下就是看和想的顺序；有关系的放在一起（例句和它的对照、题和要用的规则）；一屏只留现在要用的，用完就拿掉；放不下就换一幕，不要缩字硬塞。

## 3. 尺子（这一轮做没做到，用这几个量）

1. **量得到**：`node tools/stage-sight.mjs evals/stage-sight`（新工具，跑 stage-try 的同一套演法）：真课重演在我的屏幕（1180×734）上，第 7、18、24、26 轮演完的那一刻 `sight` 都要报「压着」，报的那几对和截图上一样；现状里的「版面 / 压着」和 `sight` 一致。
2. **交不出去**：同一份重演，老师那几段后面接上文件里写好的「改画面」段（stage-try 叫老师时交下一段），学生那边**每一次**拿到手的画面都没有压着：试演工具在学生每一个动作之前量一遍，`must` 必须为空。
3. **真老师改得好**：`evals/stage-sight/cases.json`：真课的 5 个坏画面 + 第九轮尺子里压着的几个（共 ≥ 8 个），每个交给一个扮老师的 Opus（整份舞台说明 + 自查那一段 + 截图），把它写的一轮演上去再量：两次以内干净的 ≥ 90%，而且该留的东西还在（那一问还挂着、正在讲的那样还在台上）。我看每一张前后截图。
4. **不变慢**：没压着的轮不多叫（单元测试：`must` 空时不加事件）；`sight()` 在 iPad 尺寸下一次 < 30 毫秒（试演里量）。
5. **整条流程**：e2e 的 stage 段加一节：模拟老师写一个压着的画面 → 盖上 → 模拟老师改 → 揭开 → 学生手上的画面量过没压着；花费里有一条 `why: 'sight'`。
6. 回归：`npm test`、`npm run check:stage`、`stage-must` 七张表、`npm run e2e`。

## 4. 做的顺序

1. `sight.js`（纯函数 + DOM 那一半）+ 单元测试；工具改用它；重演跑出第 1 把尺子。
2. 版面报告照真的写（B）。
3. 自查闭环（C）+ 盖层 + 事件文字 + 单元测试；试演工具认「改画面」段；第 2 把尺子。
4. 收尾重排、按钮不折行（D）。
5. 说明（E），压字节。
6. 第 3 把尺子（扮老师的 Opus，看前后截图）；不到 90% 回去改说明或自查那一段的写法。
7. e2e、回归、CLAUDE.md、`docs/stage-mainline.md` 第十轮一节；合进 main、发布。

## 5. 我自己定的事

- **改的时候盖一层**（我建议、你没另选）：学生看不到压着的样子；代价是摆错的那一次多等一轮（6～10 秒）。一轮演的过程中（边写边演）东西是一行一行出来的，中途可能短暂叠一下；量和交卷看的是演完的那一刻。
- 自查最多两次：再不行揭开、照实告诉老师，不让课停住。
- 「字太小」只写进现状，不为它叫老师（不值一轮）。
