# 第十二轮第 0 批：尺子和资料到位（实施计划）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在动教法之前先把尺子做出来、跑出基线，并让考试资料真的到老师手里。

**Architecture:** 模拟课沿用 `tools/teach-sim.mjs`（一节课的「页面」），给它加上按学生用时算的钟、课后测验和学生笔记；新写一个用 `claude -p` 命令行自动跑整节课的脚本，取代人工轮流派子代理。真课的数另写一个只读本地文件的工具。考试资料这边修收件箱、把「这一块在考试里」接进黑板课的说明。

**Tech Stack:** Node 22 ESM（`.mjs` 工具、`node --test`），`claude` 命令行（已装，`claude -p --output-format json`），Playwright + Chromium（预装，e2e 用）。不加新的 npm 依赖。

**Spec:** `docs/superpowers/specs/2026-11-15-root-design.md`（第 6.8、6.9 节，第 7 节第 0 批）

## Global Constraints

- 注释、界面文字、提交说明、给模型的提示词都用简体中文；注释写「为什么」。
- 发给模型的提示词里提到学生不用「他」「她」（模拟学生、评卷人的提示词也一样）。
- 讲课的老师只用 `claude-opus-5-5`、effort high；不加退路模型（命令行不要写 `--fallback-model`）。
- 不用 `window.confirm` / `alert` / `prompt`。
- 私人数据（`.superpowers/` 下的真课、真规则）不进 git；进 git 的样例不带个人信息。
- 任务里不提交 `kit/dist/`：每个任务只提交源码和测试，产物由主控在推送前统一 `npm run build` 提交。
- 每个任务结束 `npm test` 全过（基线：2215 个，2214 过、1 跳过）。
- 能写成纯函数的放在不碰 DOM、不碰子进程的模块里，用 `node --test` 测。
- 黑板课每轮整份说明 ≤ 160 KiB（`SYSTEM_MAX`），教材原文至少留 32 KiB；不加工具。
- 模拟课一节多长按学生用掉的时间算：读每分钟 400 字，点或选一次 10 秒，写一行 30 秒，等老师每轮 8 秒，到 40 分钟下课。

## Review Focus

1. `claude -p` 返回空、超时、不是 JSON：跑课脚本重试一次，再不行把这节课标成失败并写明停在第几轮，不挂住、不把半节课当成一节算分。
2. 学生的回复不是合法 JSON：带着报错重问一次；还不行记成「学生没有作答」接着走。
3. `lesson-audit` 遇到没有证据的课、挂着没下课的课、没记花费的轮：不出 `NaN`，那一格写「没记」。
4. 收件箱里有一份不合规矩：写明是哪一份、为什么，别的照并；全并完以后首页那一行消失，不一直挂着。
5. `buildSystem` 同时带考情、最大的资料包、最大的记忆：整份 ≤ 160 KiB，教材原文不少于 32 KiB。

**Files:**
- Create: `tools/teach-sim-lib.mjs`
- Modify: `tools/teach-sim.mjs`（`init`、`teacher`、`student`、`score`，新命令 `posttest`）
- Test: `tests/teach-sim-lib.test.js`

**Interfaces:**
- Produces（`tools/teach-sim-lib.mjs`，都是纯函数）：
  - `COSTS = { readPerMin: 400, pick: 10, line: 30, lineChars: 30, sayPer10: 5, wait: 8 }`
  - `shownChars(text: string): number`：去掉空白以后的字数。
  - `isClosed(rec): boolean`：这次作答是点一下、选一个（`quiz` 有选项、`steps` 的选择步、演示组件的 `ask`）。`rec` 是 `teach-sim.mjs` 里 `judge()` 返回的记录；`judge()` 要给记录补一个 `closed: true|false`，本函数只读它。
  - `isProduce(rec): boolean`：`!rec.closed`、不是放弃、有写的内容（`value` 或 `text` 去空白后 ≥ 2 个字）。
  - `actSeconds(rec): number`：`closed` 是 `COSTS.pick`；否则 `ceil(字数 / lineChars) * line`，至少 `line`。
  - `newClock(): { s: 0, firstProduce: null, lastProduce: 0, longestPassive: 0, produce: 0, stops: 0, wasted: 0 }`
  - `tick(clock, { read = 0, wait = false, acts = [], say = '' }): clock`（返回新对象）：`s` 加上读（`read / readPerMin * 60`）、等（`wait` 时加 `COSTS.wait`）、每个作答的 `actSeconds`、说话（`ceil(字数/10) * sayPer10`）。每个作答 `stops + 1`；`closed && ok === true && attempts === 1` 的 `wasted + 1`。有 `isProduce` 的作答时：先用 `s - lastProduce`（做这次作答之前的那一段）更新 `longestPassive`，`firstProduce` 没有就记成这次作答开始的 `s`，`produce` 加这次作答的秒数，`lastProduce = s`。
  - `lessonMetrics(st): { minutes, teacherTurns, firstProduceMin, longestPassiveMin, produceMin, stops, wastedStops, charsPerMin }`：分钟保留一位小数；`firstProduceMin` 没有产出时是 `null`；`longestPassiveMin` 把最后一次产出到下课那一段也算进去。
  - `checkScenario(sc): string[]`：返回问题的列表。要求 `id`、`subject`、`pack`、`persona`、`know`（字符串）、`aims`（2～5 件，每件 `id`、`can`、`proof`）、`posttest`（3～5 道，每道 `id`、`q`、`answer`、`kind` 是 `near` 或 `far`、`aim` 指向存在的一件，至少一道 `far`）；`minutes` 不写按 40。
- `teach-sim.mjs` 的变化（下一个任务靠这些）：
  - `init <目录> <场景> [--system 文件] [--memory 文件] [--no-plan]`：先 `checkScenario`，有问题打印并 `exit 1`。`--system` 给了就原样抄成 `system.md`（基线那一版用）；`--memory` 是一份记忆样例 JSON（`{ rules, lessons, asks, … }`，每类是带 `id` 的数组），照课堂的写法传给 `buildSystem` 的 `memory`（看 `kit/src/class/classroom.js` 的 `memoryArg`，块用场景的 `block`，没有就空）。`state.json` 多 `clock: newClock()`、`minutes`、`over: false`。
  - `teacher`：这一轮新给学生看的字（新开、新加且没藏着、改写、揭开的段在学生视图里的字，加板顶的话）算进 `read`，再加一次等。到时间（`clock.s >= minutes * 60`）或老师已经写了 40 轮：`over = true`，最后一行打印 `到时间了`。
  - `student`：回复 JSON 多一个可选的 `note`（字符串），有就追加到 `<目录>/notebook.md`（一轮一段，前面写第几轮）。作答、说话算进钟。`over` 以后再调用直接报错退出。
  - `score`：每行多 `lessonMetrics` 的全部字段。
  - `posttest <目录>`：写 `posttest.md`（只有题号和题面）和 `posttest-key.md`（题号、答案、`kind`、对的是哪件事；只给评卷人）。

```js
import assert from 'node:assert/strict';

test('选一下 10 秒；一上来就选对算一次没产生信息的停，不算产出', () => {

  assert.deepEqual([c.s, c.stops, c.wasted, c.firstProduce], [10, 1, 1, null]);
```

### Task 2: 用命令行自动跑一节模拟课、一整套

**Files:**
- Create: `tools/teach-run-lib.mjs`、`tools/teach-run.mjs`、`tools/teach-suite.mjs`
- Test: `tests/teach-run-lib.test.js`
- Modify: `evals/teaching/README.md`（「跑一轮」换成新的跑法）

**Interfaces:**
- Consumes：Task 1 的 `teach-sim.mjs` 各命令（当子进程调用）、`posttest.md` / `posttest-key.md` / `notebook.md` / `transcript.md`、`score` 的 JSON。
- Produces（`tools/teach-run-lib.mjs`，纯函数）：
  - `cliArgs({ model, effort, systemFile, resume }): string[]`：`claude` 的参数。一定带 `-p`、`--output-format json`、`--model`；有 `effort` 带 `--effort`；第一轮带 `--system-prompt-file`，之后带 `--resume <session_id>`；关掉全部工具；不带 `--fallback-model`。
  - `studentSystem(sc): string`：扮学生的说明。包含 `sc.persona`、`sc.know`；规矩：只会设定里写着会的，别的要等这节课教了才会；误解前后一致、不主动说出来；每一轮只回一个 JSON（`say`、`acts`、`sure`、`note`）；`note` 只记这一轮老师真讲了、真让自己做了的，一两句，没有就空。
  - `posttestSystem(sc, notebook: string): string`：课后测验的学生。只给人设、原来会什么、这本笔记；规矩：只用这三样里有的，笔记里没有、原来也不会的就写「不会」，不许用别的知识。
  - `extractJson(text: string): object | null`：从模型的回复里取出 JSON（可能包着代码块、前后有话）。
  - `graderPrompt({ transcript, scenario, key, answers, metrics }): string`：评卷的说明，照设计 6.8 的几项，要求只回一个 JSON。
  - `parseGrade(text): { post: [{ id, score }], found: number|null, targeted: 1|2|3|null, onlyGap: boolean|null, contentErrors: number, verdictAgree: number|null, skipped: boolean|null, overall: 1|2|3|4|5, why: string } | null`：`post[].score` 只能是 0、0.5、1；`found` 是老师在第几分钟把设定的断点问出来（没问出来 `null`）；`skipped` 是学生已经会的内容老师有没有跳过（场景没有这一项时 `null`）。字段不对返回 `null`。
- 命令：
  - `node tools/teach-run.mjs <目录> <场景.json> [--system 文件] [--memory 文件] [--teacher claude-opus-5-5] [--student claude-sonnet-5-5] [--grader claude-opus-5-5] [--fake 目录]`：跑完一节，目录里留下每轮的 `t-N.txt`、`s-N.json`、`transcript.md`、`posttest-answers.md`、`metrics.json`、`grade.json`、`run.json`（成没成、停在第几轮、每次调用花了多少）。
  - `node tools/teach-suite.mjs <输出目录> --arm <名字> [--system-dir 目录] [--memory 文件] [--only a,b] [--parallel 3]`：对 `evals/teaching/scenarios/*.json` 每个跑一节（`--system-dir` 里有 `<场景 id>.system.md` 就用它），写 `<输出目录>/summary.json` 和 `summary.md`（一行一节：课后测验同类 / 迁移各对几道、用了几分钟、白停、第一次动笔第几分钟、最长连讲几分钟、产出几分钟、总体分）。

```js
import test from 'node:test';
import assert from 'node:assert/strict';
import { cliArgs, studentSystem, posttestSystem, extractJson, graderPrompt, parseGrade } from '../tools/teach-run-lib.mjs';

const sc = { id: 'x', persona: '大三，学过一点操作系统', know: '知道缺页是什么；不知道 LRU', aims: [{ id: 'a1', can: '手算 LRU', proof: '独立做一道' }], misconception: '以为换出最早进来的', rubric: 'r' };

test('第一轮带系统提示词文件，之后带 resume；不带退路模型', () => {
  const a = cliArgs({ model: 'claude-opus-5-5', effort: 'high', systemFile: '/t/system.md' });
  const b = cliArgs({ model: 'claude-opus-5-5', effort: 'high', resume: 'abc' });
  assert.ok(a.includes('-p') && a.includes('/t/system.md') && !a.includes('--resume'));
  assert.ok(b.includes('--resume') && b.includes('abc') && !b.includes('/t/system.md'));
  assert.ok(![...a, ...b].includes('--fallback-model'));
});
test('学生的说明带人设和会什么，提到学生不用他、她', () => {
  const s = studentSystem(sc);
  assert.ok(s.includes(sc.persona) && s.includes(sc.know) && s.includes('note'));
  assert.ok(!/[他她]/.test(s.replace(sc.persona, '').replace(sc.know, '')));
});
test('课后测验的学生只拿到人设、会什么、笔记', () => {
  const s = posttestSystem(sc, '第 3 轮：LRU 换最久没用的');
  assert.ok(s.includes('LRU 换最久没用的') && s.includes('不会'));
  assert.ok(!s.includes(sc.misconception) && !s.includes(sc.rubric));
});
test('从回复里取 JSON', () => {
  assert.deepEqual(extractJson('好的。\n```json\n{"say":"嗯","acts":[]}\n```\n'), { say: '嗯', acts: [] });
  assert.deepEqual(extractJson('{"a":{"b":1}} 多余的话'), { a: { b: 1 } });
  assert.equal(extractJson('没有 JSON'), null);
});
test('评卷的说明不透露是哪一版规则', () => {
  const p = graderPrompt({ transcript: 'T', scenario: sc, key: 'K', answers: 'A', metrics: { minutes: 30 } });
  assert.ok(p.includes('T') && p.includes('K') && p.includes('A') && p.includes(sc.misconception));
  assert.ok(!/基线|根本规则|baseline|charter/.test(p));
});
test('读评卷的结果；分数不在 0、0.5、1 里的不收', () => {
  const g = parseGrade('```json\n{"post":[{"id":"p1","score":1},{"id":"p2","score":0.5}],"found":6.5,"targeted":3,"onlyGap":true,"contentErrors":0,"verdictAgree":null,"skipped":null,"overall":4,"why":"…"}\n```');
  assert.equal(g.post[1].score, 0.5);
  assert.equal(parseGrade('{"post":[{"id":"p1","score":0.7}],"overall":4,"why":""}'), null);
  assert.equal(parseGrade('乱写'), null);
});
```

```js
{ id, kind, title, space, closedBy,          // closedBy：'idle' 是挂着被页面当下课

  teacher: { turns, chars, charsPerMin, firstS, writeS, waitMin },   // firstS / writeS：每轮出第一个字、写完的平均秒数
  stops: { total, wasted, byKind: { quiz: 3, steps: 2 } },           // wasted：封闭的、第一次就对、离上一件事不到 FAST_S 秒
  produce: { count, firstMin, longestPassiveMin, minutes },
  asks: { self },                             // 学生自己发起的问

  aims: null, later: null }                   // 以后的批次填
```

- [ ] **Step 1: 写失败的测试** `tests/class-exam.test.js`

```js
import test from 'node:test';
import assert from 'node:assert/strict';
import { buildSystem, SYSTEM_MAX, TEXTBOOK_FLOOR } from '../kit/src/class/prompt.js';
import { EXAM_BUDGET } from '../kit/src/exam/context.js';

const bytes = (s) => Buffer.byteLength(s);
const board = { segs: [], pages: [], cur: 0 };
const exam = '## 统计\n- 2015–2023 年考了 4 次\n## 代表题\n### Q-408-2023-45\n某进程的页面引用串……';

test('给了考情就多一节，在资料包后面、记忆前面', () => {
  const s = buildSystem({ componentDocs: '', pack: { main: { unit: '页面置换' } }, board, subject: '操作系统', exam, memory: null });
  const i = s.indexOf('这一块在考试里（页面从入库的真题和考试大纲算的）');
  assert.ok(i > s.indexOf('页面置换') && s.includes('Q-408-2023-45'));
});
test('没给就没有这一节', () => {
  const s = buildSystem({ componentDocs: '', pack: { main: { unit: '页面置换' } }, board, subject: '操作系统' });
  assert.ok(!s.includes('这一块在考试里'));
});
test('考情、最大的资料包一起带：整份不超上限，教材原文不少于 32 KiB', () => {
  const big = '教'.repeat(60 * 1024);   // 约 180 KiB 的教材原文
  const s = buildSystem({ componentDocs: 'x'.repeat(40 * 1024), pack: { main: { unit: 'u', textbook: big, plan: '计'.repeat(30 * 1024) } }, board, subject: '操作系统', exam: '考'.repeat(Math.floor(EXAM_BUDGET / 3)) });
  assert.ok(bytes(s) <= SYSTEM_MAX);
  const kept = (s.match(/教+/g) || []).reduce((n, x) => Math.max(n, bytes(x)), 0);
  assert.ok(kept >= TEXTBOOK_FLOOR, `教材只留了 ${kept} 字节`);
});
test('同样的输入拼出来一字不差（抢跑要对指纹）', () => {
  const a = { componentDocs: '', pack: { main: { unit: 'u' } }, board, subject: '操作系统', exam };
  assert.equal(buildSystem(a), buildSystem({ ...a }));
});
```
