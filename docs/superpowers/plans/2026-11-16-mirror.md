# 第十三轮：把 claude.ai 项目搬进学习台（实施计划）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 老师每一轮看到的「关于这个学生」换成一份会重写的记忆摘要（背景，不是规矩），并且每一轮看得见当前这块板的截图、板的样子由它自己设计。

**Architecture:** 记忆库多一类 `summary`（四条：shared / math / cs / en）。纯函数在 `memory/summary.js`（给老师的字、当场记的新笔记、课后重写的提示词和读回、版本）；数据库那一层在 `memory/summarydesk.js`（首页后台一节一节重写）。`digest.js` 有摘要时拿它换掉规则、守则、要求、关于我、失误五节；没有摘要时逐字照旧。板的截图是 `class/boardeye.js`（html2canvas-pro，后台先拍、切成一屏一张），`classroom.js` 在调用和抢跑时附上。

**Tech Stack:** 现有的 `la-kit`（ESM、esbuild）、`node --test`、Playwright e2e（`tools/desk-e2e.mjs`）、html2canvas-pro（已经在依赖里）。不加新依赖。

**Spec:** `docs/superpowers/specs/2026-11-16-mirror-design.md`

**执行方式：** 主控自己一件一件做（学生定的：不拆给助手、不跑模拟课、不问问题）。发布前一道独立通读。

## Global Constraints

- 注释、界面文字、提交说明、提示词都用简体中文；注释写「为什么」。
- 发给模型的字里提到学生不用「他」「她」（新加的每一段有测试守着）。
- 讲课、写摘要只认 `claude-opus-5-5`、effort high；后台调用 `lane: 'bg'`，回的不是它就不写，调用之前先记一次「试过」。
- 整份说明 ≤ 160 KiB；记忆那一节 ≤ 28 KiB（`MEMORY_BUDGET` 只许降）；根本规则 ≤ `CHARTER_MAX`（只许降）。
- **没有摘要时，发给老师的说明和现在逐字一样**（现有测试不改断言）。一问一答、舞台课的说明一字不变（`tests/class-charter.test.js` 的 sha256）。
- 不用 `window.confirm` / `alert` / `prompt`；触控目标 ≥ 44px，输入框字号 16px；颜色用变量。
- 不删记忆库里任何旧数据；`summary` 的每一版留在 `history`（最近 8 版）。
- 上限：`SUMMARY_MAX = { shared: 4096, subject: 8192 }` 字节；新笔记 ≤ 20 条、一条 ≤ 300 字；板的图最多 2 张、长边 ≤ 1280。
- 任务里不提交 `kit/dist/`（最后一个任务统一 build）；每个任务结束 `npm test` 全过。私人数据（`.superpowers/`）不进 git。

## Review Focus

1. 重写回来的摘要比上一版短了一半以上、只回了一份、回的不是 Opus：都不写，上一版原样在。（任务 1、4）
2. 重写进行中学生又让老师记了一条新笔记：这条不能被「清掉已并的」一起清掉。（任务 1 的 `nextDoc`）
3. 老师照老习惯写 `ask` / `pref` / `slip` / `lesson` / `rule`：有摘要时都进新笔记、不报错、不再写进旧的那几类。（任务 3）
4. 截图拍不出来、平台这次不让发图、学生自己附满了图：照常调用老师，不附板的图、也不写那一句。（任务 6）
5. 抢跑：带了板的图以后，学生点「继续」仍然接得上；学生附了图或有新手写时照旧不接。（任务 6）

**Interfaces（Produces，`kit/src/memory/summary.js`，不碰 DOM）：**
- `SUMMARY_IDS = ['shared', 'math', 'cs', 'en']`；`SUMMARY_MAX = { shared: 4096, subject: 8192 }`；`NOTES_MAX = 20`；`NOTE_CHARS = 300`；`HISTORY_MAX = 8`；`SHRINK_MIN = 0.5`。
- `maxOf(id): number`。
- `summaryOf(mem, space): { shared: Doc|null, subject: Doc|null, on: boolean }`：从 `mem.summary` 取；`on` = 两条里有一条 `text` 不空。
- `summaryText({ shared, subject }, { space, today }): string`：设计 6.1 那一段（标题、那两句话、「### 三科共用」「### 英语」「### 还没并进摘要的新笔记」）；没字的小节不写。
- `noteOf({ text, quote, session, by, at }): Note`（截到 `NOTE_CHARS`）；`addNote(doc, note): { doc, added: boolean, why? }`：和已有笔记 `similarity ≥ 0.6`（用 `memo.js` 的 `similarity`）不收；超过 `NOTES_MAX` 丢最早的。`doc` 为空时造一条 `{ id, text: '', v: 0, notes: [note] }`。
- `nextDoc(prev, { id, text, by, at, startedAt }): Doc`：`v + 1`；旧的 `{ text, at, by, v }` 进 `history` 头部、留 `HISTORY_MAX` 版（旧 text 空的不进）；`notes` 只留 `at > startedAt` 的。
- `rollback(doc, { at }): Doc|null`：`history[0]` 换回来（现在这一版进 history），`by: 'me'`。
- `rewritePrompt({ space, shared, subject, transcript, said, report, aims, later, legacy, today, title }): string`、`parseRewrite(text): { shared, subject, problems: string[] }`（读 `<共用>…</共用>`、`<这一科>…</这一科>` 两段）、`checkRewrite({ prev, next, id }): { ok, why }`（空、超 `maxOf(id)`、`prev` 有字而 `utf8(next) < utf8(prev) * SHRINK_MIN`）。
- `legacyText(mem, space): string`：现在生效的规则（不含 `use: record`）、守则、要求（带最近一次原话和说过几次）、关于我，各一节：第一次重写的原料。
- `needsRewrite(session, { now }): boolean`：`kind` 是 `class` / `stage` / `talk`（或没写），`turns`（见任务 4：`sessions.usage.calls` 不可靠，用 `sessions.sum.upTo` 对 `sessions.lastTurn`……）——**以代码为准**：读 `sessions/{编号}` 上现成的「最后一轮的序号 / 最后动静的时间」字段，定下来以后写进这个函数的注释。两分钟内有动静不做；`sum.fails ≥ 2` 而且没有新的轮次不做。

**Schema：** `summary: { label: '记忆摘要', kind: 'state', writers: ['chat', 'class', 'page', 'me'], id: { re: /^(shared|math|cs|en)$/ }, required: ['text'], enums: {}, dates: [], refs: {}, tracked: [] }`。
