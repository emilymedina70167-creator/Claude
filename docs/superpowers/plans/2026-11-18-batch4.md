## 4. 每题用时

证据的每条作答带 `ms`（这题在学生屏幕上出现到第一次交，切走、锁屏、翻到别的板不算）和 `msTotal`（到这一次交）。用 3 的 `timing.js`；没在课堂里（练一练、笔记页）照旧按画出来的时刻算。课后报告每道题写「首次 40 秒、一共 2 分 10 秒」，meta/state 和 since-analysis 的作答行带用时。冲突：以前的 `ms` 是「画出来到这一次交」，报告取最大的；现在 `ms` 是首次、`msTotal` 是到这一次，报告的题取第一次的 `ms` 和最后一次的 `msTotal`。改 `session.js`、`memory/report.js`、`trail.js`。

## 5. 预检替外部挡出题错误（`--lint`，只是提示）

- 判对错的组件（answer、quiz、steps、cloze… 页面判得了分的）没写任何预案（react 的 wrong / stuck / giveup）、也没挂 board claude → 「学生答错要等你」。
- quiz 的正确选项比别的明显长（比最长的错选项长一半以上）→ 提示；正确选项的字原样出现在 q / 别的组件的题面里 → 提示。
- 同一段里一道 quiz 排在会让学生自己做的组件（answer / steps / derive do / elim do / predict / recognize）后面，而它的选项或题干里原样写着前面那道的答案 → 「这题能绕过前面那步」。做不到语义上的判断，只查原样出现。
- 落在 `tools/ext-lint.js`，测试 `tests/ext-lint.test.js`。

## 6. scene / predict 拖的过程

查了：scene 每次松手记一条 `drag`（只有松手那一刻的位置），过程没记；predict 拖猜测点一条都不记，只记「确定」那一下的结果。加：松手那一条带 `from`（从哪拖起）、`path`（停过的地方：手指停 0.5 秒以上的点，最多 8 个）、`ms`（拖了多久）；predict 每次拖猜测点记一条 `guess-drag`（同样带过程）。ext_out 写「拖 a 从 (1,0) 到 (2,1)，中途停在 (1.5,0.5)」。改 `kit/src/scene.js`、`blocks/scene.js`、`blocks/predict.js`、`prompt.js`。

## 顺带：dr-legacy-label

错题没有 session 字段、日期在这一科学习台第一节课（或第一条证据）之后的，标「错题本（没有原始作答）」不叫「旧记录」；那天正好有这一科的课的，挂上课号。改 `memory/state.js`。
