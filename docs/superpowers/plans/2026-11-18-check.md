> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 外部写一条 `board check`（六种探题），页面合书呈现、当场判、按外部写好的补讲和同构题接、记证据和每块的吸收，1 天 / 7 天从题库挑没见过的同类题复测。

**Architecture:** 新目录 `kit/src/check/`：写法、判、流程、记录、题库、手写时间线都是纯函数（`node --test`）；外壳 `shell.js` 是一个和黑板分开的控制器，外部的课、页面里的老师的课、复测的课（`kind: check`）三处共用。和计划 1 同时改的文件只加入口。检验里的 solve 等计划 1 合进主干再接。

**Tech Stack:** 原生 ES 模块、esbuild（`npm run build`）、`node --test`、Playwright e2e（`npm run e2e`）、KaTeX；现有的 `anscheck.js`（条件）、`ncalg.js`（非交换多项式）、`derivedo.js`（逐行核）、`mathinput.js`、`ink/engine.js`。

**Spec:** `docs/superpowers/specs/2026-11-18-check-design.md`（需求原文：学习台 `dev_requests/dr-plan2`；计划 1：`dev_requests/dr-batch4` 的 `plan` 和 `review`）

## Global Constraints

- 页面调用的 Claude 只用 Opus 5.5 high（`classroom.js` 的 `TEACH`）；`modelApplied` 不是 `claude-opus-5-5` 时那一次作废、这道题待核，不重试。
- 给页面里的 Claude 的话、手册、`ext_out` 只写写法、事实、页面会怎么做；不写怎么判宽严、怎么教。提示词里提到学生不用「他」「她」。
- 计划 1 的 `solve`、`board judge`、证据 `steps: [{ id, ok: true | false | 'missing' | null, why, tag }]` 照计划 1 的名字用，不改名；`unsure` → `ok: null`，画「？待外部核」，不进错题本。
- `features.js` 的 `handwriting` 照旧 `false`；检验手写板不看它。
- 不出选择题（claim 的真 / 假、discriminate 的能 / 不能是两个按钮，不算选择题），不做演示动画，不做防作弊。
- 不用 `window.confirm` / `alert` / `prompt`（`kit/src/dialog.js`）；触控目标 ≥ 44px，输入框 16px；颜色走变量（`tests/theme.test.js`）。
- 一个文档 ≤ 256 KiB（笔画 ≤ 200 KiB）；检验进度、笔画在 `sessions/{编号}/` 下（`SESSION_SCOPED`）。
- 判分等待上限 `JUDGE_WAIT = 90000`；默认停顿 `pause = 30000`；关键时刻最多 6 张；吸收 `history` 最多 5 次；复测 1 天、7 天（上海日期）。
- 外部没写 `<<< >>>` 时给页面里的 Claude 的默认话（外部原话，原样）：`指出错在哪、只补缺的那一点（不给整段答案）。`
- 注释、界面文字、提交说明用中文；改了 `kit/src/` 或 `CLAUDE-PROJECT.md` 要 `npm run build` 并提交 `kit/dist/`。

- 规则（设计 5.2、5.6′、5.6″）：只有 `cur.id` 那道能交，交过的再交不动（Review Focus 4）；交了要 Claude 判的进 `judging`、马上往下走；判回来没过的进 `owed`，当前这道做完先做 `owed` 的补讲（`phase: 'teach'`）和 retry；`timeout` 当这道题所有 Claude 项 `null`；蒙对（`guessed`）也出 retry；retry 用完 `final: 'fail'`；到可选题时这一块的必做全是一次过、`sure === 'sure'`、没有在判的、写了 `fast` 的都在时间内 → 跳过；`tick` 只在 `phase` 是 `probe` 时加 `visibleMs`，过了 `limit` 以后交的记 `late`；`late` 做对最多 `fixed`；`ext` 改判以后重算 `final`（待核判成没过 → `fail`，那道题的 retry 记进 `owed` 给复测）。
- 吸收（每块）：没做完 → `null`；有 `fail` → `未`；没有 `fail`、有 `pending` → `待核`；全是 `pass` → `成功`；其他 → `部分`。`confidentWrong` 是 `sure === 'sure'` 却没过的题。
