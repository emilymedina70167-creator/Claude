# 旧记录、写入时间、舞台刷新：执行计划（第十五轮第 5 批）

2026-11-18 写。需求在学习台 `dev_requests/dr-trail-fix`：外部在真学习台上验收上一批（版本 2026-11-18d）查出来的三条，第 1 条最要紧。

学生原话：「明明我学了，或者掌握了某些，却在后续分析推理时，出现了诊断我学了却当成没掌握去评估，或者没掌握当成掌握去评估，这些就很危险」。

读真数据看到的：`meta/state-math` 36 条矛盾里，「没讲过」是因为第1讲、第2讲是 9 月在 claude.ai 对话里讲的，学习台里没有课；「依据核不上」是因为依据写的是错题本的编号（`L1-T01`、`L2-43`）或「旧记录：…」的文字，页面只在 `evidence` 里找。外部已经照需求写了 39 条 `coverage/legacy-{块}`（`kind: legacy`、`sessions: []`、`segs: []`、`source`），可 `deskState` 按 `sessions` 一节一节数，空数组那一条一次也没数进去。

## 1 学了当成没学（最要紧）

| 做什么 | 落在哪 |
|---|---|
| 依据的编号在 `evidence`、`errors`（含 T 编号的检验记录）、`observations`、`sessions` 里都找；在证据里找到的是「核上了」，在错题本 / 观察 / 课里找到的、「旧记录：…」开头的文字都是「旧记录（没有原始作答）」：状态照算、标出来，不写「不算」。基础题过 / 复现通过要「做对的作答」只对原始作答（证据）要求；旧记录只能照它写的算 | `memory/state.js` 的 `verifyMastery` |
| `coverage` 认 `kind: legacy`：没有 `sessions` 也算讲过，记 first / last / source；每块一行写「讲过（9 月，旧记录）」，学习台里也讲过的写「讲过（9 月旧记录；2026-11-18 起 1 节）」 | `state.js` 的 `deskState` |
| 页面自己补旧的讲过：有错题、掌握的依据是旧记录、可这一块一条讲过的记录都没有的，从错题的日期、依据文字里的日期（「09-28」）、mastery 的 log 算 first / last，写 `coverage/legacy-{块}`（`by: page`、`source`）；外部写过的不动；三科都算 | `state.js` 的 `legacyCoverage`（纯函数）、`desk.js` 的 `writeTrail` |
| 每块的「最近的作答」「最近一次失手」也看错题本（旧的错题、检验记录），不只看证据 | `deskState` |
| 掌握写着过了、之后同块又有错题（错题本里日期在后面的）也报成矛盾——这是真的矛盾 | `deskState` |
| 复现组判过的依据是检验记录、记录写着过了：照旧记录算，不报 | `deskState` |
| 验收：照真数据跑一遍，L1.1.1–L1.1.8、L2.1.1–L2.1.11 都写「讲过（9 月，旧记录）」、掌握显示出来标「旧记录」，矛盾只剩真的 | `tests/memory-state.test.js`、真数据脚本 |
