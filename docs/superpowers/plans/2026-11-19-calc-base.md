## 二、定下来的写法（给外部看的，审过以后照这个写手册）

### 2.1 学生能写什么（输入框照这个读，下面的公式预览跟着认）

- 函数：`sin cos tan cot sec csc arcsin arccos arctan ln lg exp sqrt abs`，`log_2 x` / `log_2(x)`（底数），`e^x`、`e^{2x}`、`π`（或 `pi`）、`|x|`、`n!`、`C(n, k)`（两个参数才是组合数）、`choose(n, k)`、`Φ(x)`（标准正态分布函数，也写 `Phi`）、`φ(x)`（标准正态密度）。
- 不带括号的函数吃后面整个「单项」：`sin x`、`sinx` → sin(x)；`sin 2x` → sin(2x)；`sin x^2` → sin(x²)；`sinx cosx` → sin(x)·cos(x)（遇到下一个函数停）；`ln 2x` → ln(2x)；`2sinxcosx`、`x lnx`、`(x+1)lnx` 补乘号。`sin^2 x` → (sin x)²。
- 幂：`x^(1/2)`、`x^{-1}`、`x^-1`、`e^-x`；`e^2x` 照写法读成 e²·x（预览里看得见，`e^{2x}` 才是 e 的 2x 次方）。负数的奇数次方根取实数：`x^(1/3)` 在 x = −8 时是 −2。
- **不收、照实说的**：`log x`（没写底数：「写 ln x、lg x 或 log_2 x」）、`sin^-1 x`（「反三角写 arcsin」）。
- 名字冲突：题里自己定义了 `e`、`C` 这类名字时照题里的（线代课的向量 e 不受影响）；没定义时 `e` 是常数。
- 在实数取点的题里，`'` 是**求导**（`(x^2 sin x)'`），整数 / 矩阵的题里照旧是转置。`∫ f dx` / `int(f)` 是「f 的一个原函数」，只在 `calc: antideriv` 的 derive 里用。

### 2.2 实数取点：判函数式相等

- 写法：`formula: x in (0, 1)`、`formula: x in [-1, 1]`、`formula: x in (0, inf)`，或者单独一行 `domain: x in (0, 1)`；几个变量 `formula: x in (0,1), a in (1,3)`。
- **什么时候按实数取点**：变量叫 `x`、`y`（没写范围），或写了 `in` / `domain:` / `calc:`。别的名字（`n`、`λ`、`t`、`k`……）照旧整数 1…6，线代和计算机课一字不变。
- 没写范围时取 (−3, 3)。取 16 个点（按题目的写法定种子：刷新、外部和学生看到的同一组）；**标准答案在这一点没定义、不是有限数、绝对值超过 1e8 的点跳过**；有效的点不到 6 个就是「页面判不了」（`ok: null`）。
- 标准答案有定义、学生的式子没定义的点算不对（`ln x` 在 (−3,3) 上不是 `ln|x|`；写 `domain: x in (0, 3)` 就对了）——这就是「两边定义域不一样时照外部写的范围比」。
- 误差：|学生 − 答案| ≤ 1e-7 · max(1, |答案|)。对不上时说「x = 1.37 时你的式子得 0.52，应该是 0.61」（和现在整数的说法一样）。

### 2.3 `calc:`：页面自己核（`answer`、`steps do`、`practice custom` 都能写）

| 写法 | 学生写 | 页面怎么判学生 | 页面怎么核外部的 `answer:`（开题前自检，错了页面报写法错误，预检也报）|
|---|---|---|---|
| `calc: deriv of=f [order=2]` | f′（f″）的式子 | 和 `answer:` 实数取点比；没写 `answer:` 就和页面对 `of=` 符号求导的结果比 | `answer` 和页面求的导数实数取点比 |
| `calc: antideriv of=f [C=need\|any\|no]` | F（`+C`、`+ c` 都认） | F − `answer` 在每个点上是同一个常数；`C=need`（默认）少了 `+C` 判错并说「少写了 +C」，`C=any` 写不写都行，`C=no` 写了算错 | 页面对 `answer` 求导，和 `of=` 实数取点比 |
| `calc: integral of=f from=a to=b` | 一个数（`formula: -`），或 `发散` | 和 `answer:` 比值；`发散` 照 `answer:` 写没写发散 | 数值积分（a、b 可以是 `inf` / `-inf`）；不收敛、算不稳的报「页面核不了」（提醒，不挡） |
| `calc: limit of=f at=0 [side=+\|-]` | 一个数，或 `∞` `+∞` `-∞` `不存在` | 和 `answer:` 比（数按值，∞ / 不存在按类） | 数值逼近；`at=inf` 换成 1/t；两侧收敛到不同的数、或一侧 +∞ 一侧 −∞ 才认「不存在」；振荡的、算不稳的报「页面核不了」，**不猜** |
| `calc: equiv of=f at=0` | g（「x→0 时 f 和 g 等价」） | 数值算 f / g 的极限是不是 1（写 `x^3/2`、`sin(x)^3/2` 都对） | `answer` 自己代进去是 1 |
| `calc: order of=f at=0` | 一个整数 k | 和 `answer:` 比 | 数值估 f 是几阶（log|f(h)| / log h 的斜率，取整差 0.05 以内） |
| `calc: taylor of=f at=0 order=3` | 多项式（`+o(x^3)`、`+O(x^4)` 认了扔掉；`at=1` 时写 `(x-1)` 的幂） | 展开成精确系数，和 `answer:` 一项项比，「x² 的系数应该是 −1/2，你写的是 1/2」；高于 order 的项不判、说一句 | 对 `of=` 符号求 k 阶导、在 at 上取值 ÷ k!（在 at 上没定义的用数值极限），和 `answer` 每一项的系数比 |

- 答案是一个无理数（`e^2`、`pi/4`、`ln 2`）时写 `formula: -`（现有写法：式子作答、没有变量），学生能写 `e^2`、`π/4`。
- 页面判不了一律 `ok: null`：画成「？页面判不了，待外部核」，证据里 `ok: null`，不算对、不进错题本（和计划 1 的 `unsure` 同一个样子）。
- 外部写的式子（`answer:`、`of=`、`let`）的写法和现在一样严格（不补乘号的地方照旧要写 `*`），只是多了这些函数、都是弧度。

### 2.4 derive mode: do 推高数

```derive
id: dd-lim
mode: do
title: 求极限
calc: limit at=0
start: (tan(x) - sin(x))/x^3
goal: 1/2
```

- `calc: limit at=0`：每一行写「要求极限的那个式子」（前面写不写 `lim x->0`、`lim_{x→0}` 都行，页面去掉），最后一行是数。一行和上一行**恒等**（实数取点）直接过；不恒等时比两行的极限：一样也过（说一句「和上一行的极限一样」），不一样就是这一行错了：「这一行的极限是 0，上一行是 1/2」——加减里乱用等价替换就在这里被抓到。算不出极限的那一行判 `null`（「页面判不了这一步」，能接着往下写，记录里标出来）。
- `calc: antideriv`：每一行是「被积函数的一族原函数」，可以带 `∫ g dx` / `int(g)` 没积完的部分（分部积分 `x e^x - ∫ e^x dx`）；页面比两行的导数（`∫ g dx` 的导数就是 g），`+C` 去掉；最后一行不含 `∫`。
- 不写 `calc:`、`vars:` 里有 `x=real(-2, 2)` 这类实数变量时：判恒等（求导写 `'`：`(x^2 sin x)' = 2x sin x + x^2 cos x`）。
- `vars:` 多一种取法 `real(a, b)`；`samples:` 照旧（实数默认 16 点）。

### 2.5 检验题（计划 2）里

- construct 的式子（`expr`）、discriminate 的 `result`、locate 的 `fix` 能写函数式：非交换多项式那一套判不了（`'unknown'`）而且式子是实数的函数时，按 2.2 取点比（变量 x、y 默认 (−3, 3)）。检验题里要 `calc:` 那种核法，等外部和学生设计高数探题时再接（任务书：这一批不做探题类型）。

### 2.6 概率

- 学生能写 `Φ(x)`、`φ(x)`、`C(n,k)`、`n!`、`e^(-λ)`；外部的 `answer:` 本来就能用 `normpdf normcdf binompmf poissonpmf exppdf unifpdf`。
- **二维积分做小的**：`calc: integral2 of=f x=0..1 y=0..x`（内层的上下限可以含外层变量），只用来**核外部算的数**（P(X<Y)、E(XY) 这类答案外部手算容易错）；学生照旧写一个数。嵌套的 Gauss–Kronrod，约 40 行。
- 期望、方差**不另做函数**：外部的答案写成式子就行（`1/lambda^2`）；`E` 在学习台里是单位阵，另起名字只会添乱。

## 三、不做 / 换做法（请外部看这几条）

1. **高阶导不用差分，用符号求导**：任务书写「和数值求导比」；有限差分到二阶、三阶误差就上 1e-4，判 f″ 会误判。符号求导照语法树走（和、积、商、链式、幂、每个初等函数一条），精确到浮点，泰勒系数也用它。
2. **不定积分不做符号积分**：只核「学生的 F 求导等于被积函数 / 和答案差一个常数」，够判对错，不需要 CAS。
3. **振荡的极限不报「不存在」**：sin(1/x) 这种页面报「判不了」。只在两侧都收敛到不同的数、或一侧 +∞ 一侧 −∞ 时才认「不存在」。`x ln x` 这类慢收敛的（不是 h 的幂级数）外推不稳，也报判不了。
4. **泰勒系数只认有理数**：考研的麦克劳林展开系数都是有理数；`e^x` 在 x = 1 展开这种系数带 e 的，自检报「系数不是有理数，页面判不了」。
5. **不加「高数」「概率」两门课的科目**（见第一节第 9 条）；高数的写法放进新小节 `answer 的高数写法`（标 `<!-- 科目：高数 概率 -->`，不进线代的 40 KiB）和 `derive` 的「完整写法」后面。
6. **矩阵和函数混写**（`e^{At}`）、高数探题、画面：任务书说不做，不做。

## 五、我自己的看法（照任务书做之外，我定的几条）

任务书是外部提的要求，下面是我看完代码以后自己的判断，已经写进了后面的任务里：

1. **最怕的不是「判不了」，是把对的判成错。** 学生在 derive 里写对了一行、页面说「这一行的极限是 0」，比页面老实说「判不了」伤害大得多——学生会去怀疑自己本来对的推法。所以判错要比判对更有把握：
   - 数值极限用两条步长（每次减半、每次除以 3）各外推一遍，两边对得上才算收敛（Task 5）；
   - derive 里要说「这一行错了」，两行的极限都要收敛，而且差得够大（> 1e-4·max(1, |L|)）；差在 1e-7 到 1e-4 之间的报判不了，不报错（Task 7）；
   - 函数式比较只在一个点上对不上时，在它旁边再取两个点，还对不上才判错（防浮点抵消碰巧落在一个点上，Task 3）。
2. **`calc:` 一行就够，不用外部再配 `formula:`**：`deriv` / `antideriv` / `equiv` / `taylor` 自动按 x 实数取点，`limit` / `integral` / `order` 自动是「没有变量的式子作答」。外部少写一行，就少一种写错的可能（写了 `formula:` 也认，以写的为准，Task 6）。
3. **弧度这一刀加一把锁**：多一条测试把 `kit/src/` 里每一个调用 `compile` / `evaluate` / `calcValue` 的文件都列进「角度」或「弧度」两张表之一，以后谁新加一个调用、没归类，测试就红（Task 1）。不然半年后有人在图里写 `sin`，没人记得这里分过两种。
4. **分两次合进 `main`**：第一次是 Task 1–6 加上 answer 那一部分的手册、预检、示例页——任务书验收的三道 answer 题这时就能用；第二次是 Task 7–9（derive 推极限、检验题、概率）。derive 推极限是这一批里最新、数值上最没底的一块，单独审、单独上一节真课验，出问题不拖累前面能用的。
5. **页面自检有时间上限**：一个组件开题前的自检（数值极限、积分）超过 50 ms 就停下，报「页面核得太慢，没核」（提醒，不挡题），iPad 上一块板几道题不能卡住画板。
