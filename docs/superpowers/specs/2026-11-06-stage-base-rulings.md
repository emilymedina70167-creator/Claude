# 舞台的底座第一轮：做的时候我自己定的事

2026-11-08。你说「不用再问我了」以后，底座第一轮做的时候碰到计划没写清、或者计划和设计对不上的地方，我自己定了。每一条写：定了什么、为什么、定错了要付什么代价。觉得哪条不对，告诉我，改起来都不大。

## 判对错（裁判）

- **平衡二叉树：把 LL / RR 转反了，告诉老师的是「把型的名字当成了转的方向」，不是「型从下往上读了」。**
  - 为什么：LL 倒过来读还是 LL，说「读反了」是错的事实。
  - 代价：和计划里错法表的字面不一样。
- **「还没转平就插下一个」只在交给学生旋转的树上算错。**
  - 二叉排序树的插入课（只让学生插）不算错；不按托盘顺序插照样算错。
  - 为什么：平衡二叉树先转平再插是课本要求；王道的题插入顺序是给定的。
  - 代价：老师想让学生自由选顺序时会判错（不写托盘顺序就绕开了）。
- **只让学生插入的树（二叉排序树的课），托盘空了就是「做完」。**
  - 为什么：不然这种课永远做不完，预写的「做完了」永远不演。
- **消元：没弄乱前面的倍乘（化简、变号）算对；倍加只有在把当前主元凑成 ±1、又没弄乱前面时算对；别的倍加照旧算走偏。**
  - 为什么：这几种都是课本做法。
  - 代价：
    - 学生乱乘一行（没弄乱前面）不会被说成走偏。
    - 主元本来就是 1、下面也是 1 时，r1 − 2r2 会被判错。
- **增广矩阵左边消完、右边还不是阶梯形（无解）时，接着消右边。另外加了一个判断式 rankA，只算竖线左边的秩。**
  - 为什么：方程组课要比 r(A) 和 r(A|b)，只有整张的秩老师写不出 r(A)。
- **句子：「把非谓语当成了谓语」只在老师给的正确拆法（key）印证时才说，否则不说。**
  - 为什么：宁可少说，也不给老师写错的事实。
  - 代价：key 没拉非谓语那一段时，这种错认不出来。
- **句子：「从句」是泛称，对得上 key 里任何一种从句；「定语」也对得上定语从句。**
  - 代价：学生标「从句」时，不区分是哪种从句。
- **句子：学生拉的一段 key 里没有、也不和 key 冲突时，页面不判（不圈、不叫老师）。从句里拉的一段，只和同一层的 key 比。**
  - 为什么：key 不全、或者 key 没拆那个从句时，原来会把对的说成错的。
  - 代价：
    - 这种段页面不说对错，要老师看。
    - 从句里的「断早、断晚」只有成分名一字不差时才说。

## 老师怎么写

- **wrong= / call= 只能写在页面真判对错的动作上，写错地方当场报错。@名字.right / @名字.done 写下时先查能不能起作用。**
  - 为什么：硬性规定「不能静默失败」。
  - 代价：老师写在不判的东西上，会多一次报错。
  - 规则接口为此另加了一项 judges，列出哪几个动作真判对错。
- **同一样东西上开两项会抢同一处手指的（两种拖、拖和点），第二项当场报错，告诉老师先关哪一项。**
  - 代价：拉成分和点括号折起来不能同时开。
- **同一项再 open 一次，就是换掉它（只换 wrong= / undo= 也算），手势照新的重挂。**
- **{式子} 里能带空格（`answer={A + B}`），不用加引号。**
  - 这样做是把这个坑直接填上，不让老师绕开它。
  - 只改了舞台自己的分词，课堂的不动。旧的 111 个试演文件分出来的词一个不差。
- **跟着算的一排格子、树，老师或学生动了它的结构（换位、旋转、插入），它就不再跟着算了，舞台现状里说一声。**
  - 图重造时，把老师做的标记带过去。
  - 为什么：原来一拨数就整样重造，老师做的全没了，也没有提示。
  - 代价：动过结构以后再拨数，它不变了，要老师看现状。
- **说明书版本号用今天的日期 2026-11-08（计划里写的是 2026-11-06f）。**

## 学生怎么动

- **「撤一步」只在老师写了 undo=on 时出现，只撤这一回合学生自己做的那一下。**
  - 引出了预写的话、做到了挑战、做完了的那一下撤不了，按钮下写「这一下已经记下了，撤不了」。
  - 为什么：那一下已经告诉老师了，撤也收不回。
  - 代价：做到挑战以后学生想改，要老师来。
- **行把手、行号的触控区补到 44 像素（看不见的那一圈）。**
- **一件叫老师的事本身超过 2 KB（比如学生打了很长一段字）不截断。**
  - 为什么：学生打的字不能丢。
  - 代价：[学生] 那一段偶尔超 2 KB。

## 怎么做的

- **实现和审查的分工：**
  - 实现用 sonnet；多文件、要读懂现有代码的任务用 opus。
  - 审查用 sonnet；整条分支最后一审用 opus。
- **这一轮照样合并、发布。** 重新量的结果没达到设计的目标：剩下的 10 个「做不了」里只有 3 个纯属三维 / 词形，另外 7 个有底座该接住的部分。
  - 为什么：比改之前强很多，测试全过；你说做完就往下走、补缺。
  - 代价：你先摸到的是还缺几种手势的版本。
  - 没接住的排好了序，在 `docs/stage-gaps.md` 末尾一节，作为下一步「底座第二轮」先做。
- **最后一审找到的、碰到「不说假话、不静默失效」的几条，合并前全修了：**
  - 带分数的矩阵答案判错；
  - 算不出来的答案当成答错；
  - key 不全时把对的说成错；
  - 一拨数老师做的全没了；
  - 判不了的挑战照收；
  - 撤一步后「跟着变的」还写着撤掉的变化；
  - 老师写着时学生的话排到老师前面。

## 留到底座第二轮的小问题

- **老师自己示范、学生撤一步：**
  - 老师示范旋转时，不管是不是平衡二叉树的课都照 AVL 核，在二叉排序树上示范会被说「已经平衡了」。
  - 预写的话只等学生，不等老师正在演的那一轮，老师自己做完时会交错着演。
  - 撤一步时，正在等的那一问里打了一半的字会丢。
- **页面上的小毛病：**
  - 拖着放下以前「会不会被拦」是拿当时的舞台问的，偶尔和最后判的不一样（只是画面）。
  - 旧课里字面写了 `answer={…}` 的，现在会被当成 {式子} 算（以前的说明没教过这样写）。
  - 拨数的那一下在 [学生] 里没有字；做到挑战时叫老师那一条里没有拨数的经过。
  - 页面自己的「给个提示」会清掉「最后说的话」，撤一步后又回来。
  - `dial k … at=M` 要写在 M 之前才挂得上。
- **少了的东西：**
  - 树没有「托盘插完了」「结点数」的判断式。
  - `type=set` 时老师写 `answer={1, 5}` 会当场报一句看不太懂的错。
  - 同一个矩阵上「写一格」和「点开看怎么算」都不写范围时会判成抢同一处（真课碰不到）。
- **代码整洁、少几条测试、外接键盘、几处版面：** 不影响用，第二轮顺手做。
