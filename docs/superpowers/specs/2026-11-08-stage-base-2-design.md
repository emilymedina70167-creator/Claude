## 0. 为什么、要什么

第一轮做完重新量：最要紧的四项（动、页面当场、事实、分支·页面要提供什么）里，❌ 从 49 降到 10。可这 10 项里有 7 项是底座该接住没接住的（缺口单里的「乙」）。这一轮把它们接住。

**粒度**：老师（Opus，每一轮当场写镜头指令）只把时间花在教学决定上，重复的机械活页面做、做得好。不是组件库替老师教（「组件库做加法」我否过），也不是让老师从头写代码。一样东西进不进底座，三句都是才做：
1. 是机械的：这个世界的物理（能不能并、能不能摘）、数得出的量、对不对得上答案。
2. 不是教学决定：怎么引导、走偏以后说什么、要不要挂出来给学生看，都留给老师。
3. 至少两种东西用得上，或者就是这种东西本身的规则。

**原则照旧**：页面不做教学决定；事实以页面算的为准；页面当场只做画面后果和老师事先允许的反应。预写只收答案固定的（`@名字.done`、`@名字.right`、`@挑战`，这一轮加 `@ask.right`），走偏以后说什么永远等老师看着写。不说假话，不静默失败。要像游戏，不像放视频。

**成功标准**：
1. **同一批 183 项重新量**（D2 全部；L1 第 1、2、3、4、6、7 幕；L2 第 3～6 幕不靠三维的部分；E2 第 1～6 幕；E3 第 1、2、3、4、5、8 幕；各块分支），照第一轮的做法写 `try3/`、打标、用 `checkReport` 数。四项里的 ❌ 只剩甲的 3 项（L2 第 6 幕·动要三维；E3 第 1 幕·动、页面当场要词形）；乙的 7 项「底座该接住的那一部分」都做得到。
2. **第 2、3 条要的事实真在发给老师的那一条里**：第 13 节「必须出现」那张表，试演工具 `--json` 跑完由脚本查。
3. **旧课照 log 放回一模一样**：111 个旧试演文件加 `try2/` 全部重跑，原来演得上的照样演得上；不一样的只能是第 13 节列的有意改动。

## 2. 学生手上的动作（缺口第 1 条）

### 2.1 同一处的三种按法

现在两项 open 抓同一个部件，第二项当场报错：句子上拉括号、折、拖词不能同时开。改成手势层（`gesturedom.js`）按按法分：点一下就松是 `tap` / `write`；按下就滑是 `span` / `line`；按住不动 0.35 秒、托起来再拖是 `drop-on` / `drop-at`。

- 只有一项抓这个部件时照旧，按下就拖。按法不一样的能一起开（`open s mark`、`open s fold`、`open s move`）；按法一样的照旧当场报错。
- **告诉老师**：现状里开着的那一行写怎么按：`s 开着：mark（滑）、fold（点）、move（按住再拖）`。
- **用**：`gestures.js` 的 `gestureGrabs` 改成按「抓的地方 + 按法」比；`scene.js` open 的冲突检查；`pointer.js`。
- **定了**：托起来要按住 0.35 秒（iOS 拖东西的手感）。代价：开了不止一种时，拖之前先按住一下。

### 2.2 拉一条线

- **写**：造句子时加 `links=`（照黑板 `link` 组件的写法）：`links="that -> humans; !that -> anyone=就近连了名词"`；再 `open s.23 refer`（只在 that 上挂一个钩）或 `open s refer`。
- **学生**：从钩上滑出一条线，松在一个词、一道括号或句子外框上 = `refer s.23 -> s.15` / `refer s.23 -> s.15-16` / `refer s.23 -> s`（整个主句）。
- **页面**：画弧线（现在 `refer` 的箭头）。写了 `links=` 就照 `judgeLinks` 判，连错是走偏、照 `wrong=` 办；`!` 那条对上了，说明只写给老师。没写不判。`refer` 进 `judges`；「做完」照旧只看 mark，要等线连完就写 `when="s linked"`（`links=` 每一条都连对了）。
- **告诉老师**：`学生 refer s.23 -> s.15（that 连到 humans）——不是正确的下一步，像是就近连了名词（你在 links= 里写的）；that 连的是 s.22（anyone）`。
- **老师定**：连错以后怎么讲。代回去的整句、单三复数要词形，归第 3 个子项目。
- **用**：`entext.js` 的 `parseLink` / `judgeLinks`（下标换成词的 key）、`sentence.js` 的 `refer`、黑板 `link` 的弧线。钩是单独的把手（`grips.hook`），和在词上滑的拉括号不抢。

### 2.3 整样东西当把手（矩阵）

画法交整张的把手 `grips.whole`（括号那一圈），手势表一行 `{ gesture: 'drop-on', from: 'whole', to: 'whole' }`：

| 写 | 学生拖到另一张上 = | 页面做 |
|---|---|---|
| `open AB compare` | `compare AB BA` | 逐格比，不一样的格闪两下，弹回去；两张都不变 |
| `open AB put` | `put AB Sum` | 收集用的 Sum 的式子添一项 |
| `open X merge` | `merge X Y` | 同一个矩阵的倍数并成一项；不是就做不到、弹回 |

- 收集用的：`matrix Sum = collect`（加起来）、`matrix Dd = collect -`（第一张减后面的）。空着时是空格子；放了就是跟着算的 `{AA + AB}`，拨 A、B 照样跟着变。学生只能往里放。
- merge 只认「数 × 同一个矩阵（或同一串乘积）」：`{-2 A}` 和 `{-A}` 并成 `{-3 A}`，X 拿下舞台；并成 0 就是 O（抵消）。认不出写法时说「页面看不出是不是同类项（只认 数 × 矩阵）」，不说「不是同类项」。
- 跟着算的矩阵也能 open 这三种：它的数照旧由式子定，学生拨不乱。三种都不判对错；要判写挑战 `when="Sum = T"`。
- **告诉老师**：`学生把 AB 拖到 BA 上比：4 格里 2 格不一样——(1,2) 3 和 5，(2,1) −1 和 1（两张都没变）`；`学生把 X（−2A）拖到 Y（−A）上：并成了 −3A`。
- **用**：`value.js`、`goal.js` 的 `sameMeasure`、`scene.js` 的 `compare`（多认整张矩阵）。
- **定了**：只给矩阵。式子（`tex`）的同类项合并归第 3 个子项目。代价：L1 第 6 幕要把四块各造成一张跟着算的矩阵再并。

### 2.4 学生做的自己收掉

学生用 `span` / `line` 拉出来的括号、线，头上一个小 ✕（点区 44 像素），点它 = `unmark s.2-5` / `unrefer s.23`。老师画的不带。开着 `mark` 才收得了括号、开着 `refer` 才收得了线；不判，写了 `undo=on` 照样能撤。告诉老师：`学生收掉了自己拉的 s.21 V（language-acquisition；这一道 key 里没有）`。

### 2.5 一次点几样

- **写**：`ask pick t "插进 47 以后，哪几个结点的平衡因子会变？都点出来" button="猜好了" expect="t.50 t.45 t.40 t.20"`（expect 可不写；`ask pick t#1 t#3 …` 是只能点这几个）。
- **页面**：点一下亮一圈、再点取消，按按钮交；交的那一下记成一行 `pick t.45 t.50 t.40 t.20`（刷新照它放回）。圈留到老师下一轮写完或 `unpick`；之后哪一下改了这几样，变了的圈成实线、没变的成虚线淡掉（画面后果，不出字）。
- **告诉老师**：交时 `学生点了 4 个：t.45、t.50、t.40、t.20——你预期的是 t.50 t.45 t.40 t.20：一样`（或 `多点了 t.30，漏了 t.20`）；之后那一下的事实多一行 `学生先点的 4 个里，这一下以后变了的：t.45、t.50、t.40；没变的：t.20；变了却没点的：没有`。
- **定了**：交了以后圈的虚实跟着变是画面后果，默认就有（和 `bf t` 的牌子跟着变一样）。代价：学生马上看得出自己猜对了几个；老师不想这样，就在交了以后写 `unpick`。
- 「变了」由 `changed(before, after)` 算：树是平衡因子或位置变了的结点，矩阵是数变了的格，句子是挪了的词；没交就比部件的值。
- **用**：`stage.js` `waitAct` 里 tap 那一段、`armTap`。

### 2.6 手势表里多的几行

| 东西 | 写 | 学生 | 翻成 |
|---|---|---|---|
| 树 | `open t pluck` | 点一片叶子；点里面的结点晃一下（「只能摘叶子」） | `delete t#7` |
| 树 | `open t delete` | 点哪个删哪个（二叉排序树的删除） | `delete t.30` |
| 句子 | `open s move` | 按住一道括号拖到两个词之间，整段挪；按住一个词挪一个 | `move s.1-6 after s.11` |
| 句子 | `open s fold` | 点括号折起来；点小方块展开；里层折着也能折外层 | `fold s.5-19` / `unfold s.5` |

「只能摘叶子」是 pluck 这个动作本身的意思，要删里面的用 `delete`，老师挑。套着折时里层留在外层的小方块里。**用**：`tree.js` 的 `delete`、`tree.view.js` 删除的动画；`sentence.js` 的 `move`（本来就能挪一段）、`fold`（去掉「这一段里有已经折起来的词」那一条）。

## 3. 页面算得出的都写出来（缺口第 2 条）

### 3.1 量

规则交 `measures`：`{ 名字: (o, 部件, scene) → 数 | null }`。写法只有一种：`量(东西或部件)`。

| 东西 | 量 |
|---|---|
| 树 | `count(t)` 结点数、`height(t)` 层数、`height(t.50)` 那棵子树的高、`tray(t)` 托盘还剩几个 |
| 矩阵 | `rank(M)`（整张，增广的是 r(A \| b)）、`rankA(M)`（竖线左边）、`free(M)` 自由变量几个、`det(M)` |
| 句子 | `verbs(s.4-14)` 这一段里 key 的谓语几个、`verbs(s)` 整句、`left(s)` key 还差几段 |

四处能用：
1. **舞台现状**：每样东西多一行「页面算的」，就用量的写法：`页面算的：count(t) = 10，height(t) = 4，tray(t) = 1；avl 否（最小不平衡子树的根是 50，LR 型），bst 是`。
2. **挑战**：`when="count(t) = 7, t avl, height(t) = 3"`、`when="verbs(s.4-14) = 1"`。旧的 `t height=4`、`M rank=2` 照旧认。
3. **答案**：`ask value "现在秩是几？" answer={rank(M)}`。判断式不用当挑战也问得出。
4. **话和贴的字**：`label n t "结点 {count(t)}"`，画成现在的数，跟着变。

算不了（没写 key、矩阵还空着）时是 null：现状写「页面数不了：s 没写 key」，挑战那一句写「判不了」不写 ✗，答案「页面没判成」不当学生答错。

- **用**：`tree.rules.js` 的 `heightOf`、`matrix.rules.js` 的 `rrefOf`、`sentence.rules.js` 的 `keySpans`；`goal.js` 的 `operand`、`value.js` 多认 `量(…)`。
- **定了**：判断式答「是不是」，量答「几个」；带数字的旧判断式（`height=`、`rank=`、`rankA=`）里面改用量算，写法照旧。

### 3.2 每种东西多写的事实

| 东西 | 现状里（每一轮） | 这一下以后 |
|---|---|---|
| 矩阵 | r(A)、r(A \| b)、解的样子（无解 / 唯一 / 无穷多、几个自由变量）；增广矩阵每一行读回成方程，标出矛盾行 | 造的时候写了 `from=M0` 的一张，学生每写满一行和 M0 比一次 |
| 树 | 结点数、层数、托盘还剩几个；`heights t` 开着时每个结点的子树高 | 插、转、摘以后的结点数、层数 |
| 句子 | 学生每道括号里 key 的谓语几个、不在学生括号里的部分几个；多拉的括号；被挪开拆散的括号 | 同左，变了才写 |

- 读回：`第 1 行读回来：x1 + 2x2 − x3 = 1；第 3 行：0 = −3（矛盾）`。未知数照 `vars="x1 x2 x3"`，不写就是 x1、x2……
- `from=M0`：拿变了的每一行，试「原来这一行 + k × 另一行」「乘 k」「两行换了」，挑对上格子最多的：`M1 第 2 行变了，像 r2 − r1；第 3 格该是 −4，写的是 4；第 1、3 行没变；和 M0 同解：否`。猜不出写「看不出是哪一种初等行变换」。不判对错。
- 挂不挂出来给学生看，老师定（和 `bf t` 一样页面算、跟着变）：`heights t` / `unheights t` 每个结点角上标子树高；`tally s V` / `untally s` 每道学生括号上标里面 key 的谓语几个，剩下的部分在句尾标。
- **用**：`matrix.rules.js` 的 `rrefOf` / `same` 搬进 `describe`；`engines/elim.js` 的 `parseOps`；`sentence.rules.js` 的 `markSpans`。

### 3.3 扫一遍拨数

跟着拨数算的东西，规则交了 `brief(o)` 的，现状里多一行：页面把每个能拨到的值都算一遍（不真拨）。

`拨 l（−3～3）时 M：l = 1 无解（r(A) = 2，r(A | b) = 3）；l = −2 无穷多解（1 个自由变量）；别的唯一解`

- 挨着的值要点一样就并成一段；能拨到的超过 25 个不扫，写「l 能拨的值太多，页面没扫」。只有矩阵交 `brief`（增广的写解的样子，别的写秩）。
- **用**：`scene.clone()` 加 `value.js` 的重算（和 `@` 行试一遍是同一个做法）。
- **定了**：自动写，不用老师先写指令。代价：跟着拨数的矩阵，现状里每样多一行。

## 4. 发给老师的那一条不丢要紧的（缺口第 3 条）

**[学生] 按要紧程度压**（`events.js` 的 `capTries`）。每一下分三截：做了什么；裁判的结论；「正确的是……」和事实。超了上限，依次：
1. 「正确的是……」「还没拉对的还有……」和长事实，只留在每样东西的最后一下。
2. 连着几下都是正确的下一步，并成一行：`接着 3 下都是正确的下一步（mark s.2-6 定语、mark s.8 V、fold s.2-6）`。
3. 从前往后把没有错法的几下并成 `之前又试了 N 下……，细节省了`。
4. **有错法（misread）的那几下永远不并、不省**；太多时同一种并成一行：`像是谓语只圈了一半 ×3（s.8、s.12、s.19）`。

**定了**：上限从 2 KiB 提到 3 KiB。代价：叫一次老师多发 1 KiB 以内。

**拨数、拨格子的路**每一下都记，不只挂着 ask 时（`stage.js` 的 `actText` 改成从这一段的事件取，不从 `act.tries` 取）：`学生拨了 t：1 → 0 → −1（停在 −1；拨到 −1 时做到了 g1）`；每停一次记下挑战每一句那时成不成立：`学生拨了 B.2,2：−1 → 0 → 1 → 2（Dd = O：✗ ✗ ✗ ✓）`。

**[跟着变的] 按东西写**（`doc.js` 的 `derivedLines`）：一张矩阵变了一半以上的格就写整张 `Dd：(2 0; 0 −2) → (0 0; 0 0)`；这一块超过 1.5 KiB，后面的只写名字「AB、BA、T 也跟着变了（现在的数见舞台现在）」。

**部件写它显示的东西**：题卡的一行在 [学生] 里、话里的小块都写那一行的字（截到 20 个字）：`学生点了 f.3（laughing）`，不是「第 3 行」（`card.js` 部件的 `label`）。

## 5. 句子照 key 比得更全（缺口第 4 条）

- **多拉的**：新判断式 `s exact`：key 每一段都拉对，而且没有 key 里没有的括号。`s parsed` 意思不变，说明里写清「多拉的不管」。**定了**：不改 `parsed`，旧课放回一样；代价是管不管多拉的，老师挑 `exact` 还是 `parsed`。
- **一段几种成分**：key 写 `[Attr/NF designed [NF to help small businesses]]`，两种都对；学生把 designed 当谓语时说「把非谓语当成了谓语」（`parseKey` 读 `/`）。
- **两种错一起出**：成分贴错又差一两个词时，找重叠最多的那一段 key，先对范围再对成分：`成分标错了，范围也差一点：这一段是表语（to direct these funds better），学生拉的少了 better`。
- **画面不说反话**：括号里的词被挪开、不连着了，括号画成断开的虚线，成分字变淡带「?」；现状写 `a.8 a.15 那道 V 被挪开拆散了，不算一段`。
- **括号上写中文**：学生点「从句」「定语」就画中文；老师写什么画什么。现状两种都写：`s.2-6 定语（Attr）`。
- **用**：`sentence.rules.js` 的 `leftOf`、`misreadOf`、`markSpans`；`sentence.view.js` 的括号。

## 6. 预写和叫老师（缺口第 5 条）

### 6.1 预写和挑战

- **多套一层**：`@g1 goal g2 "…" when="…"` 之后能写 `@g2 …`（`@t.done` 里出的挑战也一样），写下时照先后在今天的舞台上试。**定了**：最多三层。代价：更长的一串要老师接一轮；为什么：再多就是事先排好的一整段课。
- **ask 上预写**：`@ask.right say "对，(C)。"` 写在这一轮的 ask 前面。学生答对（`ask tap … expect=`、`ask pick … expect=`、`ask value … answer=`）那一刻马上演，只演一次。这一问页面判不了对错，这一轮结束时当场报「@ask.right 要跟着一个页面判得了对错的 ask」；`@ask.wrong` 报错。
- **收集型挑战**：`goal g1 "再找一张不一样的 B，让 AB = BA" when="Dd = O" collect=B n=3`。每做到一次、B 和收过的都不一样（照 `sameMeasure`），就收一张（挑战那一条写「收了 2 / 3」）、演 `@g1` 的行（收集型的每次都演）；一样的不收、不叫；收齐了叫老师：`学生收齐了 g1 的 3 张：B = (1 0; 0 1)、(2 1; 0 2)、(0 1; 0 0)（另有 2 下和收过的一样，没收）`。
- **「或」**：`when="k.1 = k#3, k.2 = k#1 | k.1 = k#4, k.2 = k#2"`，有一组都成立就算做到。
- **按了按钮才判**：`goal g1 "…" when="s exact" on="就这样"`，只在学生按这一轮 ask next 的「就这样」时判；没成立也照常叫老师。
- **预写里指着还没有的部件**（空树上 `@t.done ask tap t … expect=t.34`）：写下时只查写法；演的时候还没有，那一行不演，下一条告诉老师「预写的这一行没演上：…」。

### 6.2 什么时候叫老师

现在两头都有毛病：一句拆完就叫（别的句子还没拆、预写的一问还在等）；`@t.done` 演完、没写下一问又不叫。改成一条：做到挑战、做完、答对一问以后，**学生手上还有事就攒着，没事了才叫**。「有事」是：预写刚出了新的一问或挑战；还有没答的 ask tap / pick / drag / value / say；还有没做到的挑战；还有交给了学生、没做完的东西（open 了 `doneBy` 的动作）。只有「接着」一类的按钮（`ask next`）不算事：做完了就当学生按了它，叫老师。

- **告诉老师**（跟下一条走）：`学生把 d 做完了（页面已经演了你预写的 1 行）；那时 a、b、c 还没做完，没叫你`。
- **用**：`loop.js` 的 `onGoal` / `onDone` 里那段判断抽成纯函数 `hasWork(scene)`，放进 `events.js`。

## 7. 回到某一步（缺口第 6 条）

撤一步照旧只撤这一回合。另加存档点，只管一样东西：

| 写 | 意思 |
|---|---|
| `keep t "插入后"` | 把 t 现在的样子存下（一样东西最多 6 个，同名的换掉） |
| `keep t "插入后" after=insert` | 以后学生每做完一次 insert，页面替你存成「插入后」 |
| `back t "插入后"` / `back t` | 你让 t 回到那一刻 / 回到学生最后那一下之前（隔着你的一轮也行，比如 `call=wrong` 叫你以后） |
| `open t back="插入后"` | 学生那边多一个「回到插入后」按钮，点了 = `back t "插入后"` |

- 回去的只是这样东西的数据（结构、值、托盘、染色、角上的字）；位置、open、别的东西、贴的字、挑战都不动。挑战照回去以后的样子重判，规则从那里接着算。跟着算的东西不能 keep，当场报。
- **告诉老师**：`学生点了「回到插入后」：t 回到了插入后的样子（层序 50 30 60 20 40 10）`；现状里列 `t 存着：插入后`。
- keep、back 都是 log 里的行，刷新照样放回；学生按的 back 照旧走 `undoPlan`，撤得了。
- **定了**：存一样东西，不倒回整个 log。代价：回不到没存过的时候（只有「学生最后那一下之前」是页面自动存的）。

## 8. 树按中序排（缺口第 7 条）

- 横坐标照中序名次（黑板 `engines/treeview.js` 的 `layout`，一个结点一列），纵坐标照层。插入时只有新结点右边的往右让一列；旋转不改中序，结点只上下移。第一列在造的时候定下，放不下镜头往后退，不重排。
- 角标分开：平衡因子右上、子树高（`heights t`）右下、`tag` 左上。
- 旋转时换父亲的那棵子树描一道橙色，滑到新父亲下面闪一下（画面后果）。
- **用**：换掉 `types/tree.js` 的 `layoutTree`；`tree.view.js` 的角标、旋转动作；跑 `npm run check:stage`。
- **定了**：所有树都按中序排，堆也是。代价：旧课截图样子变了，堆不再左右对称；重放出来的场景一样（log 是行，不是坐标）。

## 9. 矩阵的写法和摆法（缺口第 8 条）

| 毛病 | 改成 |
|---|---|
| `expect=AB`（整张）点哪一格都判没点对 | expect 写整样东西或一段，点到里面任何一个都算（哪种东西都一样） |
| `link` 连整张矩阵连成一串格，`unlink` 收不掉 | 两头是整样东西就连一道东西到东西的弧；`unlink X` 收掉连着 X 和 X 里部件的线 |
| 重造成跟着算的（`matrix P = {B A}`）掉到最底下 | 同名重造、没写 `beside=` 的留在原处 |
| 格里的 `{…}` 只能写拨数或一格 | 格里能写任意算成数的式子：`{l - 1}`、`{2 k}` |
| D 不能是空牌 | `matrix D = _ _ / _ _`：空格子，填满以前判断式、量都判不了 |
| 增广矩阵不能直接乘向量 | 式子里能写 `coef(M)`（竖线左边）、`rhs(M)`（右边一列）：`{coef(M) P - rhs(M)}` |
| 辅助的矩阵摆在学生眼前 | 造的时候写 `hide=on`：照样算、现状里照样写，画面上不摆；`show R` / `hide R`（哪种东西都能藏） |
| 东西一多，横屏出屏幕 | 往下摆会出屏幕、右边有地方就另起一列（`layout.js` 的 `reflow`）；还放不下，现状里写「画面上看不全：X、Rk」 |

## 10. 判答案（缺口第 9 条）

- **整张 Aⁿ**：`ask value "Aⁿ = ？" type=matrix free=n answer="1 n n(n-1)/2 / 0 1 n / 0 0 1"`。两边有空格的 ` / ` 是分行，贴着的 `/` 是除（和造矩阵一样）。有 `free=` 时学生那边是按格的式子框（`formulaGrid`），逐格用 `compareCells` 判；对不上的格写给老师：`第 1 行第 3 格不对：学生写 n²/2，代 n = 3 是 4.5，该是 3`。
- **省乘号**：老师写的 answer、wrong= 和学生写的走同一个 `normalizeFormula`；报错照真的原因说。`[[…]]` 修好「写得一样也判错」，照旧认，不写进说明。
- **页面自己认的错法**：answer 是 `{式子}` 时，照五条固定的改法现算常见错答，对上了写给老师「页面看出来：像是……」：`A B` → `B A`（乘反了）；`A^k` → 每格 k 次方；`k A` → 只乘了第一行 / 只乘了一格；`A^-1` → 每格取倒数 / 伴随矩阵没除以行列式；`A'` → 没转置。老师的 `wrong=` 先比；现算出来和正确答案一样的那条不算。
- **用**：`formula.js` 的 `matrixCells` / `compareCells` / `normalizeFormula`；`stepper.js` 的 `variants` 那个做法，`exact.js` 现算。
- **定了**：只做这五条，不做通用的错法生成。代价：别的错靠老师的 `wrong=`。

## 11. 第一轮留下的小问题

| 小问题 | 怎么办 |

| 撤一步丢了打了一半的字 | 重放前存下输入框的字，放完放回 |
| 拖着「会不会被拦」拿当时的舞台问 | 每次悬停拿现在的舞台问；松手照旧以裁判为准 |
| 旧课里字面写的 `answer={…}` 被当成式子 | 重放旧课（`lenient`）时算不出来就照字面比 |
| 拨数在 [学生] 里没有字、做到挑战时没有拨数的经过 | 第 4 节 |
