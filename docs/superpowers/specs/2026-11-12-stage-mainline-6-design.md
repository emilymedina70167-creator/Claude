# 舞台主线第六轮：横屏铺满（左边解析、右边画面）、一段一幕能回看

2026-11-12。接第五轮（`2026-11-12-stage-mainline-5-design.md`），主线见 `docs/stage-mainline.md`。这一份要另一个 Claude 审过、我点头以后才开工。

## 起因（我上完时态那一节说的）

- 节奏没问题，但**看不到前面学了什么**。72 分钟的课，舞台上的东西一用完就 `remove`，话最多留 3 句、老师新一轮一开口就收起，一节课讲下来画面上什么都不剩，也没处往回翻。我常常要往前看看，一节课才连得起来。
- 我**不要**回到组件库那样：一堆黑板、很多内容摞在上面、一点点往下滑。
- 「用完拿走」本身也不好：老师一样一样拿，总有漏的，已经讲完的那一段还剩一句话或一条挑战挂着（时态课截图：时间轴早拿掉了，「把绿条右端拖到…」还挂在左上角）。
- 现在**整个屏幕只用了中间**：东西一律往下摞一列，话贴在画面上方。数学、408 以后图和文字要同时在，就摆不开；用满整屏，老师能在一样东西上指着改一部分（「右边是图，左边是解析」），教学的上限高得多。
- **只做横屏。竖屏不花任何工夫**（我没有竖屏学习的场景）：竖屏照现在的样子，不坏就行。
- 要**更聪明、不死板**：怎么教由 Claude 当场定，舞台负责把它想做的用画面接住；改一处只动那一处，不动全部。
- **底座和技术路线一样都不换**（我花了大功夫推进的舞台）。

## 0. 原则和硬规矩

照旧：事实归页面、教学归老师；页面不做教学决定；教学不预制；发给老师的话不说假话、不静默失效、不用「他」「她」；老师讲课只能是 Opus 5.5 high。

这一轮另加：

- **底座不动**。下面这些一个不改意思、不换做法：
  - 老师的镜头指令：每一条写法和意思照旧，以前的课照 log 放回一模一样（只是摆的位置不同）；
  - 每样东西（`kit/src/stage/types/*`）、规则文件（`*.rules.js`）、裁判（`referee.js`）、挑战（`goal.js`）、照引擎走（`follow.js` `follows/`）；
  - 叫老师的课堂循环（`loop.js` `events.js`）、手指（`pointer.js` `gestures.js` `gesturedom.js`）；
  - 世界坐标加一个镜头（`layout.js` 的 `fitCamera`）、排版量出来写回（`o.ext`、`settle`）、新东西往下摆 / 另起一列（`slotFor` `placeFresh` `columnSlot`）；
  - 试演工具、排版检查、真手指检查、六张验收表。
  这一轮只在「话和挑战摆在哪、镜头给它们让多少地方」这一层上补，外加一条新的指令 `scene` 和一个只读的回看层。
- **只做横屏**（`view.w > view.h`）。竖屏走现在的代码，一行不改它的摆法；验收也只在横屏量（竖屏只跑现有的检查，确认没坏）。
- **不碰另一个对话框在修的事**（时态课截图查出来的那几条，在别的分支上修）：话压在句子上、句子行距太大、做完的挑战还挂着、贴的字离得远、小人底下写「fr」、生词注字太小 / 字体不一、等回话的三个点浮在中间、晚到的提示照演。**这一轮等那边合进 `main` 以后再从 `main` 开工**，在那边修好的基础上做；碰到同一处时照那边的做法接着改，不另写一套。
- **不多调用 Claude**。版面、分幕、回看全是页面自己算，回话速度不受影响。
- 说明每门课 ≤ 24576 字节（现在：数据结构 23961、线代 23469、操作系统 22802、英语 21151、组成原理 20997、计网 19772）。这一轮只加 `scene` 一行（约 150 字节）。
- 不为某一节课新造东西；横屏版面和分幕是三科所有课都用的。

## 1. 现在为什么只用了中间（量过的）

拿时态课的两段（第 23/26 轮 gave … would be、第 62/64 轮 had never gambled）照 log 放到真舞台上横屏 1180×820 演了一遍：

1. **一律竖着摞一列**：新东西摆在已有东西的下面（`scene.js` 的 `slotFor`），只有整台要缩到六成以下才另起一列（`columnSlot`）。图和字没法并排。
2. **话贴在画面上方**（`stage.js` 的 `placeCaption`：话的下沿贴着镜头里那块东西的上沿），镜头每次都要在上面给话让出高度（`reserve` 的 `top`）。横屏本来就不高，再让掉一块，整台只好缩小。
3. **挑战一直摞在左上角**，横屏时已经有一种摆法「挑战那一列留在左边、话和画面放右边」（`fitView` 的 `left`），但只在画面明显变大时才用，话还是贴在画面上方。
4. 话一句最宽 748px（`.st-line`），句子一行最宽 800（`sentence.js` 的 `WRAP`）。
5. 舞台课的外框（`.sc-root`）本来就是整屏（`position: fixed; inset: 0`），不受学习台 1120px 的上限。我截图里两边那两条暗色，要在 iPad 上量一下是 claude.ai 的外框还是页面自己的（第 2.6 节）。

## 2. 版面：横屏时左边解析栏、右边画面

### 2.1 样子

```
┌───────────────────────────────────────────────────────────────┐
│ ← 学习台  时态   ① 一般时 ② 进行时 ③ 现在完成 ④ 过去完成    下课 │  ← 顶上一条：幕条（第 3 节）
├──────────────────┬────────────────────────────────────────────┤
│ ○ 把绿条右端拖到… │                                            │
│                  │   He had never gambled before the casino   │
│ 翻译对，「一直」  │   sent him a coupon …                      │
│ 译出了从过去到…   │                                            │
│ （淡、小一点）    │        ┌─ gamble 赌博；casino 赌场 ─┐       │
│                  │                                            │
│ 新的一段：发生在  │   很久以前 ━━━━━ 从未赌过 ━━━━●      现在   │
│ 过去某件事之前的  │              sent 寄来优惠券                │
│ 事，谓语怎么写？  │                                            │
│                  │                                            │
│ [给个提示 →]     │                                            │
│ [想说点什么…][说] │                                            │
└──────────────────┴────────────────────────────────────────────┘
   左：解析栏（挑战、话、    右：画面（同一个世界、同一个镜头，
   这一问、按钮和输入框）    上面不再给话让高度）
```

- **右边就是现在的舞台**：同一个世界、同一个镜头、同样往下摆 / 另起一列，只是镜头能用的那块屏幕从「整屏减去上面的话」变成「解析栏右边那一整块」（`fitCamera` 的 `left` 本来就有）。高度全给画面，字自然变大。
- **左边是解析栏**：一列 DOM，从上往下是挑战、这一幕说过的话、这一问、底下那一条（按钮、输入框、拨数时的「就这样」）。

### 2.2 解析栏里的话：这一幕说过的都留着

- **这一幕里说过的话都留着**，不再「新一轮一开口就收起」，也不再只留 3 句。旧的一轮淡一点、小一点（字不小于 17px，对比度不低于正文的七成，深色时也看得清）；这一轮的照常；这一问在最下面，最显眼。
- 话太多、栏里放不下：栏自己能上下滑，新的一句来了滚到底；往上滑看前面时不抢着滚回来，底下出一个「回到最新 ↓」。
- 话里的小牌（`{s.had}`）照旧，点一下右边那个词闪一下（`chip` 的 `pulse` 本来就有）。
- **一幕一清**：开新的一幕（第 3 节）时整栏收起，换成新一幕的标题。所以栏里的东西有边界，不会像黑板那样越摞越长。
- 刷新、只读回看照 log 放回：话本来就在 log 里（`say` 那一行），照着放回整栏，不另存。

### 2.3 挑战、按钮、输入框也进左栏

- 挑战那几条（`goalsEl`）放在栏顶，和现在横屏「挑战留在左边」是同一个位置，只是从「浮在画面左上角」变成「栏的第一块」。
- 底下那一条（`dock`：「接着 / 给个提示 / 点好了」、输入框、`ask say` 的写字框、拨数的「就这样」）放在栏底，紧挨着这一问。**理由**：问题、答案框、按钮在一处，眼睛和手不用在屏幕两头跑；右边的画面完整留给手指去拖、去点。
- 键盘（公式小键盘、数字键盘）照旧从屏幕底下整条出来，不进栏。

### 2.4 栏多宽：页面量，不写死

- 候选宽度：屏幕宽的 30%、34%、38%、42%（不窄于 300px，不宽于 480px）。
- 每一样都算一次「右边画面能放多大」（`fitCamera` 的 `s`）和「栏里的话折成几行」，挑**画面最大、同时这一问在栏里不超过 4 行**的那一档。又宽又矮的英语句子会挑窄的栏；又大又方的图、矩阵会挑宽一点的栏。
- **不来回跳**：只在一轮开头、造了新东西、开新一幕时重算；新的一档比现在那档让画面大一成以上才换（和现在 `fitView` 的 `camSide` 同一个办法），一轮中间不换。

### 2.5 指哪打哪：改一处只动那一处

- 改一处只动那一处，舞台现在就是这样（染 `s.2`、拨 `e`、改一格 `M.1,2`、贴一张字都只动那一部分），这一轮不改它。以前不得不拆了重摆，是因为画面要和话抢地方。
- 版面这一层守着同一条：
  - 左栏只往下加一句，**加一句话不再让镜头动**（话不再占画面上方，`keepInView` 不用为它让地方）；
  - 右边只有新东西放不下、东西变大变小时镜头才挪（`keepInView` 的门槛照旧）；
  - 栏宽只在 2.4 说的那几个时候换。
- 一幕里东西可以一直留在台上，老师指着其中一部分改、在左栏讲，这一幕讲完整块收起（第 3 节），不用一样一样拿。

### 2.6 量一下 iPad 上实际有多宽

- 进舞台课时，页面把屏幕大小（`innerWidth` × `innerHeight`、`devicePixelRatio`）写进这节课的 `sessions/{编号}.screen`（只写一次，变了再写；`updateSession` 本来就有）。
- 用来确认两件事：我截图里两边的暗色是不是 claude.ai 的外框；栏宽的候选在我的 iPad 上是不是合适。开发那边读真数据看，不调用。

### 2.7 竖屏

不动：`view.w <= view.h` 时走现在的代码（话贴在画面上方、挑战在左上角、底下那一条在底下）。

## 3. 一段一幕：讲完整块收起，能翻回去原样看

### 3.1 老师的写法（说明里只加这一行）

```
scene "过去完成时"            开新的一幕：上一幕整块收起（东西、贴的字、拨盘、挑战、话），能翻回去看
scene "过去完成时" keep=tl    带着 tl 进新的一幕（还要接着用的东西）
```

- 分段是教学判断（讲到哪算一段），归老师。老师现在就会说「新的一段：……」，只是多写一行。
- `keep=` 后面写几样东西的名字，它们（连同贴在它们身上的字、它们的拨盘）留在台上进新的一幕；别的都收起。

### 3.2 收起是什么意思

- 页面在 log 里记下这一行（`scene` 和别的指令一样进 log），然后把台上**不在 keep 里的全部**拿下：东西、贴的字、拨盘、挑战、等着的那一问、左栏的话、还没演的预写反应。和老师一样一样 `remove` 的结果一样，只是一次拿干净，不会漏下一句。
- 新的一幕从空台开始（加上 keep 的）。左栏顶上写这一幕的标题。
- 第一幕从开课到第一个 `scene`，标题是这节课的课名。

### 3.3 老师忘了写：页面兜底

- 老师一轮里把台上的东西都拿掉了（`remove` 完以后一样都没剩），接着又造了新东西：页面当这里开了新的一幕，标题用新一幕老师说的第一句话的前 12 个字，在舞台现状里告诉老师「页面在这里分了一幕：…（下次可以写 scene "标题"）」。
- 只拿掉一部分、换一个例句不算新的一幕。

### 3.4 幕条：顶上一条

- 放在顶上那一条里（课名和「下课」之间，本来就空着），不占画面：`① 一般时 ② 进行时 ③ 现在完成 ④ 过去完成`，现在这一幕亮着，多了能左右滑。
- 一个是一个胶囊，触控高度 ≥ 44px；字是幕的标题，太长截断。
- 只有一幕时不显示幕条。

### 3.5 翻回去看一幕

- 点幕条上的一幕：盖上一层只读的回看（整屏，像翻开前面那一页）。
  - 右边是**那一幕结束那一刻**的画面：学生最后拖到哪、拨到哪、点了哪些，原样停在那里；左边是那一幕说过的话。
  - 做法：新建一个只读的舞台（`new Stage(el, { input: false })`），照 log 从头放到那一幕的最后一行（`replay`，瞬间放，刷新和只读翻看就是这么放的）。不另存画面。同一幕第二次打开用上次放好的。
  - 顶上一条「回看 · 第 3 幕 现在完成时」和一个大按钮「回到现在 →」；从左往右滑也回去。
  - 只能看：不能拖、不能点、不能答（`input: false`）；话里的小牌照样能点、闪一下。
- 回看的时候课照样在下面进行：老师的回话照常演在底下那块（看不见），「回到现在」上出一个点提示「老师说话了」。不自动关掉回看（是我自己要往回看的）。
- **回看时不算「很久没动」**：页面不在我回看的时候叫老师来提醒我；回到现在以后重新数。我回看过哪几幕、看了多久，跟着下一条告诉老师一句「学生翻回去看了第 2 幕「进行时」（40 秒）」——这是事实，不判断我为什么看。

### 3.6 幕的要点（我说的「攒下来的结论」）

- 一幕的要点 = 老师在这一幕里贴过的重点卡（`label … tone=key`）的字，页面照 log 收，不让老师另写。
- 回看那一层的左栏顶上，标题下面列出这一幕的要点；幕条上长按一幕，弹出它的要点（不进那一幕）。
- 下课的报告里多一段「这节课的几幕」（标题 + 要点），「以前的课」里能看到（`report.js`、`pages.js`）。不调用 Claude。

### 3.7 老师那一端知道什么

- 舞台现状多一行：「第 4 幕「过去完成时」（前面：① 一般时 ② 进行时 ③ 现在完成时）」。老师知道这节课已经走过哪几段，可以说「翻回第 2 幕看看那条时间轴」，我自己点。
- 不给老师「替学生打开某一幕」的指令（回看是我自己的事）。

## 4. 不做

- 竖屏的任何改动。
- 另一个对话框在修的那几条（第 0 节）。
- 新的一种东西、新的规则、新的判法；改任何一条已有指令的意思。
- 让老师写坐标、写放第几栏（老师看不到屏幕，以前黑板分栏量过，排版的字是负担）。
- 一整节课一张横着的长画布、往旁边推着看（本质上又是一条越来越长、要滑着找的东西）。
- 回看里接着做题、改回去（只读）。

## 5. 验收

不调用模型，横屏 1180×820 和大 iPad 横屏 1366×1024 都量。

1. **真课放回**：时态课（c-20261112-1，52 轮）照 log 整节放回，每一轮演完横屏截一张，逐张看：
   - 解析栏和画面不压着、话不压在画面的东西上；
   - 整台缩放比：每一轮和第五轮的版面比，中位数要大（字变大），没有一轮比原来小两成以上；
   - 这一节课页面兜底分出来的幕，和我们读课记录时人分的段对得上（分错的列出来）。
   真课的数据是我的私人数据，放在 `.superpowers/` 下面，不进 git；只把量出来的数写进 rulings。
2. **排版检查加三种**（`tools/stage-audit.mjs`，只在横屏）：解析栏和画面重叠；解析栏里的字小于 17px；栏里这一问被挤出栏外看不见。
3. **新的验收表 `NEW6`**（`evals/stage-gaps/new6/` 最小试演 + `tools/stage-must.mjs --table new6`）：`scene` 收得干净（台上、左栏、挑战、等着的一问、预写都没了）、`keep=` 带过去的东西和它贴的字都在、页面兜底分幕和不该分的不分、回看放出来的画面和那一幕最后一刻一样、回看时不叫「很久没动」、回看过的事实写进下一条、刷新以后幕条和每一幕都放得回来、老师现状里有幕的那一行。
4. **以前的不许坏**：`fix1` `new2` `new3` `new4` `new5` `first` 六张表照旧全 ✓；`npm run check:stage`（排版、真手指、自测）横屏照过；282 份旧试演照 log 放回（`tools/stage-try-diff.mjs`），发给老师的东西除了多出来的幕那一行以外一字不差（摆的位置变了是预期的，不算不同）。
5. **e2e** 的舞台课那一段多几步：开新的一幕、翻回去看、回到现在、刷新以后幕条还在。
6. 最后一次只读助手审（重点：页面有没有替老师做教学决定、兜底分幕会不会分错、回看时课堂循环有没有漏叫或多叫老师）。
7. 发布前截图给我在 iPad 横屏上看。

## 6. 分批

- **A 版面**（第 2 节）：解析栏、栏宽、挑战和底下那一条进栏、镜头不再为话让上方、量屏幕。做完发布一次，我先上一节课看横屏的样子。
- **B 一段一幕**（第 3 节）：`scene` 和 `keep=`、页面兜底、幕条、回看、要点、报告、现状里的那一行、回看时的课堂循环。做完发布。

## 7. 要审的人特别看的（拿不准、可能定错的）

1. 底下那一条（按钮、输入框）放进左栏栏底，而不是整屏底下：手离画面远了一点，拖完东西再去点「点好了」要横着移一段。另一种是留在整屏底下、只占右边那块的宽。
2. 页面兜底分幕（3.3）：老师拿光了再造就分。会不会在「换一个例句再讲同一件事」时分得太碎？要不要只认 `scene`、兜底只在一节课里老师一次都没写过 `scene` 时才开？
3. 回看时课照样在下面进行、不自动关：老师回话我可能错过。另一种是老师回话时回看那一层自动退到现在。
4. 一幕里话都留着：一幕很长（二三十句）时栏要滑；要不要只留最近几轮、更早的折成「前面 N 句」点开看？
5. 栏宽的候选和「这一问不超过 4 行」这个数是拍的，要拿真课放回量过再定。
