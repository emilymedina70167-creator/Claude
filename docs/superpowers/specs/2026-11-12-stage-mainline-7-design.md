# 舞台主线第七轮：第一节真课留下的课堂循环和数据

2026-11-12。接第五轮和第一节真的舞台课（英语 时态，`c-20261112-1`，72 分钟、老师 51 轮；读法和页面的六处毛病见 `docs/stage-mainline.md`「第一节真的舞台课以后」）。和第六轮（另一个对话框：横屏解析栏、分幕、回看，`2026-11-12-stage-mainline-6-design.md`）同时做，分开文件（第 7 节）。

这一轮的六件事都是我在对话里一件件定的（每件给了三种做法，我都选了推荐的那种）。

## 0. 原则

照旧：事实归页面、教学归老师；页面不做教学决定；教学不预制；发给老师的话不说假话、不静默失效、不用「他」「她」；讲课只能是 Opus 5.5 high；说明每门课 ≤ 24576 字节（现在：数据结构 23961、线代 23469、操作系统 22802、英语 21151、组成原理 20997、计网 19772）。

这一轮只多一次调用的地方是第 3 节（老师写错、学生没东西可动时马上叫老师），别处都不多调用。

## 1. 晚到的提示不演

**课上**：学生 45 秒没动，页面叫了老师（理由：挑战 g1 很久没做到）。老师还在写，学生已经把小人拖对了，预写的「对。站在过去往后看…」也演了；可老师那一轮已经演上了前几行（`paint`、`camera`），作废不了，后面的「操作：按住粉色小人…」「提示：先有 gave…」照样演了出来：挑战打了勾，底下还在教学生怎么拖。

**做法（定的是 A）**：叫老师的理由没了，这一轮剩下的不演。

- 这一次叫老师时，发出去的那一段里「叫老师的理由」全是**某几条挑战很久没做到 / 试了好多下还没做到**（`stuck`、`tries`，带着挑战的编号），没有学生答题、打字、点按钮、做到挑战这些别的理由。
- 老师那一轮已经开演、还没演完，学生做到了这几条挑战里的一条：这一轮**还没演的行不演**（已经演上的留着，不退回），这一轮照常存下（log 里只有演上的行）。
- 下一轮发给老师的「[上一轮没演的行]」里写：`第 N 行起没演：学生在那之前做到了 g1（你这一轮是因为它很久没做到才被叫来的）`。
- 学生做到挑战本身照旧是要叫老师的事：这一轮停下以后，页面照常把「做到了挑战 g1」发给老师。
- 理由里有别的（学生答了题、打了字），照旧全演。

**在哪**：`loop.js`（记下这一次叫老师的理由；`onGoal` 时看要不要停）、`stage.js` 这一轮的 `drop()`（已经有：停在下一行之前、不退回）；`loop.js` 的 `addEvent` 给 `stuck`、`tries` 事件带上挑战编号。

## 2. 对话放不下时先省最早几轮的舞台样子

**课上**：发给老师的对话有长度上限（`classroom.js` 的 `HISTORY_MAX`，200 KiB 连说明），超了就从最早成对丢掉，没有摘要。每一轮学生那一条都带着一整份「舞台现在」，这节课一共 56 KiB，占对话的一半多。课到后三分之一，老师只看得到第 40 轮以后的。

**做法（我定的，不多调用）**：放不下的时候，**先**把最早几轮学生那一条里的「[舞台现在]……」换成一句「（这一轮的舞台现在页面省略了：对话放不下）」，从最早的开始换，最近 3 条学生的不换；还放不下才照旧成对丢最早的。放得下时一字不改（以前的课的对话不变）。

- 「[学生]」那一段（学生做了什么）一直留着：它是老师判断学生的依据。
- 用这节课的记录量：102 KiB 的对话去掉早轮的舞台样子以后约 50 KiB，整节课 101 条都放得下。

**在哪**：新的纯函数 `kit/src/stage/history.js` 的 `fitHistory(msgs, { max, keep })`；`classroom.js` 的 `messages` 用它替掉现在那个 `while … splice` 的循环。

## 3. 老师写错一行，学生没东西可动

**课上**：老师把「能挪词」和「回到原句的按钮」写进了一行（`open r move undo=on back="原句"`），页面整行跳过；这一问「按住括号拖过去」演上了，学生却拖不了；46 秒后学生说「不会操作」，页面这才把写错的那一行告诉老师。另一轮老师写了一整句话没写 `say`（`would 选对了：搬家在说话之后。但 would 后面要用原形 move…`），页面跳过，这句纠正学生没看到。

**做法（定的是 A）**：

1. **写法容错，只收真课上碰到的、意思明白的两种**（照演，下一轮在「[上一轮照演了、可写错了的行]」里告诉老师下次怎么写）：
   - `open X 动作 … back="名字"`：拆成 `open X 动作 …` 和 `open X back="名字"` 两行照演（拆出来的每一行照常查）。
   - 一行开头不是指令、没有 `"` 也没有 `=`、一半以上是中文：当成 `say "这一行"` 照演。有引号或者 `=` 的（像 `lable a.1 "x"` 这种拼错的指令）照旧报错，不猜。
2. **改不过来时马上叫老师**：这一轮写了 `open`、可一条 `open` 都没演上，演完以后学生手上一样能直接动的都没有（`opens` 是空的，只剩「回到…」按钮的也算空），手上也没有一问可答（等着的只是「接着 / 就这样」这种按钮）：老师写了 `open` 就是要交给学生一只手，不猜话的意思。这时不等学生，马上带着没演的行叫老师重写。和现在「提问没演上」那一条同一个规矩（`stage.askMissed` / `askfail`）：连着两轮都这样就不再自动叫，等学生。发给老师的那一条写：`你这一轮交给学生的手（open）没演上，学生手上没有能动的：页面马上叫了你，重写那几行`。

**在哪**：容错 ① 在 `scene.js` 的 `open`（不再抛那句错，拆开照演，记一条 kept）、② 在 `script.js` 的 `parseScript`（认成 `say`，带 `forgiven`）和 `stage.js` 的 `exec`（记一条 kept）；叫老师在 `stage.js`（这一轮演完时算 `handMissed`）、`loop.js`（和 `askfail` 一样加一个 `handfail` 事件）、`events.js`（`triggers` 认它、那一句话）。

## 4. 老师能把「下课吗？」递给学生

**课上**：学生说「这节课就先结束」，老师不知道顶上有真的「下课」，自己造了一张写着「A：今天就到这里，下课」的题卡让学生点，点了不下课，又来回了 4 轮。

**做法（定的是 A）**：老师写 `ask end "今天先到这里？"`，页面弹出**顶上「下课」按钮点了以后的同一个确认框**（「下课吗？Claude 会写这节课的小结、整理记忆。」接着上 / 下课）。学生点「下课」照常下课（写小结、整理记忆、报告）；点「接着上」，发给老师「学生点了「接着上」」。老师替学生按不了，也不能自己下课。

- 说明里加一行（每门课）：`ask end "今天先到这里？"   学生说要下课时写：页面弹出下课的确认，学生点了才下课（你自己下不了课）`。
- 样子页（没有课堂）：这一问是一个「下课」按钮，点了只记一行。
- 刷新以后这一问照 log 放回，确认框再弹一次。

**在哪**：`script.js`（`ask end` 认 `button=`）、`scene.js`（`case 'ask'` 认 `end`）、`stage.js` 的等学生那里（`end` 交给 `stage.onEndAsk`，没有就画一个按钮）、`classroom.js`（`stage.onEndAsk = () => endClass({ asked: true })`，返回下没下课）、`events.js`（`end` 动作那一句）、`doc.js`（说明一行）。

## 5. 课后报告：同一个空算一道题

**课上**：「用 happen 的正确形式填空」学生先打了「simply什么意思」，又填了 will happen，老师讲完又问了一次（「再填一次：…」），学生填对 would happen。报告算成 3 道：两道错、一道「一次对」。同样，「这句里的谓语动词是哪个」点错 papers、老师「再找一次」点对 publish，算成一错一「一次对」。报告写「17 题，一次对 14」，偏高。

**做法（定的是 A）**：

1. **同一个空算一道题。** 舞台上每一次作答记一个「这一问是什么」的指纹 `sig`，报告按 `sig` 分题（`report.js` 的 `itemKey`：有 `sig` 用它，没有照旧）：
   - 填的答案（`ask value`）：`value | type | 老师写的 answer=`；
   - 点一个（`ask tap`）、点几样（`ask pick`）：`tap / pick | 预期的那几处 | 那样东西的字`（同一个名字重造成了别的句子就是另一道）；
   - 挑战：`goal | 编号 | 挑战的字 | when=`。
   
   老师换个说法重问同一个空（「再填一次：…」），就是同一道题；先错后对算「改对了」，不算「一次对」。掌握（`mastery.js`）照报告的分法数，跟着变准。以前的课的证据没有 `sig`，照旧分，不重算。
2. **答案框里打的问话不算一次作答。** 学生交上来的字有中文、而老师的答案里没有中文，或者以 `?` `？` 结尾：页面不判对错（不晃红框），记成学生说的话；发给老师写「学生在答案框里打了一句问话：「simply什么意思」（不算一次作答）」。

**在哪**：`answer.js`（纯函数 `asksBack(text, spec)`）、`stage.js` 的 `judgeValue` 和写给老师的那一句、`evidence.js`（`askSig`、问话记成说的话）、`classroom.js`（把 `sig` 传进证据）、`report.js`（`itemKey`）。

## 8. 验收

不调用模型。

1. 每一件一个测试（`tests/stage-mainline7.test.js`），复现课上的那一下：
   - 第 1 节：假的舞台上，叫老师的理由是 g1 很久没做到，老师那一轮演到第 2 行时学生做到了 g1：第 3 行起不演，下一轮的「[上一轮没演的行]」里有那一句；理由里有学生打的字时照旧全演。
   - 第 2 节：照这节课的 101 条拼出来的对话，`fitHistory` 以后一条不丢、最近 3 条学生的舞台样子都在；放得下时一字不改。
   - 第 3 节：两种容错各照演、各有一条 kept；`lable a.1 "x"` 照旧报错；`open` 全没演上、学生手上没东西、只等一个按钮：马上叫老师一次，连着两轮不再叫；手上还有一问可答时不叫。
   - 第 4 节：`ask end` 写得进去、`ask end` 带不认得的选项报错；点「接着上」发给老师的那一句；说明里有那一行、六门课不超字节。
   - 第 5 节：同一个 `answer=` 问两次、先错后对：报告一道「改对了」；`asksBack` 认「simply什么意思」、不认「would happen」「过去」（答案里本来有中文）；问话记成说的话。
2. 浏览器里一行一行喂（`tools/stage-touch-first.mjs` 加一段 `late`）：第 1 节那一下在真的舞台上照演、照停。
3. 以前的不许坏：六张验收表照旧全 ✓；`npm run check:stage`；e2e 的 `stage`、`stagestuck`、`stagedrill`；282 份旧试演照 log 放回，发给老师的东西和基线比，**只许**因为第 3 节的容错不同（以前报「没演上」的行现在演上了），逐条列出来写进 rulings。
4. 时态课照 log 放回一遍（试演工具），课上那几处（第 18 轮的 `open … back=`、第 35 轮那句没写 `say` 的话）都演上了。
5. 最后一次只读助手审：页面有没有替老师做教学决定（第 1 节停演、第 3 节容错是不是只收那两种）、第 5 节的指纹会不会把不同的两道题并成一道。

## 9. 不做

- 对话的摘要（多一次调用；第 2 节量过不用）。
- 别的写法容错（只收真课上碰到的两种；以后真课再碰到再加）。
- 老师自己下课。
- 以前的课的报告重算（没有 `sig`）。
- 第六轮的任何东西。
