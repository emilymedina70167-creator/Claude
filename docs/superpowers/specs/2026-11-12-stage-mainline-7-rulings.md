# 舞台主线第七轮：做的时候自己定的事

2026-11-12。设计 `2026-11-12-stage-mainline-7-design.md`，计划 `docs/superpowers/plans/2026-11-12-stage-mainline-7.md`。每条：定了什么 — 为什么 — 要是定错了会怎样。

## 设计里定的（对话里我选的那几种以外）

- 对话放不下：先省早轮的舞台样子、再丢轮，不写摘要 — 不多一次调用；拿这节课量过，省完 101 条都放得下 — 错了：一节课长到连省完都放不下时，最早的照旧整轮丢。
- 「交给学生的手没演上、马上叫老师」的条件：老师这一轮写了 `open`、一条都没演上、演完学生开着的手只剩「回到…」按钮或者一个都没有、手上也没有一问可答。不看有没有挑战 — 课上那一次（第 18 轮）没挂挑战；老师写了 open 就是要交给学生一只手 — 错了：老师写了 open 只是想顺手开着、并不要学生马上动手时，多一次调用。

## 做的时候定的

- 基线在后台跑，和 Task 1 同时做 — 基线钉在改舞台之前那个提交上（c098b13）— 无。
- 晚到的提示那一段真手指检查，直接在样子页里用 `LAStageDev.createLoop` 造一个课堂循环、学生那一下用 `studentDo` — 试演工具一下子给全，量不到边写边演 — 错了：和学习台的接法有出入（同一个 `createLoop`，只有 host 是假的）。
- 「一半以上是中文」把全角标点也算进去 — 课上那一句中文字 20、英文字母 19、全角标点 4，只算字凑不够一半 — 错了：中英各半、全角标点多的一行会被当成话（有引号、`=` 的照旧报错，不会把拼错的指令当成话）。
- 两条旧测试改了期望：`open t rotate back=` 不再报错；「选项表按指令是全的」那条在 `fly` 之前重说一句话（说明里的整行中文现在当成话照演，换掉了它要指的那句）— 是这次容错本来要改的行为 — 无。
- `handMissed` 写成纯函数放在 `events.js`（计划写在 `stage.js` 里算）— node 测试里造不出 Stage — 无。
- e2e 的 `stage` 段把「点顶上下课」换成老师递 `ask end`（先点「接着上」、再点「下课」）；只读翻看最后那句话随之是「那今天就到这里。」— 顶上按钮在别的段还在点 — 错了：顶上按钮那条路在舞台课里少测一次。
- 记忆数据：三条补记照课堂同一套函数（`parseMemoLines` / `planEntry` / `applyPending`）算，连同改动单一起写，改动单上加一句说明是开发那边补记 — 和老师当场写的走同一条路；守卫那一道「原话要对得上」我手核过（原因、步骤是老师原话，题目是那一轮的问，「我写的」是学生原话）— 错了：改动单的 `by` 写的是 `class` 不是 `chat`。
- 弱点 W40、W43 本身不改，只在错题上写 `weakness=` — 课堂当场写错题也不改弱点那一条 — 错了：弱点自己的 `errors` 列表里没有新错题（记忆摘要按错题的 `weakness` 找，不受影响）。
- 修数据的脚本里调格式检查的参数一开始写错了（等于没查），改对以后重查都过 — 记一笔：写数据前的检查自己也要先看它真的在查。

## 收尾的审查

做完以后请了一个没看过这轮的审查（只读整条分支），查出 5 条要紧的，都先写一条会红的测试再改（`tests/stage-mainline7.test.js` 的「审查 1–5」），全套 1758 条过：

1. 问话写给老师时被「只收不判」那一行抢在前面 — 问话那一行放到前面。
2. `asksBack` 冤枉带中文的正常答案（「3次」「x=1或x=2」）— 先判，判对了不算问话；只认问号和问话的字。
3. `value` 的指纹把答案一样的两道不同题并成一道 — 只有紧挨着重问同一问才并（`makeSigger`）。
4. 停演那一句把写错跳过的行当成「没演到」— 跳过写错的行再找第一行没演的。
5. 老师写完、舞台还在演时学生做到了，照旧全演 — `S.acting` 演完才清，演着的那一轮也能停。

留着没改的小毛病（下一轮看情况）：

- `open … back=` 拆两行时先演 back：back 的名字没存过时动作那一行也不演；动作那一行出错时会把以前就开着的同名 back 一起删掉。
- 停演用 `drop()`、没调 `cancelBeat`：「一段一停」停在两段话中间时「接着 ›」会留着；到下一轮演完前学生撤不了一步。
- 停演以后这一轮不挂页面替的那一问：学生手上还有别的挑战时没有「给个提示」（页面马上把「做到了」发给老师，只等老师回话那一阵）。
- 没写 `answer=` 的 `ask value`，学生写了带问话字的作答记成说的话（只收不判的题本来也不进报告的对错）。
- 样子页的「下课」、学习台的「接着上」不调 `onAct`：样子页点了不记一行。
- `FORGIVEN` 的定义插在 `stageLines` 的注释前面。
