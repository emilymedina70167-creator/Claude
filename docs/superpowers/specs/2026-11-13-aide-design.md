# 第九轮：课堂助手（几个 Claude 分工）设计

2026-11-13。我在对话里定的方向；这份是给照着做计划、写代码的人看的。

## 1. 要什么、为什么

**一句话**：上课的老师还是一个（Opus 5.5 high，怎么教由它当场判断），身边多一到两个助手。助手不和学生说话，只做两件事：**把老师自己处理不了的信息处理好**，**把这节课记得更准**。

**为什么现在做**：

1. **记忆的上限已经在撞了。** 2026-11-13 拉真数据量的：记忆原文约 42 万字节（不算课程地图），每节课给老师的只有 28 KiB（`MEMORY_BUDGET`）。照现在的数据开一节「直接插入排序」（DS-L8.2.1）：15 条规则、26 道错题只在目录里留一行。这才 8 节课（真正上完的长课 3 节），离考研还有 403 天，记忆一直涨。
2. **现在挑记忆的是代码，不懂内容。** `memory/digest.js` 按编号挑：先这一块，再规则、关于我、守则……放满就停。真例子：直接插入排序这一块的范围里写着「`>` 改 `>=` 后不稳定」；学生 9-28 把「稳定」理解成「后进先出」的那道错题（DS-L8-T09）挂在前一块 DS-L8.1.1，全文没进，只在弱点后面剩一个编号；折半插入那道（DS-L8-05，2012 真题点）只剩半句。读过全部记忆的 Claude 会知道：讲到 `>=` 不稳定时先探一下「稳定」，代码不会。
3. **一个 Claude 读不完也来不及读。** 老师每一轮是一次全新的调用，不记得上一轮读过什么；一轮要读完、想完、写完，学生在等（平均 27 秒，调一次工具 71 秒）。Opus 一次约能收 250 KB（`debrief.js` 的注释），全部记忆已经比这个大。
4. **我要它越来越了解我、越来越了解这场考试**（我的原话），以及用我下一次的表现回头给讲法打分。这两件也要有一层「懂内容、会合并」的东西来存。

**额度**：我说了额度很充足，多两三个 Claude 花的远比不上开发花的。所以不为省额度砍功能；砍的理由只能是「拖慢回话」或「平台同时只跑两三个」。

## 2. 目标、不做的、做了算失败的

**目标**

- G1 记忆管家：学生卡（每块一张，懂内容地合并过的记忆）+ 课前档案（这节课要知道的），替换掉代码截的那 28 KiB 里按编号挑的部分。上限问题从根上解决：卡是压过的一层，全部的卡一次读得下。
- G2 旁听：学生在动手、老师在等的空档里，助手看这一段，写几行「我看到的」（这个错法以前出现过、这一块的考法、上次哪种讲法对学生有用），进老师下一轮。
- G3 记录分工（我选的第二种）：**老师只写判断，助手写事实**。
- G4 讲法打分：每一轮老师用了什么讲法记下来，代码按学生下一次的表现算有没有用，学生卡里攒「对这个学生有效的讲法」。

**不做**

- 不让助手和学生说话、不让它决定讲什么（教学不预制：助手给事实和发现，老师当场判断）。
- 不改老师的模型（只能 Opus 5.5 high，`TEACH`）。
- 只做舞台课（`kind: stage`，现在开课一律开舞台）。旧的黑板课、一问一答照旧，不接助手。
- 不新加给老师的工具（工具每调一次多一整轮）。
- 不把掌握交给助手：掌握照旧代码按证据算（`mastery.js`）。

**做了算失败（就算功能都在）**

- 老师回话变慢：每轮 `cost.ms`、`cost.first` 比 `docs/smart-plan.md` 的基线慢。
- 老师每一轮的说明变长：整份说明、记忆那一节都不许超过现在的上限（`STAGE_SYSTEM_MAX` 150 KiB、记忆 28 KiB），旁听的几行 ≤ 1.5 KiB。
- 助手编东西进记忆：引的原话、轮次、证据编号对不上还写进去。
- 记忆变冗杂：学生卡越写越长、和原始记忆重复累加（我说过很多次别累加）。
- 助手没好、出错、不是 Opus 时课上不了或卡住：任何时候退回现在的样子（代码挑的记忆、没有旁听）。

## 3. 限制（定死的）

- **平台同时只跑两三个调用**（`lane.js`）。上课时老师占一个、提前想（`maybeSpec`）可能占一个，所以助手**一律走 `lane: 'bg'`**：讲课的调用在跑时不开、一次一个，老师不等助手。课前、课后、首页可以同时 2～3 个（照教材转写的经验：3 个，被限流自动少一个）。每晚的云端教研室不占这个名额。
- **速度硬杠**（`docs/smart-plan.md` 第 0 节）：讲课那一次调用不变重；助手的结果只以几行结论进老师那一轮。
- **助手的模型**：Opus 5.5（和教研室一样；额度充足），核验 `modelApplied`，不是就整次作废（结果不用、不写）。effort：课前、课后 high；旁听先用 high，量了慢就降 medium（交给做的人量，见第 7 节）。
- **事实归代码、判断归 Claude**：轮次、对错、次数、掌握、原话核对都是代码算；助手只做要看懂内容的事。
- **守卫**（`memory/guard.js`）照旧把关所有写进记忆的东西；助手是新的作者 `aide`，归属照 `lab`：不能改课堂当场写的、我改过的话。**对不上的不挂起等我放行**（我说过不要再加要我确认的东西）：事实那一条不收、卡那一行删掉，其余照收，记 `guard_log`（见第 9 节第 2 条）。
- 发给 Claude 的提示词里提到学生不用「他」「她」（有测试守着）。

## 4. 考虑过的做法

| 做法 | 好处 | 代价 |
|---|---|---|
| A 只做管家（学生卡 + 课前档案） | 风险最小、不占上课的名额、马上解决上限 | 上课时没人旁听 |
| B 只做旁听 | 课上马上有第二双眼睛 | 没有管家整理好的记忆，旁听只能翻原始记录，看得慢看不深 |
| **C 分三批：管家 → 旁听 + 记录分工 → 讲法打分** | 管家是另两个的地基：旁听读学生卡几秒就看完，讲法打分的结论存进学生卡 | 第一批做完上课的手感变化不大（只是老师拿到的记忆更准） |
| 把 28 KiB 调大 | 最省事（测过 4～160 KB 一样快） | 记忆一直涨，总会再撞；也没解决「按编号挑」 |

我选了 **C**（推荐的），记录分工选了**老师只写判断、助手写事实**（第二种）。

## 5. 设计

### 5.1 学生卡（第 1 批）

**是什么**：每个课程地图的块一张（`cards/{块}`，比如 `cards/DS-L8.2.1`），外加每科一张「跨块的」（`cards/x-cs`：通用弱点、思维习惯，比如「题目给定下标从 0 仍按从 1 数」这种跨章的）。卡是**从原始记忆派生出来的一层**，不是事实的来源：原始记忆（错题、弱点、观察、证据……）一条不删不改，卡随时能从它们重写。

**卡里写什么**（每张 ≤ 2 KiB，**整张重写不追加**，超了说明该合并）：

- 学生在这一块懂了什么、怎么错的（同一个误解只写一句，后面列出处：错题编号、哪节课 #轮）
- 学生当时的原话（最要紧的一两句，带出处）
- 这一块在考试里怎么考（读 `exam/block.js` 已有的画像，不另算）
- 对这个学生有效 / 没用的讲法（第 3 批才有内容，第 1 批留空节）
- 下次先测什么

每一行带出处。**出处要真有**（守卫核：编号在记忆里、`#N` 是那节课真有的轮、原话在记录里逐字找得到，照 `guard.js` 现有的规则）。卡上记 `src`：它引的那些原始记录的指纹（照 `exam/fresh.js` 的 `profileSrc` 的做法），原始记录变了就知道这张卡过时了。

**存在哪**：不进记忆库的 `COLLECTIONS`（那边首页整类订阅、自检写指纹、备份……卡是派生的，不该进那一套）。照考试资料的做法另立一类、按需读（`EXAM_COLLECTIONS` 那样）：开课时只读这一块、它 `requires` 的块、课程地图上挨着的块、这科的跨块卡，十来张。备份要带上（恢复后不用重写）。

**谁写、什么时候写**：

1. **下课后的助手**（页面，`lane: 'bg'`，首页打开时做，照现在 `fixDebriefs` 的时机）：一次调用读这节课的整段记录（`debrief.js` 的 `transcriptText`）、课后报告、这一块和相关块现在的卡、这一块的相关记忆，**同一次回答里**写：复盘（`debrief.js` 现在的那几种行）、知识点归类（`skills.js` 现在的格式）、事实记录（5.3）、这几张卡的新版本。**现在的复盘和知识点归类两次调用并进这一次**（不叠着做），存的地方、给谁用照旧（`sessions/{编号}.debrief` / `.skills`）。合并以后格式、解析尽量复用 `parseDebrief` / `parseSkills`。
2. **每晚的教研室**（云端，`memory/lab.js` 新加一种单子 `card`）：读全部记忆和全部卡，重写过时的卡（`src` 对不上的）、把几张卡里说的同一件事合到一处、跨块卡重写。回答照现在的规矩写进 `lab_inbox`，页面收（`labdesk.js`），过守卫。
3. **第一次**：卡全是空的。首页后台按块一张张补（一次一块，先补有错题、弱点的块，按 `position` 附近优先），补完为止。

### 5.2 课前档案（第 1 批）

**是什么**：这节课要知道的事，≤ 6 KiB，每行带出处。跨着所有卡读（卡全部加起来一次读得下：现在 140 块，有内容的几十张，每张 ≤ 2 KiB），挑和这节课有关的：这一块的卡、前置块里会冒出来的误解、跨块的习惯、要先测的。

**什么时候写**：首页知道下一节大概讲哪块时（`position`、备好的教案、复现组）就在后台写好，存 `cards/brief-{科}`，带着它是给哪一块写的、依据的卡的指纹。开课时直接用，**不等**。

**放进老师的哪里**：舞台说明里「你对学生的了解」那一节（`stage/doc.js` 的 `buildStageSystem`）。28 KiB 的总量不变，内部重新分：规则、守则照旧全文（`digest.js` 现在的前两段）→ **课前档案** → 这一块的卡 → 前置块的卡 → 剩下的地方照旧按 `digest.js` 现在的顺序放原始条目 → 目录。代码挑的那一套留着，**档案没有、过时（给别的块写的、依据的卡变了）、不是 Opus 写的时整节退回现在的样子**。这节课中途改讲别的块（`blockSwitch`）：卡按新块读，档案过时就不带。

**开课时档案过时或没有**：照旧开课（不等），同时后台写一份；写好了从下一轮起带上（舞台每一轮现拼说明，`classroom.js` 的 `system()`）。

### 5.3 记录分工（第 2 批）

**老师照旧写的（判断）**：`lesson`（守则又犯）、`todo`、`review`（复现组的结果）、`position`、`pref` / `rule`（学生说的偏好、规矩）、弱点「消了 / 还在」这种状态判断、`propose`。

**交给助手写的（事实）**：`error`（错题：题、学生写的原文、错在哪一步）、新弱点的候选和「又出现一次」、`note` 里描述过程的观察（停了多久、改了几次、怎么试的）、`slip`（老师自己讲错的地方：助手对着记录看更容易发现）、`recall` 的候选。

**怎么做**：老师的记忆块说明（`DESK_STAGE` / `MEMO_DOC`）改成只教判断那几种；老师写了事实那几种照旧收（别丢），但说明里不再要它写。事实由下课后的助手（5.1 第 1 条）对着整节课的记录写，走 `applyMemo({ author: 'aide' })`，过守卫，照旧受 `SESSION_CAPS`、`similarity`、`CAPS` 管（不累加）。上课时旁听（5.4）发现的事实先攒在这节课上（`sessions/{编号}/aide/…`），下课后的助手当底稿用，不在课上直接写记忆。

### 5.4 旁听（第 2 批）

**什么时候跑**：老师那一轮演完、学生开始动手以后（`loop.js` 里 `armedAt` 那个时刻起），走 `lane: 'bg'`，所以讲课和提前想在跑时它不开。学生又做了什么、老师又写了一轮，它就照最新的再看（一次只跑一个，旧的跑完不用了就扔）。

**看什么**：这节课最近几轮的记录、学生这一段攒着的动作（`S.pending.events`，`eventsText` 那样写）、课前档案、这一块和相关块的卡、这一块的考情（`exam/context.js` 已经拼好的）。

**写什么**：≤ 1.5 KiB，最多 5 行，每行一个发现带出处，三种：`以前`（这个错法 / 说法以前出现过，哪次）、`考试`（这一步在考试里怎么考，哪道题）、`讲法`（以前哪种讲法对学生有用 / 没用，第 3 批起才有依据）。只写发现，不写「下一步该怎么教」。

**进老师的哪里**：老师下一轮的学生消息里（`doc.js` 的 `turnMessage`）多一节「[助手看到的]」，标着是看到第几轮为止写的。学生的事件一来就叫老师，**不等旁听**：旁听没写完这一轮就没有这一节，写完了下一轮带上；过了两轮还没用上的扔掉。出处对不上的行（编号、轮次不存在）页面直接删掉不给老师。

**记下来**：每次旁听的输入大小、花的时间、写了什么、老师那一轮有没有带上，存在这节课上（`class_turns` 里 `kind: aide` 的系统轮，`discarded`，不进对话；或者单独的 `aide` 集合，做的人定），报告和以后的尺子要用。

### 5.5 讲法打分（第 3 批）

- **记讲法**：下课后的助手给老师的每一轮标用了什么讲法（词表先给一份：先猜再揭晓、反例、画图 / 动手、类比、直接讲规则、追问、换数再做……，词表在代码里，助手只能用词表里的）。
- **算有没有用**：代码算，不交给 Claude。看那一轮之后学生在这个知识点上的下一次作答：对没对、要没要提示、隔天复现过没过（证据和掌握里都有）。规则做的人定，原则是只按证据、样本少时不下结论（同一种讲法在同一类点上至少几次才写）。
- **写进卡**：学生卡「对这个学生有效 / 没用的讲法」那一节，下课后的助手和教研室照代码算出来的数写，带次数和出处。

### 5.6 退路和出错

- 助手的任何一次调用出错、超时、不是 Opus：这一次的结果不用，记 errlog，课照常（就是现在的样子）。
- 守卫拒收或挂起的助手写的东西：照现在 `lab` 的处理（「管理 → 自检 → 守卫」放行或不要）。
- `?dev` 的模拟 Claude（`books/devmock.js`）要能回下课后的助手、课前档案、旁听三种，e2e 不花额度。

## 6. 分批

1. **管家**：学生卡（存法、读法、守卫、备份）、下课后的助手（并掉复盘和知识点归类）、首页补卡、课前档案、舞台说明里记忆那一节重新分、教研室的 `card` 单子、退路。
2. **旁听 + 记录分工**：旁听（`loop.js` 的时机、`turnMessage` 的一节、记下来）、老师的记忆块说明只教判断、助手写事实。
3. **讲法打分**：讲法词表、下课后的助手标讲法、代码算有没有用、写进卡。

每批做完合进 `main`、发布学习台（不用问我）。

## 7. 怎么算做好了（少跑模拟，重在开发）

- 单元测试：卡的读写和出处核对、档案的过时判断、退路、旁听的时机（老师在跑时不开、过时的扔）、事实 / 判断的分工、讲法打分的计算，都写成纯函数测。
- e2e（`tools/desk-e2e.mjs`）加一段 `aide`：用模拟 Claude 走一遍补卡 → 开课带档案 → 上课时旁听写进老师那一轮 → 下课后助手写复盘、归类、事实、卡。
- 一个只读的量法工具（照 `tools/guard-audit.mjs`）：拿 `ArtifactData list` 存下来的真数据，量卡和档案的大小、出处对得上几成、档案有没有带上「直接插入排序」那个例子里漏掉的两道错题。
- 速度：上一节真课以后用 `tools/stage-lesson.mjs` 看每轮的等待，和基线比，不许慢。旁听的 effort 在这里定。

## 8. 交给做的人定的

- 卡、档案、旁听记录的集合名、编号、字段细节；卡的 `src` 指纹怎么算。
- 下课后的助手那一次调用的提示词怎么写、太长时怎么切（照 `transcriptText` 的预算）。
- 首页补卡的节奏（一次几张、隔多久）。
- 讲法打分「至少几次才下结论」的具体数。
- 旁听的 effort（先 high，量了再说）。

## 9. 审查以后定的（我的决定，读的时候可以改）

审查的助手提了 6 个问题，都能从已有的规矩里定下来，没有要另外问我的：

1. **下课后的助手一直没写成，这节课的事实谁写**：一直补，像 `fixDebriefs` 那样——下了课没做过助手的课，首页每次打开都排着（新的先）；连着三次没成的交给每晚教研室现有的 `backfill` 单子补。老师课上写了事实那几种照旧收（5.3），所以最差也有老师当场记的。不让老师的下课整理单再写事实兜底：两个作者写同一件事，去重说不清。
2. **助手写的对不上时**：不挂起。错题、弱点这类事实，对不上的那一条不收；学生卡对不上的那一行删掉，整张照收（卡是派生的，下一次照原始记忆重写）。都记 `guard_log`、`meta/guard.counts`，「管理 → 自检 → 守卫」能看到，不用我点。
3. **教研室的 `card` 单子怎么切**：一科一章一张单子，只带这一章过时的卡（`src` 对不上的）、它们引的原始记录、这一章其余的卡；跨块卡每科一张单子，带这一科全部卡的第一行（每张卡第一行是一句话的概括）。合并同一件事只在一章里做，跨章的由跨块卡收。每张单子照 `BRIEF_MAX` 以内。
4. **上课时和讲课抢名额**：上课时后台只有旁听一个（课前档案不在课上补写，见第 5 条），而且旁听**和提前想错开**：提前想在跑时旁听不开；旁听只在学生手上有东西可动的时候跑——这正是 `maybeSpec` 不提前想的时候（`canPlay`）。这样同一时刻最多两个：老师 + 提前想或旁听其中一个。已经在跑的旁听不打断（平台停不掉在飞的调用），老师照常马上叫。
5. **开课的块猜不中**：首页猜得到（`position`、备好的教案、到期的复现组）就提前写；猜不中或这节课改了块：开课那一刻和老师第一轮同时写一份（第一轮是开场，记忆用得少；这时只有老师 + 档案两个），写好了从下一轮起带上。复现课一节一份，覆盖这节课的几组。
6. **旧课**：并成一次的只给舞台课、从这一轮上线以后下课的课；旧的黑板课、一问一答、以前的课照旧走现在的复盘和知识点归类，版本号不升，不重跑。以前的记忆进卡靠首页补卡（5.1 第 3 条），不从旧课重抽事实（免得错题记两遍）。
