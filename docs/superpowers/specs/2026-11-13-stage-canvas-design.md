# 舞台主线第九轮：画面归老师（设计）

2026-11-13。接第八轮（自由构图，`docs/superpowers/specs/2026-11-13-stage-mainline-8-design.md`）。第八轮在 iPad 上的结果：话、题卡都带框，学生说「字旁边都有框，看着不舒服」，老师只能回答「那是页面画的，我改不了」；一个拨盘没进排版，被底下那一条盖住；画面整体往右偏。

## 1. 我要的（原话的意思）

- 我做那么多底座（东西、规则、裁判、手势、跟着算……），全是为了让课堂里的 Claude 能把自己想教的快速做出来、完全自主地教。第六、八轮的排版层把它固定死了，底座被锁住。
- **整个画面受老师支配，就这么简单，没有别的要求。** 我说「不想用这个显示」，它当场就能改，不能被限制，不能回答「这不是我能决定的」。
- 技术路线由你定，用最强的，token 不是问题。

## 2. 结论：画面归老师，页面只当它的手和眼

- **眼**：每一轮老师都看到画面真实的样子（一张重画出来的图），连同每样东西占哪几格。
- **手**：画面上每一样看得见的东西、它的每一个看得见的方面，老师都能用一行指令改：样子（框、背景、字号、字体、颜色、粗细、对齐、透明度、显示与否）、大小（整样东西放大缩小）、位置（放哪、谁挨着谁、精确到格）、自己画的东西（箭头、圈、括号、任意示意图）。**页面自己的默认样子也是用同一套写法写的一张「默认样式表」**，所以不存在老师改不了的地方。
- **页面不替老师做主**：老师摆过的位置页面一个像素都不挪；页面不自动加老师没要的样子。东西压着了、跑出屏幕了，页面在现状和图上告诉老师，由老师决定怎么改。
- **底座一点不动**：东西的种类、规则文件、裁判、手势、挑战、预写、跟着算、照引擎走、课堂循环、分幕和回看都照旧。只改「画成什么样、摆在哪」这一层。

### 反目标（做出来也算失败的情况）

- 学生说不要某种样子，老师查了说明还是做不到。
- 页面在老师不知道的情况下改了老师定的样子或位置。
- 回话变慢：截图、样式不许压在「学生作答 → 老师开始写」这条路上。
- 底座的行为变了（判对错、手势、挑战的结论和以前不一样）。

## 3. 三条路（为什么选第三条）

1. **页面更聪明、开关更多**（第八轮的路）：开关永远追在学生的要求后面，老师看不见画面，只能在页面留的口子里调。已经在真课里失败。不选。
2. **老师每轮直接写整块画面的网页代码**：最自由，但底座全绑在「东西」上（规则、裁判、手势、跟着算），等于扔掉底座；每轮写大量代码，回话明显变慢；刷新、回看放不回同样的画面。不选。
3. **底座不动，把「画成什么样」整层交给老师，再给它眼睛**（选这条）：老师用和现在一样的一行一条指令写样子、大小、位置、画的东西，页面照做并保证底线；每轮把画面重画成图给老师看。保住底座和速度，自由度覆盖「画面上能看到的一切」。

## 4. 眼：每轮给老师看画面

- **画面快照**：页面把舞台那一块（连同话、挑战、拨盘、底下那一条）重画到一张画布上，缩到长边 1024 像素，跟着下一条消息作为图片发给老师（平台的调用本来就收图：`ai.js` 的 `call(input, { images })`，旧黑板课发手写照片走的就是它）。
- **怎么重画**（构建者照这个做，下面的选择是我的决定）：用 html2canvas 1.4.1（MIT 许可，打进 `la-kit.js`，不连外网）。它不走 SVG foreignObject，自己按计算后的样式把节点画到画布上，在 iPad 的 Safari 上不会把画布弄「脏」（foreignObject 那条路在 Safari 上取不出像素）。舞台在拍照时不用它画不出的效果（毛玻璃 `backdrop-filter` 拍照时当成不透明底）。
- **兜底**：快照出错、超时（0.8 秒）就发第八轮的字画版面（`compose/sketch.js` 的 `sketchText`），并在那一条里写一句「这一轮没截到图」。
- **不压在回话的路上**：画面静下来（最后一次变化之后 600 毫秒没再变）就在后台先拍好、存着；学生作答、要发给老师时直接拿最新的那张。发的时候画面在那以后又变了（学生刚拖完），就当场再拍，最多等 0.5 秒，等不到发上一张并注明「图是 x 秒前的」。
- **只发最新一张**：对话历史里只留文字，旧的图不重发（额度、速度都省）。
- **文字的一份照旧**：现状里的「版面」（每样占哪几格、空着的几块、压着了哪几样、跑出屏幕的）保留，图和字一起看。新增「压着」「出了屏幕」两句（第八轮只写了没照办的关系）。
- 课堂的花费记录里记每次带图的大小（`cost.img`），「⋯」里能看到这节课看图花了多少。

## 5. 手：老师写什么

全部是一行一条，和底座的指令同一种写法（`script.js` 认、`scene.js` 存、写错当场报、进「没演上的行」）。名字（下面写作「目标」）可以是：

| 目标 | 指什么 |
|---|---|
| 东西的名字 `s`、`q`、`tl` | 一整样东西 |
| 部件 `s.3`、`a.2-5`、`m.r2`、`t.45` | 东西里的一部分（照各种东西已有的部件写法） |
| 贴的字的名字、`dial:m` | 一张贴的字、一个拨盘 |
| 画的东西的名字 | `draw` 画的 |
| `say` | 老师的话那一块 |
| `goals` | 挑战那一块 |
| `dock` | 底下那一条（按钮、输入框） |
| `bar` | 顶上那一条（返回、标题、幕条、「说过的」、下课） |
| `*` | 全部 |
| 种类名 `card`、`sentence`、`label`、`dial`、`draw`…… | 这一类的所有（包括以后新造的；见 11.5） |

### 5.1 样子：`look`

```
look say frame=none text=24 color=ink
look q frame=none
look s.3 color=g2 weight=bold
look * frame=none
look say font=serif align=center
look goals hide
look q bg=soft radius=8 shadow=off
look * frame=none always
```

- 能写的（值都是有名字的档，不写 CSS 原文，免得写错、免得压坏手指要点的地方）：
  - `frame=none|line|card`：不带框 / 只一道细线 / 一张卡（底 + 细线 + 影子）
  - `bg=none|soft|card|颜色`、`edge=none|thin|thick|颜色`、`radius=0…24`、`shadow=on|off`、`pad=0|s|m|l`
  - `text=数`（字号，像素，乘屏幕那一档）、`font=sans|serif|hand|mono`、`weight=normal|bold`、`color=颜色`、`align=left|center|right`、`opacity=0.2…1`
  - `hide` / `show`（`say`、`goals`、`bar` 里不要紧的部件、贴的字、画的东西；东西本身照旧用底座的 `hide`）
  - 颜色只写名字：`ink muted brand gold red g1…g6`，每种风格自己决定它是什么颜色（和板书标注一样）。
- 写在同一个目标上的合并；写给 `*` 的垫底，具体目标的盖在上面；部件的盖在整样东西上。
- `always`：这一条以后每节课都用（存进记忆库，见 7）。不写 `always` 的只管这节课。
- 页面自己的默认样子写成一张同样写法的「默认样式表」（`DEFAULT_LOOK`），老师的一条条叠在上面。**每一种画面元素都要有名字、每一项都要改得到**：有测试守着，新加一种东西、一种画面元素没进默认样式表、改不到的，测试不过。
- 不能照办的只有两种，当场告诉老师为什么（见 6 的底线）：会让学生要点的东西点不到；写的值不在档里。

### 5.2 大小：`scale`

```
scale s 1.4
scale tl 0.8
```

- 整样东西放大缩小（0.5～2.5），点、拖、贴的字、连线、排版都跟着准。
- 怎么做（我的决定）：每样东西多一个系数 `o.k`。场景对外给的框（`objectBox`、`partBox`，排版、贴字、连线、手指、镜头都用它）按东西的原点乘 `k`；画法（`types/*.view.js`）照旧按没缩放的框画，画在这样东西自己的一层里（`stage.layerOf(id)`），这一层用 CSS 以原点为中心整体缩放。拖的时候屏幕坐标换回这样东西自己的坐标。各种东西的画法只改「画在哪一层」和「取框用不缩放的那一个」，不改画法本身。
- 字号太小的底线：缩到手指要点的部件小于 44 像素时不照办（见 6）。

### 5.3 位置：`place`（第八轮的写法保留）和 `arrange`

- `place s main / right-of / left-of / above / below / near s.had / row / col / at=c0,r0-c1,r1`、`say "…" near= / at=` 照旧，加上 `place say|goals|dock …`（话、挑战、底下那一条也能摆）。
- **新规矩：老师摆过的归老师。** 一样东西被 `place` 过，它的位置就钉住，页面再也不挪它（长大了压到别的也不挪，只告诉老师）。
- **老师没摆过的归页面**：新东西第一次出来，页面用第八轮的求解器找一块空地放下（挨着这一轮讲的那样、阅读顺序、不压别的），之后它长大、别的东西出来时，页面只挪这些「没被摆过的」去避让，老师摆过的当墙。
- `arrange`：老师说「帮我重排」——页面照所有关系（`place` 写过的当要求、不当钉子）整体重排一遍，排完的位置记进 log。`arrange s q` 只排这几样。
- 第八轮的 `pos` 行照旧：页面每次挪了东西都写一行进 log，刷新、回看、作废照它放回。
- 镜头：固定一档字号照旧；`camera X` 凑近照旧。

### 5.4 自己画：`draw`

```
draw d1 arrow from=s.3 to=tl.fr color=g2
draw d2 circle on=s.3-4 color=brand
draw d3 brace under=s.3-4 "谓语"
draw d4 underline on=s.5 color=red
draw d5 box on=a.2-4
draw d6 text at=4,2-20,4 "先看主干"
draw d7 svg at=30,4-44,16 "<path d='M0 80 Q 50 0 100 80' />"
erase d1
```

- 现成的几种直接复用黑板的手绘形状（`kit/src/markdraw.js`：圈、长圈、套索、大括号、下划线、拱形箭头），和板书标注一个手感。
- `svg`：任意示意图，画在一个格子框里（viewBox 是 0 0 100 100 的比例），过 `kit/src/svgsafe.js` 的白名单和调色板。
- 画的东西贴在部件上的跟着那样东西走（东西挪、放大、学生拖都跟）；画在格子上的钉在那里。
- 画的东西有名字，能 `look`、`erase`；它们进排版（贴着的算那样东西的一部分，单独的算一样东西）；学生点不到它们（不挡手指）。

## 6. 页面的底线（只有这几条）

1. **学生要点的东西不能没**：输入框、发送、下课、返回学习台、这一问的按钮和输入、老师 `open` 交给学生的部件。`look … hide`、`opacity` 太低、被画的东西盖住、缩到小于 44 像素，都不照办这一部分，告诉老师「没照办：…，因为学生要点它」。
2. **值要在档里**：写了不认得的值当场报，给最像的那个（和底座的选项检查一样）。
3. **速度**：截图、样式、排版都不在「学生作答 → 发出去」的路上多等超过 0.5 秒。

除此以外页面不做任何样子、位置上的决定。

## 7. 记得住（学生说过一次，以后都这样）

- `look … always` 的那几条，页面存进记忆库 `meta/look`（页面写；`page` 角色），每节舞台课一开始先叠在默认样式表上，舞台现状里写「一直用的样子：…」。
- 老师写 `look … always` 改它、写 `look … reset always` 撤掉。学习台「管理 → 样子」里列着，我也能删。
- 只存 `look`（样子），不存位置（每节课的东西不一样）。

## 8. 说明怎么写（老师看的那一份）

- `STAGE_TEACH` 里「你决定教什么、怎么引导；画得好、动得顺、算得对是页面的事」改成：画面上的一切——放哪、多大、什么样子、画什么——都由你定；页面只负责算得对、动得顺、照你写的画；学生说不喜欢哪里的样子，当场改，没有「页面画的改不了」。
- 说明里加一小节「画面归你」：`look`、`scale`、`place`/`arrange`、`draw` 各一行例子，加一句「每轮你会收到一张画面的图，先看图再写」。第八轮的 `style` 指令不进说明（被 `look` 取代，写了照旧认、不报错）。
- 每门课说明 ≤ 24576 字节的上限不变：先压别的行腾地方（构建者量，每门课都过测试）。

## 9. 和以前几轮的关系

- 第八轮留下的：细网格、求解器（只给「没被摆过的」和 `arrange` 用）、`place`、`pos`、版面、`preview`（有了每轮的图，`preview` 变成「这一轮演完先把图给我看，再接着写」，照旧最多 6 次）。
- 第八轮分支上没合的 `style` 指令、拨盘并进排版、底下那一条留固定高、话按卡宽折行（commit 69e1c24）：拨盘、固定高、折行三处并进这一轮；`style` 换成 `look`。
- 第六轮的收放解析栏：自由构图里本来不开，这一轮把代码删掉（回看、试演工具照旧）。

## 10. 验收

**尺子：设计要求单。** 写 30 条真课里会出现的要求（学生原话的样子），每条配一个起始画面（试演文件），例如：

- 不要框（全部 / 只是话 / 只是题卡）；话放在句子左边；话大一点、居中；挑战藏起来；
- 这个词放大、标红；整句放大一倍；时间轴小一点放下面；两张矩阵并排、乘积放右边；
- 从 must 画个箭头到 make；把谓语圈起来；在两个词下面画大括号写「谓语」；画一个示意图；
- 背景干净一点、留白多一点；字换成衬线体；
- 「我不想要这个显示了」（不说具体哪里，老师看图自己判断）……

**怎么量**：每条请一个模拟老师（子代理，只给它舞台说明、那一刻的画面截图和舞台现状、学生那句话），它写一轮；页面（试演工具）照写的演出来、截图；再请另一个评卷子代理看前后两张图判「做到了没有」。

- **过线：30 条全部做到**（碰到底线的那几条，算做到的条件是老师照底线解释清楚、并给出了能做的替代）。
- 另跑：`npm test`、`npm run check:stage`、`node tools/stage-must.mjs` 的七张旧表（底座的行为不能变）、e2e 的舞台课一段、刷新放回（同一个 log 画出同一张图）。
- iPad 实机：截图在 Safari 上取得出、像不像，第一步就请我在 iPad 上打开一个试验页确认（云端只有 Chromium）。

## 11. 定下来的细节（审阅以后我定的，标「我的决定」）

1. **屏幕变了（刷新换设备、回看的小窗）**：位置一律存格子坐标，字号档也跟屏宽走，所以换屏幕时整张画面按比例缩放，钉住的东西相对位置不变。真放不下时页面不挪老师的东西，只在现状和图上写「出了屏幕：…」。「同一个 log 画出同一张图」指同一屏幕大小。（我的决定：学生只在横屏 iPad 上学，按比例就够。）
2. **老师不在的时候东西自己长大了**（学生插格子、照引擎走、拨盘改了句子）：页面不挪老师摆过的东西，下一条消息里照实说「压着：…」「出了屏幕：…」，图上也看得到；不为这件事另叫老师（不多花一轮、不打断学生）。**唯一例外是底线 1**：学生要点的部件被盖住或出了屏幕，页面把挡着的那样（优先是没被摆过的）挪开最少的距离，或者把那样东西挪回屏幕里，并告诉老师「为了让学生点得到，挪了 …」。（我的决定：底线 1 高于「不挪」。）
3. **第八轮页面自己做主的几处**：整台缩一档、句子折行宽由页面挑，**只对没被老师摆过、没写过大小的东西保留**；老师摆过、`scale` 过的不碰。页面不再自己把整台缩小：放不下就照实报告，由老师 `scale`、`arrange` 或拿掉东西。`at=` 只定位置（左上角对到那个格），不改大小、不改折行；东西比框大就照实报告「比 at= 的框大」。（我的决定。）
4. **老师的样子和底座的状态色**：底座给学生的反馈（裁判圈的错、挑战做到的勾、点着的、照引擎走亮着的、正在写的那一格）永远画在老师的样子上面，`look` 盖不掉它们；老师要不给学生看反馈，照旧用底座已有的写法（`wrong=quiet` 等）。（我的决定：不然就违反「底座的行为不变」。）
5. **`always` 按种类指**：目标多一种「种类名」：`card`、`sentence`、`array`、`matrix`、`tree`、`graph`、`table`、`timeline`、`plane`、`tex`、`label`、`dial`、`draw`，指这一类的所有（包括以后新造的）。`always` 只收种类名和固定的几块（`say` `goals` `dock` `bar` `*`），不收具体名字（下节课没有那个名字）。`meta/look` 全科共用（「不要框」说的是学生的偏好，不分科）。（我的决定。）
6. **「每一项都改得到」测到多细**：做一张「属性 × 画面元素」的表：每种元素列出对它有意义的属性，表里有的必须真起作用（测试一项一项量计算后的样式），表外的当场报「这一项对 … 不适用，能写的是 …」。**底线是学生会提的那几类都得在表里**：框（底、线、影子）、颜色、字号、字体、粗细、透明度、显示与否，对每一种画着字或画着框的元素都要有；SVG 画的线（括号、边、轴）要有颜色和粗细。（我的决定。）
7. **iPad 上截图验不过时**：改做「按场景重画」的画法：页面按每样东西的框、样式和画法的数据自己画到画布上（不靠浏览器截网页），这是一块新工作，排在计划的第一批之后、作为退路的一批，第一批的 iPad 试验一出结果就定走哪条。截图走不通也不退回「只发字画版面」。（我的决定：你说过一定要让老师看得见。）
