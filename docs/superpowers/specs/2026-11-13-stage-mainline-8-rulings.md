# 第八轮自己定的事

- **样稿和求解器一起做**：样稿发出去以后没停下等，接着做求解器（求解器不依赖样子）；样子按设计规范（字号四档、间距三档、话卡毛玻璃）落在 `stage.css` 末尾「自由构图」一节。错了的代价：样子要改的话只动 CSS。
- **摆好的位置记成 log 里的一行 `pos`**（`by: page`），不是每次刷新重新求解：刷新、回看、作废照 log 放回，排出来和当时一样（计划的「确定性」）。错了的代价：log 里多几行页面的行。
- **预览交回的是字画的版面**（一格一个字 + 版面那几行），不是 PNG：舞台课发给老师的都是文字，接图要改整条对话的拼法；字画的一定画得出、不多花看图的 token。SVG 示意图（`sketchSvg`）留着给以后要图时用。错了的代价：老师看到的是字画的图，不如真图直观。
- **第六轮的收放栏代码留着、自由构图时不开**：拆掉牵连回看、试演工具、几张旧验收表，风险大于收益。错了的代价：stage.js 里有一段不走的代码。
- **预览时不另盖「老师在排版…」**：页面本来就有等回话的三个点。
- **话默认贴着这一轮讲的那样东西**（摆位置、挑战、说话的行不算「讲」），没照办不告诉老师（老师没写过这条）。
- **贴着部件（near s.2）算照办的距离放宽到 5 格**：要绕到那样东西外面去。
