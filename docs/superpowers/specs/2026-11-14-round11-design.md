# 第十一轮：记忆追上并超过 claude.ai，学习台里有一个班主任（设计）

2026-11-14。学习台第十一轮（第十轮「教学团队管整场仗」做完测量之后）。这一份写第十一轮的全貌，详细设计其中的 A「记忆追上 claude.ai」；B「班主任」的画面和对话我还要单独过一遍，做到时在这一份里补成详细设计；C「考情补齐」是开发这边的资料活，和 A 同时做。

## 一、为什么

我说的（2026-11-14）：
- 学习台的智能大脑是 Claude，要通过不断地调用 Claude 来进行，它是核心；理解的内容一定要靠 Claude，代码负责让它有依据、不乱说。
- 我一直更信外部的 Claude（claude.ai），因为 Anthropic 的记忆「我说了什么，下一次都肯定会改」；学习台的记忆是我自己搭的，我怕它离 claude.ai 差很多，设想的系统学习就都落不了地。
- 我要的是一个**整个记忆系统不差于 Anthropic、甚至更强**的学习台。
- 学习之外也要一个 Claude 在学习台里，权限很大，能操作整个学习台的任何数据。
- 外部 Claude 上课的缺点去不掉（不叫不动、写黑板慢、割裂），所以上课用内部；课外也不另开一套外部记忆——两套记忆没法完全协同。一本账、内部维护、让我看得见。

开发这边 2026-11-14 拿真数据量的（8 节课、我打的 90 句话）：
1. 我说过的要求、纠正、期望大约 15 件，**大部分记下了，下一节也照做**（「前面没讲到就别出这种题」「选对了别插话」「开课先报怎么走」……）。
2. **漏了一件，说了 5 次**：「开场复习只做两三句，我是来学新内容的」（11-05、11-12、11-14 三次）。全库找不到一条把它当成我的要求记下。开发那边 11-14 手工补了 `profile/p-newfirst`。
3. **记了没做到**：11-14 第一节课记下「画面上任何两样东西都不能重叠」，十分钟后第二节课我又说了三次。
4. 为什么漏：我说的话能不能变成记忆，全靠老师一边讲课一边自己想起来写一条，没有任何东西兜底；下课后的助手只在下了课以后跑，今天两节都挂着没下课；11-12 那节是课堂助手上线以前开的。claude.ai 让我放心，是因为它有专门的一步回头看我说了什么——学习台缺的就是这一步。
5. 记忆单独卡 28 KiB 是旧账：当时我怕记忆重了拖慢回话，后来测速量过，说明从 4 KB 到 160 KB 第一个字都是 7–8 秒（`docs/talk-plan.md`），真正的上限只有整份说明的 150 / 160 KiB（给对话留地方）。
6. 删课会把我在那节课里说的话一起删掉（证据跟着课走），可我在一节失败的课里提的要求往往最要紧。

## 三、目标、不做的、做成这样就算失败

**目标**（第 A 块的尺子，每条都量，见第九节）
1. **一句不漏**：我在课上（以后也在班主任那里）打的每一句话，下课前都有去处：记成了哪一条、已经记过了哪一条、或者「不用记」和为什么。要求、纠正、期望漏记 0 件。
2. **下一次就用上**：记下的要求，下一节照做，不用我说第二遍；同一件事我说第二遍算一次失败。
3. **不记错**：不编我没说过的话，不把我的问题（「readers 是读者的意思吗」）当成要求，不把一时的话（「这节课先到这」）当成长期的。
4. **不过时**：我改口了换成新的，旧的标「被换掉」；我说「不用了」就停。
5. **懂我**：一个全新的 Claude 只读学习台给老师的那一份，描述出来的就是我（我自己看，开发那边对原始记录打分）。
6. **我看得见**：「管理」里一张表：我说过的话 → 记成了什么 → 之后几节做到没有。

**不做的**
- 不给我加任何要确认的东西（2026-11-03：我说了就直接改，不对我撤销）。
- 不另起一套外部记忆；claude.ai 项目不当记忆的维护者。
- 不拿关键词、正则当「理解」（「别」「不要」「能不能」）：哪句是要求由 Claude 判断，页面只负责每句都有去处、引的原话真有。

**做成这样就算失败**（就算功能都在）
- 我还得说第二遍。
- 记忆越来越长、越来越乱：把每句话都记成一条，老师读到的全是噪音。
- 上课回话变慢（`docs/smart-plan.md` 第 0 节的硬杠）。
- 我的要求被判断错了还改不回来（被机械地钉死）。

## 四、约束

- 上课的老师只能是 Opus 5.5 high；助手、班主任也只认 Opus（`aidedesk.js` 只认 Opus）。后台的调用一律 `lane: 'bg'`，讲课优先。
- 一本账：学习台的数据库。每个角色读跟自己的活有关的那几页；谁写的别人下次都看得到。
- 写进记忆的都过守卫（`memory/guard.js`）：引的原话要在原始记录里逐字找到。
- 发给 Claude 的提示词里不用「他」「她」。
- 每一轮整份说明守住舞台课 150 KiB、黑板课 160 KiB。
- 数据库一共 25000 条文档（现在用了约 11570）：不按「一句话一条」存。
- 改了学习台、课堂的东西合进 main 之前跑 `npm test`、`npm run build`、`npm run e2e`，舞台的画面先跑 `npm run check:stage`。

## 五、做法（Approaches）

「我说的话怎么变成记忆」考虑过三种：

| 做法 | 怎么做 | 为什么不选 / 选 |
|---|---|---|
| 1 老师当场记（现状加强说明） | 说明里再强调「学生说了要求就写 memo」 | 现在就是这样，量出来会漏：老师在讲课，顾不上；而且挂在一个人的注意力上，没有兜底 |
| 2 关键词兜底 | 页面按「别」「不要」「能不能」挑出像要求的句子 | 机械：「别再出现这种格式」能挑出来，「只做 2-3 句就行啊，这是来学新内容还是来复习的？」靠字面挑不准；我反感拿机械提取替代 Claude 的理解 |
| **3 专门一步「话的账」（选这个）** | 一个专门的 Claude 把我新打的每一句过一遍，每句给一个去处；页面数着每句都有去处，引的原话逐字核 | 理解交给 Claude，兜底交给代码：漏一句页面就知道。这就是 claude.ai 那一步，只是这里每一句都查得到 |

（第 B 块的做法另写。）

## 六、A 的详细设计

### 6.0 现在为什么会漏（读代码查到的，2026-11-14）

- 课后的助手被明令不记偏好：`aide/after.js` 的说明写着「判断（……偏好、规则）老师课上记过了，你不写」，`parseAfter` 收到非事实的种类直接不收。当初的分工假定老师当场会记——老师一漏，没有任何兜底。
- 「关于我」（`profile`）在给老师的记忆里排第 10（`digest.js` 的 `PACK_ORDER`），不在核心组里，按数据库的顺序装、不挑，放不下就进目录只剩一行。记下的要求下一节没照做，很可能就是被挤进了目录。
- 课后的助手只在下了课、在首页上才跑；开一节新课不会关上一节，挂着的课 12 小时没动静才算下课（`session.js` 的 `idleClose`）。我今天的两节课到现在都没被整理。
- 我打的话存成证据时丢了「第几轮」：`session.js` 的 `sayEvidence` 不像 `toEvidence` 那样带 `turnOf(ctx)`（舞台课 `classroom.js:246` 传了也没用）。
- 舞台课里老师写的 memo 被守卫拒了，拒的那一条存成 `role: system, kind: note`，可 `messages()` 只发老师和学生的轮：老师永远不知道自己没记上。
- 删课有几种情况会删一半：快照读失败也算读完了，按空的证据排删除，最后把这节课本身删了、证据留成孤儿；`deleting` 那一下没等写完；一次永久性的错吞掉整批；`online()` 卡住以后这一页不再重试。删课按的是内存里的快照，不是按课号查。
- 记忆的 28 KiB：黑板课 `class/prompt.js` 的 `MEMORY_BUDGET`，舞台课 `stage/doc.js` 里写死的 `28*1024`；五个测试钉着它（`memory-digest-fit`、`memory-class`、`aide-digest`、`aide-review`、`stage-class`）。
- `CLAUDE.md` 里写的 `PROFILE_SPILL` 已经删了（8fa1c63），`SESSION_CAPS.pref` 定义了没用上。

### 6.1 新的一类：我的要求 `asks`

我说过的要求、纠正、期望（要老师以后照做的）单独一类，不再混在「关于我」里：「关于我」是事实（用什么设备、底子、目标、什么讲法对我有用），「我的要求」是规矩（要照做、要查守没守、要给我看）。

- 编号 `A-…`，状态类（`schema.js` 的 `COLLECTIONS` 加一类）。
- 字段：`text`（一句话写清要求，Claude 写，照做的人看得懂：「开场复习最多两三句，主要时间给新内容」）、`quotes`（我的原话：`[{ ev, at, session, text }]`——**页面从证据里抄原文**，不让 Claude 重打，所以引的话一定是真的；课删了原话也还在）、`scope`（`all` / 一科 `math|cs|en` / 几块）、`measure`（页面能直接量的那几种之一，没有就空：`overlap` 画面重叠、以后可以加）、`status`（`active` / `replaced`（`into` 新的那条）/ `dropped`（我说不用了，`why`）/ `void`）、`since`、`by`、`checks`（守没守，`[{ session, result: kept|broken|absent, basis, by }]`，见 6.5）、`broken`（犯过几次，页面数）。
- 谁能写：课堂、课后助手（作者 `aide`）、话的账、教研室、班主任、我、开发。都过守卫。
- 以前记在 `profile` 里、其实是要求的那些（「选对了别插话」「前面没讲到别出题」「任何两样东西不能重叠」「不想看到框」「开场复习两三句」……）开发那边一次挪过来：Claude 逐条判断是不是要求，是的建一条 `A-…`（`from: profile/…`，原话照证据补），`profile` 那条标 `merged into=A-…`（`schema.js` 的 `refs` 放开 `into` 可以指 `asks`），老师不会读到两遍。

### 6.2 话的账：我说的每一句都有去处

一个专门的 Claude（Opus 5.5，`lane: 'bg'`，effort 先用 medium，尺子量了召回不够再调高）把我**新打的话**过一遍，每一句写一行去处：

| 去处 | 例子 | 页面做什么 |
|---|---|---|
| `新要求 text=… scope=… [measure=…]` | 只做 2-3 句就行啊，这是来学新内容还是来复习的？ | 建 `A-…`，原话页面从证据抄 |
| `又说了 A-…` | 直接进入新内容学习（已经有那一条） | 原话加进那条的 `quotes`；**那条在这节课以前就有 → 记一次没做到**（我不该说第二遍） |
| `改了 A-… text=…` | 不是放角落，话框是主要内容，要放中间 | 旧的 `replaced`，新的接着 `quotes` |
| `不用了 A-… why=…` | 现在可以多做几道了 | `dropped` |
| `关于我 topic=… text=…` | 下个月期末，只有周末有空 | 照 `pref` 的路写进 `profile` |
| `这一次` | 这节课先到这；你先优化好你的交互 | 只进这节课（6.3），不进长期的 |
| `不用记 why=…` | readers 是读者的意思吗？；每年研究人员发表数百万的论文（作答） | 只记去处 |

- **页面兜底**：每一句（`src: say`，打字的、Pencil 写的、附图的那句话都算）都要有且只有一行；编号对不上、指的 `A-…` 不存在、`text` 照抄了我的原话以外的东西都不收；少了的那几句单独再问一次；还少就记进这节课的 `said.missing`，「管理 → 自检」和体检里报出来，下次首页打开再试。
- **它拿到的**：新的那几句，每句带时间、前一轮老师说了什么（我在回应什么）、后一轮老师怎么接的（截短）；我现在所有的要求全文；「关于我」和守则的标题（免得重复）；这节课前面的去处。
- **什么时候跑**（按一节课的水位线 `said.upTo`，只看水位线以后的新话）：
  1. **课上**：我打了一句（不是拨盘、拖动、作答），隔 20 秒没再打就跑一次（后台，不等它，讲课优先）。
  2. **首页打开时**：所有有新话没过账的课——下了课的、挂着的、我丢下不管又开了新课的、正在删的——都先过账，过账排在课后的助手前面。
  3. **删课之前**：先过账再删（6.6）。
  4. 试了两次都没成，交给教研室一张 `said` 单子（照 `after` 的做法）。
- **存在哪**：每节课一份 `sessions/{编号}/said/main`（`{ upTo, lines: { 证据编号: { to, why } }, missing, at, v }`，跟着课走），只有要求和「关于我」进长期的。数据库不会一句一条地涨。
- 以后班主任那里我说的话（B），同一条账、同一个提示词，出处写 `chat`。
- **一句 = 我发的一条消息**（一条证据）。一条消息里可能有好几件事（「只做 2-3 句就行啊，这是来学新内容还是来复习的？」是一个要求加一句反问；也可能一条里两个要求），所以一条消息可以有好几个去处：`lines: { 证据编号: [{ to, why }, …] }`，每条消息至少一个。标准答案也按消息标、可以多个。
- **只有图的消息**（Pencil 写的、附图、没打字）：话的账只读字，不看图；这种消息页面直接记成「图，没读」，不调用，「你这节课说的」里照样列出来。以后真有用 Pencil 写要求的情况再加看图。
- **老师课上已经记了的**：老师的 memo 多一种 `ask`（写法和话的账的「新要求」一样），原来的 `pref` 只用来记关于我的事实；话的账碰到老师这节课已经记成 `A-…` 的那句，去处写 `已记 A-…`，不重复建、不算没做到。
- **用什么身份写**：话的账的作者是 `said`（照课后的助手 `aide` 那样严：对不上直接不收、不挂起）。「改了」「不用了」能改任何人写的要求，包括我自己在「你说过的」里改过的——依据是我后来说的原话，我后说的为准；改之前是什么照旧记在 `log` 里。
- **「又说了」分两种**：`又说了 A-… why=没照做`（老师没照做我才又说）和 `又说了 A-… why=附和`（「对，就这样」、在改口的同一句里提到、我主动重申）。只有「没照做」、而且那条在这节课以前就有，才记一次没做到。

### 6.3 当场生效

- 课上过账出来的新要求、改了的、「这一次」的，从老师的下一次调用起就在说明里：舞台课 `buildStageSystem`、黑板课 `buildSystem` 的记忆那一节最前面「学生的要求」（6.4）每次调用都重拼（`classroom.js` 的 `system()` 本来每次都重建），这节课新加的那几条后面标「这节课刚说的」；「这一次」的只在这节课里、标「这节课学生说的」。不靠老师自己记、不靠对话历史（历史会被压缩）。
- 过账要几十秒，所以紧跟我那句话的那一轮还是老师自己看着原话回应（它本来就看得到）；钉住的是之后的每一轮。
- 顺手修：舞台课老师的 memo 被拒，下一轮的学生消息前面加一行「[页面] 你上一轮记的 … 没收：原因」（照黑板课的做法）；`sayEvidence` 带上 `turn`。

### 6.4 我的要求放最前，记忆按剩下的地方取

- 记忆那一节（`digest.js` 的 `memoryDigest`）最前面加「学生的要求」：这一科和全科的 `active` 要求**全文**，每条一行（要求 + 最近一次原话 + 日期），犯过的标「犯过 N 次，最近一次 …」，犯过两次的排进红线那一段（6.5）。这一段不跟别的抢、不进目录；要求多到 8 KiB 以上时下课整理顺带合并（照 `CAPS` 的做法，只叫整理、不拒收）。
- 去掉记忆单独的 28 KiB：**别的东西照今天的分法先分完，记忆只长进真正空着的地方**——先按记忆 28 KiB 照今天的规矩把资料包、教材（黑板课的整章补齐 `systemWithBooks`、舞台课的 40 KiB）、「这一块在考试里」都分好，量出整份离 150 / 160 KiB 还差多少，留余量后按 8 KiB 一档取整全给记忆，再拼正式的（取整是为了每一轮开头不抖、抢跑接得上）。所以教材、资料包一点不比今天少（教材少了老师就要调工具取、多等一整轮，那才是真的慢），记忆至少还是 28 KiB、空着的地方都归它。五个钉 28 KiB 的测试改成「整份不超上限」「这一块的、要求全文一定在」「放得下的不进目录」。
- 「关于我」进核心组，按和这节课的相关程度排（这一科的、这一块的先），不再按数据库的顺序。
- 改完拿真课量一次每轮出第一个字的时间（`tools/stage-lesson.mjs`）；照测速不应该变慢，真变慢了退回。

### 6.5 守没守

- **我说了第二遍**：话的账判出「又说了」一条在这节课以前就有的要求 → 页面记一次 `broken`（依据就是那句原话）。这是最硬的一条，不用任何人判断。
- **页面能量的**：`measure=overlap` 的要求，页面数这节课每一条学生消息里「[舞台现在]」的「压着：…」行（舞台已经每一轮写着，存在 `class_turns` 里），有就记**这节课一次** `broken`（`by: page`），依据写哪几轮、哪两样压着。不分是老师摆的还是页面排出来的：我看到的就是压着了；页面自己排出来的那几种同时记进开发那边的毛病单（`meta/health` 一条），开发去修页面。只有舞台课有「压着」这一行，黑板课不量、交给课后的助手判。以后能量的种类往 `measure` 里加。
- **课后的助手判**：`after.js` 加一节「## 要求」：这节课碰得上的每条要求一行 `A-…｜做到|没做到|没碰上｜依据（#轮次 或原话）`；页面核依据（轮次真有、原话真在）；和页面量的冲突时以页面的为准。`after.js` 那句「偏好老师课上记过了，你不写」改掉：要求由话的账记，助手只判守没守。
- **升级**：一条要求犯过两次，记忆里就排进红线那一段，写「这条犯过 N 次：最近一次 …」；舞台课老师说明里写明红线那一段是硬规矩。以后几节都做到了，犯过的次数照旧留着（给我看），只是不再排红线（连着 3 节做到退回普通）。
- 犯了的也进成绩单（B 做好以后，同一张）。

### 6.6 删课不删我的话

- `asks` 自己存着原话，删课不碰 `asks`、`profile`。
- 删一节课之前先给它过账（6.2，等最多 60 秒）；过账没成，这节课 `src: say` 的证据先留着（`keptWords`），别的照删，下次首页打开过完账再删。
- 删课改结实：删哪些按课号现查（`where('session', '==', 编号)`），不按内存里的快照；`deleting` 等写进去再动手；一样一样删、单个出错记下来继续，不整批放弃；证据没删干净不删这节课本身；卡住的下次打开重来。体检里有「证据指着已经没有的课」时页面自己清（原来只记一笔）。

### 6.7 给我看：「你说过的」

- 「管理」里一页「你说过的」（地址 `#asks`）：一条一张卡——上面一句要求（大字），下面我的原话和日期（小字，几次就几行，「说了 3 次」），右边之后每一节课一个小点（做到 / 没做到 / 没碰上，点开看依据）；犯过两次的卡上一枚朱砂小字「犯过 2 次」。卡上「改」「不用了」（`meChange`，直接生效）。停用、被换掉的收在最下面。
- 「以前的课」点进一节：多一段「你这节课说的」：每一句 → 去处（记成了哪条 / 不用记），一眼看出有没有漏。
- 下课小结那一行小字后面加一句「你说的 N 条要求都记下了」（有新的才写）。
- 版式照学习台现在的紫藤 iOS（分组白卡、0.5px 细线、宋体标题）；先做出来截图给我看再定细节。

## 七、B 班主任（大纲，详细设计做到时补）

我说的：学习之外也要一个 Claude 在学习台里，权限很大，能操作整个学习台任何数据。和第十轮的「总教练」合成一个角色（开发这边定的：一个角色一份态势，不会出现教练说一套、跟我聊的说另一套）。

- **是什么**：首页上随时能找的 Opus 5.5。同一个 Claude、同一本账，和老师、助手、教研室的区别只在三处——交给它什么活、先读哪几页、允许它动什么。
- **它先读的**：全貌，不卡 28 KiB——四科到哪了、预测分和测出来几成、路线和截止日、最近几节课、我所有的要求（A 的那一类）、态势文档、成绩单；不够自己翻任何一页（读的工具不限集合）。它不用秒回，读得多不要紧。
- **它能做的**：读任何数据；改几乎任何东西（课程地图、计划、记忆、规则、复现排期、考试档案）；直接开课、改下一节的块。不用我确认。
- **三条底线**（保护我的数据，代码层面拦）：① 我说过的原话、我的作答记录（`evidence`）只读——它理解错了，原始记录得还在，才能重新理解；② 它改的每一样都留痕（`by: head`、改之前是什么）、能撤销；③ 照样过守卫（不能编我没说过的话、引的题号作答要真有）。
- **总教练的活**：每周整篇重写一份「态势」（我在哪、路线、哪些判断被证实或推翻、下一段的重点），别的 Claude 各拿跟自己有关的一段；排到考试那天的路线（分段、截止日），页面核（截止日在考试前、每段的块真有、按学习速度排得下）；所有判断写成**到期能对答案的预测**（「这块两周内到真题级」「3 月底前 OS 学不完第 3 章」「这次模考 380–420」），到期页面自动对，对了几成记成成绩单，我随时能看；同一类判断错过的，下次带着「上次这样判错了，原因是……」一起写。
- **判断的四种**（2026-11-14 我说「肯定是所有啊」）：每块离真题级差什么；这道错是不是真题的老坑；这周、这个月学什么和为什么；进度够不够、什么时候必须到哪。数字全从页面算好的取（预测分、还能多拿几分、学习速度、真题级），它只写理解和判断，每句挂证据，页面核。
- **我课外说的话也进账**：我跟它说「下个月期末，只有周末有空」，走 A 的话的账，变成要求或关于我的一条，下一节课的老师就读到。
- **上线前先证明**：给它造一把尺子——几个模拟学生，各藏着答案（某块有某个误解、某科学得慢、某块其实早会了），只给它看作答，让不知情的评卷人对照答案打分：抓到几成、有没有编造；达标才接进学习台。尺子跑完挑一个模拟学生的完整报告给我看，我点头再往下。
- 首页放在哪、怎么跟它聊、聊天记录怎么存，做到 B 时先给我看样子再定。

3. **量什么，合格线**：
   - 每句有去处：100%。

   - 说了几次的同一件事并成一条：「直接学新内容」那 5 句并成 1 条，并且后面几次判成「又说了」。
   - 「它眼里的你」：一个全新的 Claude 只读页面下一节英语课会给老师的那一份记忆，写「这是个什么样的学生、上课要守什么、每块卡在哪」；开发那边对原始记录逐条打分（对的、漏的、编的），编的必须是 0；**给我看，我说像我**才算过。
4. **以后每节真课**（做完以后一直量）：这节课我说了第二遍的次数、犯了的要求、过账漏的句子；写进 `results.md` 的一张表，往后看是不是一直往 0 走。
