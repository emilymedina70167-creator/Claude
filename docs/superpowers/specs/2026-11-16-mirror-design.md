# 第十三轮：把 claude.ai 项目搬进学习台（设计）

2026-11-16。第十二轮第 1 批发布以后的第一节真课（英语黑板课，23 分钟）上完，和我当晚商量定的。**记忆这一块和以前的做法冲突时，以这一份为准**（我说的）。

## 1. 起因

那节真课（数据在 `.superpowers/root-next/`，不进 git）：

- 老师每分钟写 577 个字（以前的黑板课 253～473），我第 8 分钟才第一次动笔；讲完一节再甩一组题（9 句每句写三样），我说「量大堆」「不测了，继续」。
- 出第一个字平均 13 秒，开课那一轮 49 秒（教材 8 秒没读完，老师自己取了 5 次）。
- 板是一页排好版的讲义。每块板一个样：一行图例、重点框、要背的粉框、易错框、一处红圈、一个黄色大括号。例句和译文被并成一行、一行蓝字被框切掉，老师都不知道。

我说的：

- 基本就是回到上一代的黑板，做了点设计。学下来比舞台好，但提升有限。
- 我做了足够多的东西，但 Claude 不用，还是甩文字；排版一言难尽。我找不到问题在哪。
- 为什么我说的明明是建议，却总变成固定的？
- 我最初做学习台就是这样想的：**把 claude.ai 项目搬进学习台**，只是它的教学呈现能力提升，后面有教学团队。记忆直接就要 claude.ai 项目的那种能力：一份记忆摘要，根据我的学习反馈改记忆、改教学。
- 让 Claude 自己看见黑板、自己设计。一定不要限制它。

找到的原因（都有那节课的证据）：

1. **老师看不见自己写出来的板。** 它闭着眼写标记文字。舞台第九轮给老师看截图以后，画面的达成率 20/30 → 27/30。
2. **板的样子被记忆里的规则定成了模板**（rule-c1、c2、c3）。那 9 句是照我以前的要求 A-9「练习固定两步：写主干 + 完整翻译」出的。
3. **建议变固定，是模型的倾向加上记忆系统的放大。** 模型会把写进说明的话当指令、记话时顺手概括、不会淡忘。学习台又把「要求」单独一类、每轮全文、放最前、写明冲突时以它为准、没有轻重和期限。那节课里我说「换一个高效点的测验」，老师当场写成了一条永久的要求「优先用点选、选择这类快的形式检验」。

## 2. 要做成什么

学习台 = claude.ai 项目 + 更强的呈现 + 后台的教学团队。

- **记忆照 claude.ai 的做法**：一份会重写的摘要，当背景给老师；我说记住就记；我能看能改。
- **老师看得见板，样子由它自己设计。**
- **学习的账不动**：错题、弱点、掌握、复现、要记的、留着的题和隔天验、预测分。这是「学习体系化」，由页面按作答算，不是给老师的指令。

## 3. 目标、不做、怎样算失败

**目标**

- G1 老师每一轮看到的「关于这个学生」是一份摘要（三科共用一份 + 这一科一份），标明是背景。规则、守则、要求、关于我、失误不再一条条发给它。
- G2 摘要每节课后由后台的 Claude 重写（不是追加）；我课上、对班主任说的要记的当场记成新笔记，下一次重写并进去；我在「管理」里看全文、直接改、能退回上一版。
- G3 老师每一轮带着当前这块板的截图；说明里管「板该长什么样」的话拿掉。
- G4 回话不变慢：截图在后台先拍好；抢跑照样接得上；不加工具轮。

**不做**

- 不做新组件、不做更直接的画法（先看有了眼睛、没了模板以后输出变没变好）。
- 不动学习的账、预测分、考情、教研室、留着的题。
- 舞台课、一问一答的说明一字不动。
- 不删记忆库里任何一条旧数据。
- 原计划第十二轮第 2 批（`work`、`board judge`、备课从终点出发）先放着，这一批上完真课再排。

**做成这样就算失败**

- 摘要又长成一条条规矩（「以后每次都……」「每块板都要……」）。
- 我说的一句话被推广成我没说过的做法。
- 我说过的事实（教材是哪本、目标、底子）在某次重写里丢了。
- 回话变慢。
- 老师还是看不见板，或者看见了说明里仍有话规定板的样子。

## 4. 约束

- 讲课、写摘要的都只能是 Opus 5.5、effort high；后台的调用走 `lane: 'bg'`，回的不是 Opus 5.5 就不写。
- 发给老师的字里提到学生不用「他」「她」。
- 每轮整份说明 ≤ 160 KiB；记忆那一节 ≤ 28 KiB（只许降）。
- `la-kit.js` 自包含；不用 `window.confirm` / `alert` / `prompt`；界面以 iPad 为准。
- 教学不预制。

## 5. 做法的选择

**记忆**

- A 在现有的十六类上修：给「要求」加轻重、期限、情形，降优先级。修的是症状，一条条的规矩还在，过几个月还得再修。
- **B 一份摘要（选了这个）**：claude.ai 就是这样做的。重写而不是追加，旧的自然淡出；是背景不是命令；我能直接看和改。代价：「记了但这一次没照做」会偶尔出现（claude.ai 也这样）；我再说一次它当场照做，摘要里的分量加重。
- C 两套并存让老师自己取舍：老师面前又是两份互相打架的东西。排除。

**老师的眼睛**

- **A 每轮附截图（选了这个）**：舞台现成的拍法（`stage/snap.js`，html2canvas-pro，后台先拍）。一屏一张，最多两张。
- B 把渲染结果写成文字（每段多高、哪里溢出）：现在已经有一部分（版面那一节），老师照样排不好。排除。
- C 写完先自查一轮再给我看（舞台第十轮的做法）：每轮多一次调用，回话变慢。这一批不做。

## 6. 设计

### 6.1 记忆摘要

**数据**：记忆库新加一类 `summary`（记忆摘要，状态类），四条：`shared`（三科共用）、`math`、`cs`、`en`。

```
{ id: 'en',
  text: '……',                 // 摘要全文（Markdown，小标题随内容定）
  at, by,                     // 最后一次重写：什么时候、谁（page 后台的 Claude / me 我自己 / chat 开发）
  v: 7,                       // 第几版
  notes: [{ text, at, by, session?, quote? }],   // 还没并进摘要的新笔记（当场记的）
  history: [{ text, at, by, v }] }                // 以前的版本，最近 8 版
```

上限：`shared` 4 KiB，每科 8 KiB（汉字 3 字节，一科约 2700 字）。新笔记最多 20 条，一条最多 300 字。

**给老师看**（`memory/summary.js` 的 `summaryText`，`digest.js` 调）：

```
## 你对这个学生的了解（记忆摘要）

这是以前的课后整理出来的背景，帮你了解这个学生；它不是规程，怎么教由你当场判断。学生这节课当面说的，照做。

### 三科共用
……
### 英语
……
### 还没并进摘要的新笔记
- 11-16 英语课：……（学生的原话「……」）
```

有摘要时（这一科的或共用的，有一条有字就算），`memoryDigest`：

- 最前面放它，全文，先占预算；
- 规则、守则、关于我、没归纳的失误、「学生的要求」这五节不带；目录里也不列这几类；
- `use: 'all'`（下课那一次、复现课、备课）时，`use: record` 的规则照旧带，放在一节「记录的制度（学生定的：错题、弱点、复现怎么记）」里：它们管的是账怎么记，不是怎么教；
- 「这节课学生说的（只管这节课）」照旧；
- 别的节（上一节停在哪、这一块、以前的课、弱点、错题、掌握、要记的、原文、助手的档案和卡）一字不变。

没有摘要时（新的数据库、自动测试的示例记忆）一切照旧，一个字不变。

根本规则最后一条的后半句（「记忆里『学生的要求』是学生的原话，和上面任何一条冲突时照它」）换成：记忆摘要是背景，不是规程；学生当面说的照做。字节只降不涨。

**当场记**：有摘要时，课堂老师、班主任的记忆块说明换一份短的（`SUMMARY_MEMO_DOC`）：

- 关于这个学生、关于怎么教这个学生，值得以后的课知道的：`know text="…" [basis=say]`。写看到的事实和学生的原话，带上当时的情形；不写成「以后每次都……」。
- 以前的五种（`pref` `ask` `rule` `slip` `lesson`）老师要是照旧写了，页面当成 `know` 收下，不报错。
- 学习的账照旧：`error` `weakness` `review` `position` `recall` `todo` `note` `block`。
- `know` 写进这一科（或共用）摘要的 `notes`；`basis=say` 时页面把学生最近那句原话抄上。和已有笔记说的是同一件事的不收。

**课后重写**（`memory/summarydesk.js`，首页后台，`lane: 'bg'`，Opus 5.5 high）：

- 哪些课要重写：有课堂的轮次、而且上一次重写以后又有新的轮次的课（下了课的、挂着的都算；首页开着说明学生不在课堂里）。两分钟内还有动静的先不动。班主任的对话同理。一次一节，早的先做。
- 给它的材料：现在的两份摘要和新笔记；这节课的记录稿（`debrief.js` 的 `transcriptText`）；学生这节课打的每一句（单列出来，带时间）；课后报告；要拿下的事和状态；这一科最近的课后验结果。第一次（还没有摘要）另给旧的规则、守则、要求、关于我当原料。
- 要它做的（提示词的要点）：
  - 把两份摘要各重写一遍，整份输出；这节课没提到的旧内容，仍然成立就留着，被新证据推翻就改，学生明说不要了就删。
  - 写事实和观察：学生是谁、目标、底子、手边的材料；学生说过的话留原话，带日期和当时的情形；什么讲法对这个学生有效、什么无效，只写有证据的（作答、课后验）。
  - **不把学生的一句话推广成规矩。** 学生明说「以后都……」或者同一件事说了几次，照实写「说过几次」。
  - 不写一节课的流水账、不抄错题（另有记录）。
  - 新笔记都要并进去。
  - 超了上限先压旧的、不要紧的。
- 页面核：是 Opus 5.5；两份都在、不空、不超上限；比上一版短了一半以上不收（防丢）；「他」「她」换成「学生」。不过就不写，记一次试过，试满两次这节课先跳过（下次有新的轮次再试）。
- 写：旧版进 `history`（留 8 版），已并的新笔记清掉（重写开始以后新加的留着），`sessions/{编号}.sum = { at, upTo }` 记这节课并到第几轮。
- 有摘要以后，「话的账」（课上每 20 秒一次、首页过账）不再跑：我说的每一句由课后重写来读。删课不等过账。

**我看、我改**（「管理 → 记忆摘要」）：四份各一个文本框，全文；「存」「看上一版」「退回上一版」；新笔记列在下面，能删。我存的那一版 `by: me`。

**班主任**：有摘要时，说明里「学生的要求」那一节换成摘要全文（四份都给）；记忆块说明换成 `SUMMARY_MEMO_DOC`；回完不再过话的账，班主任的对话也进课后重写。

**第一版摘要**：开发这边（我）读真的记忆库里现在生效的规则、守则、要求、关于我，写出四份，用 `chat` 的身份写进去，原文同时放在 `evals/memory/summary-first/`（私人内容不进 git 的放 `.superpowers/`）。之后每一版由页面重写。

### 6.2 老师看得见板

- 新文件 `class/boardeye.js`：包一层 `stage/snap.js` 的 `createSnapper`，拍当前这块板（连常驻栏）。板一变（写了新段、学生作答、翻板）标脏，静下来 0.6 秒在后台拍；拍整块板、按学生屏幕的宽度，切成一屏一张，最多 2 张，每张长边 ≤ 1280。
- 调用老师时（每一轮的第一次调用、抢跑那一次）：把最近拍的那几张放在图的最前面，学生附的图、手写排在后面；发出去的最后一条消息末尾加一句「[画面] 前 N 张图是页面拍的学生现在看到的这块板（从上往下一屏一张）」。板比两屏长写明后面没拍。拍不出来就不附、不提。平台一次最多几张图照 `maxImages`，学生的图优先，板的图让。
- 抢跑：抢跑那一次带同样的图；真发的时候只要学生没附图、没新手写，指纹一样就接上（现在是有图就不接）。
- 第一轮（板还是空的）不拍。只读翻看不拍。
- 说明：
  - 黑板指令里加一小节「你看得见板」：每一轮附着截图；板长什么样由你设计；看到排坏了（挤在一起、被切掉、重点不突出）就改。
  - 「一块板放多少」那一节只留事实：一轮最多一块新板（页面的限制）、板可以比一屏长、学生能调字号、横屏左图右文。「先讲透、不要压缩、不要甩好几块板」这些话拿掉。
- 记录：每轮的 `cost` 里记 `eye: N`（附了几张）。

### 6.3 首页后台的顺序

`backTick`：有摘要（或者记忆库里没有任何旧的规则、要求）时，先做课后重写，不做话的账；否则照旧。别的后台步骤（报告、归类、复盘、留题、助手）不动。

## 7. 以前的记忆能力里留下来的

- **证据**：每一次作答、每一句话都记着，重写摘要读的就是它。
- **每一句都有人读**：换了读的人（课后重写），`sessions.sum.upTo` 记着读到哪。
- **版本和退回**：摘要每一版都留着（claude.ai 没有）。
- **学习的账**和按这一块挑着带的做法（这一块的错题、弱点、掌握先装）。
- **只读的查**：老师的 `memory_read`、班主任的 `search_chats`、开课时页面先放好的以前的课。
- 守卫、体检、出错记录、写库的出口照旧。

停用的（代码留着，有摘要时不走）：话的账、「我的要求」这一类的写入、失误并进守则、规则接在根本规则后面。

- 管记录的那 12 条规则（`use: record`）照旧在下课、复现、备课时带。

## 10. 风险

- **摘要也会长成规矩。** 写摘要的也是模型。挡它的：提示词里那一条、每次整份重写、我看得到改得了、上限。真课以后读每一版。
- **重写丢东西。** 短了一半以上不收；留 8 版；旧的规则一条没删，随时能对照。
- **截图拖慢 iPad。** 后台拍、静下来才拍；量出来慢就降分辨率、只拍一屏。
- **看得见也不设计。** 那就说明笔是问题，下一批给它更直接的写法。
