# 外部主 Claude 的学习台（第十五轮设计）

2026-11-17 写，给学生看过再动手。

## 1. 为什么改

第十四轮把「claude.ai 项目」搬进学习台：页面里调用的 Claude 当老师、班主任、记忆的主人。做完以后学生说了两件触及核心的事：

- **学习本身的质量**：学生原话「重要是学习本身质量问题，Claude 能知道多少东西，anthropic 做的记忆能力就是会让人放心」。页面里的 Claude 一次调用最多 256 KiB 文字（平台写明，`sample.d.ts`），一轮最多连着调 7 次工具，搜索只按字找；记忆是我们自己搭的，数据多了以后学生不放心。
- **AI 教学该抓长处**：学生原话「ai 教学在带着学、边教边学这一块就是有劣势，在实时响应这一块就是做不到很好，那在 ai 教学的长处，为什么不去抓住？」——AI 的长处是课前把学生的全部记录、这一块的真题想透，答案能用代码验算，课后能慢慢完整地分析，不嫌烦。

外部能力测了一遍（`docs/external-probe.md`，结果在学习台 `meta/probe-external`，2026-11-17）：

| 量了什么 | 外部（claude.ai 项目对话） | 学习台里面 |
|---|---|---|
| 一条回复里连着调工具 | 20 次没被拦，平均约 4.5 秒一次（含它想下一步） | 第 7 次以后平台关掉工具 |
| 读学习台的数据 | 能，`class_turns`、`evidence`、整节课都读得完 | 能 |
| 看学习台里的图 | 能，教材原页图连手写批注都读得出 | 能（页面直接给） |
| 记得学生 | claude.ai 记忆（记得学生的背景、在学哪一讲）、搜以前的对话、自己的记忆文件区 | 我们搭的笔记本 |
| 按意思搜 | 项目知识能（但那 14 个 PDF 文字层是乱码） | 只按字找 |
| 跑代码、子代理、网页、定时任务、对话里画图 | 都有 | 没有 |
| 写学习台 | 每一轮第一次写要学生点一次「Allow once」，没有「一直允许」；删要再确认 | 不用点 |
| 被页面叫起来 | 不能：学生发一句它才动 | 能：学生一作答页面就叫它 |

所以这一轮：**外部主 Claude 当主讲、拍板、管记住学生；学习台负责呈现、即时判分、记录、算事实；页面里的 Claude 当助教**，做「不用学生开口、马上要做、要自动做」的事。学生原话：「整个教学团队的价值仍然在吗？我觉得这个我依然觉得是很重要的」——在，分工按长处重排。

## 2. 目标、不做的、做坏了的样子

**目标**

1. 外部主 Claude 在学习台的黑板上上课：板上的组件、即时判分、标注、让图动、作答记录、课后报告，和现在课堂里的一样好用。
2. 一个来回里学生只做两下：在对话框里发一句、最多点一次「允许」；外部一轮只写一次学习台。（实测：一轮里第一次写要点一次，同一轮后面的写没再弹，这一条第 1 批先实测确认。）
3. 外部开工读得到它要的一切（学生的项目指令、笔记本、上一节的要点、夜班的底稿、页面算的事实），不用学生转述。
4. 教学团队四个位置：练习教练、记录员、夜班、板边助教（第 4 节）。
5. 每个来回「学生交了 → 新板出现」隔几秒，页面自动记，内外两条路能比。

**不做的**

- 不删学习台里面那条路（页面里的老师、第十四轮的项目 Claude）。数据、代码都留着，学生以后定。
- 不把实时黑板旧代码照搬回来（`archive/` 里的 `live.js` 那一套：一段一段写、`meta/now` 汇总、对话框里说话）。
- 不让外部发布新的 artifact：一切照旧在学习台这一个里。

**做坏了的样子**（技术上能跑也算失败）

- 学生每做一步都要回对话框点好几下、等很久，比在里面上课累。
- 两个老师抢话：外部讲着，里面的助教换了讲法、改了板。
- 外部的记忆和学习台的笔记本各说各的，学生在一边说过的事另一边不知道。
- 夜班、记录员写的底稿替主 Claude 下了结论（「你线代不行，先补 X」），主 Claude 被带偏。
- 外部写错一条格式，页面静默不认，学生以为记下了其实没有。

## 3. 怎么搭（选了哪条路）

考虑过三条：

- **A. 拿回旧的实时黑板**：外部一段一段写 `steps`，页面画；学生说「好了」外部再去读 `meta/now`。现成，但一轮要写好几次（每次都可能弹允许），课堂里后来长出来的东西（预案、拍子、要拿下的事、老师看得见板、标注时间线、草稿、信心）全都接不上，等于两套黑板。
- **B. 外部开学习台现有的课堂引擎（选这条）**：外部每一轮把它的整段回复（和页面里的老师输出一模一样的写法：说的话 + ```` ```board ```` 块）写成学习台里的**一条**文档；页面把它当成老师这一轮的回复，走课堂原来的那条路（`classroom.js` 的 `finishTurn`）画板、执行标注、建预案、记 memo / note。学生作答以后，页面把这一轮的现状写成一条文档，外部读它。一轮一次写、一次读，课堂已有的东西全部能用，外部和页面里的老师用的是同一份写法手册。
- **C. 外部每节课发布自己的 artifact**：违反「一个学习台」，数据和记录都散了。不考虑。

选 B 的原因：一轮只写一次正合「Allow once」；不另造一块板；以后内外两个老师能在同一块板上接力。

## 4. 各自做什么

| 谁 | 做什么 | 什么时候动 |
|---|---|---|
| **外部主 Claude**（claude.ai 项目对话，学生选的模型） | 上新课、讲透、看学生作答下判断；定计划（今天做什么、复现哪几组、盯哪个错法）；跟学生谈情况；是学生情况分析的唯一判断者 | 学生在对话里发话 |
| **学习台（代码）** | 画板、即时判分、记作答、算事实（掌握参考、预测分、真题统计、到期）、存截图、记来回时间 | 一直 |
| **练习教练**（页面里的 Claude，课堂引擎现有的老师） | 照主 Claude 写的计划带学生练、复现：错了当场追问、换一道、拆一步 | 学生在首页点开主 Claude 排的练习 |
| **记录员**（页面里的 Claude，后台） | 每节课下课后（外部上的、教练带的都算）读完整节作答，写一页这节课的要点给主 Claude：做了什么、错在哪一步、哪种错法、哪里没做完；每条带出处。只写事实不写结论 | 下课后首页后台自动 |
| **夜班**（每晚的定时任务，云端 Claude，能跑代码） | 照主 Claude 的计划备明天的东西：出新题并用代码和页面引擎验算；对这一块的真题和考点；写一页「底稿」：这一周的事实和趋势、到期的、异常的，每条带出处；可以写「可以怎么排」的建议，但标明是建议 | 每晚 |
| **板边助教**（页面里的 Claude，第二批再做） | 外部讲课时，学生在板上做错、卡住，当场给一句提示；只在主 Claude 写的那块板、那一题的范围里，不改板、不换讲法；给过的提示记下来，主 Claude 下一轮看得到 | 学生作答以后，主 Claude 回话之前 |

首页的「班主任」（第十四轮的 `#chat`）：外部主 Claude 就是班主任而且更强，首页那一页收起来，改成一行「去外部对话」的说明；代码和以前的对话留着。**这是我的判断，学生核。**

**共用的东西**：同一本笔记本（`notebook`）、同一份项目指令（`meta/instructions`）、同一个学习台的数据。外部的 claude.ai 记忆管「它对学生这个人的了解」；教学上要紧的事，外部写进学习台的笔记本，里面那几位才看得到。

## 5. 外部的板：数据怎么走

新的一种课 `kind: ext`（外部主讲的黑板课）。

- **开课**：外部写 `sessions/{编号}`（`kind: ext`、`block`、`title`、`space`、`status: open`、`startedAt`），可选资料包 `sessions/{编号}/pack/main`。学生在首页「上课」那一行看到这节课，点进去是黑板。编号照现有的 `c-YYYYMMDD-n`；页面不替它开。
- **外部的一轮**：写 `sessions/{编号}/ext_in/{三位数序号}` = `{ seq, text, model, at, after }`。`text` 和页面里老师的回复同一种写法（说的话、`board new/add/replace/hide/show/pin/mark/figure/react/why/aims/note/memo` 块）；`after` 是它读过的现状序号（下一条）。页面订阅这一类，新的一条到了就照课堂原来那条路画上去、执行，记成这一轮的 `class_turns`（作者记 `ext`）。
- **学生这边的现状**：学生作答、打字、附图、Pencil 写字、点「交给老师」时，页面照现在给老师拼的那一份（作答行、没交的草稿、要拿下的事的状态、写法错误、黑板现状），写成 `sessions/{编号}/ext_out/{序号}` = `{ seq, text, shots: [asset 编号], at }`。截图存进学习台的图片里，外部用读图的工具取。
- **什么时候写 `ext_out`**：和现在一样，作答 1.5 秒合并一次就写一条（序号往上加）；外部读的时候读它上一次读过的序号（`after`）以后的全部。预案（`board react`）照旧在页面当场接。
- **「交给老师」**：板下面一个按钮。点了：先写好 `ext_out`，再把一句短话复制到剪贴板（「好了，现状在 ext_out/007」加作答的几行），学生在对话框里粘贴发出。外部收到就去读那一条（或者直接用粘过来的几行，省一次读）。
- **写法错误**：现在页面里的老师写错组件，页面会叫它当场重写；外部叫不来，就把错误写进下一份 `ext_out` 的最前面，板上那一段照旧标红。
- **模型**：外部写 `model`（它自己报的模型）。页面在板顶照实标。硬性规定「讲课的只能是 Opus 5.5」在外部怎么算，见第 9 节第 1 条。
- **一轮只写一次**：外部这一轮要改的记忆（memo / note 块）都写在同一条 `text` 里，页面拆出来执行，所以学生每轮最多点一次「允许」。别的数据（`meta/today`、复现组、题库）外部单独写，记一条 `journal`（第 6 节）。
- **来回时间**：页面记「`ext_out` 写好的时刻 → 对应的 `ext_in` 到达的时刻」，下课写进报告；页面里的课照旧记 `cost.first`，两边能比。

## 6. 外部老师的手册（`CLAUDE-PROJECT.md` 重写）

学生的项目指令只有一句「先读学习台里的 `CLAUDE-PROJECT.md`」，所以手册就是外部的全部说明。只写事实和写法，不写怎么教：

1. 学习台是什么、在哪；开工先读：`meta/instructions`（学生写的项目指令）、`notebook` 里 pin 的文件、记录员和夜班最新写的那几页、「学习台里有什么」（页面每次打开写一份 `meta/catalog`，就是里面那个 Claude 读的同一段）。
2. 外部的板：第 5 节的读写格式、一轮只写一次、交给老师的那句话长什么样。
3. 组件写法：学习台里的 `components/*.md`（已有），课堂指令的写法（`PROTOCOL_DOC` 那一段，要搬进手册）。
4. 各类数据的格式（第七节已有，补上 `ext`、`ext_in`、`ext_out`、`meta/today`、`notebook` 的 doc_id 是 path 的 base64url、日期按上海时间）。
5. 改学习台的数据：先读那一条，写的时候记一条 `journal/j-…`（`{ at, by: 'chat', path, op, before, after }`），学生在「Claude 改过的」里看得到、能撤销；删除要带确认。
6. 教学团队：练习教练、记录员、夜班、板边助教各在哪写、写什么，主 Claude 怎么交给它们（练习写进 `meta/today` 的 `drill` / `review` 项；夜班读 `plan/…` 的计划，第 7 节）。
7. 第一节「只做开发」那句删掉。

## 7. 团队之间怎么交接

- **主 Claude → 练习教练**：写 `meta/today` 的一项（现有格式：`review` 带复现组编号、`drill` 带题号；新加 `kind: coach`：`{ block, why, focus（要盯的错法、原话）, ids（可选的题）}`）。学生在首页点开，页面开一节页面里老师带的课（`kind: class`），资料包里放主 Claude 写的 `why` 和 `focus`。
- **记录员 → 主 Claude**：每节下课后写笔记本 `记录/YYYY-MM-DD-{课号}.md`（pin 由主 Claude 自己定），一节一页：每条事实后面带出处（证据编号、第几轮）。第十四轮的「课后那一轮」改成这个固定岗位：提示里写清这是学生定的岗位和产出，**只写事实和趋势，不写结论和建议**。
- **主 Claude → 夜班**：主 Claude 想让夜班做什么，写进笔记本 `计划/夜班.md`（怎么写由它定）。夜班照它做；没写就只做底稿。
- **夜班 → 主 Claude**：每晚写笔记本 `底稿/YYYY-MM-DD.md`（事实、趋势、到期、异常，每条带出处；「可以怎么排」单独一节，标明是建议）；出的题写 `drills`（照现有的验题：页面画不出来的标 `broken`）。定时任务的提示词换成夜班的岗位说明（`docs/lab-prompt.md` 重写；**改定时任务之前给学生看**）。
- **板边助教**（第二批）：外部那一轮的 `text` 里可以写 `board coach target=题号 …`，说明这一题助教能不能当场给提示、给到哪一步为止（不写就不给）。学生做错时页面叫页面里的 Claude 写一句，写在那一题下面，标「助教」，记进下一份 `ext_out`。

## 8. 分批

1. **外部的板**：`kind: ext`、`ext_in` / `ext_out`、交给老师、截图、写法错误、来回时间、首页列这种课、以前的课里能翻看；手册重写；`meta/catalog`。e2e 加一段：模拟外部写三轮、学生作答、交给老师、下课、报告。做完发布，学生用外部上一节真课。
2. **团队**：记录员（替换课后那一轮）、练习教练（`meta/today` 的 `coach`）、夜班的提示词（学生看过再改定时任务）、首页的班主任收起来。
3. **板边助教**。
4. **试一下**：把学习台里转写干净的教材文字放进 claude.ai 项目知识（外部有写项目文件的工具），看按意思搜好不好用；好用就把真题、考点画像也放进去。

## 8.1 动手时要照顾到的（建造者读过以后补的，我定的）

- **页面现在不认 `kind: ext`**：`session.js` 的 `kindOf` 不认识的一律当 `class`，开课页就会去抢跑调用页面里的老师。要改：`kindOf`、`schema.js` 里 `sessions.kind` 能取的值、`after.js` 的 `isClass`、`TEACH_KINDS`、`oldKind` 都认 `ext`。
- **ext 课里关掉页面去叫老师的那几处**：`flush` 最后不调 `converse`，改成写 `ext_out`；抢跑、对话压缩、停久了提醒、写错了叫它重写都不开（写错的放进下一份 `ext_out`）。
- **外部写的字段别被页面盖回去**：`updateSession` 现在拿本地那份整份写回，会把外部写的 `status: closed` 盖掉。ext 课里页面只合并自己那几个字段（花费、换块），写之前先读最新的。
- **开课的字段由页面补齐**：外部只写第 5 节那几个字段；页面第一次打开这节课时补上 `createClass` 平时写的（`subject`、`aims: []`、抄资料包），机械的活归页面。
- **同一条 `ext_in` 只执行一次**：执行完页面在那一条上写 `done: { at }`。打开时没 `done` 的按序号补执行，有 `done` 的照 `class_turns` 放回（和现在刷新一样）；两台设备同时开着时，后到的看见 `done` 就只放回不执行。
- **ext 那一轮的 memo、note 用课堂老师的身份（`class`）执行**，守卫照课堂的规矩核原话；学生在对话框里说的话由外部抄进那一轮（第 9 节第 1 条），守卫才核得到。

## 9. 要学生定的

1. **上外部的课时，学生的话在哪里说**：对话框里（外部直接看到，claude.ai 的记忆也记得），还是学习台的输入框里（页面记下来，但每句都要再到对话框里发一下外部才动）。我的建议：在对话框里说；外部每一轮把学生这一句原话抄进 `ext_in` 的 `said`，页面记成学生说的话（证据），记录员、守卫、以后的课都看得到。学习台的输入框在外部课里收起来，板上作答照旧。
2. **学生几天不去对话框的时候，首页「今天」谁排**：外部只在学生发话时才动。我的建议：主 Claude 在笔记本里写一份长期的计划（`计划/…`），夜班每晚照这份计划写第二天的 `meta/today`；没有计划时首页只列事实。
3. **外部讲课的模型**：硬性规定「课堂里讲课的只能是 Opus 5.5 high，不是就整轮作废」。外部报的模型页面核不了（只能信它写的 `model`），学生在 claude.ai 里自己选模型。我的建议：外部这一轮写的不是 Opus 5.5 时页面照样画，但板顶标出来；学生要的话改成作废。

我自己定的、学生看的时候核一下：首页的班主任收起来（第 4 节）；记录员、夜班的底稿只写事实不写结论（第 4、7 节，照学生前一条说的分层）；学生用 iPad 分屏，一边 claude.ai 一边学习台（学生说过「分屏并压缩到最小，这个不是问题」）。

## 10. 留给动手的人

- `ext_in` 到达时页面要等学生不在写东西（照 `quiet.js` 的规矩）再翻板；`ext_out` 的拼法尽量复用 `buildSystem` 里黑板现状那一段的函数，不另写一套。
