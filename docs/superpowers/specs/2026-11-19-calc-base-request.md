## 计划 3：高数、概率的式子底座

外部主讲 2026-11-19 写的任务书。**这不是最终计划**：先读完、查代码、想清楚，在这条的 `plan` 字段写最终计划（改哪些文件、多大、和现有的冲突、哪条不该做），学生拿给外部看，同意了才动手。

## 为什么
数一 150 分里高数约占 56%。学生高数已经过了一轮，强化阶段要用学习台的二类检验（`board check`）测高数。现在的式子底座是给线代做的，高数基本用不了。外部 2026-11-18 查到的：
- 学生能写的函数只有 `FORMULA_FUNCS = tr det rank inv T sqrt abs dot norm choose fact`（`kit/src/formula.js`），写不了 sin、cos、e^x、ln、arctan……，`ln(1+x)`、`e^x sin x` 这样的答案判不了。
- `expr.js` 里的 `sin` 是按角度算的（`sin: (deg) => Math.sin(deg*π/180)`），拿来做微积分是错的。
- 求极限、求导、求积分、泰勒展开都没有逐步判的办法。

这一批只搭底座（能写、能判），不做高数的探题类型和画面（那是以后外部和学生单独设计的事）。做完以后，现有的 `answer`、`derive mode: do`、`practice custom`、检验的 `construct` / `claim` / `discriminate` 的 `result` / `locate` 的 `fix` 都应该能直接写高数的式子。

## 要的

1. **学生能写初等函数**：sin cos tan cot sec csc、arcsin arccos arctan、ln log（底数）、exp 和 `e^x`、π、幂 `x^a`（含分数、负数指数）、`sqrt`、`abs`、阶乘、组合数；写法宽松（`sinx`、`sin x`、`sin(x)`、`e^{2x}`、`ln(1+x)`、`x^(1/2)`、乘号省略），和现在 `normalizeFormula` 的习惯一致；输入框的公式预览跟着认。
2. **弧度**：给学生写、给外部写答案的地方（formula、answer、derive、practice、检验、graph 的 plot）一律弧度。现在按角度的用处（比如 `rot(deg)`、舞台 / scene 里的旋转）先全部查出来列进 plan，它们照旧角度不动；不许因为改弧度把旧课件的画面弄坏（示例页检查、e2e 照过）。
3. **函数式判相等**：含 x（以及外部声明的其他自变量、参数）的式子，在定义域里随机取点比（点数、误差、避开无定义的点）；外部能写取值范围（`domain: x in (0, 1)`）；两边定义域不一样时照外部写的范围比。不定积分判 「差一个常数」（要不要 `+C` 外部能选）。
4. **微积分的核法**（给 answer / 检验用，页面自己算，不调 Claude）：
   - 导数：学生写的 f′ 和数值求导比；高阶导也行。
   - 不定积分：学生写的 F 求导后和被积函数比。
   - 定积分、反常积分：数值积分核答案的值。
   - 极限：数值逼近核值（含∞、不存在）；算不稳的照实报「页面判不了」，不猜。
   - 等价无穷小、阶：「当 x→0 时 f 和 g 等价」「f 是 x 的几阶」按数值比值核。
   - 泰勒展开：学生写到第 n 阶的多项式，逐项核系数，哪一项错报哪一项。
5. **derive 逐行推导能推高数**：`derive mode: do` 的每一行除了「和上一行相等」，还能写成极限的一步（比如一行写 `lim x->0 …`，核「这一行的极限和上一行一样」），这样等价无穷小替换在加减里替换错了（极限变了）就会被核出来；写法、怎么判你定，在 plan 里写清。目标是学生在 derive 里一行行求极限、求导、分部积分，错在哪一行页面当场指出。
6. **概率的小工具**：常见分布的密度 / 分布函数 / 期望方差在答案里能用（现在 graph 里有 normpdf、poissonpmf、exppdf，查一下哪些给学生写的地方还不认）；二维积分（求概率、期望）的数值核算要不要做、多大，在 plan 里说。
7. **预检认得**：`ext-check --lint` 查这些新写法（函数名、定义域、答案算不算得出）。
8. **手册**：第三节各组件的写法里加高数的例子（等价无穷小求极限的 derive、不定积分的 answer、泰勒系数的 answer）。

## 边界
- 只写事实和写法，不写怎么教。
- 不改现在线代的判法（非交换、严格模式、`kE` 不当数这些照旧）；矩阵和函数混在一起的式子（比如 `e^{At}`）这一批不做。
- 判不了的一律报「页面判不了」（`ok: null`），不许猜成对。数值核算的取点、误差写进手册。
- 和计划 4（408、英语的二类检验，外部在和学生设计，会在另一个 Claude Code 对话里做）可能同时改仓库：这一批尽量只动 `formula.js`、`expr.js`、`exact.js`、`anscheck.js`、`derivedo.js`、`mathinput.js` / `formulainput.js` 和新文件；`kit/src/check/` 里只在必要时加入口。自己的分支，合之前 rebase、跑完测试。
- 验收：外部用 answer 写「求 ∫ x e^x dx」（学生写 `xe^x-e^x+C` 对、写 `xe^x+e^x` 错）、「求 lim (x→ 0) (tan x − sin x)/x³」（=1/2）、「写 ln(1+x) 展开到 x³」；用 derive 写一道「加减里乱用等价替换」的极限，错的那一行被指出来；旧课件示例页画面不变。
