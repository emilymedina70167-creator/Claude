# 视觉交互组件：按考纲量覆盖度，补到「完全辐射」

2026-11-20。学生要的：高数、线代、概率、英语语法、数据结构五门课，视觉交互类组件的数量和质量再进化一轮；动手之前先看有没有空间。学生定的标准（原话）：「一个坐标能力组件可以辐射到很多知识，但是有些是完全辐射，有些只是勉强够用，我不要勉强的」「我需要辐射完全的同时，质量也够强」。

## 一、标准

**每个值得用图的考点都要是完全辐射。勉强够用的和做不到的算同一类：缺口。**

「完全辐射」五条，缺一条不算：

1. **页面自己算**：主讲只写题目里的量，过程和结果不用手算（切线的斜率、黎曼和、分位点、交线都由页面算）。
2. **学生能动手**：在图上拖、点、填，不只是看。
3. **当场判**：学生做的对不对页面知道，记成作答、报给主讲。
4. **画面清楚**：iPad 上不叠字、不误导，和张宇、王道、田静的讲法对得上。
5. **写起来不绕**：主讲几行就能写对，不用拼凑技巧。

纯计算、纯记忆的考点不硬配图（求导法则、积分技巧、判别法的计算、限定词），这类不算缺口。

范围：学习台里的考点树只有 408（`syllabus`，数据结构 72 个节点）；数学一、英语一的大纲没入库。数学按数学一大纲（凭模型的了解）加张宇 1000 题的章目录（高数 18 章、线代 6 章、概率 6 章，学习台的教材 B43）；英语语法按课程地图里田静《句句真研》的 8 章（`curriculum` 的 `EN-L1`～`EN-L8`）。

## 二、怎么量的

每门课按考点写探针：用现有组件把「理想的演法」真写出来，`node tools/check-lesson.mjs` 在 iPad 竖屏、横屏渲染，看截图。探针和截图在 `.superpowers/audit-visual/{hm,la,ps,en,ds}/`（不进 git）：高数 7 个文件 38 个组件，线代 5 个文件 36 个，概率 6 个文件 26 个，英语 5 个文件 21 个，数据结构 13 个文件约 80 个。

评级：`A` 完全辐射；`B` 够得着但勉强（写明差在哪条）；`C` 做不到；`N` 不需要图。

## 三、结论

| 课 | 档 | 一句话 |
|---|---|---|
| 高数 | 很不足 | 需求高的考点几乎没有一个 A。函数图画间断点会连线、超出窗口会压成平线、`show` 按角度算三角函数；切线、黎曼和、级数、区域、曲面全靠主讲手算或者做不到 |
| 概率 | 不足 | 正态、二项的基本图是 A；三大抽样分布、分位点、二维随机变量、抽样模拟、事件和贝叶斯是 B / C |
| 英语语法 | 中等空间 | 连线、断句、时间轴、拨时态是 A；长难句的层次（最要紧的一块）画出来看不清，句子变换看不到「谁挪到哪」 |
| 线代 | 够用 | 绝大多数 A；剩含参行列式、三个平面的位置关系、基变换的坐标分解几处 B，加几处画面毛病 |
| 数据结构 | 超出 | 大纲的算法全有专门的演示，能先猜、填表、认错法、当练习题、在舞台上自己动手；只剩存储结构的对照、双端队列等零星几处 |

## 四、要做什么

按「一样东西能盖住多少行」排，分六批，每一批自己能发布。前一批做完、发布，再写下一批的执行计划（后面的批要用到前面做出来的东西）。

### 第 1 批：坐标图 `graph` 做成一元微积分和一维概率的底座

盖住高数表里 16 行、概率表里 8 行。

- **画对**：间断点自动断开，跳跃间断点两头画空心 / 实心点（哪头等于函数值哪头实心）；超出窗口的裁掉，不压成平线；振荡的地方加密采样；标签互相让开。`show` 里的三角函数改成弧度（和曲线一致）；`text` 的字用板书的颜色。
- **页面自己算**：`f(x) = 式子` 定义函数，后面写 `f(x)`、`f'(x)`、`f''(x)`（符号求导）；`sum(k, 1, n, 式子)`、`prod(…)`、`int(式子, t, a, b)`；`roots(式子, x, a, b)`。新命令 `tangent`（切线）、`secant`（割线）、`riemann`（黎曼和矩形，左 / 右 / 中点）、`area`（两条曲线之间）、`dots`（数列、部分和的点）。
- **概率的函数**：Γ、B 函数，χ² / t / F 的密度、分布函数、分位点，正态的分位点，二项、泊松的分布函数，几何、超几何分布。
- **学生动手、当场判**：点沿着曲线拖（`drag on=f`）；`goal`（拖到、调到算做到，和 `scene` 一样是关卡、记作答）；`pick`（在图上点出极值点、拐点、间断点……页面判）；`after`（做到以后才显示）。

### 第 2 批：平面上的二元内容，仍然在 `graph` 里

## 五、做的时候守的线

- 不约束主讲怎么教：手册里只写「能做什么、写法、页面会怎么做」，不写「应该」。新组件的说明照 `tests/manual-words.test.js` 的规矩。
- 能写成纯函数的放在不碰 DOM 的模块里，`node --test` 测；画面在 iPad 两种尺寸、紫藤的白天晚上两种风格下看截图。
- 手册里每个例子照抄就能用；写错的在页面上报出来。
- 判错要比判对更有把握：页面拿不准的（数值上差一点、函数在那一点没定义）记 `ok: null`，不判错。
- 每一批：`npm test`、`npm run build`、`npm run check:pages`、`npm run e2e` 都过，升版本号，记进 `CLAUDE.md`，合进 `main`，重新发布学习台。
- 验收的尺子就是第三节的表：每一批做完，把它盖住的行重新写探针、重新渲染，逐行改评级；不到 A 的不算做完。
