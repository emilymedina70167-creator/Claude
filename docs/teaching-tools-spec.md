# 需求：给课堂里的 Claude 更多教具（提升教学能力上限）

给 Claude Code 的实现说明。课堂模式（`docs/classroom-spec.md`）已经实现：课堂里的 Claude 一边说话一边用组件库写黑板。这一份在它上面加「教具」：让它能像站在黑板前的老师一样指、圈、演示、算，而且算得准。

## 0. 要解决什么

课堂里的 Claude 只能输出文字。黑板上出现的一切，都是页面读了这段文字后用组件库画出来的。所以它的教学能力，上限就是组件库给它的「手」：

- 老师讲秩一时，把三行逐行框起来、旁边写「×(−1)、×2、×1」；讲迹时把主对角线框出来；推 $A^2$ 时把中间的 $\boldsymbol\beta^{\mathrm T}\boldsymbol\alpha$ 圈起来。课堂里的 Claude 现在只能写静态公式，做不出「看这里」。
- $B$、$B^2$、$B^3$ 里那两个 1 往右上角「退」，分块矩阵要画分块线、把子块当元素算：这些是「动」的过程，现在只能给结果。
- 它现场改数出题，算错了就会把错的答案写上黑板。学生分不清是自己错了还是题错了。

两条做法：

- **精心做好的工具**（这一份的主体）：要互动、要判分、反复用的，做成组件和指令，页面负责画、算、自检。
- **让 Claude 自己手搓**（第三批）：偶尔用、不用互动的示意图，开一个受约束的口子。

原则不变：写错要在页面上报出来、让它重写，不能静默失败；能写成纯函数的放进不碰 DOM 的模块，用 `node --test` 测。

## 1. 第一批（这次实现）

### 1.1 板书标注：`board mark` / `board unmark`

对黑板上**已经有的东西**做标注。一轮里可以先 `new` / `add` 再 `mark`（按出现顺序执行）。

````
````board mark target=b5 term=mid note="1×1：一个数"
````

````board mark target=m-rank1
row 1 note="×(−1)"
row 2 note="×2" color=pink
row 3 note="×1"
````
````

- 开头那行是一条标注；块里每行再写一条（`target=` 不写就沿用开头那行的）。
- **target**：段的 id（`b5`、常驻栏的 `k1`）或组件的 `id:`。
- **标哪里**（不写就是整个 target）：

| 写法 | 标的是 | 用在 |
|---|---|---|
| `term=名字` | 公式里用 `\hl{名字}{…}` 包起来的那一项 | 任何公式 |
| `row=2`、`col=3`、`diag`、`entry=2,3`、`block=1,2` | 矩阵的第 2 行 / 第 3 列 / 主对角线 / 一个元素 / 一个子块 | `matrix` 组件（几个矩阵时加 `of=名字`） |
| `step=2` | 第 2 步 | `steps` |
| `label=Ax`、`item=4` | 图里标签是 Ax 的那个东西 / 第 4 条命令画的东西 | `scene`、`graph` |
| `at=[1, 2]` | 图里坐标 (1, 2) 那个点 | `scene`、`graph` |

  `row 2` 这种省掉等号的写法也认。
- **style**：`circle` 圈、`box` 框、`underline` 下划线、`highlight` 涂底色、`strike` 划掉（约去的项）、`arrow` 箭头指过去（配 `note`）。不写时：项、元素、点用圈；行、列、子块、整个组件用框；对角线用斜着的长框。
- **color**：`yellow`（默认）`pink` `blue` `green` `orange` `purple` `red` `white`，含义和图里一致。
- **note**：旁边写的一句话（Markdown + `$公式$`，要短）。`side=right|left|above|below` 指定写在哪边，不写自动选。
- **id**：`id=m3` 起个名字，以后好撤；不写页面自动编 m1、m2……
- 撤：`board unmark id=m3`、`board unmark target=b5`（这个目标上的全部）、`board unmark all`。
- 标注留在板上，直到撤掉、或者所在的段被 `replace` / `hide`。翻板走了再翻回来还在。刷新后照课堂记录（`class_turns` 的 `boardOps`）重放回来。
- 找不到目标（id 写错、`\hl` 的名字不对、矩阵没有第 4 行……）：这条不执行，「[系统] 指令 mark … 没执行：原因」告诉它，和 figure 一样。
- 黑板现状里每段下面列出现有的标注（id、标的什么、注释），它知道板上已经圈了什么。
- 画法：粉笔手绘感的 SVG（略带抖动的线），第一次出现时一笔画出来（减少动态效果时直接出现）；注释是 HTML（能写公式），垫一层和黑板同色的底，压在内容上也看得清。不挡点击（`pointer-events: none`）。尺寸变了（转屏、字体加载、翻板回来）跟着重新量。

公式里的两个宏（KaTeX，`trust` 只放行 `\htmlData`）：

- `\hl{名字}{…}`：给一项起名字，`mark term=名字` 用。名字只用字母、数字、`-`、`_`。本身不画任何东西。
- `\chalk{颜色}{…}`：这一项直接用彩色粉笔写（静态的，随风格变色，比 `\color` 好）。

KaTeX 自带的 `\boxed`、`\cancel`、`\underbrace{…}_{\text{…}}` 照常能用：写的时候就要圈、要划的，直接写进公式；讲着讲着才要指的，用 `mark`。

### 1.2 会动的矩阵：`matrix` 组件

```matrix
id: m-rank1
title: 三行成比例
let A = [[-1, -1, 2], [2, 2, -4], [1, 1, -2]]
matrix A label="A ="
mark row 1 note="×(−1)"
mark row 2 note="×2"
mark row 3 note="×1"
```

字段：`id`、`title`、`q`（上方说明）、`note`（下方备注）、`link`（绑定 steps）。命令（一行一条，按顺序排成一行公式）：

| 命令 | 作用 |
|---|---|
| `let 名字 = 表达式`、`slider 名字 最小 最大 = 初值 step=1 label="k" play` | 和 `scene` 一样。滑块按 `step` 取整，`B^k` 这类整数次幂可以拖着看 |
| `matrix 表达式` | 画出它的值：矩阵、向量（列向量）、数（不带括号）。精确分数。可选 `label="A ="`（前面的 TeX）、`name=A`（给 mark 用；表达式就是一个变量名时默认用它）、`from=k` / `until=k` |
| `tex 公式` | 矩阵之间的一段公式：`tex =`、`tex \times`、`tex +` |
| `split rows=2 cols=1` | 分块线：第 2 行后面、第 1 列后面各画一条（可以写 `rows=1,3`）。管最近的那个矩阵，或者加 `of=名字` |
| `mark …` | 和 `board mark` 同样的写法（`row` / `col` / `diag` / `entry` / `block`，`note`、`color`、`style`），画出来就带着。可加 `from=k` / `until=k` |
| `product A B` | 画出 $A$、$B$ 和 $AB$，结果里的数可以点：点哪个，就高亮 $A$ 的那一行和 $B$ 的那一列，下面写出「对应相乘再相加」的式子 |

- 标签和 `tex` 里可以用 `\calc{…}`（见 1.3），跟着变量变：`matrix B^k label="B^{\calc{k}} ="`。
- 变量变了（拖滑块、`figure set` / `play`、绑定的 steps 揭开一步），值变了的格子闪一下；一个数挪到了别的格子（比如 1 往右上角退），它会飞过去。
- 课堂指令：`figure target=m-rank1 set k=2`、`play k 1 3 3s`、`highlight 2`（第 2 条命令画的东西闪一下）都能用；`board mark target=m-rank1 row=2` 能标它的行列。
- 向量和转置：`a'` 是行（1×n），`a*b'` 是外积（n×n 矩阵），`a'*b` 是一个数。这条规则表达式里处处一样。
- 写错（表达式算不出来、`mark` 的行号超出、`split` 的位置不对）：组件自检报出来，课堂里要求重写。

### 1.3 验算：页面来算，Claude 不手算

- **`\calc{表达式}`**：任何公式里都能写（板顶说的话、段落、组件的题面 / 提示 / 解析、矩阵的标签）。页面用精确分数算出来、写成公式。比如 `$A^2=\calc{A^2}$`、`$\boldsymbol\beta^{\mathrm T}\boldsymbol\alpha=\calc{b'*a}$`。算不出来（变量没定义、尺寸不对）：画成红字，课堂里当写法错误要求重写。
- **这节课的量**：一个不显示的 `let` 块，定义整节课都用的量，后面的段、组件、`\calc` 都能直接用（组件自己的 `let` 优先）：

  ```let
  A = [[-1, -1, 2], [2, 2, -4], [1, 1, -2]]
  a = [-1, 2, 1]
  b = [1, 1, -2]
  ```

  黑板现状里列出这节课定义过的量，课堂说明被压缩以后它也记得。
- **精确计算的引擎**：分数用 BigInt，不丢精度；`det inv rank rref tr` 都是精确的。新增函数 `tr`、`rank`、`rref`、`diag`，单位矩阵 `I(3)` 也可以写成 `E(3)`（教材的记号）。开方、三角这类算不准的，退回小数并标出来。
- **`calc` 工具**（查看方式支持工具时才给）：`{ expr, vars? }` → 精确结果（分数文字 + TeX）。每用一次课堂 Claude 要多等一轮（整份说明重读一遍），所以说明里写清：只在改数出新题、要先知道结果才能决定怎么出题时用；写上黑板的数用 `\calc`。

## 2. 第二批：出题和判题

- **自定义练习**：它写出题模板（随机取数的范围、条件、答案的表达式），页面不断出新题、自动判分。`practice` 组件加 `type: custom`：
  - `pick 名字 = int(最小, 最大) [nonzero]`、`choice(…)`、`vec(维数, 最小, 最大)`、`mat(行, 列, 最小, 最大)`；`let` 推导量；`where 条件`（不满足重取，300 次取不到就报错）。
  - `q:` / `hint:` / `explain:` 用 `\calc{…}` 写出这一题的数；`answer:` 精确算出来判分，也可以配 `formula: n`。
  - 组件创建时先取十几组数试一遍，算不出来、条件取不到当写法错误报出来。连着两题尽量不取同一组数。
  - 作答记录里的题目是算好数的原文，课堂 Claude 看得到学生做的是哪一题。
- **含 n 的式子判分**：学生写 $(-1)^{n-1}A$ 这类答案，页面代几组 $n$（和题里的量）去比较，写法不同但等价的算对；错的时候指出在哪些 $n$ 上对不上（比如漏了 $n-1$ 次方）。`answer` 和 `steps`（`do: true` 的步）加 `formula: n`：
  - 输入框认省略乘号（`3A`、`(n-1)A`、`nA`）、上标（`A²`、`3ⁿ⁻¹`）、`·×÷`、`ᵀ` / `^T`、希腊字母；框下面实时写成公式；iPad 上弹符号小键盘（$n$、题里用到的量、括号、乘方），Apple Pencil 点进去用随手写。
  - 代 $n=1,\dots,6$（`formula: n=0..5` 可改，`formula: n, k` 几个变量），精确比较；标准答案在某个 $n$ 上没定义就跳过那个 $n$。
  - 标准答案里没有矩阵的 $n$ 次幂时，学生直接写 $A^n$ 不算（提示要化简，不计一次）。
  - 作答记录带「代值检查：n = 3 对，n = 1、2、4 不对」，课堂 Claude 看得到错在哪。

## 3. 第三批：表达空间

- **自由画图**：它当场写 SVG 画示意图（只允许图形元素，不允许脚本、外部链接）；页面统一配色，写坏了报错让它重写。
- **分拍板书**：一段推导分几拍出现，跟着它说的话一句一句写上去；或者学生点「下一行」。
- **教材原图上板**：课前把讲义里关键的幻灯片存进课堂的 assets，它能贴上黑板，自己也能看。

## 4. 第四批：看见学生

- **板上手写**：学生用 Pencil 在黑板上写的，随作答变成图片发给它；手写作答重新打开（`features.js`）。
- **察觉卡住**：学生在一处停了很久没动，页面提醒它，它可以轻轻问一句（可关）。
