# 测量的尺子：模拟学生（tools/forecast-sim.mjs）

设计：`docs/superpowers/specs/2026-11-14-round10-measure-design.md` 6.7。生成学生的那一边不用测量自己的模型：指数遗忘（时间常数 90 / 180 / 45 天，复习对了 ×2.5、错了 ×0.6）、课堂题和真题的难度差 0.6 / 2.4（测量假设 1.2）、底子是先验的 1.8 倍 / 0.4 倍（乘一个随机数）、每题 5% 粗心、考场折扣 0.85～0.95。12 种设定，每个学生学 13 个月，第 0、3、8、13 个月各当天真考一次，和测量那天的「如果今天考」比。

## 合格线和结果（2026-11-14，480 个学生，每次抽 400 遍卷）

| 项 | 合格线 | 结果 |
|---|---|---|
| 数据够了（这一科 ≥ 20 道真题级作答）的 80% 范围覆盖 | 75%～85% | **78%**（2870 个），中位数平均偏 −4.6（算低） |
| 第 0 个月总分 | 覆盖 ≥ 80%、不算高 | **87%**，偏 −0.8 |
| 同一时点证据多的范围更窄（408，第 13 个月） | 全部证据 < 三成证据 | **24.1 < 25.6** |

## 第一次跑没过，改了什么（rulings 里也记着）

- 第一次：数据够了 72%、第 0 个月 58%、范围没变窄。原因：每块的 K 各抽各的，几百块加起来互相抵消，总分的范围窄得假；而底子说高说低是整个人、整个部分的事。
- 加了**共同因子**（`priors.js` 的 `PART_SPREAD` 1.0、`PERSON_SHARE` 0.5）：每一遍抽卷，同一部分的块一起高一起低，其中一半是四科共用的「整个人」；一块的作答越多受它影响越小。
- 讲过的块的先验 `TAUGHT_MIN` 0.2 → 0.35：讲过的块系统性地算低。
- 「范围变窄」的比法改成同一时点比证据多少（第 0 个月大家都接近零，本来就窄，和第 13 个月比不出东西）。
