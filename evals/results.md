# 验收结果

每一轮：扮演老师的子代理只拿老师能拿到的说明，写真题的实时黑板课和课堂输出；页面检查脚本在两种 iPad 尺寸（820×1180、1180×820）下渲染、走一遍演示，报「错」（写法错误、算不出来、控制台报错、冲出版面）和「注意」（一屏放不下、字叠在一起、要横着滑）。

「一次写对」：一个文件在两种尺寸下都没有「错」。

## 0-baseline（2026-10-14 的组件库，阶段 2 之前）

37 个文件（线代 8 题 + 408 每门 6 题，各加一份课堂输出）。

| 科目 | 一次写对 | 错在哪 |
|---|---|---|
| 线代 | 5/8 | 三维图、函数图里用不了 `let` 块的量（3 个文件） |
| 数据结构 | 7/7 | （检查脚本自己卡住过一次，修了） |
| 操作系统 | 6/7 | `\calc{av' + row(A, 2)}`：一行加一列数算不出来 |
| 组成原理 | 2/6 | `practice` 里 `n` 是保留的名字（3 处）；`int()` 的上下界不能写式子；浮点 `bits` 第 0 步挂了问题、`ask: sign / exp` 问不到 |
| 计网 | 5/6 | `practice` 里 `n` 是保留的名字 |
| **合计** | **76%（28/37）** | |

「注意」里最多的是「一屏放不下」（29 处）：板上内容太多。这是写法上的事，页面已经通过 `meta/screen`（实时黑板）和黑板现状（课堂）告诉老师。

### 同一批课件，换成现在的组件库

不改课件，只换 `la-kit.js`（阶段 2 的修正之后）：**97%（36/37）**。剩下的一处是 `practice` 里 `let E = …`（阶码），已经放开（`practice` 里 `E`、`I` 可以当名字）。

注意：这些修正就是照着这批课件的报错做的，所以 97% 只说明「报出来的都修了」，不能当成下一轮的预期。下一轮要换一批题。

### 摩擦报告（想做但做不到）里已经做了的

- 学生自己填一整张表（调度、页面置换、Dijkstra 的每一轮……）：`mode: fill`。
- 记录里说清是哪种错法：错法诊断（每个演示组件 2 种以上，见 `CLAUDE-PROJECT.md`）。
- 在图上按顺序点：`ask: order`。
- 菜单外的过程：`frames`。
- 线代的过程：`elim`（秩、极大无关组、方程组、含参讨论、求逆、矩阵方程，`mode: do` 学生自己做行变换）、`det`、`eig`、`schmidt`、`quad`。
- 答案不唯一（特解、$P$、$Q$）：`answer` 的 `check:`；根号的数能写。
- 除不尽的数（平均周转时间、ASL）：`type: num`。
- TCP 的轮次口径写进说明。

### 还没做的（并进 `docs/quality-plan.md` 阶段 4、5）

- 数据结构：AVL / 红黑树 / B 树、由遍历序列建树、`trace` 的指针和链表、学生写代码判题、`practice` 出算法题。
- 操作系统：PV 同步、多级页表、`mem` 综合链、文件的索引结构。
- 组成原理：汇编 / 栈帧、存储器扩展、乘除法、浮点加减、校验码。
- 计网：CRC、距离向量、CSMA/CD、IP 地址的答案类型。
- `\calc` 显示小数、组件字段里用 `let` / `\calc`。
