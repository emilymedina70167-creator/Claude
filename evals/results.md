### 摩擦报告：五门课最想要的

几门课不约而同提到的：

1. **学生自己动手、页面逐步判**：
   - 自己建 B 树 / 哈夫曼树 / AVL，自己改链表指针（数据结构）；
   - 过程表（改进型 CLOCK 每一轮的访问位、修改位和指针，分区分配每一步的空闲分区表）（操作系统）；
   - 点半码元画波形、拖时间线（计网）；
   - 学生写 P/V 代码，`pv` 来判（操作系统）。

   现在这些多半还是截图交给老师。
2. **演示组件当 `practice` 的随机题型**：`practice type: mul / fadd / div / hamming / frag / nextval / huffman`，出题、判分、错法诊断都用现成的引擎。现在只能在自定义题型里拿 `bit`、`xor`、`log2` 把算法重写一遍，又容易错。表达式里能用 `next()`、`nextval()`、`postfix()`、`huffcode()` 也是同一个需求。
3. **含参数的精确计算**（线代）：`\calc`、`det`、`eig`、`elim` 认 $t$、$\lambda$、$n$，结果写成含 $t$ 的式子；$A^n$ 的答案是一个元素含 $n$ 的矩阵，每格是一个式子框。
4. **答案能用学生前面的答案**（线代：`inv(ans(q-P))`，学生选的 $P$ 不同，后面照样判对）；方程、区间、带小数点的定点数、双符号位的答案类型（组成原理）。
5. **演示组件上的滑块**：拖距离、速率、帧长、窗口、MTU，看结果怎么变（计网）。
6. **写法上拿不准的地方**，说明里补一句：
   - 跨段的 `let`；
   - `frag` 的 `ask: offset`、`tcp` 的 `ask: len` 问的是哪一片 / 哪一段；
   - `formula:` 能不能用在计网，能不能用 `t` 作变量；
   - `hamming` 只写 `recv:` 行不行；
   - `mark` 能不能标 `derive` 行里的 `\hl`。

### 摩擦报告（想做但做不到）里已经做了的

- 学生自己填一整张表（调度、页面置换、Dijkstra 的每一轮……）：`mode: fill`。
- 记录里说清是哪种错法：错法诊断（每个演示组件 2 种以上，见 `CLAUDE-PROJECT.md`）。
- 在图上按顺序点：`ask: order`。
- 菜单外的过程：`frames`。
- 线代的过程：`elim`（秩、极大无关组、方程组、含参讨论、求逆、矩阵方程，`mode: do` 学生自己做行变换）、`det`、`eig`、`schmidt`、`quad`。
- 答案不唯一（特解、$P$、$Q$）：`answer` 的 `check:`；根号的数能写。
- 除不尽的数（平均周转时间、ASL）：`type: num`。
- TCP 的轮次口径写进说明。
