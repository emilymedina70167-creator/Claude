# 摩擦报告 · 操作系统（0-baseline）

只照 `CLAUDE-PROJECT.md`、`system-操作系统.md` 和题库写，没看渲染效果。下面「做到了」是指「照说明应该能做到」，有没有真的画出来要看检查脚本。

## 通用（每题都碰到的）

1. **一次写完整条路径，后面的板和结论会提前露出来。**实时黑板没有「到这一步才出现」：一次写完 6 块板，页面会直接翻到第 6 块（板号最大的是当前板）；常驻栏里「刚得出的结论」（抢占规则、RR 约定、Belady 结论）从一开始就在。真实上课我会一块块写，所以这主要是验收方式造成的；但也说明实时黑板本身做不了「答完才揭开下一块」，节奏全靠我在对话里一轮轮写。
2. **`let` 块的作用范围拿不准。**说明写「定义一次，之后所有的段……都能直接用」。我把 `let` 放在第 1 块板的第一段，后面几块板的 `\calc`、`answer:` 都靠它，os-file 的常驻栏 k1 也用了它。不确定：(a)「之后」是按 `seq` 还是按板号；(b) 常驻栏的段能不能用正文段里定义的量；(c) 学生直接停在第 5 块板时，第 1 块板的 `let` 有没有算过。说明里只有一个段内的例子。
3. **变量名的规则不全。**只知道 `I`、`E`、`pi`、`e`、`step`、`t` 是保留的。`T` 是转置函数，我差点拿它当「周转时间」的变量名；`and`、`or`、`not`、`bit`、`row`、`col`、`mod`、`div` 也都是函数名，撞了会怎样没写。多字母名（`arr`、`fin`、`tat`、`per`、`tlb`）、带数字的名（`a1`）能不能用，说明里只有 `mu` 一个例子。我全用了不带数字的短名，希望能用。
4. **`\calc` 只会写分数。**命中率 0.9 进了 `\calc` 会写成 $\tfrac{9}{10}$，平均周转 15.25 会写成 $\tfrac{61}{4}$，可 408 的题面、答案都写小数（0.9、15.25、130 ns）。我只好把 0.9 手写在式子里，只让 `\calc` 算最后的结果。想要一个「写成小数」的选项。
5. **演示组件的 `ask` 不能带我自己的提示和解析。**`sched` / `paging` / `banker` 只有 `ask:` 的种类，没有 `hint:` / `explain:`。比如 RR 的 `ask: next` 在 t = 4 点错（选了 P1），我想提示一句「t = 2 时谁先入队」，做不到，只能在前面另放一道 `quiz` 先讲约定。
6. **演示组件算出来的数，正文用不了。**`sched` 算出了每个进程的完成时间，可 `\calc` 读不到；`explain` 里要说「P2 在 12 完成」只能自己算。FCFS 那块板为了让页面算完成时间，我拿下三角全 1 矩阵乘运行时间向量凑前缀和（`fin = L*run`，答案 `mat(fin, tat)`），是借线代的矩阵硬凑的，对学生毫无意义；SJF、SRTF、RR 的完成时间根本写不成表达式。
7. **`practice type: custom` 出不了算法题。**表达式里没有调度、置换、安全性检查这类函数，所以说明推荐的节奏（最后用自定义题型练熟）在 os-sched、os-page、os-banker 三题都做不到，只能自己换一组固定数据，用 `mode: quiz`。os-addr2、os-file 这种纯计算题倒很好用。
8. **一屏放不放得下没法预判。**说明给了「一句话 + 一张图 + 一道题」的经验，但没写演示组件大概多高（`paging` 12 列 × 3～4 行的表、`banker` 5 行的表、14 行代码的 `trace` 加变量栏）。os-page 第 3 块板放了两个 `paging` 加一道 `answer`，os-pv 第 3 块板放了 `trace` 加 `quiz`，我猜会放不下，但只能等 `meta/screen` 写回 `fits: false` 再改。
9. **矩阵 / 向量答案的格子没有行名、列名。**填「完成 / 周转」表、Need 矩阵、「页目录号 / 页表索引」时，我用 `before:` 写一个 `\begin{matrix}P_1\\ P_2…\end{matrix}` 或 `\begin{bmatrix}\text{页目录号}\\ \text{页表索引}\end{bmatrix}=` 当行名，不知道能不能和格子一行行对齐；列名只能写在 `q` 里。想要 `rows: P1, P2, P3, P4` 和 `cols: 完成, 周转` 这样的字段。
10. **`quiz` 能不能写 `id:`、`title:`。**实时黑板要求会作答的组件都写 `id:`，可 `quiz` 的示例里既没有 `id` 也没有 `title`。我写了 `id:`，没写 `title:`。
11. **实时黑板的「板书」按钮在哪。**说明只说 guided 在左下角、课堂在输入框的「⋯」菜单里，实时黑板没有输入框。我不敢写「打开板书画甘特图」，都写成「在草稿纸上画」。
12. 小的不一致：第二节原则 7 说「术语第一次出现时附英文」，计算机课那段又说「术语用中文，不附英文」。我按后一条，但最好在原则 7 里注明只管线代。
13. 这次的 board.json 格式里没有 `meta/board` 的 `context`，所以没写；真实上课我会把王道的定义和口径写进去，给页面里转写手写的 Claude 参考。

## os-sched　进程调度

**理想的教法**：一条 0～26 的时间轴（整数刻度），学生用 Pencil 或手指把 P1～P4 的色块拖上去拼甘特图，页面逐段判，指出「第一处错在 t = 几」；旁边一张空表（完成 / 周转 / 带权周转），学生填，页面逐格判。SJF 和 SRTF 的甘特图上下对齐，学生先点出「从哪一刻开始不一样」，页面再在那一刻画条竖线，写出「P2 要 4 < P1 还剩 7」。RR 那块板上，就绪队列是一排能拖的卡片：t = 2 时学生自己把 P3、P1 拖进队尾，页面判顺序。最后程序随机出几组进程，四种算法轮着练。

**现有组件做到了**：
- FCFS：学生自己填 4×2 的「完成 / 周转」表和平均值（`answer`，页面判，数由 `let` 加矩阵算）。
- SJF / SRTF / RR 各一个 `sched` 演示，`ask: next, avg`：每次调度先点谁，最后写平均周转时间。
- 抢占时刻先用填空猜（t = ?，答案 1），再走 SRTF 演示。
- RR 的约定先用选择题猜再揭晓；后面 RR 演示里 t = 4 那次 `ask: next` 正好检验这个约定。
- 换一组数（P1 0 7, P2 2 4, P3 4 1, P4 5 4）用 `mode: quiz` 自己做 SRTF 平均周转、RR 运行序列。这组数里 SRTF 抢占两次，RR 有两次「新到达和时间片用完撞在同一时刻」。

**想做但做不到的**：
- **学生画甘特图**：没有能拖的时间轴，只能在纸上画，页面不判。
- **填 SJF / SRTF / RR 的完成时间、周转时间表**：`sched` 的 quiz 只有「运行序列」「平均周转」「平均等待」，没有填表；完成时间也写不成表达式（见通用 6）。这张表页面判不了，学生只能看演示最后一步自己对照。「教到什么程度」的第一条（自己能填表），页面只能通过平均值间接检验。
- **SJF 和 SRTF 对齐比较**：两个 `sched` 只能分别放在两块板上，学生要翻板对照；没法在 t = 1 处画竖线、标出差别。
- RR 的就绪队列不能让学生自己排，只能点「下一个是谁」。
- 随机出调度题练熟。

**写法上拿不准的**：
- SRTF 里的 `ask: next` 是每个调度点都问，还是只在换进程时问？t = 2、t = 3 有新进程到达，但 P2 继续跑，这两次问不问？
- RR 的 `mode: quiz` 写运行序列时，同一个进程连着两个时间片（原题最后 P3 在 23～25、25～26 连着跑）写一次还是两次？我换的那组数没有这种情况，原题有。
- `ask: avg` 是不是在最后一步之前问？学生答错后页面直接揭晓整张表，我就没机会针对「忘了减到达时间」说话。
- `before:` 里的 `\begin{matrix}P_1\\ …\end{matrix}` 能不能和 4×2 的格子对齐。

## os-page　页面置换和 Belady 异常

**理想的教法**：一张空的王道表（12 列 × 3 行），学生每一列点选或写进内存里的页，点「缺页 ✓」，圈出换出的页；页面逐列判，指出第一处错的列。Belady 那块板上，3 块和 4 块的表上下对齐，学生拖一个光标走过每一列，页面把「3 块里有、4 块里没有」的页标红，一眼看出从第 7 列起不再包含。LRU 旁边画一个按最近访问排序的「栈」：n 块的内存就是栈顶 n 个，n 块和 n+1 块的包含关系是学生自己看出来的，不是我讲出来的。最后随机出引用串练。

**现有组件做到了**：
- FIFO 3 块：`ask: hit, victim, faults`，每次访问先判命中还是缺页，要换时点出换谁，最后写总数。
- 4 块：先凭直觉猜（多 / 少 / 一样），再用 `mode: quiz` 自己数缺页次数。Belady 是学生自己数出来的。
- 两张 FIFO 表都停在第 7 次访问（`start: 7`），学生找出「3 块里有、4 块里没有」的页（`answer`，答案 1）。
- LRU：`ask: victim, faults`。OPT：`mode: quiz`、`quiz: victims`。这串引用里，OPT 正好两次碰到「以后都不用的有两页」。
- 「为什么只有 FIFO」用 `steps` 走：LRU 内存里是哪些页 → n 块和 n+1 块的包含关系 → FIFO 为什么不包含 → 一句话总结（自由作答，再对照）。

**想做但做不到的**：
- **学生自己填内存状态表**（「教到什么程度」的第一条）：`ask` 只问命中、换谁、总数，quiz 只有缺页次数或换出序列；表本身一直是页面填好的。
- 两张表**对齐比较、自动标出不包含的页**：只能放两个独立的 `paging`，能不能一屏放下也不知道。
- **LRU 栈视图**，让「栈性质」看得见：现在只能用 `steps` 的文字讲。
- 随机出引用串的练习。

**写法上拿不准的**：
- `start: 7` 的第 7 步是不是「第 7 次访问之后」。第 0 步是开始的样子，照理第 k 步就是第 k 次访问之后，但说明没写明。
- `ask: hit, victim` 一起写时，同一次访问是不是先问命中、再问换谁。
- OPT「以后都不用的有好几页时换先调入的」是组件的约定；考题如果另有约定，说明没写怎么改。

## os-addr2　二级页表和快表

**理想的教法**：32 个格子的二进制位。学生先把 0x00403A10 一位位填进去（或者把每个十六进制位拖开成 4 位），再用手指在位之间「切两刀」，页面判切口是不是在第 22、12 位之间。接着动画走一遍「页目录 → 页表 → 页框 → 数据」，每碰一次内存计一次数。有效访问时间让学生自己写出式子 0.9 × (10 + 100) + 0.1 × (10 + 3 × 100)，页面判式子是否等价，不只判最后的 130。

**现有组件做到了**：
- 为什么是 10 位：`answer` 算一页放几个页表项（页面算 4096 / 4），`explain` 用 `\calc` 推出 10、10、12。
- 拆地址：`answer` 填页目录号、页表索引（`shr`、`and` 让页面算），`type: hex` 填偏移。
- `practice` 自定义题型随机出 32 位地址拆两段，用 `hex(v, 8)` 写题面。这个很好用。
- `sketch` 画查表路径，两道填空数访存次数（3 次和 1 次）。
- `steps` 三步列出有效访问时间（每步 `do: true` 填数，页面判）；`practice` 随机换页表级数、时间、命中率，用 `where ans == floor(ans)` 保证答案是整数。

**想做但做不到的**：
- **`addr` 组件只有一级页表**（页号 | 偏移），画不出页目录和二级页表；`cost:` 也只按一级算（没命中 = 快表 + 页表 + 取数）。这道题的核心（10 | 10 | 12、访存 3 次）它都画不了，只能用 `sketch` 画静态图。想要 `levels: 10, 10, 12`，每一级画一张表。
- 学生在二进制位上**切分**：现在只能填数。
- **判式子**：有效访问时间只能判数，`formula: n` 只认含 n 的式子。学生式子思路错了（比如没命中只算 2 次访存）、数却碰巧凑对，页面看不出来。
- 原想让学生把 0x00403A10 写成 32 位二进制（`type: bin`、`width: 32`），怕一块板放不下就删了。

**写法上拿不准的**：
- `hex(v, 8)` 写出来带不带 `0x` 或 `H`？「四位一组」是不是写成 `0040 3A10`？我的题面写成「（十六进制）$\calc{hex(v, 8)}$」，如果组件自己带了 H，就重复了。
- `type: hex` 的 `width` 是按十六进制位还是二进制位算？没写清楚，我就没写 `width`。
- `steps` 的 `do: true` 步里能不能写 `ask:`？示例里 do 步没有 `ask`。

## os-pv　PV 操作：水果盘

**理想的教法**：一个「并发小剧场」。左边四列是四个进程的代码（P、V、动作），右边是三个信号量的值、各自的等待队列，还有盘子里放着什么。学生每次点「让爸爸走一步」「让女儿走一步」，页面执行一条语句：P 让值减 1，该阻塞就把进程放进等待队列（那一列变灰），V 唤醒队首。盘子里出现两个水果、拿了不存在的水果、所有人都阻塞（死锁），页面当场报出来。学生自己写四个进程（模板填空：每个进程选 P(?)、动作、V(?)），页面把所有交替顺序穷举一遍，告诉学生「这种顺序下盘里会有两个水果」，并能回放那条顺序。最后把盘子改成能放两个，让学生自己试出要不要加 mutex。

**现有组件做到了**：
- `steps` 用选择题理清关系（互斥 / 同步 / 没关系）和信号量初值。
- `steps` 四步 `do: true`，学生自己写四个进程（可以粘贴手写截图），写完对照参考答案。
- `trace`：把一种固定的交替顺序写成 `main` 里一行行的 P / V 调用，`predict` 让学生在第 6、8、10 行先猜 plate / orange 的值（−1、−1、0），再问「妈妈在第几行之后被唤醒」。
- `steps` 讲「为什么不用 mutex」（三个信号量之和 ≤ 1），再问「盘子能放两个呢」。
- `findbug`：女儿先 V(plate) 再取苹果的错解。

**想做但做不到的**：
- **没有任何并发 / 信号量组件。**`trace` 是单线程的 C 解释器，我用 `void P(int &s){ s = s - 1; }` 加一个写死顺序的 `main` 凑出信号量的值。谁在等、谁被唤醒只写在注释里，解释器并不知道；学生也不能换一种顺序试。「能在一种具体的交替执行顺序下跟踪」只做到了我给定的那一种，而且阻塞是假的。
- **判学生写的 PV 代码**：只能自由作答再对照，或者交截图让我看；页面判不了对错，更找不出哪种交替顺序会出错。
- 「说明不会出错」需要学生自己找反例或给出论证，现在只能靠选择题和文字。
- `findbug` 只能点整行（我一行写一个进程），点不到具体哪条语句错。

**写法上拿不准的**：
- `trace` 的 `predict` 写在函数调用那一行（`P(plate);`）上，「执行完这一行」是不是指 P 返回之后？调用时解释器会跳进第 1 行，问的时机我不确定。
- 代码里的 `//` 注释（还是中文）、写成一行的函数体，解释器认不认？说明没提注释。
- `steps` 的 `do: true` 步里，`answer:` 是一段代码（我用反引号包起来了），页面会不会先当表达式去算、算不出来就报写法错误？说明只说「能算出数时判对错，其余自由作答」。
- 多行代码写不进 `steps` 的 `show:` / `answer:`：只有续行，不知道换行会不会保留。所以我把每个进程压成了一行。

## os-banker　银行家算法

**理想的教法**：`banker` 已经接近理想。还想要：填 Need 矩阵时格子带进程名和资源名；安全性检查的每一轮，学生不只点进程，还要写出新的 Work（页面判），这样「Work 加 Allocation」这个最常错的地方才有地方暴露出来；处理请求时，学生按顺序勾出三步检查，写出试分配后的 Available、Allocation、Need，页面逐项判；最后随机出状态和请求来练。

**现有组件做到了**：
- `answer` 填 5×3 的 Need（`answer: M - A`，页面算）。
- 先用 `quiz` 问 Work 加的是 Allocation 还是 Need / Max（最常见的错），再用 `banker` 的 `ask: next` 走安全性检查。
- `steps` 用选择题排三步检查的顺序，再用 `banker`（`request: P1 1 0 2`，`ask: request, next`）走一遍。
- 换一个请求 P4 (3, 3, 0)（前两步都过、试分配后不安全），用 `mode: quiz` 判能不能分配，再加一道选择题问卡在哪一步。

**想做但做不到的**：
- `ask:` 没有 `work`：学生不用写出 Work 也能一路点下去，Work 加错了看不出来。
- 请求题的 quiz 只判「能 / 不能」，卡在哪一步要另加选择题；试分配后的三个向量页面不判。
- 随机出银行家题：`practice` 的表达式里没有安全性检查。

**写法上拿不准的**：
- `max:` / `alloc:` 说明写「一行一个进程」，例子却是一行里用分号隔开；我照例子用分号写在一行里。
- `ask: request, next` 里，`request` 是在试分配之前问还是之后问？
- 用 `row(N, 2)` 取 P1 那一行（P0 是第 1 行），容易数错；要是能按进程名取就好了。

## os-file　混合索引

**理想的教法**：一个 `inode` 组件，参数是直接项个数、间接级数、块大小、地址项大小。它画出索引结点和每一级的索引块，旁边写着每一级管的块号范围（页面算）。给一个文件偏移（或者让学生拖一个偏移滑块），页面高亮从索引结点到数据块的路径，每读一次磁盘计一次数。`ask` 能问「落在哪一级」「在二级里是第几个一级索引块的第几项」「读几次磁盘」。

**现有组件做到了**：
- `sketch` 画出混合索引的结构（静态图）。
- `answer` 算一块放 256 个地址、每一级管几块（向量 [10, 256, 256², 256³]）、最大文件（16 843 018 KB），数全由 `\calc` 和表达式算。
- `steps` 四步：在第几块 → 一级间接管到哪 → 落在哪一级 → 读几次磁盘。
- `practice` 自定义题型：随机直接项个数（8 / 10 / 12）、块大小（1 / 2 / 4 KB）；先随机挑一级、再在那一级里取块号，保证直接、一级、二级都会出现；起点用 `(L >= 1)*d` 这种比较式凑出来。这题用 practice 很顺手。

**想做但做不到的**：
- **没有文件系统 / 索引结构的组件**：图是死的，偏移变了图不会跟着高亮路径；学生也不能在图上点出「第 300 块在哪个索引块的第几项」。
- 16 843 018 KB 这种大数学生只能整个敲进去；408 的答案常写成「10 + 256 + 256² + 256³ 块」，页面只认数，不认式子。

**写法上拿不准的**：
- 常驻栏 k1 用了第 1 块板 `let` 里的 `per`（见通用 2）。
- `sketch` 的 `rect` 不写 `fill` 时是不是只画边框？我当它是。

## 课堂（class.class.json）

挑了 os-sched 的 FCFS 一段来上：
- 第一轮：换一块板放 `sched`（`ask: avg`）；常驻栏写周转时间公式，「到达时间」用 `\hl{arr}{…}` 包起来，预备学生忘了减时圈它。
- 第二轮：学生填了 16.75（四个完成时间的平均，忘了减到达时间）。我用 `board mark target=k1 term=arr` 圈出公式里那一项，再 `board add` 一道只算 P2 的小题。
- 第三轮：学生说「没懂，为什么？」，按缺知识处理：换板，`sketch` 画 P2 的时间线（还没到 / 等 / 跑），再出一道 P4 的等待加周转，让学生马上用一次。

**拿不准、做不到的**：
- 编作答记录时不知道 `sched` 的 `ask: avg` 那条长什么样（system 里只有 `answer`、`steps` 的例子），我照 `answer` 的格式编了「[作答] b1 里的 sched sc-fcfs「FCFS」平均周转时间：填了 16.75（错，第 1 次）」。
- 学生答错 `ask: avg` 后，演示会马上揭晓整张表；我第二轮出的「P2 的周转时间」在表里就看得到，这道小题的检验力打了折扣。想要 `ask` 答错时先不揭晓、给一次重答，或者由我来决定什么时候揭晓。
- 我想在第二轮直接圈 `sched` 表里 P2 那一行的完成时间，但不知道 `sched` 的 `item=` 序号对应什么（甘特图的段？表的行？就绪队列的格子？），`label=P2` 会圈到哪一个也不知道，只好圈常驻栏里的公式。
- `sketch` 的时间刻度（0、1、8）是我手写的位置和数字，只有 12 和 11 用了 `\calc`；`sketch` 不能按数据自动画时间轴。
- 资料包 `plan` 里我写了 `\hl{arr}{…}`。pack 是 JSON 字符串，课堂 Claude 看到的是不是原样（反斜杠有没有被吃掉），说明没讲。

## 最后：如果组件库只能再加三样

1. **演示组件的「填表 / 画图」作答**：`sched` 的甘特图（把色块拖到时间轴上，吸附到整数）和完成 / 周转时间表，`paging` 的内存状态表（每列填页、标缺页和换出），`banker` 的 Work 列。理由：6 题里有 3 题「教到什么程度」的第一条就是「自己能画出甘特图 / 填出表」，现在页面一格都不判，只判最后一个数或一个序列；学生错在哪一格、哪一刻，我和页面都看不到。
2. **并发 / 信号量组件（`pv`）**：声明信号量和几个进程的代码，学生点「让谁走一步」，页面跟踪信号量的值、等待队列和共享缓冲区，出错（两个水果、死锁、取空）当场报；还能把学生写的代码在所有交替顺序下跑一遍，给出出错的那条顺序。理由：PV 是 408 必考的大题，现在只能靠选择题、文字和截图，用 `trace` 凑出来的单线程版本连阻塞都是假的。
3. **演示组件能随机出数据，结果能被 `\calc` 读到**：`sched` / `paging` / `banker` / `addr` 的 `mode: quiz` 支持 `pick` 随机生成输入（进程、引用串、资源状态、地址），或者给操作系统加几种 practice 内置题型；同时 `\calc` 能读演示组件算出的量（比如某个进程的完成时间）。理由：说明推荐的「最后用 practice 练熟」在调度、置换、银行家三题都做不到；`explain` 或课堂里说的话要引用演示结果时只能心算，违背「数让页面算」。

（排第四的：多级页表的 `addr`（`levels: 10, 10, 12`）和混合索引的 `inode` 组件。这两道题现在都只能用静态 `sketch` 画。）
