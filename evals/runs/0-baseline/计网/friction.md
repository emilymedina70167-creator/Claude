# 计网 · 摩擦报告（0-baseline）

写了 6 节实时黑板课（`cn-subnet` `cn-cwnd` `cn-gbn` `cn-crc` `cn-dv` `cn-web`）和一段课堂（用的是 `cn-gbn`）。下面先列几题都碰到的问题，再一题一节，最后是「只能再加三样」。

## 通用（几题都碰到的）

1. **没有填表的组件。**路由表、每一轮的 cwnd、子网划分表、时序表，计网的大题几乎都是「填一张表」。我只能拿矩阵形状的 `answer`（`[[…], […]]`）冒充表格：没有表头，行标签只能塞进 `before:` 的 TeX 里、和格子对不齐；格子里只能填数（不能填 ∞、下一跳的字母、IP）；说明里也没写错一格时是整题判错，还是会指出错的是哪一格。
2. **没有 IP 地址（点分十进制）的答案类型。**`answer` 只有数 / 向量 / 矩阵 / `seq` / `bin` / `hex`。`subnet` 演示自己的 `ask` 收点分十进制，`answer` 和 `practice` 却不收。我只好让学生只写最后一段（`before: 192.168.\calc{c}.`），题目一跨字节（比如切 /22）这招就不灵了。
3. **表达式里没有 ∞。**距离向量里的「不可达」只能写在正文里，算不出来，也填不进答案。
4. **演示组件的「步号」怎么对应题目里的轮次 / 时刻，说明没写。**`tcp` 的第 k 步是不是第 k 轮？`window` 的超时是第几步？所以 `ask: 5, 6, 12…` 的步号是我按「第 k 步 = 第 k 轮」猜的；课堂第二轮编作答记录时，「第 9 步」也是猜的；课堂里想 `figure set step=` 停在「3 号帧到达乙」那一刻，同样不知道写几。
5. **`board mark target=… item= / label=` 在 `tcp` / `window` / `subnet` 里指的是什么，说明没写**（帧？时序图上的某条线？表的某一行？）。`label=3` 在 GBN 的时序图上可能对上 3 号帧第一次发送、重传、ACK3……好几样东西。
6. **一次写完的实时黑板里，没有「答完才出现」的段。**常驻栏里的结论、下一步的图从一开始就看得到。我把结论性的 pin 的 `seq` 排在对应那块板后面（真实上课时它会在学生答完后才写），但照这份文件一次写进去就是剧透。`after` 只在线代的 `predict` 里有；`sketch` 不能「揭晓后再画出来」。
7. **`let` 块的作用范围不够清楚。**说明写「定义一次，之后所有的段……都能直接用」。我把整节课的量都放在第 1 块板的第 1 段里；常驻栏里的 `\calc`、后面板上的段能不能用，按 `seq` 还是按板号算「之后」，没写。
8. **`quiz` 的例子里没有 `id:`、`title:`**，可实时黑板要求会作答的组件都写 `id:`。我照写了，不知道 `quiz` 认不认（会不会报「看不懂这一行」）。
9. **`practice type: custom` 只能随机取数，不能随机挑文字**（问哪个部门、问网络地址还是广播地址、哪种连接方式）。我用 `(k == 2)*T1 + (k == 3)*(T1 + T2)` 这种分段式拼出来，或者干脆把三问并成一个向量。
10. **`bin(x, w)` 固定四位一组。**CRC 的比特串显示成「11 0101 1011 0000」，生成多项式显示成「1 0011」，看着像几个数；IP 更自然的是八位一组。没有不分组、八位一组的写法。
11. **科目标签是「文档只给这门课」还是「组件只给这门课用」？**`net`（能画拓扑）、`graph`、`scene`、`predict` 都标了别的科目。我想用 `net` 画路由器拓扑（不跑算法），但说明里没有不跑算法的写法，也不确定计网课能不能用，所以拓扑全用 `sketch` 手画。
12. 有一处是**我自己心算了**：GBN「只丢 1 号帧的确认」那块板，结论（GBN 不用重传）是我推出来的：ACK2 会在 1 号帧超时前到。它依赖组件默认的 `delay` 和 `timeout`，说明里只写了 `timeout` 默认 `2 × delay + 2`，没写 `delay` 默认是多少。

## cn-subnet　按主机数划分子网

**理想的教法**
- 画一条 0～255 的地址条（最后一段），学生用 Pencil 或手指在上面拖出每个子网块的起止。块大小必须是 2 的幂、起点必须对齐，拖错了页面当场说「/26 的起点要是 64 的倍数」。
- 每个块旁边展开最后 8 位的二进制（网络位 | 主机位），学生点「主机位全 0 / 全 1」，看网络地址和广播地址是怎么来的。
- 让学生试一次「先分小的」，自己看到对齐留下的空洞。
- 最后填一张「部门 | 网络地址/前缀 | 掩码 | 可分配范围 | 广播地址」的表，逐格判对错。

**现有组件做到了**
- `subnet ip: 202.118.1.77/26`：拆开一个子网，`ask: net, bcast, hosts` 先猜。
- `answer`：
  - 主机位 `[h1, h2, h3]` 和掩码最后一段 `[256 - S1, …]` 都用表达式判，主机位用 `floor(log2(n + 1)) + 1` 由页面算。
  - 3×3 矩阵冒充三行表，填首个 / 末个可分配地址和广播地址。
- `subnet split: … hosts: 120, 60, 20 ask: subnet`：在原题上先写每个子网的网络地址。
- `quiz`：问对齐（/26 能不能从 .32 开始）。
- `practice custom`：随机出三个部门的题，问第 k 个子网的四个地址。

**想做但做不到的**
- 学生自己在地址条上摆块（拖、点），页面判对齐：没有这个组件。
- `split` 总是从大到小排，没法演示「先分小的」出什么问题。
- 说明里 `split` 只有 `ask: subnet`，没写 `mode: quiz`，学生不能在 split 上自己写出整张表。
- `ask: subnet` 只问网络地址。广播地址、可分配范围、掩码在 split 里问不了，只能另开 `answer`。
- 答案写不了点分十进制，掩码也只能写最后一段的数（见通用 2）。
- 用矩阵冒充的表格：没有表头，不知道会不会指出错的是哪一格（见通用 1）。

**拿不准的地方**
- `split` 画出来的表里，是不是已经列了广播地址和可分配范围？如果列了，第 3 块板一揭晓，第 4 块板的题就被剧透了（学生翻回去就能抄）。
- `ask: subnet` 要学生写「202.118.1.128」还是「202.118.1.128/26」？
- 没有 `ceil`，主机位只能写成 `floor(log2(n + 1)) + 1`，依赖浮点的 `log2`。说明说精确计算用大整数，可 `log2` 显然不是精确的，n + 1 恰好是 2 的幂时会不会差一点、被 floor 掉？
- 原题的数据测不出「忘了减 2」：120、60、20 不减 2 也落在同样的位数上。所以「别忘了减 2」只能靠练习题的随机数去碰（比如 62 和 63）。这是题目本身的问题，不算组件的问题。

## cn-cwnd　TCP 拥塞控制

**理想的教法**
- 给一张空的「轮次—cwnd」坐标格，学生用 Pencil 一轮一轮点出 cwnd（或者拖出折线），ssthresh 也自己画成虚线。
- 页面逐轮判，在错的那一轮停下来问「这一轮处在哪个阶段？」。
- 同一张图上叠 Reno 和 Tahoe 两条线对比。
- 最后学生自己填出 22 轮的表。

**现有组件做到了**
- `tcp`：
  - 画折线；在关键轮次用 `ask: 步号` 先填 cwnd。
  - `events: 3dup@…, timeout@…` 复现两种事件，`start:` 从事件前一轮开始看。
  - `mode: quiz at:` 单问一轮。
- 先拿一组好算的数（ssthresh 8）把三个阶段分开走，再上原题，最后换一组数做 quiz。
- `quiz` 问快恢复的规则，`conjecture` 问为什么两种事件区别对待。

**想做但做不到的**
- 只能问 cwnd，不能问 ssthresh（`ask` 只有 `cwnd` 一种）。「事件之后 ssthresh 是多少」只好用选择题问规则，问不了具体的数。
- `mode: quiz` 一次只能问一轮（`at:` 只写一个数）。「填出每一轮」只能 `ask:` 写一长串步号，或者开好几个 quiz 组件。
- 学生画折线、页面判：没有。
- Reno 和 Tahoe 两条线叠在一张图上：没有，只能开两个组件。
- 表达式没有循环，算不出 cwnd 序列。所以「整串 cwnd」不能用 `answer type: seq` 判（答案只能我手算写死），我没这么做。

**拿不准的地方（这一题最严重）**
- **轮次从几开始数？**`rounds: 22` 是第 1～22 轮，还是第 0～22 轮？
- **事件那一轮的值是事件前的还是事件后的？**`3dup@12` 是不是「第 12 轮的 cwnd 还是事件前的值，第 13 轮才减半」？
- **奇数怎么减半？**
  - 按「第 1 轮 cwnd = 1」数，原题第 12 轮 cwnd = 23，是奇数。ssthresh = 23 / 2 是 11 还是 11.5？说明只写了「ssthresh = cwnd / 2」。
  - 按王道、谢希仁常见的「从第 0 轮数」，第 12 轮 cwnd = 24，减半是 12。
  - 两种数法差一轮，后面整条线都不一样。题库写的是「第 1～22 轮」，我没法确认页面用的也是同一种数法，只好把所有数都交给 `tcp` 自己算，正文里一个具体数都不写。
- 「第 0 步是开始的样子」，那第 1 步是第 1 轮吗？`ask: 5, 6` 的步号是不是等于轮次？
- 快恢复有的教材是 cwnd = ssthresh + 3，组件用的是 cwnd = ssthresh。说明没写教材不一样时怎么改（不像磁盘的 SCAN / LOOK 那样写了）。
- `start:` 和 `ask:` 一起用时，`start` 之前的步上的问还问不问？

## cn-gbn　后退 N 帧 / 选择重传

**理想的教法**
- 时序图由学生自己「画」：在发送方时间轴上点一下发出一帧、标出哪一帧丢了、在接收方点「收下 / 丢弃」、画出确认，页面一步步判。
- 关键时刻停下来问：「乙收到 3 号帧，做什么？」「这个确认号是几？」
- 窗口上限：在序号环（0～2ⁿ−1）上拖动发送窗口和接收窗口。窗口取大了，页面当场演示「旧帧被当成新帧收下」那个错误。

**现有组件做到了**
- `window`：
  - 跑 GBN 和 SR，丢帧（`lost`）、丢确认（`acklost`）都能演示。
  - `ask: resend, total` 先猜，`mode: quiz` 数一共发了几帧。
- `quiz` 问接收方怎么处理失序帧、累积确认和逐帧确认的差别。
- 窗口上限用 `steps` 加一张 `sketch`（序号环上的新旧两个窗口）讲。
- `practice custom`：由序号位数 n 出两种上限 `[2^n - 1, 2^(n - 1)]`。

**想做但做不到的**
- `window` 没有序号位数（比如 `bits:` 那样的模 2ⁿ 编号），帧号一直往上加，没法演示窗口取 2ⁿ 时「撞号」。窗口上限的来由只能靠静态的 sketch 和文字。
- 不能问「乙这时发的确认号是几」（没有 `ask: ack`）。而累积确认和逐帧确认的区别，恰恰要靠这一问。
- 学生画时序图、页面判：没有。只能让学生在 Notability 里画、用「交截图」交上来，由我看。

**拿不准的地方**
- 组件画的确认号是哪种约定？王道 GBN 是「ACKn = n 号及以前都收到了」，也有教材是「下一个要 n 号」。板上我写的是王道的说法，要是图上标的是另一种，学生会被弄糊涂。
- `ask: resend` 要学生怎么写（「2 3 4 5」「2,3,4,5」「2～5」）？按集合判还是按顺序判？
- GBN 是一个计时器还是每帧一个？默认 `delay` 是多少？见通用 12。
- `total` 只数数据帧，还是连确认一起数？`mode: quiz` 的说明写「数据帧」，`ask: total` 写的是「一共发了几帧」。

**课堂那三轮（class.class.json）**
- 第二轮想把演示停到「3 号帧到达乙」那一步再圈出来，可是没有按事件定位的写法，只有 `set step=数`，而步号要猜。所以只用了 `board mark target=w-gbn label=3`，不确定会圈到哪条线。
- 演示组件翻步（学生点「下一步」）以后，画上去的标注跟不跟着重画？说明只写了「图被拖动、`figure set` 之后，标注跟着挪」。
- 第三轮学生没答 `qz-b2` 就问「没懂，为什么？」，这里两条红线有点冲突：红线 2 是「没作答就不往下推」，红线 3 是「缺知识就直接讲清楚」。我按缺知识处理，讲完给了一个新的小问题（`qz-b3`），重传哪几帧留给学生自己再答。说明里没写这种情况该听哪条。
- 作答记录的格式，说明只给了 `answer` 和 `steps` 的例子。演示组件里 `ask` 的作答长什么样（带不带步号、问题名），我是照着那两个例子编的。

## cn-crc　CRC 校验

**理想的教法**
- 一个「模 2 竖式」组件，按教材的格式画：被除数在上，商写在上方；每一步把除数对齐到当前最高位，写出异或结果，往下落一位。
- 学生**一行一行自己写**（或者只写商的每一位、最后的余数），哪一行写错页面就指出来。
- 写完后把余数拖到数据后面，拼成发送串；接收方再除一遍；随便翻转一位，看余数变得不为 0。

**现有组件做到了**
- `answer type: bin width:` 判生成多项式的比特串、一次异或、余数、发送串、接收方的余数。
- `derive` 一行一行写出竖式，每一行的二进制都由 `\calc{bin(…)}` 页面算，翻转一位后的余数也由页面算。
- `practice custom`：随机数据、随机挑一个 4 次生成多项式出 CRC 题。

**想做但做不到的**
- **没有 CRC / 模 2 除法组件。**为了「让页面算」，我在 `let` 里把除法拆开写成 `xor`、`shl`、`floor(log2(…))` 的链：
  - 竖式那 4 步，是我自己先除了一遍，才知道正好 4 步。
  - 随机出题时，要写 10 行带保护的 `xor(w, (w >= 16)*shl(g, max(floor(log2(max(w, 1))) - 4, 0)))`。
  - 能用，但很脆，换一个老师多半写不出来。
- **`derive` 不是竖式**：
  - 没有商，没有错位对齐、往下落位，只能把每一行都补成 14 位等宽串硬对齐。
  - 学生只能点「下一行」看，不能自己写某一行再让页面判。
- 学生在 Notability 里写的竖式过程，页面判不了，只判最后的余数。
- 不能从比特串写出多项式（`bin(gen, 5)` 写不成 $x^4+x+1$）。练习题只好直接给比特串，少练了「多项式 → 比特串」这一步。

**拿不准的地方**
- `bin(x, 14)` 四位一组是从右往左分的吗？能不能关掉分组？见通用 10。
- `derive` 里以 `\oplus\ \text{除数} =` 开头的行，等号还对不对得齐？我每一行都写成「标签 = 比特串」来凑对齐。
- `type: bin` 配上值为 0 的 `answer`（`Y10`）、`width: 4`，学生写 `0000` 判不判对？说明没有值为 0 的例子。
- `practice` 的 `width:` 只能写一个固定的数吗？我本想让生成多项式的次数也随机（3 次、4 次），因为不知道 `width:` 能不能写表达式，只好固定成 4 次。

## cn-dv　距离向量路由

**理想的教法**
- 在拓扑图上点一个路由器，旁边弹出它的距离向量表。
- 「交换一次」按钮让所有路由器同时更新（页面按 Bellman-Ford 算）。学生先在表里填自己算的新值（距离 + 下一跳），页面逐格判。
- 可以点断一条链路、改一条代价，看好消息几轮传遍，坏消息怎么一轮一轮慢慢数到无穷大（每一轮一列的表）。

**现有组件做到了**
- `sketch` 画拓扑，代价用 `\calc` 写进图里。
- Markdown 表格列出初始的距离向量。
- `steps` 带着走第一次、第二次交换，`do: true` 那几步的数用 `min(…)` 表达式判。
- `steps` 走一遍「C–D 断了」的无穷计数。
- `practice custom`：随机代价，答案是三个 `min` 表达式组成的向量。

**想做但做不到的**
- **没有距离向量 / RIP 的演示组件。**`net` 只有 bfs、dfs、prim、kruskal、dijkstra、floyd、topo、critical，而且标的是数据结构。
  - 每次交换以后的表，全靠我在 `steps` 里写 `min(…)`。
  - 练习题只能固定一种拓扑，因为每种拓扑「第二次交换后」的式子都得我自己推。
- 路由表填表（距离 + 下一跳）没有组件，下一跳只能做成选择题。
- ∞ 写不进答案（见通用 3）。
- 无穷计数只演示了两轮，后面只能用文字说「一直加下去」，没法让学生看着它一轮轮涨到 16。
- 学生在拓扑图上点出下一跳：没有，`sketch` 不能点。

**拿不准的地方**
- Markdown 表格能不能渲染？说明里只说是「普通 Markdown」。
- `sketch` 的 `<tex>` 里写的 `\calc{cAB}`，取的是不是这节课 `let` 块里的量？
- 计网课里能不能拿 `net` 只画拓扑、不跑算法？见通用 11。
- 「所有路由器同时交换」是同步的模型。坏消息那段我用的是「C 先收到 B 的旧表」的异步说法，而在同步模型下，第一次交换时 B 也会同时收到 C 的「不可达」。两种说法教材里都有，组件没法帮我精确地演示同步的那一种。

## cn-web　访问一个网页要几个 RTT

**理想的教法**
- 一块「搭时序图」的板：学生从工具条上拖出报文（SYN、SYN+ACK、ACK+请求、响应、DNS 查询、ARP 请求……），放在两条时间线之间。
- 页面自动按 RTT 画刻度、数出一共几个 RTT，并检查先后顺序：握手前不能发请求，非持久连接要重新握手，ARP 在 DNS 前面。
- 同一张图上切换「非持久 / 持久 / 流水线」，用动画对比。

**现有组件做到了**
- `sketch`：画了「取一个对象的握手 + 请求」时序图，和「持久、非流水线」的整张时序图。
- `answer` 用表达式（`2*(k + 1)`、`1 + 1 + k`）判 RTT 数。
- `answer type: seq` 排 ARP、DNS、TCP、HTTP 的先后。
- `quiz` 问 ARP 查的是谁的 MAC 地址。
- `practice custom`：换图片数，三种方式一起答。

**想做但做不到的**
- **没有通用的时序图组件。**`tcp handshake` 只画三次握手，`window` 只画数据链路层的帧。HTTP 的几种连接方式、DNS、ARP 都只能用 sketch 手画：静态的，不能动，也不能「揭晓后再画出来」。
- 学生画时序图、页面数 RTT：没有，只能在 Notability 里画、交截图给我看。
- 「非持久 / 持久 / 流水线」这种文字没法随机挑，练习题只好每题三问一起答（见通用 9）。
- 剧透只能靠挪板来躲：「持久、非流水线」的时序图就是第 2 块板那道题的答案，放在同一屏会剧透，我只好把图挪到第 3 块板。如果 sketch 能「答完才出现」，就不用这样拆了。

**拿不准的地方**
- `sketch` 里 `class="small"` 在 iPad 上是多大的字？`<text>` 的 y 是不是基线？我按 SVG 的规矩算过标签不压线，但看不到效果。
- `type: seq` 的答案我写成字母 `c b d a`；学生连写成 `cbda` 也认（说明写了单字符可以连写）。可学生要是写成「ARP DNS TCP HTTP」就会被判错，没有登记同义写法的办法。

## 如果组件库只能再加三样

1. **填表组件（`table`）。**
   - 要什么：
     - 表头、行头；每一格一个答案表达式，可以是数、∞、字母 / 词、点分十进制 IP（带不带 `/前缀`）、二进制。
     - 逐格判，错的格子标出来。
     - 可以一行一行解锁（第 k 轮、第 k 次交换）。
   - 为什么：计网（路由表、每一轮的 cwnd、子网划分表、时序表）、操作系统、组成原理的大题几乎都是「填一张表」。现在只能用矩阵形状的 `answer` 冒充：没有表头，填不了 ∞ 和 IP，也不知道错在哪一格。
   - 顺手把 IP 地址做成 `answer` / `practice` 的一种答案类型。
2. **路由演示组件**（距离向量，最好连链路状态一起）。
   - 要什么：
     - 写拓扑和代价，页面按同步交换一轮一轮算出每个路由器的表（距离 + 下一跳）。
     - `ask:` 问某一格、某个下一跳；`mode: quiz` 让学生写出第 k 次交换后的表。
     - 能「断一条链路 / 改一条代价」，演示好消息传得快、坏消息传得慢和无穷计数。
   - 为什么：RIP / 距离向量是 408 必考，现在完全没有组件，推导和判分全靠老师手写 `min(…)`，换一个拓扑就得重推一遍。
3. **CRC（模 2 除法）组件。**
   - 要什么：
     - 写数据和生成多项式（多项式、比特串都认），按教材竖式一步步画：商、对齐、异或、落位。
     - `ask:` 问下一行、商、余数；`mode: quiz` 写校验码。
     - 能做接收方校验，能翻转某一位看余数。
   - 为什么：CRC 每年都考。这一题我只能拼 10 行的 `let` 链来「让页面算」，竖式也不像竖式，学生没法一步步写、一步步判。

再往后想要的：`window` 加序号位数（演示撞号）；`tcp` 能问 ssthresh、一次问好几轮；有「答完才显示」的段。
