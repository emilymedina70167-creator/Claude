# 拿现在的舞台去实现理想演法，记下接不住的

另外有几个老师，不看现在的技术，写出了理想中想怎么教几块内容（`evals/stage-gaps/ideal/{块}.md`）。你的事：**拿现在的舞台，一幕一幕真的去写、去演，记下哪些做到了、哪些勉强、哪些做不了。** 记下来的东西用来决定舞台下一步补什么，所以要**准**：不夸，也不漏。

## 你手里有的

- **舞台的说明**：`evals/stage-gaps/stage-doc.txt`。这是真上课时老师看到的同一份；8 种东西的写法全带了，不按科目删。只能用这里写了的指令。
- **理想演法**：你这一科的 `evals/stage-gaps/ideal/*.md`。
- **试演工具** `tools/stage-try.mjs`：把一幕放到真的舞台上演。它用的是和学习台同一份课堂循环，只把老师那一端换成假的。所以输出里的东西，就是真上课时老师会收到的。

## 工具怎么用

先构建一次：

```bash
node proto/stage/build.mjs
```

每一幕写一个文件 `evals/stage-gaps/try/{块}/{幕1|分支1|…}.txt`：

- 普通的行是老师的镜头指令，照 `stage-doc.txt` 写。连着的几行是一段，就是老师的一轮。
- `学生:` 开头的一行是学生的一下。
  - **直接动画面**（老师 `open` 交给学生的东西）：
    - `学生: write B.1,1 2`：拨矩阵的一格
    - `学生: mul C.1,2`：点开乘积的一格看怎么算
    - `学生: swap a#1 a#3`：拖格子，或者拖树的结点换值
    - `学生: move s.3 after s.5`：拖句子里的词
    - `学生: vec p u = 3 1`：拖平面上的向量
    - `学生: rotate t.30 left`：在 30 往左转（把 30 的右孩子拖到 30 上）
    - `学生: insert t 47`：托盘里的 47 拖进树；`学生: insert t.45 right 47`：拖到 45 右边的空位（`open t place`）
    - `学生: rowop M r3 - 2r1`：r1 的把手拖到 r3 上、倍数框写 -2；`学生: rowop M r1 <-> r3`：拖到行号上；`学生: rowop M 3r2`：点行号、写 3
    - `学生: write M.2,3 -3/2`：老师写了 `open M edit input=keypad` 时用数字键盘写一格
    - `学生: mark s.2-4 V`：从 s.2 拉到 s.4、点成分；`学生: fold s.3-6`：点这一段的括号折起来
    - `学生: dial k 3`：拨数器拨到 3
    - `学生: undo`：撤一步（老师 `open … undo=on` 时）
    - `学生: pick t.45 t.50`：老师 `ask pick` 时照先后点这几个，再点「点好了」
    - `学生: refer s.23 -> s.15`：从 s.23 的钩拉线松在 s.15 上（`-> s.1-2` 松在那道括号上，`-> s` 松在句子外框上）；`学生: unrefer s.23`：点那条线上的 ✕
    - `学生: unmark s.21`：点学生拉的那道括号上的 ✕
    - `学生: move s.1-6 after s.11`：`open s move` 时按住这一段的括号 0.35 秒再拖到 s.11 后面（`before s.1` 是最前面）
    - `学生: unfold s.5`：点 s.5 所在的小方块
    - `学生: delete t.7`：`open t pluck` / `open t delete` 时点 t.7
    - `学生: compare AB BA`：按住 AB 的括号拖到 BA 上；`学生: put AB Sum`：拖进收集用的 Sum；`学生: merge X Y`：拖到 Y 上并同类项
    - `学生: back t "插入后"`：点「回到插入后」
    - 这几种都和真的手指走同一条路：页面的裁判先判，老师写了 `wrong=block` 又走偏的不演、弹回去；报告里分「没演上」和「页面没让做」
  - **回答正在等的那一问**（老师 `ask` 的）：
    - `学生: tap a.7`：点
    - `学生: drag a#1 a#6`：拖
    - `学生: value 4`：填
    - `学生: value 1 n n(n-1)/2 / 0 1 n / 0 0 1`：按格的那一问一格一格填，「 / 」分行
    - `学生: say 我觉得是……`：打字
    - `学生: next`：点按钮
- 学生动了以后要页面叫老师、老师再接一轮的，就在后面接着写老师的下一段。工具会照真的课堂循环判断「这一下叫不叫老师」，叫了就交出你写的下一段。
- `#` 开头的行是注释。

然后跑：

```bash
node tools/stage-try.mjs evals/stage-gaps/try/L1/幕1.txt --shots evals/stage-gaps/try/L1/shots
```

竖屏、横屏各演一遍。每一步之后输出：
- 演上了几行、**没演上的行和报错原文**；
- **舞台现在**：老师看到的那一段；
- **挑战**判成什么样；
- **页面叫了老师**（为什么，和发过去的整条），或者**还没叫老师、攒着**的；
- **没交给学生**：学生要动的东西没 `open`；
- **排版**：压着的、出了屏幕的；
- **截图**路径。

截图要自己打开看（Read 图片文件）：报告里没报错，不等于画面对。

## 每一项打一个标

主线每一幕标六项：画面、动、老师说、学生做、页面当场、事实。
- 「老师说」只查话里指着画面的东西（`{A.1,1}` 这样的小块）写不写得出来，说什么不用查。
- 「老师凭什么接」是老师自己的事，不打标。
- 每个分支标一项：页面要提供什么。

三种标：
- ✅ **做到了**：写得出来、演出来是理想里那个意思，要的事实在「舞台现在」或者「页面叫了老师」那一整条里有。
- ⚠️ **勉强**：写得出来，但有下面任何一种情况——画面不是那个样子、要绕路（比如没有那种东西，拿格子硬凑）、意思走了样、要的事实不全、要老师自己算。
- ❌ **做不了**：说明里没有能写的指令，或者写了演不出来。

每个 ⚠️ 和 ❌ 下面写三行：
- **要的**：理想里要的是什么，一句话；
- **指令**：你试了哪几行，写文件和行号，或者原样贴；
- **结果**：实际发生了什么，写报错原文、「舞台现在」里缺了什么，或者截图路径。

## 两条纪律

1. **不许改理想去迁就舞台。** 做不到就记 ❌，不许把那一幕改成舞台能做的样子再标 ✅。能做到一部分，就标 ⚠️，写清哪部分做不到。
2. **不许改仓库里的代码。** 只写 `evals/stage-gaps/try/` 和你那一份报告。写错指令先查 `stage-doc.txt` 改对；改了三次还写不出来的，按 ❌ 记，结果里写「照说明写不出来」并贴出最后一版。

## 交什么

写到 `evals/stage-gaps/report/{线代|数据结构|英语}.md`。每块一节，格式固定（有脚本检查）：

```
## L1

- ✅ 第 1 幕·画面：两张矩阵并排，乘积在右边
- ✅ 第 1 幕·动：……
- ⚠️ 第 2 幕·事实：学生改了 B 的一格以后，页面没说「乘积第 1 列变成了 0」
  - 要的：学生改了哪一格、乘积哪几格跟着变成了什么
  - 指令：`try/L1/幕2.txt` 第 3–9 行
  - 结果：「页面叫了老师」那一条只有「学生拨了 B.1,1：1 → 2」和整张 C，没有哪几格变了
- ❌ 分支 1·页面要提供什么：……
  - 要的：……
  - 指令：……
  - 结果：……
```

每一节最后可以加一段 `说明：…`，写你觉得重要、又不在上面任何一项里的发现。比如说明里某条写法写得不清楚，让你写错了好几次。

写完跑：

```bash
node tools/stage-gaps-check.mjs report
```

你这一科是 ✓ 再交。

提到学生就写「学生」。
