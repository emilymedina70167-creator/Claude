# E1 时态：一般、进行、完成、完成进行（be/have 合起来算一个谓语、中间插副词要圈全）

整块画面是一个「时态的世界」，六幕都在里面：上面一条句子（每个词是一块牌，谓语套在一个透明的胶囊里），中间一条时间轴（过去 — 现在 — 将来，上面站着一个能拖的小人），旁边两个拨盘（时间、状态）和一张 4×4 的「时态图鉴」（第 1 幕开始收集，后面几幕一直在）。学生随时能拨、能拖、能圈，句子和时间轴两边互相跟着变。

## 主线

### 第 1 幕：时态的变化全在谓语这一整块里，谓语可以是一个词，也可以是好几个词，但算一个
- 画面：上方一句英文，词是一块块的牌：「Railroads | combine | with each other.」，谓语 combine 套在一个圆角透明胶囊里（别的词是平的纸牌）；句子下面并排两个能转的拨盘：左「时间」四格（过去 / 现在 / 将来 / 过去将来），右「状态」四格（一般 / 进行 / 完成 / 完成进行），起始停在「现在 · 一般」；右下角一张 4×4 的空表「时态图鉴」（行 = 一般、进行、完成、完成进行，列 = 过去、现在、将来、过去将来），格子是空的淡框；最下面的时间轴先压暗，这一幕不用它。
- 动：学生转任何一个拨盘，页面当场换胶囊里的词：现在·进行 → are combining，现在·完成 → have combined，现在·完成进行 → have been combining，将来·完成进行 → will have been combining，过去·一般 → combined，过去将来·一般 → would combine……；胶囊跟着词数伸长缩短，Railroads 和 with each other 一动不动（换词那一刻它们淡淡闪一下灰，表示「我没变」）；没变的词原地不动，只有变了的词淡出、新词从胶囊里长出来（比如 are combining → were combining 只换 are）；某个组合第一次出现时，图鉴里对应的格子亮起、填上这个谓语（像收集卡片）；转到「过去将来 × 进行 / 完成 / 完成进行」时胶囊变成灰的「×」，图鉴那格画叉。
- 老师说：「两个钮随便拨，盯住句子——哪儿在变？」（拨过几下以后）「来个挑战：拨出一个四个词的谓语。」（做到以后）「点这一块里随便哪个词。」最后才给名字：「对，时态 = 时间 × 状态，变化全在谓语这一块里；谓语可以是好几个词，但它们是一个整体，一句只有这一个。」
- 学生做：先自由转两个拨盘；接着做挑战「拨出 4 个词的谓语」；然后点胶囊里任意一个词（比如 been），再点一个胶囊外的词（比如 Railroads）对比。
- 页面当场：每拨一下当场换谓语、伸缩胶囊、亮起图鉴里的格；拨到 4 个词（will have been combining）时胶囊亮一圈，弹出我预写的一句「四个词，还是一个谓语」；点胶囊里任何一个词，整块一起亮（不是只亮那个词），胶囊上浮出小字「一整块」；点胶囊外的词只亮它自己。
- 事实：学生拨过的组合，按先后（例如「现在·一般 → 现在·进行 → 过去·进行 → 现在·完成 …」）；图鉴收了几格、哪几格没碰过、有没有拨到「×」格；挑战用了几下、最后停在哪个组合；学生在「一般」那一行左右拨时间时（combine → combined → will combine，词本身变了或多了 will）和在「进行 / 完成」那一行左右拨时间时（只换第一个词）是不是两种都拨过；学生点的是哪个词、点了几次。
- 老师凭什么接：两种行都拨过、挑战三下以内做到 → 问一句「一般那一行和别的行，拨时间的时候有什么不一样？」，学生说得出「别的行只换第一个词」就进第 2 幕（这正是第 2 幕要钉牢的）；学生只在「一般」行里来回拨 → 我把状态钮拨到「进行」递给学生再拨时间；拨了十几下凑不出 4 个词 → 我让图鉴里「将来 · 完成进行」那一格轻轻闪一下，不说答案。

### 第 2 幕：进行 = be + doing：be 管时间和人称，doing 管「正在」；圈谓语要把 be 和 doing 一起圈
- 画面：换一句真题：「Home prices | are holding | steady | in most regions.」（2004 Text 3），胶囊里是 are holding；拨盘停在「现在 · 进行」；时间轴亮起来：「现在」那根竖线上站着一个小人，小人脚下一段波浪线在往前流（正在进行）；句子左边一个「换主语」卷轴：Home prices / I / The price of these homes / Every cat with an owner。
- 动：学生拨时间钮：are holding → were holding → will be holding，波浪线跟着滑到过去 / 将来那一段；学生转主语卷轴，页面把主语换掉、be 跟着变（I → am holding，The price of these homes → is holding），从 be 拉一根细线连到主语的核心词（连到 price，不连 homes），of these homes 那一截压暗成「修饰」；holding 那块牌在所有变化里一动不动；最后我把句子换成「Every cat with an owner, for instance, is running a small-scale study in operant conditioning.」（2009 完形），时间轴不变。
- 老师说：「这回只拨时间、只换主语，看胶囊里哪个词一直没动？」（学生点出 holding 以后）「那前面那个 are 在管什么？」（卷到 The price of these homes 时我先把 be 那格掏空）「这时候用哪个？先自己放。」最后给名字：「进行 = be + doing：be 管时间和人称，doing 管『正在』，两个合起来才是谓语。」（换到 Every cat 那句）「用笔圈出这一句的谓语。」
- 学生做：拨时间钮、转主语卷轴；点出「一直没变的那个词」；主语停在 The price of these homes 时，从 is / are 两块牌里挑一块拖进胶囊的空格；最后在 Every cat 那句上用 Apple Pencil 一笔圈出谓语。
- 页面当场：拨钮、换主语当场换词、挪波浪线、画主语线；学生点对 holding 时它描一圈金边（我事先允许的）；拖进 are 时，线从 are 连到 homes、中间的 of 那块牌一闪（线跳过了 price），拖进 is 时线连到 price、of these homes 自己压暗；Pencil 圈完，页面把圈住的词吸成学生的胶囊（不判对错、不变色），句里没被圈进去、又长着动词样子的词（比如 running）下面浮出一个小问号牌「这个词归谁？」（我事先允许的反应）。
- 事实：学生点「没变的词」点的是哪个（holding / are / prices）；拖进胶囊的是 is 还是 are，主语核心词页面算的是 price（of these homes 是修饰）；Pencil 圈住了哪几个词（例如「is」「is running」「is running a small-scale study」「cat … is running」），和真正的谓语 is running 比少了谁、多了谁；句子里每个像动词的词是什么形式（is = be 的 does 形式，running = doing，conditioning 是名词化的 -ing、不在谓语里）；圈了几次、擦掉重圈几次、用了多久。
- 老师凭什么接：is 选对、圈出 is running → 第 3 幕；只圈 is（和 EN-L3-03 那次一样）→ 分支 1；选了 are、线连到 homes → 不多讲，让学生把 of these homes 拖开看主语剩下什么（顺手还 cj-b5 那笔欠账，问一句就收）；圈进了 a small-scale study → 我只问「study 长得像动词哪种形式？」，让学生自己把它拖出胶囊。

### 第 3 幕：完成 = 站在一个时间点回头看之前；have 跟着「站在哪」变：had 是站在过去
- 画面：时间轴放大占屏幕中间：左「过去」、中间竖线「现在」、右「将来」；过去段上一个红点「sent（赌场寄来优惠券）」，红点左边一段虚线框「gambled？」，框里写「0 次」；轴上方是句子「He | had never gambled | before the casino sent him a coupon for $20 worth of gambling.」（2006 Part B），had never gambled 在胶囊里，never 那块牌在胶囊里往上拱起一点（这一幕不讲它）；一个能拖的小人提着一盏灯，灯光只往身后（左边）照成一个扇形，小人先站在红点 sent 上，灯光正好罩住「gambled？」那一段。
- 动：学生拖小人：拖到「现在」，胶囊里 had 当场换成 has，gambled 不动，句子后半截 before the casino sent… 变灰（站点已经不在 sent 了）；拖到将来某一点，had → will have；灯光扇形跟着小人走，照到哪段哪段亮，小人前面（右边）一直是暗的；小人每停一处，轴下面印一个印子写着那一处的谓语（had gambled / has gambled / will have gambled），印子排成一列；接着我换成学生上次错的句子「By 1830 the former Spanish and Portuguese colonies had become independent nations.」，轴上标出 1800、1830、2026（现在），小人先放在轴外，事件条还没有。
- 老师说：「拖这个小人，盯住胶囊——哪个词跟着它变？」（拖过三处以后）「灯往哪边照？」「那 had 在说什么？」最后才给名字：「完成 = 站在一个时间点回头看之前。站在过去回头看 = had + done，过去完成时。」（换到 1830 那句）「小人该站哪儿？『变成独立国家』这件事在哪一段？你来摆。」
- 学生做：把小人拖到过去、现在、将来各一处；手写或打一句「had 在说什么」；1830 那句里，自己把小人拖到该站的地方，再在轴上用手指按住拉出「成为独立国家」那件事的一条事件条（从哪年拉到哪年）。
- 页面当场：小人一动，have 那一个词当场换，done 那个词（gambled / become）一直不动、描金边；灯光照亮身后的事件；1830 那句里学生松手以后，小人站在哪、条在哪，页面原样画出来，并画后果：条在小人身后、在灯里 → 胶囊亮一圈（我预写的一句「对，站在 1830 回头看」）；条从 1830 往后拉（像学生上次译的「开始变成」）→ 灯照不到那一截，那一截是暗的，胶囊变成虚线框，页面不说话。
- 事实：小人停过的位置（年份或区间：过去 / 现在 / 将来）和每处对应的谓语；学生写的「had 在说什么」原文；1830 那句：小人落在哪一年（离 1830 多远）、事件条从哪年到哪年、条在灯里的比例（全在 1830 之前 / 跨过 1830 / 全在 1830 之后）；学生有没有点 become 看它的形式（become 的 did 和 done 长得一样，页面按前面有 had 定为 done，并告诉我学生看了没有）。
- 老师凭什么接：小人站在 1830、条在 1830 之前 → 让学生判时态、口头译一遍，说出「截止到 1830 年……已经成为」就进第 4 幕；条从 1830 往后拉，或者把 had become 叫成一般过去时（EN-L3-02 那次就这样）→ 分支 2；三处都拖过却写不出 had 在说什么 → 我把三个印子和三个小人位置对齐成一列让学生对着看，不讲。

### 第 4 幕：现在完成时和一般过去时差在那件事连不连到「现在」；「完成」不等于做完
- 画面：时间轴只留「过去 — 现在」（将来那段压暗），小人提灯站在「现在」；轴上一条事件条「学英语」，左端钉在 15 年前，右端是一个能拖的圆把手，先放在「现在」上、越过一点、带一截往前流的波浪；上方句子「We | have learned | English | for 15 years.」；句子右边一张小牌「现在还在学吗？」，答案跟着条变；下面第二排先藏着：「He | has left | , so I cannot find him now.」，小人脚下一个气泡「现在找不到人」，旁边一块能拖的时间牌「two hours ago」。
- 动：学生拖右端把手：右端碰到「现在」竖线时胶囊里是 have learned、小牌写「还在学」；把右端往左拖离「现在」（比如停在 3 年前），胶囊当场变成 learned（have 淡出），条和「现在」之间空出一段，小牌写「现在不学了」；第二排出来以后：学生把 two hours ago 拖进第二句，has left 当场掉成 left（句子变成 He left two hours ago），时间轴上事件从「影响连到现在」的样子缩成过去的一个点，小人脚下的气泡消失；学生把 , so I cannot find him now 拖走时，气泡也跟着消失，但 has left 不变红。
- 老师说：「拉这条的右头，看句子什么时候少了 have。」（拉过几下）「有 have 的时候，这件事和小人是什么关系？」「这条还没学完，也能说 have learned？」（第二排）「He has left，事情做完了吧？那为什么还用完成时——看小人脚下。」「把 two hours ago 放进去试试。」最后：「现在完成时 = 从过去到现在，做完没做完都行，要跟现在连着；一般过去时 = 只在过去，现在不那样了，常带过去的时间。」
- 学生做：来回拖右端把手几次；在小牌「完成 = 做完了吗？」下面点「是 / 不一定」；第二排里把 two hours ago 拖进句子、再拖出来，把 so I cannot find him now 拖走再放回来；最后一个小挑战：给出「...the response has been favorable...」「...the response was favorable...」两句，学生给每句各拉一条事件条（右端拉到哪儿）。
- 页面当场：右端碰到「现在」那一刻胶囊长出 have、离开那一刻 have 淡出，句子当场读成另一句；two hours ago 拖进去 has 当场掉下来变成 left（我事先写好的规则：句里有 ago 这种过去的时间点，谓语换成一般过去）；response 两句学生松手后，页面把条画在学生拉到的地方：has been 那条右端碰到「现在」→ 胶囊亮一圈（预写的反应）；was 那条右端也拉到「现在」→ 只照样画出来，不评判。
- 事实：右端停过的位置和每次胶囊里是什么（几次停在「现在」上、几次离开）；学生点的「是 / 不一定」；two hours ago、so I cannot find him now 各拖进拖出几次；response 两句各拉成什么样：has been 那条右端离「现在」多远，was 那条右端在不在「现在」之前。
- 老师凭什么接：点「不一定」、response 两条都对 → 第 5 幕；点了「是」（以为完成 = 做完）→ 我把学英语那条右端越过「现在」往前流的那一截放大给学生看，问「这一截学完了吗」；was 那条也拉到「现在」→ 我把「现在还……吗？」那张小牌挂到 was 那句上，让学生自己对着读。

### 第 5 幕：完成进行 = have + been + doing：been 是「完成」和「进行」拼起来共用的那个词；强调过程用它，强调结果用完成时
- 画面：两块拼图牌：左「完成：have + done」，右「进行：be + doing」，done 那一格和 be 那一格的边是能咬合的齿；下面一句真题「That kind of electronic spying | ＿＿＿＿ | for decades.」（2003 Text 1），谓语是一个空槽，空槽旁边一张动词卡 go on；时间轴：小人提灯站在「现在」，过去那一段从几十年前开始；右边再放一对句子和两张中文意思卡：「We have not won the match.」配「我们没赢下这场比赛」，「We have been working hard for several months.」配「我们努力了好几个月」，每句下面一个开关「强调结果 ◉ / 强调过程 〰」。
- 动：学生把两块拼图拖到一起：done 和 be 那两格重叠，be 变成它的 done 形式 been（这一个词同时属于两块），拼成「have + been + doing」三格；学生把拼好的牌拖进空槽，go on 自动套进去成 has been going on，has 拉一根线连到主语核心词 kind（of electronic spying 压暗）；时间轴上同时出现灯光（完成的回头看）和一段一直流到小人脚下的波浪（进行的过程）；学生拨两句下面的开关，句子在两种形式之间变（have been working ↔ have worked），时间轴上对应地变成小人脚下的一枚结果印章或一条流动的波浪。
- 老师说：「这两块能拼起来，试试。」（拼好以后）「中间那个词归哪一块？」（点 been 以后）「been 是 be 的哪种形式？」「拼好的放进 spying 那句。」「对着中文拨这两个开关——哪句在说『一直在做』？」最后：「have been doing：站在现在回头看，强调过程；have done：回头看，强调结果。」
- 学生做：拖两块拼图咬合；点中间那个共用的词；把拼好的牌拖进 spying 那句的空槽；对着两张中文意思卡拨两个开关；再点出 spying 那句里「告诉你在强调过程」的那块牌。
- 页面当场：拼图咬上时 be 当场变成 been、整块亮一下；点 been 弹出它的形式卡（be / was·were / been / being），been 那格亮、标「done」；空槽套进去后句子读顺、主语线连到 kind；拨开关当场换谓语、换时间轴上的印章或波浪（开关只在两种合法的形式之间换）。
- 事实：拼图试了几次才咬上、学生先拿哪一块去靠；点的是哪个词（been / have / doing）；空槽里最后是什么（has been going on / have been going on）；两句的开关最后停在哪：「没赢下比赛」配的是结果还是过程，「努力了好几个月」配的是哪一个；学生点的「强调过程的牌」是哪块（for decades / electronic / spying）。
- 老师凭什么接：拼得出、点得出 been 是 be 的 done、两个开关都对 → 第 6 幕；把 been 当成「过去」（形式卡上点了 was）→ 我把 been 和第 3 幕 had become 里的 become 两张形式卡并排，让学生看两个都在 done 那一格，再把小人拖回第 3 幕那一下；has / have 放错 → 我把 That kind of electronic spying 拆开拖远一点，让学生自己看核心词是哪个。

### 第 6 幕：副词夹在 be/have 和后面那个词中间：要从第一个词圈到最后一个动词，副词在里面；再判时态、按中文语序译（真题演练）
- 画面：一叠卡片，一次一张真题句，第一张是学生上次错的那句「Scientific publishing has long been a licence to print money.」（2020 Text 2）；卡片下面是前几幕收集好的时态图鉴，缩成一排能把胶囊拖进去的格子；最下面一行中文积木「科学出版业」「长期以来」「一直是」「一本万利」，打乱放着；后面依次排着：Americans' life expectancy has nearly doubled over the past century.（演练 12）、...lots of working folks had already seen signs of the slowdown themselves.（演练 10）、A good innovational thinker is always exploring the many other possibilities.（演练 17）、In recent years, railroads have been combining with each other...（演练 15）、This tendency in the natural sciences has long been evident in the social sciences too.（演练 18）、The question of GDP and its usefulness has annoyed policymakers for over half a century.（例句，带中文积木「半个多世纪以来」）。
- 动：学生用 Apple Pencil 在句子上一笔圈谓语（圈得歪也行），页面把圈吸到最近的词边上变成胶囊；胶囊里如果夹着副词，学生能把副词往上一挑，副词浮到胶囊上方一格，胶囊在下面合拢（has long been → has been）；学生把合拢的胶囊拖进图鉴的一格；学生排中文积木；一张卡做完翻下一张。
- 老师说：「先圈这一句的谓语，按你想的圈。」（圈完）「胶囊里有不长动词样子的词吗？挑出来。」「放进图鉴哪一格？」「排中文：哪块先说？」后面几张卡我只在学生停住、或者和前一张错法一样时才说话。
- 学生做：每张卡：Pencil 圈谓语 → 把夹在中间的副词挑出来 → 把合拢的胶囊拖进图鉴的一格 → 排中文积木（最后两张不给积木，用 Pencil 手写译文）。
- 页面当场：圈完页面只把圈吸成胶囊（不判）；挑副词：只有副词挑得出去，挑 been、doubled 挑不动（弹回来、抖一下：它是动词形式，属于谓语，这是画面后果）；胶囊拖进格子：页面按公式算时态，对的格子把胶囊吸进去、亮一下，弹出我预写的一句（比如「has been = have + done，现在完成」），不对的格子不吸、胶囊滑回原位（我事先允许页面这样判）；中文积木排好以后，页面在英文块和中文积木之间画对应线，不评判；整张卡做完翻下一张。
- 事实：每张卡：学生圈住的词和真正谓语比（只圈 has / 圈了 has long / 圈到 a licence / 圈对 has long been），少了谁、多了谁；副词挑没挑出来、挑的是哪个、有没有想挑动词；胶囊拖到了哪格、第几次才吸进；中文积木最后的顺序，时间状语（长期以来 / 半个多世纪以来 / 近年来 / 过去一个世纪里）在谓语前还是在句末；手写译文认出来的原文；每张卡用的时间；这一叠里哪种夹法（has long been / have already seen / is always exploring / has nearly doubled）最慢、错得最多。
- 老师凭什么接：一叠里圈全、格子对、语序对 → 下课前换两句没见过的真题（不带积木、不带图鉴，手写「谓语 + 时态 + 译文」）看学生能不能整套自己做；只圈 has、丢 been，或把 to print 也圈进来 → 分支 1；胶囊拖进「一般 · 过去」→ 分支 2；时间状语排到句末 → 分支 3。

## 分支 1：谓语没圈全（只圈 has / is / had，丢了 been / running / become），或者把非谓语 to print 当成谓语
- 学生会怎么做：在「Scientific publishing has long been a licence to print money.」上只圈 has（或 has long），been 留在胶囊外面；在「Every cat with an owner, for instance, is running a small-scale study…」上只圈 is；或者把 to print 里的 print 也圈成谓语，一句里出现两个胶囊。
- 老师想演什么：我不说「漏了 been」。让页面「按学生圈的读」：把学生的胶囊当作整句唯一的谓语，把句子剩下的词按「谓语就是 has」重新排——has 成了实义动词「拥有」，句子读成「科学出版业长期拥有……」，been 那块牌没处放，悬在半空、下面一个问号；学生点 been 看形式卡（be / was·were / been：done），我把第 5 幕的「完成：have + done」拼图牌拿过来，让学生把 has 和 been 往两格里放——正好填满，胶囊自己补全成 has long been；最后让学生自己数：这句里长得像动词的词有几个（has、been、print），每个只能去一个地方：谓语胶囊，或者「非谓语」托盘；to print 拖进胶囊时胶囊不收、弹回托盘（前面有 to）。is running 那句一样：按「谓语就是 is」读，running 悬空，学生把 is 和 running 放进第 2 幕的「be + doing」两格。
- 页面要提供什么：按学生圈的那一块当谓语，把句子剩下的词重新排一遍、画出哪些动词形式没处放（「悬空」的词）；每个词的词形（do / does / did / done / doing / to do）和它在这句里属于谓语还是非谓语；学生圈的和真正谓语的差（少了 been / running，多了 long 之外的 a licence 等）；学生放进拼图两格的是哪两个词、动词形式分到胶囊和托盘的结果、哪个分错；告诉我这是不是和 EN-L1-01、EN-L3-03 同一个样子（W40 又出现了一次，这次是第几张卡）。

## 分支 2：完成时判成一般过去时（had become / has been 叫「一般过去时」，译成「曾经……」「开始变成」）
- 学生会怎么做：把 had become 的胶囊拖进图鉴「一般 · 过去」那格；把 has long been 判成一般过去时、译成「曾经是……」；1830 那句把事件条从 1830 往后拉（「1830 年开始变成」），或者把小人放在「现在」。
- 老师想演什么：把学生的判断照原样演出来，让学生自己看出和原句不是一个画面：学生说一般过去，页面就把句子改成真正的一般过去「The colonies became independent nations in 1830.」，画成 1830 那一点上的一个圆点（小人不用提灯）；原句「By 1830 … had become …」画成小人站在 1830、灯照着身后那一整段；两幅上下并排，学生自己点哪一幅是原句。再点 become 的形式卡：become / became / become，原句里是第三格 done，前面有 had，套进第 3 幕的「have + done」正好是完成。has long been 那句同样：「…was a licence…」和「…has long been a licence…」并排，一条右端离开「现在」，一条右端连到小人脚下（第 4 幕那一条）。最后两句中文「截止到 1830 年，……已经成为独立的国家」「1830 年，……开始变成独立的区域」，学生各拖到上下两幅图里配上。
- 页面要提供什么：能把同一句换成学生说的那个时态（became in 1830 / was），按换后的时态画在时间轴上，和原句的画面并排；告诉我学生拖进了哪格、按那一格换出来的句子是什么；每个动词的三种形式和这一句用的是哪一种（become 的 did 和 done 同形时，按前面有没有 had 定是 done）；学生两句中文各配到了哪一幅；1830 那句里学生拉的条的起止年和小人的位置。

## 分支 3：翻译时时间、地点状语留在句末，没调到中文语序（W41）
- 学生会怎么做：「The question of GDP and its usefulness has annoyed policymakers for over half a century.」排成「GDP 及其有效性的问题 / 一直困扰着 / 政策制定者 / 半个多世纪以来」；「Home prices are holding steady in most regions.」手写成「房价保持稳定在大多数地区」。
- 老师想演什么：让学生自己读出别扭、自己把状语挪到前面，并看到它和时态是连着的：for over half a century 正是第 4 幕那种「从过去连到现在」的条的长度。画面上英文在上、学生的中文积木在下，每块中文积木和它对应的英文块之间连一根线（学生的顺序下线是平行的，中文读起来是英文的顺序）；我把「半个多世纪以来」那块积木变成时间轴上那条条的标签（条从半个世纪前一直到小人脚下），让学生拖着这块积木往句子前面放，其余积木自动让位；再让学生自己拿 Home prices 那句把「在大多数地区」挪一次。规则不由我说，学生挪完两句后我只问「中文里时间、地点放在哪儿？」
- 页面要提供什么：每块中文积木对应哪块英文，各是什么成分（时间状语、地点状语、主语、谓语、宾语）；学生排出的顺序里状语在谓语前还是在句末；英文块和中文积木之间的对应线；学生手写的译文认出来以后，状语短语在中文句里的位置；告诉我这和 W41 以前记的是不是同一种错、这一节里出现了第几次。
