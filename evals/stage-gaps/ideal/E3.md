# E3 非谓语动词（作主语、宾语、表语、定语、状语）

## 主线

### 第 1 幕：一句话只有一把谓语座位，多出来的动词要换个样子（doing / to do）才放得进去
- 画面：板中间一条词块句「laugh · probably · has · little influence · on physical fitness」（2011 年完形原句，把 laughing 还原成原形），每个词一块；laugh 和 has 是动词块（金边），laugh 底下挂一个形态拨轮（原形 laugh / 三单 laughs / 过去式 laughed / doing / done / to do，开始停在原形），has 不能拨；句子上方只有一把金色座位，牌子写「谓语」；右上角一个计数「想当谓语的动词 2 · 座位 1」；句子下面一行空着，留给中文读法；第二条「suffer · is · inevitable」（2014 阅读 C 节，suffer 也带拨轮）先藏在下面。
- 动：学生拨 laugh 的拨轮，那一块当场换词形，页面马上重算谁想当谓语：有人称、有时态的（has、laughs、读成过去式的 laughed，还有句首光秃秃的原形 laugh）底下亮一道金线往上连到座位，两道金线挤一把座位时座位抖一下、计数是 2；laugh 拨成 laughing 或 to laugh 时它的金线熄掉换成银线，这一块自己套上一个「主语」括号，计数变 1，读法行出中文；拨成 done 时银线是虚的，括号套不上（done 当不了主语这个事实由页面算）。
- 老师说：「两个动词，一把座位。拨一拨 laugh，让这句话通顺。」通了以后指着 laughing：「它现在还是谓语吗？在句子里当什么？」
- 学生做：在 laugh 的拨轮上随便试，觉得通了点「就这样」；接着在第二条句子上拨 suffer。
- 页面当场：词形、金线银线、计数、座位抖动、主语括号当场变（画面后果）；老师事先允许的反应：第一次停在「Laughing probably has …」或「To laugh probably has …」时读法行出「笑对身体健康的影响可能很小」，座位上方冒一句「通了」，然后 suffer 那句从下面滑上来；suffer 那句停在 suffering 或 to suffer 时读法行出「苦难是不可避免的」。
- 事实：学生拨过的形按顺序列出，每一形当时想当谓语的有几个（例：laughs → 2；laughed → 读成过去式是 2、读成 done 当不了主语；laughing → 1，作主语）；laughed 这种 -ed 词两种读法都标出来；从开始到拨通拨了几下、用了多久；第二句第一下拨到哪个形；点「就这样」时停在哪个形。
- 老师凭什么接：两句都很快拨到 doing / to do，说得出「变成像名词的东西当主语」→ 第 2 幕；停在 laughs、laughed 这种两个谓语的形上就点「就这样」，或者说不出 laughing 还算不算谓语 → 分支 1 的演法（两道金线挤一把座位，让学生自己看第二道挤不进去）；拨到 to laugh 也算通，不追问，留到第 4 幕讲 doing 和 to do 作主语时位置的差别。

### 第 2 幕：to do 一定不是谓语；doing / done 挨着 be / have 才和它合成一个谓语，单独出现就不是
- 画面：四条句子上下排开，每个词一块，都没有标记：①「Every cat with an owner, for instance, is running a small-scale study in operant conditioning.」（2009 完形，学生 10 月只圈了 is 的那句）②「Fortunately, the White House is starting to pay attention.」（2005 阅读 Text 2）③「The human nose is an underrated tool.」（2005 完形）④「The human nose is underrated.」（老师从③改写，句尾标「改写」）；每条右边一个盖着的计数「谓语 ?」；板边一个空托盘，能放从句子里拿出来的词块。
- 动：学生用手指或 Pencil 圈词，圈住的词块吸齐成一个金框；学生能把 is 从句子里拖进托盘，句子当场合拢（①变成「Every cat with an owner, for instance, running a small-scale study …」），原来和 is 吸在一起的 running 散开、变成银色，句尾出一个红色缺口「这句没有谓语了」，计数掀开变 0；拖回去，is 和后面的 running「啪」地吸成一个金框。to pay 这种块左边有一枚小锁（to 锁），拿 is 去靠它吸不上；③的 underrated 前面隔着 an，拿 is 去靠也吸不上；④的 is underrated 本来就吸在一起。
- 老师说：「每句圈出完整的谓语，一句只有一个。」圈完：「把①里的 is 拿出来，running 还是谓语吗？」最后指着②的 starting 和 to pay、③④的两个 underrated：「同样是 doing、done，什么时候算谓语？」
- 学生做：四句各圈一个谓语；自己拿 is 进出托盘试几次（哪一句都行）；最后在下面的框里写一句规律。
- 页面当场：圈的范围按词块吸齐；拿出、放回时的散开、吸合、缺口、计数；小锁和吸不上（画面后果）；老师事先允许的反应：四句都圈对（is running / is starting / is / is underrated）时四个计数一起掀开「1 1 1 1」，每句里没圈的动词底下出银线和一个小签（to pay → to do；③的 underrated → 单独的 done）。
- 事实：每句圈住了哪几个词、改圈了几次（例：①只圈了 is；②把 to pay 也圈进去）；学生拿 is 试过哪几句、拿出时看到了什么（running 散开、计数 0）；有没有拿 is 去靠 to pay 或③的 underrated；写的规律原文；规律里有没有提到 done、have。
- 老师凭什么接：四句都对、规律里说到「挨着 be / have 才算」和「to do 一律不是」→ 第 3 幕；①只圈 is（EN-L3-03 的老样子）或②把 to pay 圈进谓语 → 分支 1；规律只说 doing 没说 done → 指③④让学生对着看两个 underrated，再往托盘里放一块 have，当场写一条「Millions of mothers have gone to work.」让学生拿掉 have，看 gone 怎么变。

### 第 3 幕：doing / to do 连同它带的宾语和修饰整块当一个名词作主语，一整块是「一件事」，谓语用单数
- 画面：上面一条「Making friends ( is / are ) extremely important to teenagers.」（2003 完形），谓语位置是一个 is / are 拨轮；下面一条「To anticipate every imaginable driving situation is a difficult programming problem.」（2019 阅读 Text 3），To 前面钉着一个括号的左把手，右把手先停在 anticipate 后面；两条句子底下各有「主语｜谓语｜表语」三格骨架，格子空着。
- 动：第一句学生先拨 is / are，再拖括号框主语，框住的词合成一整块、底色统一（老师打开的话，块上方出一张小签「一件事」）；第二句学生拖右把手往右一块一块扩，括号停在哪页面就在哪重新分块：括号里是一块，括号外剩下的词按位置对应骨架的格子亮起来；括号只框到 anticipate 时，anticipate 后面冒出一个虚线小插口「预见……什么？」（anticipate 是及物动词），宾语框进来插口才消失；括号扩到 situation 时整块落进骨架的「主语」格。
- 老师说：「先拨：is 还是 are？」拨完不说对错：「把主语框出来。」第二句：「这个主语从哪到哪？anticipate 后面那个小口要填上。」
- 学生做：拨 is / are；框出 Making friends；第二句把右把手拖到它觉得的主语末尾；最后在框里写一句「什么样的东西能当主语」。
- 页面当场：拨轮、括号吸齐、整块底色、插口出现消失、落进骨架格子（画面后果）；老师事先允许的反应：第一句框成 Making friends 并且停在 is 时，读法行出「交朋友对青少年来说是极为重要的」；第二句框到 situation 时出「预见每种可能的驾驶情况是个困难的编程问题」。
- 事实：第一句先拨的是 is 还是 are（拨 are 就是把 friends 当成了主语核心，和 EN-L3-09 把 books 当核心是同一个毛病）、框完以后改没改拨；第二句右把手停过的词按顺序（例：anticipate → every → imaginable → situation），最后停在哪，插口出现时学生停了多久；学生写的那句原文。
- 老师凭什么接：第一句先拨 are → 先不说，等学生框成 Making friends、看见整块，再问「一件事用 is 还是 are」让学生自己改；第二句一次框到 situation、写出「doing / to do 连着后面一串当名词」→ 第 4 幕；右把手停在 every / imaginable / driving 上就不动了 → 分支 2。

### 第 4 幕：to do 作主语常挪到句尾、句首用 It 占位；能分清占位的 It 和真的「它」
- 画面：第 3 幕框好的那句「To anticipate every imaginable driving situation is a difficult programming problem.」，主语整块还亮着；下面两条先盖着：「It is painful to read these roundabout accounts today.」（2010 阅读 C 节）「It is important to do so.」（2002 完形）；最后一条判别句也先盖着：「It also raises questions concerning "values."」（2002 阅读 B 节）。
- 动：学生按住主语整块往句尾拖，离开句首时句首留一个空洞，松手在句尾，空洞里冒出一块「It」，It 和句尾那块之间连一根虚线，句子重排成「It is a difficult programming problem to anticipate every imaginable driving situation.」；反过来把句尾的 to do 块拖回句首，It 收回去、虚线消失；学生只拖了块里的一部分（比如只拖 to anticipate），剩下的词留在原处，页面照样重排，读法行照这个样子读。
- 老师说：「主语这么长，头重脚轻。把它整块挪到句尾，看看句首会怎样。」挪完：「这个 It 指谁？」后两句：「反过来做：把真正的主语找出来，挪回句首。」
- 学生做：挪第一句；第二、三句先框出 to do 块（右把手拖到 today、so），再拖回句首；最后在判别句里试着找一块「真正的主语」去换 It。
- 页面当场：空洞、It 冒出来和收回去、虚线、重排后的句子（画面后果）；老师事先允许的反应：第二句挪回句首后读法行出书上的译文「现在要去理解这些拐弯抹角的解释是令人痛苦的」；判别句里学生拖 concerning "values" 去换 It 时 It 不收回（这个 It 后面没有能被它占位的 to do 块，是页面算的），读法行出直译「涉及价值也提出了问题」，让学生自己读出不通。
- 事实：每次拖的是整块还是一部分（拖了哪几个词）；It 出来以后学生有没有把它删掉或再拖走；第二、三句框到哪个词才拖；判别句里学生拖了什么去换 It、试了几次才停；学生回答「It 指谁」的原文。
- 老师凭什么接：三句都利落、判别句里自己说出「这个 It 就是它，后面没有真正的主语」→ 回到第 3 幕的 Making friends，让学生也把它挪到句尾读一读（读得通但考研里少见：doing 作主语多在句首，to do 多在句尾用 It），一句话收住 → 第 5 幕；只拖了一部分 → 分支 2 的做法；把 It 当成指前文的代词 → 让学生把句尾那块拖回 It 的位置读一遍，读得通的就是占位的 It。

### 第 5 幕：作宾语时介词后面只能接 doing，动词后面接哪个看这个动词；系动词后面的 to do 是表语
- 画面：左边一块能拖的词组「make connections in the brain」，带拨轮（原形 / doing / to do / done）；右边一列六张「前面的词」卡：enjoy、want、begin、of、without、by，每张卡后面一个空位；底下一张 6 行 × 2 列的表（行是这六个词，列是 doing、to do），格子空着；表下面三条真题句先盖着：「Americans stopped taking prosperity for granted.」（2000 阅读）「Thinking is essentially a process of making connections in the brain.」（2014 完形）「The trick is to direct these funds better.」（2013 阅读 B 节）；最边上四块小卡「Seeing」「To see」「believing」「to believe」和一块「is」。
- 动：学生把词组拖到某张卡后面的空位、拨轮拨到 doing 或 to do，表里那一格先记成学生的猜（问号）；学生点卡片，卡片翻过来，背面是这个词的搭配（enjoy：doing 能 / to do 不能；begin：两个都能……，从搭配表里取），表里那一行的问号换成「能 / 不能」，和学生的猜一致的格子和不一致的格子颜色分开；三条真题句揭开以后，学生在每句上框非谓语块、贴成分签（主语 / 宾语 / 表语）；贴在 is 后面那块的签旁边出一个能点的「＝」，点一下等号两边对调，句子重排成「To direct these funds better is the trick.」。
- 老师说：「先猜：每个词后面接 doing 还是 to do？猜完一行翻一张。」三个介词翻完：「of、without、by 有什么共同点？」最后指着 The trick 那句：「is 后面这块是宾语吗？点一下等号。」
- 学生做：六行都先猜再翻；在框里写「介词后面接什么」；三条真题句框块、贴签，点等号对调；最后用四块小卡和 is 拼出两句自己觉得对的。
- 页面当场：拖放、拨轮、翻卡、表里的能 / 不能和学生的猜分色、框块吸齐、等号对调的动画和对调后的句子（画面后果）；老师事先允许的反应：小卡拼成 Seeing is believing 或 To see is to believe 时出一个小勾，拼成 Seeing is to believe 或 To see is believing 时两块边上出小字「前后不一样」。
- 事实：每一行先猜的是什么、翻卡以后对了几行，三个介词行是不是一开始就都猜 doing（还是翻了一张才改）；学生写的规律原文；三条真题句的框和贴签（例：把 to direct these funds better 贴成宾语；of making connections in the brain 有没有框全）；等号点了没有、对调前后改没改签；小卡拼成了哪两句。
- 老师凭什么接：介词三行一开始就全猜 doing 或翻一张就改对、写出「介词后只能 doing」→ 第 6 幕；The trick 那句贴成「宾语」（W44：is 标对后直接数后面的块，没先看是不是系动词）→ 让学生点等号对调，对调读得通就是「主语 ＝ 表语」，再把 is 头上亮出系动词的标记（老师当场写），让学生自己把签改成表语；学生问 stop 后面接 to do 什么意思 → 一句话带过（停下来去做别的），不展开，书上没讲。

### 第 6 幕：修饰名词的是定语，看这个名词和动词的关系：主动用 doing、被动用 done、目的用 to do
- 画面：三条句子，谓语已经是金框（前几幕的样子），多出来的那个动词还是原形、带拨轮（doing / done / to do）：①「The human nose is an (underrate) tool.」（2005 完形）②「It also raises questions (concern) "values."」（2002 阅读 B 节，第 4 幕的判别句）③「Permission (run) a nuclear plant is a public trust.」（2012 阅读 Text 2）；每条右边一个空的「代入」小窗；板下面一张三行的小表「doing ＝ ？ / done ＝ ？ / to do ＝ ？」空着。
- 动：学生从动词块拉一根线连到一个名词，线是弯的、箭头落在名词上；代入窗当场换成用这个名词当主语的三张卡：主动「the tool underrates …（工具去低估别的）」、被动「the tool is underrated（工具被低估）」、目的「the tool is to underrate …（工具是为了去低估）」；学生点一张卡，拨轮自己转到对应的形（主动 doing、被动 done、目的 to do），读法行出中文；学生也能先拨拨轮，代入窗把对应的那张卡亮起来；线改连到 nose，三张卡就换成 nose 当主语的。
- 老师说：「这些动词没座位了，它们去修饰谁？拉根线连过去。」连上：「把 tool 放进去读：工具低估别人，还是工具被低估？」三句做完：「doing、done、to do 各是哪种关系？填表。」
- 学生做：每句拉一根线；在代入窗里挑读得通的那张卡，或者直接拨拨轮；②③把动词后面带的宾语一起框进修饰块（concerning "values"、to run a nuclear plant）；最后填表。
- 页面当场：线、代入卡、卡和拨轮联动、读法行（画面后果）；老师事先允许的反应：一句的线连对、形也对时线变实线，修饰块和名词并成一块名词词组，名词前面冒出书上的「……的」译法（被低估的工具 / 涉及「价值」的问题 / 运营核电站的许可）。
- 事实：每句的线连到哪个名词（①连 tool 还是 nose）、改过几次；挑了哪张卡、拨轮最后停在哪、先拨还是先连；②③的修饰块框到哪个词（有没有把 "values"、a nuclear plant 带上）；表里学生填的原文。
- 老师凭什么接：三句都对、表填对 → 第 7 幕；①连到 nose 或拨成 underrating → 不说对错，指着代入窗让学生把两张卡对着读；③挑了主动卡拨成 running → 让学生读「许可在运营核电站」和「许可是为了（让人）运营核电站」，自己挑；修饰块框到一半就停 → 分支 2。

### 第 7 幕：修饰整句的是状语，它的逻辑主语是句子的主语；修饰谁看位置、看逗号，拿不准就代入
- 画面：上面一对句子并排：「I saw a passing plane.」「Passing the cafe, I saw a friend.」，两个 passing 块各带一个线头，逗号画成一道竖着的粉笔小墙，每句的主语 I 头上一个「句子主语」小牌，整句底下一道横杠代表「整个句子」；下面三条先盖着，多出来的动词是带拨轮的原形：「In just one generation, millions of mothers have gone to work, (transform) basic family economics.」（2007 阅读 Text 3）「(test) this idea, he turned to the university-admissions process.」（2013 完形）「Depending on the comments (receive), the editor would accept the paper for publication or decline it.」（2008 阅读 Text 2）；右边还是第 6 幕的代入窗。
- 动：学生从线头拉线，连到某个名词或连到整句横杠（连横杠就是连到句子主语）；代入窗当场用连到的那个当主语出三张卡，英文代入句和中文都有（例：连 cafe →「the cafe passes …（咖啡馆经过……）」；连横杠 →「I pass the cafe（我经过咖啡馆）」）；线穿过逗号小墙时墙亮一下（只亮，不拦）；下面三句学生拨形、拉线，拨到的形和亮起的卡互相联动，和第 6 幕一样。
- 老师说：「两个 passing，各修饰谁？拉线。」连完：「把你连的那个放进去读一读。」下面三句：「先拨形再拉线；最后一句有两个动词，一个一个来。」
- 学生做：两个 passing 各拉一根线，看代入卡，觉得不对就改线；下面三句各拨形、拉线，最后一句 depend、receive 各一根；最后在框里写一句「定语和状语差在哪」。
- 页面当场：线、墙亮、代入卡、拨轮联动、读法行（画面后果）；老师事先允许的反应：一根线连对、形也对时线变实线，状语那根在句子旁边补出书上的译法（「改变了基本的家庭经济（模式）」「为了验证这一观点」「编者依靠收到的评论来决定……」）。
- 事实：每根线连到哪（例：Passing 连到 cafe / friend / 整句）、改过几次、改之前读过哪几张卡；线有没有穿过逗号；拨轮最后停在哪个形；Depending 那句两根线是不是各连对（received → comments，被动，定语；Depending → 整句 / editor，主动，状语）；transform 有没有拨成 transformed（读成「母亲们被改变」）；学生写的那句原文。
- 老师凭什么接：都对、写出「定语修饰名词、状语修饰句子，看的是谁去做」→ 第 8 幕；线连到挨着的名词（cafe、comments、work）→ 分支 3；(test) 拨成 testing → 指代入窗里「he 去验证」和「he 为了验证」两张卡，问句子里的 he 是边验证边转向，还是为了验证才转向。

### 第 8 幕：分析句子先找谓语，作主宾表的非谓语留着，作定语状语的先折起来——自己拆一次 8 月拆错的句子
- 画面：学生 8 月做错的那句「Policies designed to help small businesses often fail.」（EN-L3-01），每个词一块，没有任何标记；上方「主干」一行空着；右边一棵空的用法树（两支：「当名词用：主语 / 宾语 / 表语」「修饰：定语（修饰名词）/ 状语（修饰句子）」，每片叶子下面 doing / done / to do 三个小格）；这节课做过的句子缩成小卡片排在树底下（Making friends …、to anticipate …、taking prosperity for granted、to direct these funds better、underrated、to run a nuclear plant、transforming …、To test this idea、Depending on …、received）。
- 动：学生照这节课的做法一步步来：圈谓语（金框，be / have 吸合和 to 锁照旧）、框非谓语块（括号）、拉线到修饰对象（代入窗照旧）、给块贴成分签；贴了「定语」「状语」的块能往上一推折起来，折成一个小圆点挂在原处（点一下展开）；折到只剩核心时，主干那一行自动写出剩下的词；树底下的小卡片能拖到树叶的小格里，放上去就停在那里。
- 老师说：「这句你 8 月拆过。用今天的办法自己拆：先找谓语。」拆完：「主干是什么？翻译写下来。」最后：「把今天的句子挂到树上。」
- 学生做：圈 fail；框出 designed to help small businesses；拉线到 Policies；把它折起来；在主干行下面写主干和译文；把十张小卡挂到树叶上（例：Making friends → 主语 · doing；to run a nuclear plant → 定语 · to do）。
- 页面当场：金框、括号、线、折叠展开、主干行（画面后果）；老师事先允许的反应：主干只剩 Policies … fail 时，旁边淡淡地并排放出学生 8 月的旧答案（主干「policies help small businesses」、译文「设计的支持来帮助经常失败的小企业」）；小卡挂到树上只停住，不判对错。
- 事实：圈的谓语是哪个（fail / help / designed）、改了几次；框块的左右边界；线连到哪；折起来的是哪几块，有没有把作主宾表的块也折了；写的主干和译文原文；树上每张卡挂在哪片叶子哪一格，和每张卡在前几幕里的成分对不对得上（页面按前几幕的结果比，只告诉老师）；从开始到写完主干用了多久。
- 老师凭什么接：一次圈对 fail、主干写 Policies fail、译文意思对 → 拿旧答案对比一句话收住，再看树上挂错的卡，一张张点开让学生回看那根线或那个括号自己改；圈了 help 或 designed → 分支 1；框块断在 small 那里（designed to help small | businesses）→ 分支 2；树上把 Depending 挂到定语、received 挂到状语 → 拿第 7 幕那句重新拉一次线。

## 分支 1：把非谓语当成谓语，或者谓语没圈全（W40、EN-L3-01、EN-L3-03）
- 学生会怎么做：第 8 幕「Policies designed to help small businesses often fail.」里圈 help（或 designed）当谓语，主干写成「policies help small businesses」，把 often fail 挂到 businesses 上，译成「设计的支持来帮助经常失败的小企业」；或者第 2 幕的猫那句只圈 is、不带 running，第 1 幕停在 laughs + has 这种两个谓语的形上。
- 老师想演什么：不说「错了」，让页面把学生这种拆法的后果摆出来：按学生的拆法 help 坐上座位，可 fail 也有时态，第二道金线也伸向座位，两道挤一把（和第 1 幕一样抖一下），fail 前面冒出一个空的主语插口「谁失败？」；再把 help 前面那枚 to 锁放大闪一下，请学生把 help 拖上座位——锁着拖不动；designed 的两种读法并排：读成过去式（谓语）那 fail 还是没座位，读成 done 就去修饰 Policies；学生自己把 fail 拖上座位后，designed to help small businesses 自己并成一块、往 Policies 挂一根线，读法行出「旨在帮助小企业的政策往往会失败」，和学生 8 月的译文上下并排，让学生自己说两句意思差在哪。猫那句：把 is 拿进托盘，running 散开、计数变 0、句尾出缺口，让学生看到 is 和 running 是一块的。
- 页面要提供什么：按学生的拆法算每一种读法里谓语有几个、哪个有时态的动词没有主语；to do 的锁（to 后面的动词拖不上座位）；-ed 词两种读法并排和各自的后果；按学生的拆法直译出的中文（让错的拆法自己露出怪意思）；学生 8 月那条错题的原文（主干和译文）调出来并排；学生把哪些词拖上过座位、试了几次，最后是自己拖对的，还是看了读法才改的。

## 分支 2：框非谓语词组时从名词前那串修饰词中间断开（W43、EN-L3-06、EN-L3-07）
- 学生会怎么做：第 3 幕框主语时右把手停在 imaginable 或 driving 上：「[To anticipate every imaginable] [driving situation] is a difficult programming problem.」；或者第 6 幕把 concerning 单独框成定语、"values" 落在外面；第 8 幕框成「designed to help small」把 businesses 漏在外面。
- 老师想演什么：让学生看见那串修饰词都指着同一个名词：页面从 every、imaginable、driving 各拉一根细箭头指到 situation，被括号右边线切断的那几根变成红色断线；anticipate 后面的虚线插口「预见……什么？」一直开着；括号外剩下的「driving situation」被页面当成新的一块去读，读法行出按学生分块的直译（「预见每种可能的……，驾驶情况是一个困难的编程问题」）；学生把右把手拖到 situation，箭头全接上、插口关上、读法变正常。再给一条同一个模式的「The computer is the 21st century's culture machine.」（EN-L3-06）让学生框表语一次，所有格 's 也是一根指向 machine 的箭头。
- 页面要提供什么：名词词组内部谁修饰谁（限定词、形容词、名词作定语、所有格各自指向哪个中心名词），画成箭头；括号边界切断了哪几根；及物动词有没有宾语（括号里有没有它的宾语）；按学生的括号重新分块后的直译；右把手停过的位置序列；学生以前同一个模式的错题原文（EN-L3-06 的 the 21st century's | culture machine、EN-L3-07 的 a negative | implication）调出来并排。

## 分支 3：按「挨着谁」判非谓语修饰谁（EN-L3-10 的老毛病搬到非谓语上）
- 学生会怎么做：第 7 幕「Passing the cafe, I saw a friend.」把 Passing 的线连到挨着的 cafe；「Depending on the comments received, the editor would …」把 Depending 连到 comments、把 received 连到后面的 editor；mothers 那句把 transforming 连到 work。
- 老师想演什么：代入窗按学生连的那个出读法：「the cafe passes the cafe（咖啡馆经过咖啡馆）」，学生自己读出不通；页面把逗号小墙亮起来，标出 Passing 这一块和句子主体隔着逗号、Passing 和 cafe 之间还隔着 the；学生把线改连到整句横杠，读法变成「经过那个咖啡馆时，我看见了一个朋友」；再让学生看上面一条「I saw a passing plane.」：passing 前后直接挨着 plane、没有逗号，两句并排对比。最后把学生 10 月的错题「By 1830 the former Spanish and Portuguese colonies had become independent nations.」拿上来，页面把 By 1830 两种挂法的读法并排：当「……的」挂到 colonies 前面读成「1830 年以前的殖民地已经成为独立的国家」，挂到整句读成「到 1830 年，以前西班牙和葡萄牙的殖民地已经成为独立的国家」，让学生自己挑、自己说凭什么。
- 页面要提供什么：学生每根线连到哪个词、改线的先后；按连到的词生成代入句（英文的主动 / 被动 / 目的三种和中文）；非谓语块前后是不是直接挨着名词、中间隔了什么、和句子主体之间有没有逗号；句子主语是谁；介词短语（By 1830）挂到名词和挂到整句两种读法的直译；学生 10 月那条错题的原文。
