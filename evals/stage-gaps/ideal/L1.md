# L1 可交换的情形、方阵的幂、f(A)

## 主线

### 第 1 幕：顺序一换，乘积就可能变：AB = O，BA 却不是 O（开头顺手收掉上节消去律的欠账）
- 画面：桌面左边三张矩阵牌：A = (1 2; 2 4)、上节学生自己造的 B = (2 2; −1 −1)（牌角小字「你上次造的」）、C = (1 0; 2 1)；右边一个「乘法台」，两个槽 [左][右]，放进两张牌下面就出乘积牌，台上现在放着 A·B，乘积牌是 O = (0 0; 0 0)。下面一条挑战：「造一个 D ≠ C，让 AD = AC」，D 是一张空牌，旁边并排两个乘积位 AC = (5 2; 10 4) 和 AD（空）。
- 动：学生改 D 的任意一格（点格子上下拨），或者把桌上别的牌拖到 D 上「加进去」（D 变成 D + 那张牌），AD 当场重算，和 AC 一样的格亮起来。挑战做完后，老师让乘法台上的 A、B 两张牌飞着换槽，乘积牌从 O 翻成 BA = (6 12; −3 −6)；接着老师把 AD、AC 两个乘积位也一起翻成 DA、CA。
- 老师说：「上次你造的 B 让 AB = O。先收个尾：造一个不等于 C 的 D，让 AD = AC。」做完后：「现在把 A、B 换个位置乘。先猜：BA 也是 O 吗？」翻牌以后：「这节课就问一件事：顺序换了，什么时候结果不变？」
- 学生做：改 D 的格子或把 B 牌拖到 D 上；翻 BA 之前在三个选项里点一个（是 O / 不是 O / 说不准）；DA = (7 14; 1 2)、CA = (1 2; 4 8) 出来后，用 Pencil 圈出两张不一样的格。
- 页面当场：AD 每改一下就重算、和 AC 相同的格亮；四格全亮且 D ≠ C 时挑战条打勾，说老师预写的一句「对，AD = AC，D 却不是 C」；学生点完猜测才翻 BA 的牌；DA、CA 同时翻出，不一样的格不自动标，等学生圈。
- 事实：学生最后的 D 和 D − C（比如拖 B 得 D = (3 2; 1 0)，D − C = B）；D − C 的每一列是不是 (2, −1)ᵀ 的倍数（用没用上「被 A 吃成 O」的思路）；是拖牌还是一格一格试、试了几次、每次 AD 和 AC 差在哪几格；猜 BA 选了哪一项；圈了哪几格、对不对（DA − CA = (6 12; −3 −6)，四格全不一样，正好就是 BA）。
- 老师凭什么接：一两下就把 B 拖到 C 上造出 D、猜「不是 O」或「说不准」→ 进第 2 幕；一格一格乱试超过半分钟 → 老师指着 AB = O 那张牌问「被 A 乘完是 O 的，你手上有谁？」再让学生试；猜「是 O」→ 不讲，翻牌就是答案，学生圈完格子后让学生自己说一句「AB = O 不代表 BA = O」再进第 2 幕。

### 第 2 幕：(A+B)² 拆开是四块，中间的 AB 和 BA 并不起来，差的正好是 BA − AB
- 画面：先只有一个手写框「(A+B)² = ______」，A = (1 2; 2 4)、B = (2 2; −1 −1) 两张牌留在桌上。学生写完后出现「方块图」：一个大正方形横竖各切一刀成四块，左沿标「左边那个 (A+B)」分成 A、B 两段，上沿标「右边那个 (A+B)」分成 A、B 两段；每块角上写它是谁乘谁（AA、AB、BA、BB），块里是页面算好的真矩阵：A² = (5 10; 10 20)、AB = (0 0; 0 0)、BA = (6 12; −3 −6)、B² = (2 2; −1 −1)。右边两张大牌：「真的 (A+B)²」= (3 4; 1 3)² = (13 24; 6 13)，「公式 A² + 2AB + B²」= (7 12; 9 19)；最下面一个空的「差」位和一个空的「合计」位。
- 动：方块图出现时，老师让 (A+B)(A+B) 这串式子「拆线」：左沿每一段和上沿每一段各拉一根线，依次汇进四块。学生把 AB 块往 BA 块上拖想并成 2AB：两块碰上后逐格比，不一样的格闪一下，两块弹回原位。学生把四块一块块拖进合计，合计到 (13 24; 6 13) 时和「真的」那张牌叠上。学生把「公式」牌拖到「真的」牌上，逐格相减，差 (6 12; −3 −6) 落进差位。之后 A、B 两张牌的格子全部解锁：学生拨任何一格，四块、两张大牌、差全部当场跟着变。
- 老师说：「先写你觉得 (A+B)² 是多少。」方块图出来后：「你写的 2AB，是方块图里哪两块并起来的？你把它们并一下。」差出来后：「这个差，你在方块图里见过它吗？」学生自己拨过几组之后：「什么时候差是 O？」
- 学生做：在手写框里写展开式；拖 AB 块到 BA 块上；把四块拖进合计；把公式牌拖到真的牌上；在方块图里点出和差一样的那一块，或者写出差 = BA − AB；拨 A、B 的数至少三组，看差怎么跟着变；最后写一句「(A+B)² = A² + 2AB + B² 什么时候成立」。
- 页面当场：拖并时逐格比较，不一样就闪出不同的格、弹回；一样就合成一块「2AB」并发一声（这一组 A、B 里不会发生，拨到能换的数时才会）；合计和真的一样时叠上去；公式牌和真的相减出差；拨数时一切当场重算，差变成 O 的那一刻差位缩成一个 O 并亮一下（画面后果，不说话）。
- 事实：学生手写的展开式读成了哪几项（A²、AB、BA、B²，还是 2AB、2BA），是不是把 AB、BA 并了；拖并试了几次、弹回后有没有改去拖别的块；学生说差等于什么、和 BA − AB 对不对；拨过的每一组 A、B 和那一组的差，有没有拨到差为 O 的、那一组是什么样（比如 B 拨成了 A 的倍数、拨成了 kE）；学生写的条件读成了什么命题（AB = BA / A = B = O / 别的）。
- 老师凭什么接：手写框里直接写 2AB、拖并弹回后说「是不是算错了」→ 分支 1；写对四项、自己指出差就是 BA − AB、条件写 AB = BA → 进第 3 幕；条件写成「A、B 都是 O」或者说公式「不成立」→ 分支 1 的后半；拨数时自己撞到差为 O 的一组 → 老师把这一组先存着，第 4 幕开头拿出来当第一张收藏。

### 第 3 幕：学生自己做练习 2.1：(A−B)(A+B) 的方块里，−BA 和 AB 抵消不掉，剩下 AB − BA
- 画面：练习 2.1 的题卡：A = (3 4; −1 −2)、B = (1 1; −3 −2)，求 A² − B² 和 (A−B)(A+B)，下面四个选项 (A)(B)(C)(D) 是四张小卡（每张两块矩阵，照原题）。题卡下面两个空方块图：一个左沿、上沿都空着，旁边一摞边沿标签 A、B、−A、−B；另一个是只有 A²、−B² 两块的「A² − B²」。
- 动：学生把标签拖到左沿、上沿，搭出 (A−B)(A+B) 的方块（左沿 A、−B，上沿 A、B）；每搭好一块，块里马上出页面算的矩阵：A² = (5 4; −1 0)、AB = (−9 −5; 5 3)、−BA = (−2 −2; 7 8)、−B² = (2 1; −3 −1)。学生把 −BA 块拖向 AB 块想抵消：只有两块加起来是 O 才会一起消失，这里两块合成一块，剩下 AB − BA = (−11 −7; 12 11) 留在原地。学生把各块拖进合计，得 (−4 −2; 8 10)；另一个方块合计得 A² − B² = (7 5; −4 −1)。
- 老师说：「这题你自己来，先在方块图里搭出 (A−B)(A+B)。」学生拖了抵消之后：「数里 −ab 和 ba 会消掉，这儿呢？」选完选项：「两个结果为什么不一样？指一块给我看。」
- 学生做：拖标签搭方块；拖 −BA 块到 AB 块；两个方块各合计；点选项；用 Pencil 圈出剩下的那块并写一句为什么。
- 页面当场：标签搭错（比如左沿放了 A、B，上沿放了 A、−B）也照搭的样子算出来，不拦；抵消不成时剩下的块留在原位、角上写它是 AB − BA；合计和直接算的 (A−B)(A+B) 一样时叠上；选项点了先不揭对错，学生写完为什么再一起出，选 (C) 时说预写的一句「对，(C)」。
- 事实：学生搭的方块左沿、上沿各是什么：是 (A−B)(A+B)，还是搭成了 (A+B)(A−B)（那一个合计是 (18 12; −16 −12)，和 (−4 −2; 8 10) 不一样）；有没有试过抵消、抵消后剩的是什么；选了哪项；写的为什么里有没有说出 AB ≠ BA、有没有指到剩下那一块；两个结果是不是都写了（W8 漏答小问）。
- 老师凭什么接：搭对、选 (C)、理由指到剩下那块 → 进第 4 幕；选 (A) 或 (B)（以为两个结果一样）→ 分支 1，把剩下的 AB − BA 和两个合计之差叠在一起看；搭成 (A+B)(A−B) → 不说破，让学生把两种顺序都搭出来，两个合计并排，学生自己说出「谁在左边要紧」，再接着选；只写了一个结果 → 老师指着题卡上「分别」两个字，让学生补。

### 第 4 幕：找能和 A 换的 B：收藏起来看出它们的共同点，再找跟谁都能换的
- 画面：方块图回到 (A+B)²，A 牌上了锁：A = (1 2; 0 3)；B 牌四格都能拨，起始是 (0 1; 1 0)。挑战条：「让中间两块并得起来。B 不能是 O。并上一次，这一对就进收藏架；收满 4 对，要互不相同。」右边一个四格的空收藏架。下面一台「随机 A 测试机」：一个槽放一张 B 牌，按一下，页面造 20 张随机整数 2 阶矩阵当 A，挨个算 AB、BA，亮 20 盏灯（能换的绿、不能换的灰）。
- 动：学生拨 B 的格，AB、BA 两块和差位当场变；差变成 O 的那一刻，两块自己滑到一起并成「2AB」，这一对缩成一张小卡飞进收藏架。第一轮收满后，老师把锁着的 A 换成 A = (2 0; 0 3)，收藏架清空，再收一轮。最后学生把觉得「跟谁都能换」的 B 放进测试机，20 盏灯一盏一盏亮。
- 老师说：「A 锁着，你去找能和它换的 B，越不一样越好。」收满后：「看看架上这四张 B，它们和 A 有什么关系？」第二轮后：「有没有一张 B，放进测试机能把 20 盏灯全点亮？」
- 学生做：拨 B 的四格找能并起来的；收满 4 对后在架子下面手写「这些 B 的共同点」；第二轮再收 4 对；挑 B 放进测试机，可以试好几张；最后写一句「哪些矩阵和任何矩阵都能换」。
- 页面当场：差为 O 自动合块进架，说预写的一句「并上了！」；和架上已有的一样的 B 收不进（那张小卡抖一下）；测试机一盏盏亮灯、报亮了几盏；学生改 A 是改不动的（锁着），只有老师换。
- 事实：学生拨过的每个 B 和它的 BA − AB；对 A = (1 2; 0 3)，能换的 B 恰好是 pA + qE（形如 (a, d−a; 0, d)），架上每张 B 的 p、q 是多少，有没有 kE（p = 0）、A 自己（p = 1, q = 0）、A² = (1 8; 0 9) = 4A − 3E 这几类；学生有没有试对角的 B = (1 0; 0 2)，那一下差是 (0 −2; 0 0)，没并上；第二轮能换的恰好是全部对角阵，学生收的是不是都是对角的；测试机里每张 B 亮了几盏（只有 kE 才 20 盏全亮，比如对角的 (1 0; 0 2) 只亮几盏）；学生手写的共同点读成了什么。
- 老师凭什么接：架上既有 kE、又有 A 或 A + E 这类，学生写出「B 是 A 的几倍加 E 的几倍」或「是 A 自己算出来的」，测试机里只用 kE 全点亮 → 老师这时给名字：「AB = BA 叫 A、B 可交换；数量矩阵 kE 和谁都可交换」，进第 5 幕问为什么；只收到 E、2E、3E（一直往对角线上拨）→ 老师不说，让学生试一张「和 A 长得很像的」B，看学生会不会想到 B = A；乱拨半天一对都收不到 → 老师先把 B 拨成 E 收下第一张；共同点写成「都是 O 或 E」→ 分支 1 的后半（条件太窄）。

### 第 5 幕：为什么它们能换：每动一步都要拿出依据，kE 靠 EC = C 和 CE = C，A 和 A² 只靠挪括号
- 画面：一条「珠串」：一个乘积摆成一行，矩阵是方珠（写字母），数是圆币，括号是能挪的细弧；珠串下面实时写出这一串真乘出来的矩阵。右边一摞依据卡：结合律（挪括号）、数乘结合律（圆币能滑到串上任何地方）、EC = C、CE = C、AE = EA = A、交换（每次用都要指是哪两颗珠子）。第一串：(AB)(AB)，A = (3 4; −1 −2)、B = (1 1; −3 −2)，下面写 (56 30; −30 −16)，目标位「A A B B」下面写 A²B² = (2 −1; 2 1)。第二串：(5E)C，C 是一颗「任意珠」（下面每 2 秒换一张随机 C，让学生看到真算的两头），目标 C(5E)。第三串：A·A²（三颗 A 珠，括号括住后两颗），目标 A²·A。
- 动：学生拖珠子换位、拖括号、拖圆币；每动一下，页面问「凭哪条？」，学生把一张依据卡拖到这一步的等号上。页面查这条依据这一步真的成不成立：挪括号总成立；圆币滑动总成立；E 珠紧挨在 C 左边用 EC = C，E 珠化开消失；从 C 右边「长出」一颗 E 珠用 CE = C；两颗方珠换位，只有页面算出这两个矩阵真能交换才过得去，不然珠子卡住，那一对珠子下面闪出两种顺序乘出来的不同矩阵。每成立一步，珠串下面多写一行等式和依据。
- 老师说：「第一串：把 ABAB 变成 AABB。」卡住后：「卡在哪两颗中间？」第二串：「证 (5E)C = C(5E)。每动一下都要拿一张卡。」第三串：「A 和 A² 为什么能换？」最后：「第二串里哪一步离了 E 就不行？点它。」
- 学生做：在三条珠串上拖珠子、括号、圆币，每一步拖一张依据卡；三串各走到目标或者卡住；第二串走完后点出离不开 E 的那几步。
- 页面当场：成立的一步写上等号和依据；不成立的换位卡住并闪出两种顺序的矩阵（第一串卡在中间的 B、A：BA = (2 2; −7 −8)，AB = (−9 −5; 5 3)）；第二串走完把每一行连成一条链 (5E)C = 5(EC) = 5C = 5(CE) = C(5E)，用当前的随机 C 把两头各算一遍（都等于 5C）；第三串只挪括号走完时，把括号的滑动重放一遍（三颗珠子一动不动，只有括号在动）。
- 事实：每一步学生动了什么、拿的哪张卡、这张卡这一步成不成立；有没有拿「交换」卡去换 5E 和 C（要证的就是这一句）；EC = C 和 CE = C 各用了没有，用在链的哪一边；第一串卡住时学生是去改括号、去找卡，还是说「那就是不能变」；第三串有没有动过任何一颗珠子的位置；最后点的「离不开 E」是不是 EC = C、CE = C 那两步。
- 老师凭什么接：三串顺利走完、自己点到 EC = C 和 CE = C → 老师把第二串的 5E 换成 D = diag(1, 2) 让学生再走一遍，走到 D 贴着 C 时没有卡能用，页面拿 C = (0 1; 0 0) 算出 DC = (0 1; 0 0)、CD = (0 2; 0 0)，学生说出「只有 E 的倍数才行」，进第 6 幕；第二串直接拿「交换」卡，或者只用了 EC = C 一边就说完了 → 分支 3；第三串去换珠子的位置（以为 A 和 A² 要「换位」才能换）→ 老师只重放括号的动画，问「珠子动了吗？」（接上一块 L2-22 括号和位置分不清）。

### 第 6 幕：A 和 E 能换，数的公式就能照搬：(A−E)(A−2E) 化开是 A² − 3A + 2E，f(A) 的常数项是 3E
- 画面：左边一个方块图：左沿 A、−E，上沿 A、−2E，四块里先写着没化简的珠串：A·A、A·(−2E)、(−E)·A、(−E)·(−2E)，每块下面用具体的 A = (2 −1; −3 3) 真算一份。右边并排一张数的方块图作对照：(x−1)(x−2)，四块 x²、−2x、−x、2。下面一张练习 2.2 的题卡：「f(x) = x² − 5x + 3，A = (2 −1; −3 3)，f(A) = ？」，一块写字区，一个 2×2 的答案槽。
- 动：学生点一块，用第 5 幕的依据卡化简：A·(−2E) → −2A（圆币滑出来、E 珠化开），(−E)·A → −A，(−E)·(−2E) → 2E（两枚圆币相乘成 2，E·E 化成一颗 E）；四块变成 A²、−2A、−A、2E。学生把 −2A 块拖到 −A 块上：两块都是「A 的几倍」才并得上，圆币 −2 和 −1 叠成 −3，并成 −3A（A² 块拖过去撞了不并）。合计 A² − 3A + 2E 下面的真矩阵 (3 −2; −6 5) 和直接算的 (A−E)(A−2E) 对上叠住。两张方块图并排时，老师让数的那张四块和矩阵这张四块一一连线。后半学生在写字区自己算 f(A)，把结果写进答案槽。
- 老师说：「把这四块化到不能再化。」并完后：「和右边数的那张比一比。」「x² − 3x + 2 能拆成 (x−1)(x−2)，换成 A 为什么也行？」后半：「练习 2.2，你来算 f(A)。」
- 学生做：点块、拖依据卡化简；拖块合并；手写一句为什么数的公式能搬过来；在写字区用 Pencil 算 A²、5A，写出 f(A)，把四个数写进答案槽（或者写一个字母）。
- 页面当场：化简每一步照第 5 幕的规矩查依据；合块只在两块都是同一个矩阵的倍数时并；合计和直接乘的一样时叠上；答案槽写完和页面算的 f(A) = O 比，对了说预写的一句「对，是零矩阵」，不对不说话，只把结果交给老师。
- 事实：每块化简用了哪张卡，有没有带着 E 不化（AE、EA、E² 原样留着），系数合得对不对（−2A − A 应为 −3A）；学生写的「为什么能搬」里有没有「A 和 E 可交换」或「AE = EA」；学生在写字区写的 f(A) 式子里常数项是 3 还是 3E；答案槽里的四个数和 O 比，像哪种错：每格加了 3 得 (0 3; 3 0)、漏了常数得 (−3 0; 0 −3)、A² 按每格平方得 (−3 6; 24 −3)、5A 算错；答案写的是零矩阵（带括号的 O 或四个 0）还是一个数字 0、外面是圆括号还是竖线。
- 老师凭什么接：化简干净、说出 A 和 E 可交换、f(A) 写成零矩阵 → 进第 7 幕；块里留着 AE、EA，或者把 −2AE − EA 并成 −AE → 分支 3；写字区常数项是 3、答案 (0 3; 3 0) 或 (−3 0; 0 −3)、或者写成数字 0 → 分支 2；A² 按格平方 → 老师把 A² 拆回 A·A，在 A² 块上画出 (1,1) 格那一行乘一列 2·2 + (−1)(−3) = 7，让学生自己重算。

### 第 7 幕：方阵的幂：和 E 能换，二项式就能用，(A+E)³ 和 Aⁿ 都靠它
- 画面：先是一张题卡「A² = 2A，把 (A+E)³ 化成 aA + bE」（上次说「不会」的那题），角上放一个具体的 A = (1 1; 1 1)，下面页面写着 A² = (2 2; 2 2) = 2A，答案位「__A + __E」，旁边一块珠串堆：(A+E)(A+E)(A+E) 展开的 8 串珠子。然后换成主题：A = (1 1 0; 0 1 1; 0 0 1)，一个「×A」按钮和一排幂的牌位 A¹、A²、A³……；一个「拆牌台」，能把 A 拆成两张牌的和；一个珠串堆，(P+Q)ⁿ 展开的所有珠串，n 能拨（2～6）；一个 3×3 的答案格，每格能写含 n 的式子。
- 动：(A+E)³：学生把 8 串珠子按「A 有几颗」拖成堆，因为 A 和 E 能换，同一堆里的珠串真矩阵一样、能叠成一摞（1、3、3、1 四摞）；E 珠贴着谁就化掉；学生把「A² = 2A」做成一张降次卡，拖到 A³ 上化成 4A。主题：学生按「×A」，A² = (1 2 1; 0 1 2; 0 0 1)、A³ = (1 3 3; 0 1 3; 0 0 1)、A⁴ = (1 4 6; 0 1 4; 0 0 1) 一张张出来；学生在拆牌台上把对角线的三个 1 拖出去成一张 E，剩下 N = (0 1 0; 0 0 1; 0 0 0)；页面接着出 N、N²、N³：那一斜行 1 每乘一次往右上挪一格，N² = (0 0 1; 0 0 0; 0 0 0)，N³ 时那一格滑出右上角，变成 O。学生拨珠串堆的 n：(E+N)ⁿ 的 2ⁿ 串按 N 的颗数自动叠成 C(n, k) 摞，N 有 3 颗及以上的那几摞变灰淡出（N³ = O）。
- 老师说：「这题你上次说不会。现在 A 和 E 能换，你来展开 (A+E)³。」主题：「这个 A 的 n 次方。先多乘几次看看。」「把 A 拆成两张简单的牌，拆完要能用二项式，两张牌得满足什么？」「拨 n，数每一摞有几串，再看 Aⁿ 右上角。」最后：「写出 Aⁿ，再写 A¹⁰⁰。」
- 学生做：把 (A+E)³ 的珠串拖成堆、用降次卡，填 a、b；按「×A」几次；在拆牌台上拖出对角线把 A 拆成两张；拨 n；在答案格每一格写含 n 的式子；再填 A¹⁰⁰ 的九个数。
- 页面当场：(A+E)³ 填的 a、b 代 A = (1 1; 1 1) 验：(A+E)³ = (14 13; 13 14) 是不是 aA + bE，对了说预写的一句「13A + E，对」；每按一次「×A」出下一张幂；拆牌时两张牌能换（页面算 PQ = QP）时珠串堆自动叠摞，不能换时同一摞里的珠串真矩阵不一样，叠不上、散开，各串下面写出自己的矩阵；Aⁿ 写完代 n = 1～30 和真算的幂逐格比，全对说预写的一句「对」；A¹⁰⁰ 和真算的比。
- 事实：(A+E)³ 学生是按堆用二项式，还是一串一串硬乘；AE、E²A、E³ 化掉了没有；a、b 对不对（对的是 13、1）；按「×A」按了几次、有没有自己说出右上角 1、3、6、10 的规律；学生怎么拆的、两张牌能不能换（E + N 能；页面给出 PQ 和 QP）；拨过哪些 n、每摞几串；学生写的 Aⁿ 哪一格从第几个 n 开始对不上（比如右上角写成 n²、n(n+1)/2，或者中间写成 n−1）；A¹⁰⁰ 右上角是不是 4950。
- 老师凭什么接：(A+E)³ 还是一串串硬乘、E 不化 → 分支 3，回来再做；拆成 E + N、Aⁿ = (1 n n(n−1)/2; 0 1 n; 0 0 1)、A¹⁰⁰ 对 → 收尾：让学生在方块图、收藏架、珠串堆三处各指一下「可交换」帮了什么忙，写进这节课的一页；拆成两张不能换的牌还硬套二项式 → 把那两张牌放进第 2 幕的方块图，中间两块并不起来，学生自己说为什么这里二项式不能用；右上角写错 → 把学生的式子代 n = 3～6 的值和真幂并排，对不上的那一格亮出来，学生自己改。

## 分支 1：以为 (A+B)² = A² + 2AB + B² 本来就对；问条件只想到「A、B 都是 O」，或者把「不一定成立」说成「不成立」（L2-24、W27）
- 学生会怎么做：第 2 幕手写框里写 A² + 2AB + B²（「直接展开不就是这个」）；拖 AB 块到 BA 块弹回来后，说「是不是算错了」，或者改拖 BA 去并别的块；问什么时候成立，写「A、B 都是零矩阵」或「A = B = E」，再追问写「不知道」；问「A² + 2AB + B² 对不对」写「不成立」；练习 2.1 选 (A) 或 (B)，以为两个结果一样。
- 老师想演什么：不讲道理，让两块对质：把 AB 块和 BA 块叠成半透明的上下两层，四格各写出两个数（0 对 6、0 对 12、0 对 −3、0 对 −6），学生自己读出不一样；再让学生亲手把四块一块块加进合计，看合计和「真的 (A+B)²」严丝合缝，最后把自己写的公式牌叠上去，看差在哪几格、差就是 BA 那一块。条件太窄时：老师把 B 依次换成 5E、A 自己、A + E，每一对都并上了、公式都成立，可没有一对是 O，问「你的条件漏了谁？」；学生说「不成立」时：老师拿 B = 5E 那一对放进方块图，并上了，问「这一对成立了，那该说不成立，还是不一定成立？」；2.1 选 (A)(B) 时：把两个合计并排，差 (−11 −7; 12 11) 叠到第 3 幕剩下的那一块上，正好是 AB − BA。
- 页面要提供什么：把学生手写的展开式读成项的列表，认出哪些是并过的项（2AB、2BA）、漏了哪项；两块叠层时逐格对照两个数；学生写的条件读成能判的命题（「A = O 且 B = O」「A = B = E」「AB = BA」），拿收藏架和随机造的几百对去测，报告它充分不充分、必要不必要，并给出第一对「公式成立但不满足条件」的反例；学生下了「不成立」这类全称否定时，自动找一对让公式成立的（比如 (A, 5E)）交给老师，老师决定拿不拿出来；2.1 两个合计之差和 AB − BA 是否相等。

## 分支 2：f(A) 的常数项当成数，零矩阵写成数字 0（W19；L2-43）
- 学生会怎么做：练习 2.2 写成 f(A) = A² − 5A + 3，算的时候四格都加 3，答案槽写 (0 3; 3 0)；或者 3 干脆丢了，写 (−3 0; 0 −3)；或者算对了，最后写「f(A) = 0」，或者矩阵外面画竖线。
- 老师想演什么：拿出一个「配方台」：f(x) 的三项是三张牌，x² 和 −5x 换成 A²、−5A 两张方牌（里面是真矩阵 (7 −5; −15 12)、(−10 5; 15 −15)），+3 是一枚圆币；让学生把圆币加到方牌上——数和表加不上（加法本身没定义，圆币弹回来，这是数学规矩，不是页面拦人）。学生的「每格加 3」等于偷偷把圆币换成了全是 3 的牌 (3 3; 3 3)：老师把这张牌和 3E = (3 0; 0 3) 并排放，问「f(x) 里的 3 是 3·x⁰，x⁰ 到了 A 这边是谁？」学生拖一张 E 牌贴上圆币，圆币变成 3E，只铺在对角线上，合计变成 (0 0; 0 0)；再把学生的 (0 3; 3 0) 和它叠上，多出来的正是对角线外那两个 3。写成数字 0 时：答案位换成一个 2×2 的槽，问学生槽里放的是一个数还是一张表，再翻出 L2-43 当时写成 0 的那一行让学生自己对照。
- 页面要提供什么：学生写的 f(A) 每一格和对的比，告诉老师像哪一种错：每格加了常数（和对的差正好是 (0 3; 3 0)，即全 3 矩阵减 3E）、漏了常数（差是 −3E）、A² 按格平方、5A 只乘了一格；读懂学生手写：f(A) = A² − 5A + 3 里 3 后面有没有 E，答案是零矩阵（带括号的 O 或四个 0 的矩阵）还是一个数字 0，外面是圆括号还是竖线；配方台上每一项的真矩阵、圆币贴上 E 前后的合计。

## 分支 3：拿「位置可换」当理由，E 碰到了不会消（W18；L2-33、L2-39、L2-30、L2-45）
- 学生会怎么做：第 5 幕证 (5E)C = C(5E) 时直接把 C 珠拖过 5E，拿「交换」卡当依据，或者只用了 EC = C 一步就说证完（缺 CE = C）；第 6 幕的方块里把 A·(−2E)、(−E)·A 写成 −2AE − EA，再并成 −AE；第 7 幕 (A+E)³ 一串串硬乘，AE、E²A、E³ 都原样留着，还写出 EA² = 4AE 这种式子。
- 老师想演什么：拿「交换」卡的那一步：页面把要证的那一行和学生用的那张卡上下并排，两行一模一样，老师问「拿要证的话当理由，行吗？」；再把 5E 换成 D = diag(1, 2)，同一张「交换」卡照样能「证」出 DC = CD，页面拿 C = (0 1; 0 0) 算出 DC = (0 1; 0 0)、CD = (0 2; 0 0)，这张卡把错的也证成了，所以它不能当理由；学生回去只用数乘结合律、EC = C、CE = C 重走一遍，链上左边的 EC = C 和右边的 CE = C 两步亮起来。E 不会消：在具体的 A = (2 −1; −3 3) 上真算 AE 和 EA，两块都等于 A 本身，拖到 A 牌上严丝合缝地叠住；−2AE、−EA 两块化成 −2A、−A，两枚圆币 −2、−1 叠起来是 −3；再把学生写的 −AE 那张（真算出来是 −A）和 −3A 并排，差 −2A 亮出来。(A+E)³ 硬乘时：把学生那串还带 E 的式子每一项都代 A = (1 1; 1 1) 真算出来，一项项摆开，学生看到 E²A、AE 那几项和 A 是同一张牌。
- 页面要提供什么：每一步用的依据卡，并判断这张卡是不是就是要证的结论（或者要靠它才成立）；链里 EC = C、CE = C 各出现了没有、在哪一边；拿学生用的那张卡去「证」一对不可交换的矩阵，找出反例对、算出两边；学生写的式子读成项，哪些项还带着能消的 E（AE、EA、E²、E²A、E³），系数合得对不对（−2AE − EA 应为 −3A，学生写 −AE 差了 −2A），代具体的 A 把学生的式子和对的式子各算一遍、差多少。
