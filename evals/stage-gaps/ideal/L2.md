# L2 线性方程组：消元、含参讨论、通解的几何样子

## 主线

### 第 1 幕：方程组的解就是「用 a1、a2、a3 凑出 β 的配方」，配方可以不止一个，两个配方的差凑出来的是零向量
- 画面：左边一张方格平面（横竖 −4 到 6），从原点出发三根彩色箭头 a1 = (1, 0)（蓝）、a2 = (0, 1)（橙）、a3 = (1, 1)（绿），点 (3, 2) 上一颗星 β；上方一行式子 x1·(1; 0) + x2·(0; 1) + x3·(1; 1) = (3; 2)，三个 x 是活的数字；下面三个同色滑块 x1、x2、x3（−4 到 4，拖动连续，在整数和半格上轻轻吸一下）；右边一个小 3D 框，三根轴标 x1、x2、x3，先是空的；右下角一张空的「配方」小表。
- 动：学生拨哪个滑块，对应那段箭头就伸缩：x1·a1 从原点出发，x2·a2 接在它的尖上，x3·a3 再接上，三段首尾相接成一条链，系数是负数时那段反向；链的尖和 β 之间一直连着一根淡虚线，随尖移动变长变短；3D 框里一个小点跟着 (x1, x2, x3) 走。
- 老师说：「三根箭头各拉几倍、首尾接起来，让尖落到星上。」凑到以后：「还有别的拉法吗？」凑到三个以后指着 3D 框：「每个配方是那边的一个点，看它们站成什么样。」最后：「配方 1 减配方 2，按这个差去拉箭头，尖到哪了？」
- 学生做：拨三个滑块把链尖凑到 β；再凑第二个、第三个不一样的配方；然后在配方表里点两行，看按两行之差拉出来的那条链。
- 页面当场：链尖和 β 重合时星亮、链从虚变实，这一组 (x1, x2, x3) 记进配方表、在 3D 框里钉一个点，说预写的一句「凑到了！还有别的拉法吗？」；同一个配方再凑一次，表里那一行闪一下、不另记；学生点了两行配方，左边从原点画出按差值拉的链（差是 (1, 1, −1) 时：先向右一格、再向上一格、再沿 a3 退回原点，原点闪一下）。
- 事实：每次停手时三个滑块的值、链尖坐标、离 β 差的向量和长度；凑到的配方（如 (3, 2, 0)、(2, 1, 1)、(1, 0, 2)）、有没有重复；这些点在 3D 里是否共线、所在直线是 (3, 2, 0) + s(−1, −1, 1)；学生选的两行之差、按差拉出的链尖是否正好在原点；学生的拨法（是不是先定 x3、再用 x1、x2 补，说明已经感到 x3 是随便取的）。
- 老师凭什么接：凑到三个、点共线，学生看着回到原点的那条链说出类似「加上这一圈，尖不动」→ 进第 2 幕；凑到一个以后来回拨了一分钟还找不到第二个 → 把 x3 锁在 1，只让学生拨 x1、x2（不说答案）；学生说「答案只能有一个」→ 我把 x3 推到 2，让学生看尖偏了多少、再自己用 x1、x2 补回去。

### 第 2 幕：同一个方程组「行着看」：每个方程是一张平面，配方的点都在两张平面的交线上；写成增广矩阵时，每一列只放一个未知数的系数
- 画面：第 1 幕那行向量式子按分量拆成两行方程 x1 + x3 = 3、x2 + x3 = 2（拆的过程：上、下两个分量各拉成一行）；3D 框放大到右边大半屏，两张半透明平面 x1 + x3 = 3（紫）、x2 + x3 = 2（青），第 1 幕钉的点还在；下方一张空的 2×4 格子，列头 x1、x2、x3（和三根箭头同色）、一道竖线、b，学生用 Apple Pencil 往格子里写数。
- 动：学生能在 3D 里直接拖当前点（左边的箭头链和三个滑块跟着变），点落在哪张平面上，那张平面就亮；3D 框单指转、双指缩放；格子里每写满一行，页面把这一行按列头读回成方程写在行右边，并在 3D 里画出这一行的平面——和原来那张重合就合成一张，不重合就多出一张虚线平面；每写满一列，页面在左边按这一列画一根箭头（和原来那根重合就合成一根）。
- 老师说：「你那几个点，各满足哪个方程？」→「两张平面交在哪？在线上再找一个表里没有的点。」→「把两个方程抄成一张数表，一列只放一个未知数的系数。」
- 学生做：在 3D 里拖点，找一个不在配方表里、但同时在两张平面上的点；然后在 2×4 格子里写增广矩阵（第 1 个方程没有 x2，第 2 个方程没有 x1）。
- 页面当场：点同时落在两张平面上时，两张平面的交线亮出来、左边链尖同时落到 β 上、星亮，说预写的「这也是一个配方」并记进表；格子写好后读回的方程、画出的平面和箭头都照学生写的如实画（写错了就是多一张虚线平面、多一根错位的箭头，页面不拦、不提示）。
- 事实：当前点满足哪几个方程、各差多少；交线的参数式、配方点是否全在交线上；学生写的每一格的数、它在原方程里属于哪个未知数（错位、漏格、空格）；每一行读回成的方程和原方程是否一样；读回的平面和原平面的夹角或距离；每一列画出的箭头和 a1、a2、a3、β 是否重合。
- 老师凭什么接：交线上找到新点、矩阵读回和原方程一样 → 给名字「这叫增广矩阵 [A | b]：前三列是 a1、a2、a3，最后一列是 β；一行是一张平面，一列是一根箭头」，进第 3 幕；矩阵里缺项没补 0，或系数错了列（W7 的老毛病）→ 分支 1。

### 第 3 幕：把一行加上另一行的 k 倍，只有被加的那一行的平面绕着一根「铰链」转，三张平面的公共点不动
- 画面：新的方程组 x1 + 2x2 = 2、x1 − 4x3 = 0、x1 + 2x2 − 2x3 = 0（就是 B13-43.2 取 λ = 0、μ = 1），学生先在 3×4 格子里自己写增广矩阵（又有两处缺项），写对后是 (1 2 0 | 2; 1 0 −4 | 0; 1 2 −2 | 0)；3D 里三张半透明平面（红、绿、蓝，矩阵每一行左边一枚同色圆点），交在一点 P = (4, −1, 1)，P 是一颗亮点；矩阵每一行右边一个把手「⠿」。
- 动：学生把第 1 行的把手拖到第 3 行上，第 3 行旁边出现一个 k 滑块（−3 到 3，起点 0），第 3 行四个数随 k 实时变成 (1 + k, 2 + 2k, −2 | 2k)；第 3 张平面随 k 绕一根固定的直线转——这根线就是第 1、3 张平面原来的交线（x1 + 2x2 = 2、x3 = 1），画成一根发亮的铰链；第 1、2 张平面和矩阵第 1、2 行纹丝不动，P 一直亮在原处；松手后 k 定格，旧矩阵缩到上方，中间一根箭头写「r3 + k·r1」。
- 老师说：「把第 1 行拖到第 3 行上，拨 k，盯着三样：谁在动、谁不动、P 走没走。」→「拨到第 3 行第一个数变成 0。」→「现在第 3 张平面是什么样？」
- 学生做：拖把手、来回拨 k；挑战：让第 3 行第 1 个数变成 0；然后说出拨的时候什么没动、第 3 张平面最后变成了什么样。
- 页面当场：k 每变一点，第 3 行的数和第 3 张平面跟着变；k = −1 时第 3 行变成 (0 0 −2 | −2)，第 3 张平面正好转成水平（x3 = 1），说预写的「做到了」；整个拨的过程中 P 不动、第 1、2 张平面不动（这是这个世界本来的规律，不是提示）。
- 事实：k 的当前值、第 3 行的四个数；哪几行变了（这一幕只会是第 3 行）；P 代进三个方程的值（一直全是 0）；铰链的方程；第 3 张平面和水平面的夹角；学生停留过的 k 值；挑战完成时的 k；学生说的「没动的」里有没有 P、有没有第 1 行。
- 老师凭什么接：学生说出「只有第 3 张在转、P 不动」→ 给名字「这叫倍加，是同解变换：换了方程，没换解」，进第 4 幕；学生以为第 1 行也要跟着改（问「第 1 行要不要也减」，或者把第 3 行拖到了第 1 行上还以为是同一件事）→ 先演一遍分支 2 的画面；学生这时还没学过 L2.4 初等行变换，这一幕就是第一次见，不假设学生会，另外两种行变换（换行、乘非零数）等第 4 幕学生要用时再给。

### 第 4 幕：自己一步一张地消成阶梯形，从最下面一行往上读出 P；台阶有几级，就有几个真约束
- 画面：回到原来的增广矩阵 (1 2 0 | 2; 1 0 −4 | 0; 1 2 −2 | 0)（第 3 幕是用把手拨的，这一次学生自己写），左下角三格（第 2 行第 1 格、第 3 行第 1、2 格）外面画一道虚线的台阶线；矩阵下面一张空的 3×4 格子，旁边一小格写「这一步做了什么」；3D 里三张平面和 P；角上一行小字列着能用的三种行变换：倍加、换行、一行乘非零数。
- 动：学生每写好一张新矩阵并写下这一步（如「r2 − r1」），页面把上一张缩到上面一排（排成 A → … → B 一串），按学生写的新矩阵重画三张平面：数变了的行，它的平面从旧位置转到新位置；P 永远是当前三张平面的公共点（学生写的新矩阵解集变了，P 就跟着跑或者消失）；消完后学生点最下面那张平面，它和 x3 轴的交点亮出来、读出 x3；再点第 2 张，它和 x3 = 1 这张水平面的交线（x2 = −1、x3 = 1，平行于 x1 轴）亮出来；再点第 1 张，交出 P。
- 老师说：「把台阶线下面全变成 0，一步写一张。」→（成了以后）「最下面那张平面里只剩谁？从它开始往上读。」→「台阶一共几级？」
- 学生做：用 Apple Pencil 写每一步的新矩阵（整张写，像在纸上）和这一步的操作，消成 (1 2 0 | 2; 0 −2 −4 | −2; 0 0 −2 | −2)；然后从下往上填 x3 = 1、x2 = −1、x1 = 4。
- 页面当场：新矩阵一写完，平面照新矩阵移动、P 照新矩阵重算；台阶线下全是 0 时台阶线变实线，说预写的「阶梯形 ✓」；填的 x 对上 P 的坐标时，那根轴上的刻度亮一下。
- 事实：学生每一步写的整张矩阵（逐格识别的结果）；和上一张比哪几行变了，变了的行是不是「旧的这一行 + k×另一行」（k 是多少）、「两行对换」或「×一个非零数」；新方程组的解集（点、线、空）和上一张是否相同；算错的格子（例如 −4 写成 4）和它本该是多少；是不是阶梯形、台阶几级、台阶头在哪几列；学生填的 x 和真解的差。
- 老师凭什么接：每一步都同解、消成阶梯形、读对 → 指着三级台阶给名字「行阶梯形；台阶数 = 真约束的个数 = 秩 r(A) = 3；真约束和未知数一样多，只剩一个点」（学生到时候学过 L2.6 秩就对上，没学过这里是第一次给），进第 5 幕；某一步改了不该改的行、解集变了 → 分支 2；只有被加的一行变了、但有一格算错（P 跑了）→ 不讲规则，把这一行的新、旧两张平面并排放，问「P 还在你这张平面上吗」。

### 第 5 幕：把一个系数换成 λ、两个常数换成含 μ 的式子，拨着看：台阶塌掉一级时，解要么没了，要么变成一整条线，由最后一列那个数说了算
- 画面：同一个方程组里，第 1 个方程 x3 的系数 0 变成 λ，第 1 个方程右边的 2 变成 μ + 1，第 2 个方程右边的 0 变成 μ − 1（就是 B13-43.2：x1 + 2x2 + λx3 = μ + 1、x1 − 4x3 = μ − 1、x1 + 2x2 − 2x3 = 0），两个滑块 λ、μ（−4 到 4，起点 λ = 0、μ = 1，在整数上轻轻吸一下）；3D 三张平面和 P；左边是学生要带着字母重写的消元格子；右下角一张 λ–μ 小地图（两根轴，空的）。
- 动：学生拨 λ、μ，三张平面、P、阶梯形里每个数都实时跟着变：λ 一变第 1 张平面倾斜，μ 一变第 1、2 张平面一起平移；每次松手，小地图上在 (λ, μ) 处落一个点，颜色由页面按这时解的样子算（一个点 / 一条线 / 没有）。
- 老师说：「刚才的两步消元，带着字母再走一遍。」→「拨 λ、μ，想办法让三张平面没有公共点。」→「再想办法让公共点不止一个。」→（地图上点多了以后）「地图上哪些地方不是一个点？看阶梯形最后一行。」
- 学生做：先带字母写出两步消元的结果，最后一行是 (0 0 −2 − λ | −μ − 1)；然后两个挑战：拨到无解、拨到无穷多解；最后用 Pencil 在小地图上圈出「无解」的地方，并写出条件（λ = −2 且 μ ≠ −1）。
- 页面当场：没有公共点时 P 熄灭，说预写的「挑战完成：没有解了」；出现一整条公共线时这条线亮起来，说预写的「挑战完成：解不止一个」；λ 拨到 −2 时第 1、3 张平面变成平行（页面画一对平行记号和两平面之间的距离），λ = −2、μ = −1 时两张合成一张；学生圈完、点「铺满」后，页面把整张地图每一点按解的样子涂色，和学生圈的叠在一起（只画，不判）。
- 事实：当前 (λ, μ)；阶梯形每一格的值和带字母的式子；最后一行系数部分和右边各是不是 0；r(A)、r([A | b]) 各是几；解的样子，唯一解时的坐标（例如 μ = −1、λ ≠ −2 时不管 λ 是多少都是 (−2, 1, 0)）；哪两张平面平行或重合、平行时相距 |μ + 1|/3；地图上学生试过的点和颜色；学生带字母写的每一格对不对、哪一格不对；学生圈的区域和真区域（λ = −2 这根竖线、去掉 μ = −1 这一点）差在哪。
- 老师凭什么接：学生说出「最后一行左边全是 0、右边不是 0，就成了 0 = 几，没有解」→ 给名字「r(A) ≠ r([A | b]) 无解；相等且等于 3 唯一解；相等但小于 3 无穷多解」，停在 λ = −2、μ = −1 进第 6 幕；学生只看左边说「λ = −2 就是无穷多」→ 分支 3；拨了一分钟地图上全是同一种颜色 → 指着最后一行的 −2 − λ：「它什么时候是 0？」

### 第 6 幕：一整条线怎么写全：没有台阶头的那个未知数随便取；取 0 得一个特解；Ax = 0 的线过原点、和它平行；通解 = 特解 + k·ξ
- 画面：停在 λ = −2、μ = −1：第 1、3 张平面重合成一张，和第 2 张交成一条亮线 L；学生上一幕写的阶梯形 (1 2 −2 | 0; 0 −2 −2 | −2; 0 0 0 | 0)，只有两级台阶，第 3 列没有台阶头（这一列淡淡地标出来）；L 上一个可拖的点 Q，旁边实时写 Q 的坐标 (x1, x2, x3)。
- 动：学生沿 L 拖 Q（Q 只能在 L 上滑），坐标实时变；之后我把第 2 个方程右边的 −2 慢慢缩成 0：第 2 张平面平移到过原点（第 1、3 张本来就过原点），L 跟着平移成过原点的 L0，原来的 L 留一条虚影；最后出现一个 k 滑块，点 η + kξ 沿 L 跑。
- 老师说：「拖 Q，看哪个坐标你说了算。」→「让 x3 = 0，Q 在哪？再让 x3 = 1。」→「这两点连一根箭头。」→「把右边全换成 0，看 L 去哪了，箭头在不在新的那条线上。」→「L 上随便一个点，怎么一句话写出来？」
- 学生做：拖 Q，说出「x3 定了，x2、x1 就跟着定了」；把 Q 拖到 x3 = 0（η = (−2, 1, 0)）和 x3 = 1（(2, 0, 1)）钉住；连箭头读出差 (4, −1, 1)；再在右边换成 0 的阶梯形里取 x3 = 1 自己算一遍，对上这根箭头；最后在答题框写 x = (−2, 1, 0)ᵀ + k(4, −1, 1)ᵀ。
- 页面当场：Q 拖到 x3 = 0、x3 = 1 时吸住并钉一个点；两个钉点之间画箭头、标出差；右边变 0 时第 2 张平面平移的动画；学生把箭头的尾巴拖到原点时，箭头整根落在 L0 上，L0 亮；学生写的通解，页面按 k 从 −3 到 3 把它算出的点一路画出来（落在 L 上的是实点，不在的是空心点）。
- 事实：Q 的坐标、x3 的值；两个钉点和它们的差；差代进 Ax = 0 每一行的值；学生写的通解里特解代进 Ax = b 的残差、方向向量代进 Ax = 0 的残差、方向向量是不是非零、扫出的点是不是整条 L；学生用的是「自由变量取 0 / 取 1」还是别的等价写法（例如特解取 (2, 0, 1)、方向取 (−4, 1, −1)，一样对）。
- 老师凭什么接：写对 → 给名字「x3 叫自由变量（没有台阶头的列），个数 = 3 − r = 1；η 叫特解；Ax = 0 叫导出组，ξ 是它的基础解系；通解 = η + kξ」，再回指第 1 幕绕回原点的那条链：「(1, 1, −1) 就是那个方程组的 ξ，加上它尖不动」，进第 7 幕；学生在带着右边那一列的方程里取 x3 = 1，把 (2, 0, 1) 当成 ξ → 不说，只让学生拨 k 滑块看自己写的通解：k = 1 时点 (0, 1, 1) 离开 L（空心），学生自己看出「方向不对」。

### 第 7 幕：两个自由变量：两根箭头张成一张平面；能代表所有解的一组箭头要是解、不能共线、个数够 n − r
- 画面：Ax = 0，A = (1 2 −1; 2 4 −2; −1 −2 1)；3D 里三张平面完全叠成一张过原点的 x1 + 2x2 − x3 = 0（三种颜色的边框叠在一起）；平面上一颗目标星 T = (3, −1, 1)；左边是消元格子；下面两根可编辑的箭头 u、v（坐标可写、尖可拖）和两个滑块 k1、k2，点 k1u + k2v 实时画出来。
- 动：学生拨 k1、k2，点 k1u + k2v 跟着走，走过的地方留下淡淡的轨迹，轨迹慢慢铺成一片；我换上别的一对箭头时，轨迹照样实时画：两根共线就只能铺成一条线；有一根不在平面上，点一离开平面就和平面之间连一根红线，红线长短跟着变。
- 老师说：「消一下，台阶几级、自由的有几个？」→「x2、x3 一个取 1、一个取 0，各算一根箭头。」→「拨 k1、k2 去够那颗星。」→（够到以后换成 ξ1 和 2ξ1）「换这两根呢？」→（再换成 ξ1 和 (1, 1, 1)）「这两根呢？」→「能代表所有解的一组箭头，要满足哪几条？」
- 学生做：消元写出 (1 2 −1; 0 0 0; 0 0 0)，说出两个自由变量 x2、x3；算出 ξ1 = (−2, 1, 0)、ξ2 = (1, 0, 1) 填进 u、v；拨 k1、k2 让点落到 T（k1 = −1、k2 = 1）；用我换上的两对箭头再去够 T，说出够不着的原因；最后写下这组箭头要满足的几条。
- 页面当场：点到 T 时星亮，说预写的「够到了」；轨迹铺满时那片平面从半透明变实；换成 ξ1、2ξ1 时怎么拨轨迹都只在一条线上、T 一直够不着；换成 ξ1、(1, 1, 1) 时只要 k2 ≠ 0，点就离开平面，红线跟着长出来。
- 事实：学生的阶梯形对不对、台阶数 1、自由变量是哪两个；学生算的 ξ1、ξ2 代进 Ax = 0 的值、两根是否线性无关；k1、k2 的当前值、点的坐标、离 T 多远、离平面多远；每一对箭头张成的是一条线还是一张面；学生写的几条和课本三条（是 Ax = 0 的解、线性无关、任一解都能由它们线性表示）比，缺哪条。
- 老师凭什么接：三条都写出来（说法不限）→ 给名字「这样一组叫基础解系，个数 = n − r(A) = 3 − 1 = 2，通解 k1ξ1 + k2ξ2」，再把右边换成 b = (1, 2, −1)：整张平面平移，学生自己写 η + k1ξ1 + k2ξ2（η 取 x2 = x3 = 0 得 (1, 0, 0)），进第 8 幕；只写出「是解」「要两根」→ 我再换回 ξ1、2ξ1 让学生拨，看出「两根不能共线」。

### 第 8 幕：自己做一道含参的题 B13-36.1（存在两个不同的解，求 λ、a 和通解），全程学生写、页面算、我看
- 画面：A = (λ 1 1; 0 λ − 1 0; 1 1 λ)、b = (a, 1, 1)ᵀ，题干「已知 Ax = b 存在两个不同的解，(1) 求 λ、a；(2) 求通解」；一开始只有写字区（学生写的式子和每一张矩阵页面都识别、都算），没有 3D、没有滑块；学生写出候选的 λ 之后，才放出 3D（三张平面）、一个 λ 滑块和一个 a 滑块。
- 动：学生写 |A| 或消元，页面跟着算；学生点「看 λ = 1」「看 λ = −1」，3D 换成那一 λ 的三张平面，拨 a 时第 1 张平面平移；学生把 λ 滑块从 0 往 1 拨时，第 2 张平面 (λ − 1)x2 = 1 越飞越远，λ = 1 时整张没了（画面边上一个箭头指着它飞走的方向）；λ = −1 时拨 a，三张平面两两交成三根平行的线（一个三棱柱的样子），a = −2 那一下三根线合成一根。
- 老师说：「两个不同的解，说明是哪一种情形？」→ 然后基本不说，看学生写；学生卡住超过两分钟才指一处，例如「λ = 1 时，第 2 个方程写出来是什么？」
- 学生做：写出「两个不同的解 ⇒ 无穷多解 ⇒ r(A) = r([A | b]) < 3」；算 |A| = (λ − 1)²(λ + 1)；分别把 λ = 1、λ = −1 代进增广矩阵消元，舍掉 λ = 1，由最后一行 (0 0 0 | a + 2) 得 a = −2；写出通解 x = (3/2, −1/2, 0)ᵀ + k(1, 0, 1)ᵀ。
- 页面当场：学生写的每张矩阵只算、不显示对错（我要看时再打开）；学生写出 |A| 的式子后，在 λ 轴上把学生这个式子的根打点（画面后果，对不对学生自己拿滑块去试）；λ = −1 下 a 拨到 −2 时三棱柱合成一条线，这条线亮；写出通解后照第 6 幕把 k 从 −3 到 3 的点画出来。
- 事实：学生的 |A| 式子和真的展开是否相等、根对不对；每一步矩阵是否同解、错在哪一格；λ = 1 时的矛盾行 (0 0 0 | 1)，对所有 a 都无解；λ = −1 时最后一行 (0 0 0 | a + 2)；学生的结论（λ、a 的值，有没有把 λ = 1 留下）；通解里特解的残差、方向向量的残差、方向向量个数是不是 3 − r = 1；学生消元时有没有除以含 λ 的式子（如 r3 − (1/λ)·r1）而没讨论它为 0。
- 老师凭什么接：全对 → 最后给 B13-44.5（4 个未知数、两个自由变量，没有 3D，页面只把学生写的 η、ξ1、ξ2 代进四个方程画成四根残差柱，并判 ξ1、ξ2 是否线性无关、个数是否 = 4 − 2），做完下课；λ = 1、λ = −1 都留下 → 分支 3；学生用 1/λ 消元 → 把 λ 拨到 0 给学生看第 1 行第 1 个数成了 0，「这一步还做得了吗」；学生认为 λ = −1、a ≠ −2 时「三张平面两两都不平行，应该有交点」→ 拨 a 给学生看三棱柱，让学生自己说出「不平行也可以没有公共点」。

## 分支 1：缺项不补 0（W7），增广矩阵里系数错了列
- 学生会怎么做：写增广矩阵时遇到缺项直接跳过，后面的系数往前挤：第 2 幕把 x2 + x3 = 2 写成 (1 1 | 2)，x2 的 1 落进了 x1 那一列；第 3 幕把 x1 − 4x3 = 0 写成 (1 −4 0 | 0)，−4 落进了 x2 那一列，或者只写三格 (1 −4 | 0)（和 L1-05 一样：缺项直接跳过，写出少一列的系数表）。
- 老师想演什么：不说「要补 0」，让学生看到自己写的那一行说的是另一个方程：页面把学生写的行按列头读回成「x1 − 4x2 = 0」，在 3D 里画出这张虚线平面，和真的 x1 − 4x3 = 0 并排；P = (4, −1, 1) 在真平面上，到虚平面拉一根红线；左边列视角里，这一列画出的箭头也和原来那根对不上。我只问「−4 是跟着谁的？」，让学生把 −4 拖回 x3 那一列、x2 那一格自己写 0：虚平面转回去和真平面合成一张，红线消失。之后每次写增广矩阵，让学生先写出列头 x1 x2 x3 | b 再填。
- 页面要提供什么：每一格的数在原方程里属于哪个未知数（错位的格、少格的行、空格）；学生写的每一行按列头读回成的方程；虚平面和真平面的夹角；P 代进学生那一行的值（例如 4 − 4·(−1) = 8 ≠ 0）；拖回以后两张平面合上的动画；这一节课里这种错出现了第几次、每次缺的是哪个位置的未知数（中间的还是第一个）。

## 分支 2：倍加时改动了被加行以外的行（W6）
- 学生会怎么做：第 4 幕做「r2 − r1」时把第 1 行也改了：新矩阵的第 1 行写成 (0 2 4 | 2)（做成了 r1 − r2），或者第 1、2 行都写成 (0 −2 −4 | −2)；或者把「第 1 行加到第 2 行」理解成改第 1 行（和 L1-10「第 2 行加到第 3 行」做成改动第 1、2 行一样）。
- 老师想演什么：拿第 3 幕的铰链做对比，让画面说话：把学生这一步前、后两张矩阵各自的三张平面叠在一起放，学生本来不该动的第 1 张平面跳了位置，P 不再是公共点；两行写成一样的时候，第 1、2 张平面合成一张，公共点从一个点变成一整条线（「一个方程被弄丢了」）。然后让学生用把手把第 1 行拖到第 2 行上重做一次，看第 1 张平面一动不动、P 一直亮着；最后让学生自己对比两次，说出「被加的那一行变，拿来加的那一行不变」。
- 页面要提供什么：前、后两张矩阵逐行比：哪几行变了，每个变了的行是不是「原来这一行 + k×另一行」、属于哪一种（只有被加行变了 / 拿来加的那行也变了 / 两行变成一样）；新矩阵的解集（点、线、空）和原来的比；原来的 P 代进新矩阵每一行的值；学生的矩阵和「只改第 2 行」的正确结果并排；这个错这节课第几次出现、出现在哪种说法上（「r2 − r1」还是「第 1 行加到第 2 行」）。

## 分支 3：只看系数那一边就下结论，不看最后一列
- 学生会怎么做：第 8 幕算出 |A| = (λ − 1)²(λ + 1) = 0 后直接写「λ = 1 或 λ = −1」，不代回去消元；或者第 5 幕说「λ = −2 时 −2 − λ = 0，台阶少了一级，所以无穷多解」，没看右边的 −μ − 1；或者 B13-35.2 选 (D)「r(A) < n 就有无穷多解」。
- 老师想演什么：让画面替学生检验学生留下的那个值：λ = 1 时，让学生自己把 λ 从 0.5 往 1 拨，看第 2 张平面 (λ − 1)x2 = 1 越飞越远、到 λ = 1 整张消失；增广矩阵第 2 行读回成「0·x1 + 0·x2 + 0·x3 = 1」，再化成「0 = 1」；再让学生把 a 从 −4 拨到 4，三张平面怎么摆都没有公共点。第 5 幕的情形：停在 λ = −2、μ = 0，两张平行平面隔着 1/3 的距离，问「这两张平面的公共点在哪？」，再让学生拨 μ，两张慢慢靠拢、在 μ = −1 合上。最后让学生自己补一句：系数那边少了一级台阶，还要看最后一列。
- 页面要提供什么：r(A)、r([A | b]) 分开算、分开显示；矛盾的那一行和它读回的「0 = 几」；λ 接近 1 时第 2 张平面离原点的距离 1/|λ − 1|；a（或 μ）扫过一整段时每个值下解的样子（λ = 1 时一路都是无解）；学生给的结论和每个候选值真实的情形逐一对照；B13-35.2 的 (B)(C)(D) 各造一个具体的反例方程组（按选项里的 m、n、r 造，画出它的平面），供我挑着给学生看。
