# 英语：拿现在的舞台演 E1–E3

试演文件都在 `evals/stage-gaps/try/E{1,2,3}/`，截图在各自的 `shots/`。下面「幕2.txt 第 5 行」都是那一块目录下的文件。

先说几条贯穿三块的事实（后面每一项不再重复解释）：

- **句子上学生能做的只有两样**：点一个词（`ask tap`，一轮只能点一下，点了就叫老师）、按住一个词拖到同一句的别处（`open s` / `ask drag`，一次一个词）。圈一段、拉括号、拉线、挂钩子、折起来、把词拖进别的东西里，说明里都没有给学生的写法。
- **句子不跟任何东西联动**：拨数（`dial`）只驱动 `group stride=`、`vec w = k u` 和 `{d}` 字；句子里的词只能老师 `rewrite`。页面不知道哪个词是动词、什么形式、谓语是哪几个。
- **挑战（goal）判不了句子**：`when=` 写词会报「「ago」不是舞台上的东西」，写坐标会报「「(0,0)」不是舞台上的东西」。绕路是拿部件比部件：`h.4 = h#10`（第 4 个位置上是不是一开始第 10 个的那个词）、`p.me = p.N`（向量和一个点比）。说明里没写这种写法，是试出来的。挑战做到一次就完，回不去，所以「拨到哪个就变成哪个」只能接一种。
- **`ask tap … expect=s.2-5`（一段）时，点这一段里的一个词被判成「点的不是它」**（E1 幕1b.txt 第 5–6 行）。
- **试演工具里学生拨不了数**：学生能写的只有 write / swap / move / vec / mul、tap / drag / value / say / next，所以凡是靠拨数的，页面会不会报「学生拨了 t：2 → 3」没能在工具里看到。
- **点题卡的一行，页面只报「学生点了 w.3（第 3 行）」**，不报那一行写的是什么；话里写 `{q.4}` 小块上也只画「第 4 行」（E3 `幕5b.txt`）。拿题卡当选项、代入窗、词形卡的地方，老师每次都要回头对。

说明里让我写错了好几次的：
- `goal … when=` 那一行只给了「C = O、D != O、A = B、B.1,2 > 0、a sorted」，没说句子的词、平面的向量算什么值、能不能和一个字比。我照字面写了 6 次都被拒：`h.4 = ago`、`s.5 != been`、`c.1 = 科学出版业`（「不是舞台上的东西」），`p.me = (0,0)`（同上），`p.bar != (3, 0)`（逗号把坐标切开，报「「0)」看不懂」）。后来才试出拿部件比部件能判。
- `ask tap … expect=a.7` 只举了一个部件；写成一段（`expect=s.2-5`、`expect=s.10-11`）以后点这一段里的词判成没点对，说明里没写一段该怎么写。
- 句子里想留一个空位，写 `___` 会粘到前一个词上（「homes___」「spying___」），说明里没有「空位」的写法。
