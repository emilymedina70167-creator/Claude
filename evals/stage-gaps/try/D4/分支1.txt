# D4 分支 1：树高公式搞反。n 拨到 7、8、15、16 看层数跳；最瘦的 4 层平衡树按层排进数组出现空格
tree c = 1 2 3 4 5 6 7
dial n = 7 range=1-20
label ln dial:n "n = {n}" side=right
say "把 $n$ 拨到 8：第 8 个结点坐哪？"
set n 8
# 拨数不会让树长出第 8 个结点：老师只能自己 append
append c 8
ask value "到几个结点才有第 4 层？" answer=8
