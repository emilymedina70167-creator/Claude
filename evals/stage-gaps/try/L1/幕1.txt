# L1 第 1 幕：AB = O 收尾（造 D ≠ C 让 AD = AC），再翻成 BA
matrix A = 1 2 / 2 4
matrix B = 2 2 / -1 -1 beside=A
matrix C = 1 0 / 2 1 beside=B
label tb B "你上次造的" side=above tone=note
product P = A B
mul P
matrix D = 0 0 / 0 0
product X = A C
mul X
product Y = A D
mul Y
say "上次你造的 {B} 让 {P} = O。先收个尾：造一个不等于 {C} 的 {D}，让 AD = AC。"
open D edit range=-3..3
goal g1 "改 {D}，让 AD = AC，D 却不是 C" when="Y = X, D != C"
@g1 say "对，AD = AC，D 却不是 C。"
@g1 card q = "BA 是 O" "BA 不是 O" "说不准"
@g1 ask tap q "现在把 A、B 换个位置乘。先猜：BA 也是 O 吗？"
学生: write D.1,1 3
学生: write D.1,2 2
学生: write D.2,1 1
学生: write D.2,2 0
学生: tap q.2
product P = B A
mul P
product X = C A
mul X
product Y = D A
mul Y
say "顺序一换，{P} 不是 O 了。这节课就问：顺序换了，什么时候结果不变？"
ask tap Y "{Y} 和 {X} 哪几格不一样？点一格"
学生: tap Y.1,1
say "对，这一格不一样。"
