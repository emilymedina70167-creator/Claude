# L2 第 3 幕：倍加 r3 + k·r1，只有第 3 行变（三维平面没有，只试矩阵）
matrix M = 1 2 0 | 2 / 1 0 -4 | 0 / 1 2 -2 | 0
dial k = 0 range=-3..3 at=M
rowop M r3 + k r1
say "把第 1 行加到第 3 行上，拨 {k}，盯着：谁在动、谁不动。"
goal g1 "让第 3 行第 1 个数变成 0" when="M.3,1 = 0"
@g1 say "做到了。"
@g1 ask say "现在第 3 行说的是哪个方程？"
rowop M r3 - r1
say "老师来：{M.r3} 变成了 0 0 −2 | −2。"
ask say "什么没动？"
学生: say 第 1、2 行没动
say "对，这叫倍加。"
