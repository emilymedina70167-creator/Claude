# L3 第 3 幕：λE − A 把非零向量压回原点 ⇔ |λE − A| = 0
tex f = "\hl{a}{A\xi} = \hl{l}{\lambda\xi}"
say "挪一下。"
retex f "\hl{a}{A\xi} = \hl{l}{\lambda E\xi}"
next f "\hl{l}{\lambda E\xi} - \hl{a}{A\xi} = 0"
next f "(\lambda E - A)\xi = 0"
plane p range=-4..4
vec p e1 = 1 0 color=g1
vec p e2 = 0 1 color=g6
sum p s = e1 + e2
dial lam = 0 range=-2..6 at=p
transform p = lam-3 -1 / -2 lam-2
card k = "A = (3 1; 2 2)"
cover k.1
say "拨 {lam}，看正方形变成什么。什么时候被压成一条线？"
ask value "让它压成线段的 λ（先找一个）" answer=4
学生: value 4
ask say "写出 |λE − A| 展开成的多项式"
学生: say λ^2 - 5λ + 6
say "嗯。"
