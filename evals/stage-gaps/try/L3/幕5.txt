# L3 第 5 幕：判三根向量是不是特征向量（三维空间、平面、线都没有，只试「A 乘它」这一半）
matrix A = 2 2 -2 / 2 5 -4 / -2 -4 5
matrix X = 1 / 2 / -1 beside=A
product W = A X
mul W
cover W
matrix Y = 0 / 0 / 0
label ly Y "你算的 A 乘它" side=left tone=note
say "先自己乘：{A} 乘 {X}，写进 {Y}。"
open Y edit range=-20..20
goal g1 "写对 A 乘它" when="Y = W"
@g1 uncover W
@g1 card c = "是特征向量" "不是特征向量"
@g1 ask tap c "它是特征向量吗？"
学生: write Y.1,1 8
学生: write Y.2,1 16
学生: write Y.3,1 -15
学生: tap c.1
say "是的话 λ 是几？"
ask value "λ = ？" answer=0
学生: value 8
say "嗯。"
