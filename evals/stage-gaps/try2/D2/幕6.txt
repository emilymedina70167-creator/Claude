# D2 第 6 幕：高 h 层的 AVL 至少几个结点
# 只看形状：3 层的满树（结点里写 ·），右上角两个计数（没有跟着树算的式子，只能贴死字）
tree s = · · · · · · ·
bf s
label c1 s "结点 7 · 高 3" side=right tone=key
# 两行空表：拿矩阵凑（第 1 行是 h，第 2 行最少、第 3 行最多；没填的写 0），学生用键盘写一格
matrix T = 1 2 3 4 5 6 / 1 2 0 0 0 0 / 1 3 0 0 0 0
say "摘叶子，摘到最少。规矩：不许有红的，还得是 3 层。"
# 学生点叶子摘掉：没有学生删结点的动作；只能 ask tap 一下，老师 delete
ask tap s "点一个要摘的叶子"
学生: tap s#7
delete s#7
retext c1 "结点 6 · 高 3"
ask tap s "再点一个"
学生: tap s#6
delete s#6
retext c1 "结点 5 · 高 3"
ask tap s "再点一个"
学生: tap s#5
delete s#5
retext c1 "结点 4 · 高 3"
# 摘到最少时计数亮一下：挑战写不出「结点数 = 4」，只能写层数和平衡
goal g1 "最瘦的 3 层" when="s avl, s height=3"
ask tap s "还能再摘吗？再点一个，或者点按钮" 
学生: tap s#4
# 老师接：5 层不摘，拼（拖小卡到根下面：没有）；老师直接造一棵最瘦的 5 层
ungoal g1
unlabel
tree s = 8 5 11 3 7 10 12 2 4 6 _ 9 _ _ _ 1
bf s
say "根的左边像谁？右边像谁？"
ask say "左边、右边各是前面哪一棵？"
学生: say 左边是最瘦的4层，右边是最瘦的3层
# 老师接：表交给学生写（键盘写一格），页面逐格判
open T edit input=keypad
goal g2 "把表填完" when="T.2,3 = 4, T.2,4 = 7, T.2,5 = 12, T.2,6 = 20, T.3,3 = 7, T.3,4 = 15, T.3,5 = 31, T.3,6 = 63"
@g2 ask value "20 个结点的 AVL，最多能有几层？" answer=6 wrong="5=拿最满的那一头 2^h−1 算的;4=两行都没对上"
学生: write T.2,3 4
学生: write T.2,4 7
学生: write T.2,5 12
学生: write T.2,6 20
学生: write T.3,3 7
学生: write T.3,4 15
学生: write T.3,5 31
学生: write T.3,6 63
学生: value 6
