# D3 分支 2：下一个只在刚锁的那个点指到的点里挑——顺着箭头往下走，不看全体没锁的
# 第 6 幕第 3 轮开头：锁了 1、5、4；牌子 2「8」、3「13」
graph g = 1>2:10 1>5:5 2>3:1 2>5:2 3>4:4 4>1:7 4>3:6 5>2:3 5>3:9 5>4:2
paint g.1 g.5 g.4 g4
tag g ∞
tag g.1 0
tag g.5 5
tag g.4 7
tag g.2 8
tag g.3 13
paint g.1~5 g.5~4 g.5~2 g.4~3 g4
array q = 2 3 hide=on
# 存下第 3 轮开头，好倒回来看
keep g "第 3 轮开头"
ask tap g.2 g.3 "第 3 轮：锁谁？" expect=g.2
学生: tap g.3
# 老师接：页面只说「点的不是它」；刚锁的是 4、4 只指向 3、全体没锁里最小的是 2（8）——都要老师自己看。先照学生的锁上
paint g.3 g4
say "{g.3} 锁在 13。剩下的 {g.2} 也锁上。"
ask tap g.2 "点 2 锁上" expect=g.2
学生: tap g.2
# 老师接：2→3 亮，8+1 = 9 < 13，可 3 已经锁了——relax 照改，不裂；裂缝和那条更短的路老师自己贴
paint g.2 g4
glow g.2~3
relax g.2 -> g.3
label crack g.3 "1→5→2→3 = 9 < 13" side=below tone=key
keep g "现在"
say "锁死的 13 被一条更短的路打败了。倒回第 3 轮开头看看。"
# 倒回第 3 轮开头（学生的记录不清掉）；打开候场队伍
back g "第 3 轮开头"
show q
label lq q "还没锁的，按牌子从小到大：2（8）、3（13）" side=above tone=note
ask say "{g.2} 不是 {g.4} 指到的，可它排在前面。锁的该是离谁最近的？"
学生: say 离起点最近的，不是离刚锁的那个最近的
# 老师接：看完回到现在
back g "现在"
hide q
unlabel lq
# 学生去改已锁的点：牌子学生写不了，只能问一个数；页面不知道 3 是锁了的
ask value "3 已经锁了。它的牌子你想改成几？" answer=9
学生: value 9
