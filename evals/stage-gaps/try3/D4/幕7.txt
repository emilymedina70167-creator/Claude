# D4 第 7 幕：建堆。第一段只许爸爸和孩子对调（页面拦不住别的）；第二段「筛」是老师预写 / 下一轮写的 compare + swap；第三段 2018 真题
# 下面那一排跟着树算（array a = {t#1} …），树上换了它跟着换
tree t = 53 17 78 09 45 65 87 32 layout=compact
array a = {t#1} {t#2} {t#3} {t#4} {t#5} {t#6} {t#7} {t#8}
card log = "记录"
say "只许爸爸和孩子对调，把它变成每个爸爸都不比孩子小的样子。"
open t undo=on
goal g1 "每个爸爸都不比孩子小" when="t#1 >= t#2, t#1 >= t#3, t#2 >= t#4, t#2 >= t#5, t#3 >= t#6, t#3 >= t#7, t#4 >= t#8"
@g1 say "是大根堆了。"
@g1 ask value "你一共换了几次？"

# 老师接：换回原来那一排，这回「筛」。从哪个结点开始？答对了演预写的比较 + 对调
