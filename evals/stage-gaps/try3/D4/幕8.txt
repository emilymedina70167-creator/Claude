# 空位：树的结点不能写成 _（「值不能是 _」），只能写一个「空」字当空位；学生拖孩子上来它就往下走；最后一个补上以后学生点那片「空」叶子摘掉
tree t = 87 45 78 32 17 65 53 09 layout=compact
array a = {t#1} {t#2} {t#3} {t#4} {t#5} {t#6} {t#7} {t#8}
array out = 87
label lo out "拿走的" side=left tone=note
write t#1 空
keep t "根空了"
say "87 拿走了。根空了，谁来补？把它拖进空位。"
open t back="根空了"
open t pluck
goal g1 "补好根、摘掉空位，再调成大根堆" when="count(t) = 7, t#1 >= t#2, t#1 >= t#3, t#2 >= t#4, t#2 >= t#5, t#3 >= t#6, t#3 >= t#7"
@g1 say "又是大根堆了。"
@g1 ask value "09 往下筛，一共比较了几次？" answer=4 wrong="2=只数了对调的两次"

# 老师接：堆排序。87 不扔，和最后一个对调；排好区 = 预写的染色 + 灰掉
ungoal g1
tree t = 87 45 78 32 17 65 53 09 layout=compact
remove out
say "这回 {t#1} 别扔：和最后一个换，看它去了哪。再把前面的调回大根堆。"
open t undo=on
goal g2 "第 1 轮：87 换到最后，前 7 个调回大根堆" when="t#8 = 87, t#1 >= t#2, t#1 >= t#3, t#2 >= t#4, t#2 >= t#5, t#3 >= t#6, t#3 >= t#7"
@g2 paint t#8 a.8 g3
@g2 dim t#8
@g2 goal g3 "第 2 轮：78 换到第 7 个，前 6 个调回大根堆" when="t#7 = 78, t#1 >= t#2, t#1 >= t#3, t#2 >= t#4, t#2 >= t#5, t#3 >= t#6"
@g3 paint t#7 a.7 g3
@g3 dim t#7
@g3 ask next "两轮了。剩下的页面接着排" button="接着排"
