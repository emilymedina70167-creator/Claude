# L1 第 4 幕（第三次）：A 锁着，找能和 A 换的 B（差 BA − AB 跟着算），收集型挑战收 4 张；换 A 再收；测试机
matrix A = 1 2 / 0 3
label la A "A（锁着）" side=above tone=note
matrix B = 0 1 / 1 0 beside=A
label lb B "B（你来拨）" side=above tone=note
matrix AB = {A B}
matrix BA = {B A} beside=AB
matrix Df = {B A - A B}
label l1 AB "AB" side=left tone=note
label l2 BA "BA" side=right tone=note
label l3 Df "差 BA − AB" side=left tone=key
say "{A} 锁着，你去找能和它换的 {B}，越不一样越好。"
open B edit range=-3..3
goal g1 "让 AB、BA 并得起来，B 不能是 O；收 4 张互不相同的 B" when="Df = O, B != O" collect=B n=4
@g1 pulse Df
@g1 say "并上了！"
学生: write B.1,2 0
学生: write B.2,1 0
学生: write B.1,1 1
学生: write B.2,2 1
# 再收一次一样的：不收
学生: write B.2,2 2
学生: write B.2,2 1
学生: write B.1,2 2
