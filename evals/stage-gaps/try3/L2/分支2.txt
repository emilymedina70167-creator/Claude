# L2 分支 2（第三次）：做「r2 − r1」时把第 1 行也改了（from= 页面比上一张；keep / back 写回上一张；用把手重做）
matrix M0 = 1 2 0 | 2 / 1 0 -4 | 0 / 1 2 -2 | 0 vars="x1 x2 x3"
label l0 M0 "上一张" side=above tone=note
matrix M1 = 1 2 0 | 2 / 1 0 -4 | 0 / 1 2 -2 | 0 beside=M0 from=M0 vars="x1 x2 x3"
label l1 M1 "这一步写在这里" side=above tone=note
keep M1 "上一张"
say "做 r2 − r1，把新的整张写进 {M1}。"
open M1 edit input=keypad
ask value "这一步做了什么？"
学生: write M1.1,1 0
学生: write M1.1,3 4
学生: write M1.2,1 0
学生: write M1.2,2 -2
学生: write M1.2,4 -2
学生: value r2 - r1
# 老师：P 代进去、正确的那张并排（初等矩阵藏着）
matrix Pv = 4 / -1 / 1
matrix Res = {coef(M1) Pv - rhs(M1)} beside=Pv
label lr Res "P 代进你这张（左 − 右）" side=above tone=note
matrix E21 = 1 0 0 / -1 1 0 / 0 0 1 hide=on
matrix Ok = {E21 M0}
label lok Ok "只改第 2 行的结果" side=above tone=note
say "P 代进你这张，第 1 行还是 0 吗？和 {Ok} 比，哪几行不一样？"
ask say "被加的那一行变，拿来加的那一行呢？"
学生: say 拿来加的那行不该变
# 用把手重做一次：先把 M1 回到上一张
back M1 "上一张"
close M1
open M1 rowop wrong=mark undo=on
say "用把手做一次：把第 1 行拖到第 2 行上。"
goal g1 "用把手做 r2 − r1" when="M1.2,1 = 0, M1 same M0"
@g1 say "第 1 行一动没动。"
学生: rowop M1 r2 - r1
say "嗯。"
