# L2 分支 3（第三次）：只看系数那一边就下结论（B13-36.1：|A| = 0 直接写 λ = 1 或 λ = −1）；r(A)、r(A | b) 分开看，扫一遍 a
dial l = 0 range=-2..2
dial a = 0 range=-4..4
label ll dial:l "λ = {l}" side=right
label la dial:a "a = {a}" side=right
matrix M = {l} 1 1 | {a} / 0 {l - 1} 0 | 1 / 1 1 {l} | 1 vars="x1 x2 x3"
# r(A)、r(A | b) 分开显示给学生（量写进贴的字，跟着变）
label lr M "r(A) = {rankA(M)}，r(A | b) = {rank(M)}" side=below tone=key
say "两个不同的解，你算出 |A| = 0 就写了 λ = 1 或 λ = −1。把 λ 拨到 1，看看第 2 个方程。"
goal g1 "把 λ 拨到 1" when="l = 1"
@g1 ask say "第 2 个方程现在写出来是什么？"
学生: dial l 1
学生: say 0 = 1
# 判断式不用当挑战也问得出：现在秩是几
@ask.right say "对，r(A) = 1。"
ask value "现在竖线左边的秩 r(A) 是几？" answer={rankA(M)}
学生: value 1
@ask.right say "对：r(A) ≠ r(A | b)。"
ask value "整张的秩 r(A | b) 是几？" answer={rank(M)}
学生: value 2
# 再让学生把 a 从 −4 拨到 4，看是不是一路都没有解
say "λ = 1 时，把 {a} 从 −4 拨到 4，有没有哪个 a 有解？"
ask next "拨完点下面" button="拨完了"
学生: dial a -4
学生: dial a 4
学生: next
# 取 a = 4 那一张抄成数，让学生自己消一步，看页面读回什么
matrix W = 1 1 1 | 4 / 0 0 0 | 1 / 1 1 1 | 1 vars="x1 x2 x3"
open W rowop wrong=mark undo=on
say "a = 4 时是 {W}。你来消：把第 1 行拖到第 3 行上。"
ask next "消完点下面" button="消好了"
学生: rowop W r3 - r1
学生: next
say "{W.r3} 读回来是什么？"
ask say "系数那边少了一级台阶，还要看哪里？"
学生: say 还要看最后一列
say "嗯。"
