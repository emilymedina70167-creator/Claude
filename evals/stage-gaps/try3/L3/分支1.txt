# L3 分支 1（第三次量）：提出公因子 (λ − 1) 以后丢掉了，只剩 λ² − 11λ + 10，以为只有 1 和 10
matrix A = 2 2 -2 / 2 5 -4 / -2 -4 5
matrix E = 1 0 0 / 0 1 0 / 0 0 1 hide=on
matrix EA = {E - A} hide=on
tex f = "|\lambda E - A| = \begin{vmatrix}\lambda-2&-2&0\\-4&\lambda-9&0\\2&4&\lambda-1\end{vmatrix}"
card k = "tr A = 12"
cover k.1
ask value "按第 3 列展开，写成 λ 的式子" type=formula free=λ answer="(λ-1)^2(λ-10)"
学生: value λ^2-11λ+10
# 页面只说不对的话，老师再问一遍、这回把「丢了因子」写进 wrong=，看换了写法的同一个错认不认
