# L3 第 2 幕（第三次量）：这条线上每个非零向量都满足 Aξ = λξ；λ 可以是负的；零向量不算
plane p range=-5..5
matrix A = 3 1 / 2 2
vec p u = 1 1 color=g4
span p u stay
# v 只能沿 (1,1) 这条线滑：拿拨数 k 当系数，v = k u（能滑过原点到另一头）
dial k = 1 range=-3..3 at=p
vec p v = k u color=g1
vec p w = {A v} color=g6
say "沿这条线拨 {p.v}：长的、短的、翻到另一头，框里填几？"
ask value "Av = □·v，□ 填几？" answer=4 wrong="1=看成没变;2=只看了变长多少"
学生: dial k 2
学生: dial k -1
学生: value 4
say "{p.v} 缩到原点呢？"
ask say "v 是零向量时，□ 该填几？"
学生: dial k 0
学生: say 哪个都行，0 乘几都是 0
# 起名字，再开右边的 C：第二块平面（不写 beside=，那是 matrix 的写法，见 幕2c.txt）
say "所以零向量不算。这种只被拉长的向量叫[特征向量]，倍数叫[特征值]。"
fly say.1 -> n1 p.u
plane q range=-6..6
matrix C = 1 2 / 3 0
vec q a = 1 0 color=g1
vec q b = {C a} color=g6
span q a
matrix V2 = {q.a} hide=on
matrix W2 = {C V2} hide=on
matrix K2 = {V2.1,1} {W2.1,1} / {V2.2,1} {W2.2,1} hide=on
matrix Dg = {V2.1,1} 0 / 0 {V2.1,1} hide=on
matrix R2 = {Dg^-1 W2} hide=on
open q.a
goal g1 "右边的 C：把特征方向找全" when="det(K2) = 0" collect=R2 n=2
@g1 span q a stay
@g1 ask value "这条线上 Cv = □·v，□ = ？" answer={R2.1,1}
学生: vec q a = 1 1
学生: value 3
学生: vec q a = -2 3
学生: value 2
say "念一下 {q.a} 和 {q.b} 的坐标：是几倍？"
ask value "Cv = □·v，□ = ？" answer={R2.1,1}
学生: value -2
say "嗯。"
