# L3 第 8 幕第二屏（第三次量）：λ = 1 的平面里挑一根和 ξ1 垂直的、写 Q（三维里转 ξ2、吸住、直角记号：要三维，没有；这里量写坐标、写 Q 的那一半）
matrix A = 2 2 -2 / 2 5 -4 / -2 -4 5
matrix E = 1 0 0 / 0 1 0 / 0 0 1 hide=on
matrix EA = {E - A} hide=on
matrix X1 = -2 / 1 / 0
label l1 X1 "ξ1" side=above tone=key
matrix X2 = 2 / 0 / 1 beside=X1
label l2 X2 "ξ2（能改）" side=above tone=key
matrix Z = {EA X2} hide=on
matrix Dt = {X1' X2}
label ld Dt "ξ1 · ξ2" side=above tone=note
open X2 edit input=keypad
say "{X1}、{X2} 垂直吗？把 {X2} 换成平面里和 {X1} 垂直的一根。"
goal g1 "ξ2 还是 λ = 1 的特征向量，又和 ξ1 垂直" when="Z = O, Dt.1,1 = 0"
@g1 say "垂直了，A 乘它也还是它自己。"

学生: write X2.3,1 0
学生: write X2.1,1 2
