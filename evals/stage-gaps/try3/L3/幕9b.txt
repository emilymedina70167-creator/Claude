# L3 第 9 幕的草稿区（第三次量）：C 拆成一列乘一行、D 的 (λ + 1)³ 和 r(−E − D)（「看三维」：要三维，没有）
matrix C = 1 -2 1 / 2 -4 2 / 1 -2 1
label lc C "C" side=above tone=key
matrix u = _ / _ / _
matrix w = _ _ _ beside=u
matrix UW = {u w} beside=w
label lu UW "你拆的：一列 × 一行" side=above tone=note
open u edit input=keypad
open w edit input=keypad
say "{C} 三行什么关系？把它拆成一列乘一行。"
goal g1 "拆出来乘回去等于 C" when="UW = C"
@g1 say "对：秩是 1。"
@g1 ask value "C 的三个特征值（空格隔开）" type=seq answer="0 0 -2" wrong="0 0 2=迹的符号；0 -2=少写了一重"
学生: write u.1,1 1
学生: write u.2,1 2
学生: write u.3,1 1
学生: write w.1,1 1
学生: write w.1,2 2
学生: write w.1,3 1
学生: write w.1,2 -2
学生: value 0 0 -2
# D 的草稿
remove u
remove w
remove UW
remove C
matrix D = 2 -1 2 / 5 -3 3 / -1 0 -2
label ld D "D" side=above tone=key
matrix E = 1 0 0 / 0 1 0 / 0 0 1 hide=on
matrix ED = {E + D} hide=on
say "{D} 的重根，数一数够不够。"
@ask.right show ED
@ask.right ask value "r(−E − D) = ？" answer={rank(ED)} wrong="1=以为三重根就有两个自由未知量"
ask value "|λE − D| = ？" type=formula free=λ answer="(λ+1)^3"
学生: value (λ+1)^3
学生: value 2
say "嗯。"
