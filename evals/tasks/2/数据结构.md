# 验收题库（第二批）· 数据结构

第二批：和第一批不重的题。每题是一节「实时黑板」课（2～6 块板）。题面的数都核对过。

## ds-btree　B 树的插入

依次插入 5, 6, 9, 13, 8, 2, 12, 15，建一棵初始为空的 4 阶 B 树。画出最后的树。（2020 年统考）
（答案：根结点 [6 9]，下一层 [2 5]、[8]、[12 13 15]）

教到什么程度：说清 4 阶 B 树每个结点最多几个关键字、什么时候分裂、分裂时哪个关键字上移；自己画出每次分裂后的树。

## ds-huffman　哈夫曼编码

字符 a～f 出现的次数分别是 6, 3, 8, 2, 10, 4。构造哈夫曼树，求 WPL，写出每个字符的编码。（2021 年统考的数）
（答案：WPL = 80）

教到什么程度：自己一步步合并（每次挑最小的两棵）；会算 WPL（两种算法：叶子权 × 路径长度、非叶结点权之和）；知道哈夫曼编码为什么是前缀码。

## ds-postfix　中缀转后缀

把中缀表达式 A+B*(C-D)-E/F 转成后缀表达式，写出过程中栈的变化。
（答案：A B C D - * + E F / -）

教到什么程度：自己写出每读一个符号以后栈里有什么、输出了什么；说清同优先级的运算符为什么要先弹出（左结合）。

## ds-nextval　KMP 的 next 和 nextval

模式串 abaabc，求 next 数组和 nextval 数组（王道：从 1 数，next[1] = 0）。
（答案：next = 0 1 1 2 2 3；nextval = 0 1 0 2 1 3）

教到什么程度：说清 next[j] 是什么意思（最长相等前后缀 + 1）；自己算出每一位；知道 nextval 改进了什么情况。

## ds-reverse　算法设计：单链表就地逆置

带头结点的单链表 L，写一个算法把它就地逆置，空间 O(1)。

教到什么程度：自己写出头插法逆置的代码，在一个具体的链表上跟踪每一步指针怎么变；说清为什么要先记下 p->next。
