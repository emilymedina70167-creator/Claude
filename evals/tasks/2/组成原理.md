# 验收题库（第二批）· 组成原理

第二批：和第一批不重的题。每题是一节「实时黑板」课（2～6 块板）。题面的数都核对过。

## co-fadd　浮点加法

阶码 3 位、尾数 8 位（不算符号位），都用双符号位补码，0 舍 1 入。$x = 2^{010}\times 0.11011011$，$y = 2^{100}\times(-0.10101100)$，求 $x + y$。
（答案：$[x+y]_浮$ = 00,011；11.00010110，即 $2^{011}\times(-0.11101010)$）

教到什么程度：自己走对阶、尾数相加、规格化、舍入、溢出判断五步；说清为什么小阶向大阶看齐；会判补码尾数是不是规格化的（00.1×× / 11.0××）。

## co-booth　Booth 补码一位乘

$x = -0.1101$，$y = 0.1011$，用补码一位乘法（Booth）求 $[x\cdot y]_补$。
（答案：$[x\cdot y]_补 = 1.01110001$，$x\cdot y = -0.10001111$）

教到什么程度：自己填出部分积、乘数、附加位那张表；说清看哪两位决定加什么；知道一共加几次、移几次。

## co-div　原码加减交替除法

$x = -0.1011$，$y = -0.1101$，用原码加减交替法求 $x \div y$ 的商和余数。
（答案：商 0.1101，余数 $-0.0111\times 2^{-4}$）

教到什么程度：自己写出每一步的余数和上商；说清余数为负时下一步为什么是加 |y|（而不是先恢复）；最后余数怎么处理、符号跟谁。

## co-hamming　海明码

信息位 1010，求偶校验的海明码；如果收到的是 1000010，哪一位错了？
（答案：海明码 1010010；收到 1000010 时第 5 位错，改正后 1010010）

教到什么程度：会算要几个校验位（2^k ≥ n + k + 1）；说清每个校验位管哪几位；自己算出纠错的 S 并定位。

## co-align　结构体的对齐（32 位）

32 位机器上，`struct { char a; int b; short c; }`，各成员按自己的大小对齐，整个结构体按最大成员对齐。求各成员的偏移和 sizeof；把成员按大小重排能省几个字节？
（答案：a 偏移 0，b 偏移 4，c 偏移 8，sizeof = 12；重排成 int、short、char 后 sizeof = 8，省 4 个字节）

教到什么程度：自己画出内存布局和填充的字节；说清为什么要对齐；会算重排后的大小。
