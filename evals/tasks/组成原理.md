# 验收题库 · 组成原理

每题是一节「实时黑板」课（2～6 块板）要教会的东西。题面是 408 的典型题（王道口径），数都核对过。
「教到什么程度」写的是这节课结束时学生要能独立做到的事；用什么组件、怎么推进由老师自己定。

## co-arith　补码加减和标志位

8 位补码，x = 100，y = 50。计算 x + y 和 x − y 的机器数，写出每次运算后的 OF、SF、ZF、CF。
（答案：x + y = 1001 0110，结果当有符号数是 −106，OF = 1；x − y = 0011 0010，OF = 0）

教到什么程度：会写补码、会把减法变成加补码；说清 OF（有符号溢出）和 CF（无符号进位 / 借位）的区别和各自怎么算。

## co-float　IEEE 754 单精度

把 −10.375 写成 IEEE 754 单精度浮点数（十六进制）。反过来，0xC1260000 表示多少？
（答案：0xC1260000）

教到什么程度：会把十进制小数化成二进制、规格化成 1.xxx × 2^E；阶码用移码（偏置 127）；能拆出符号、阶码、尾数三个字段。

## co-cache　组相联映射和 LRU

主存地址 16 位，按字节编址；cache 共 8 行，块大小 16 B，2 路组相联，LRU 替换，开始为空。依次访问（十六进制地址）0x0010、0x0050、0x0010、0x0090、0x0050、0x0010。写出每次访问的组号、标记，是否命中。
（答案：组号都是 1；标记依次 0、1、0、2、1、0；只有第 3 次命中）

教到什么程度：会把地址拆成标记 / 组号 / 块内地址三段；知道组相联里替换只在一组之内；LRU 换出谁说得清。

## co-pipe　流水线的数据冒险

五段流水线（IF、ID、EX、MEM、WB），寄存器前半周期写、后半周期读，不用转发。指令序列：
add r1, r2, r3；sub r4, r1, r5；and r6, r1, r7；or r8, r2, r9。
找出数据相关，画出时空图，要插入几个阻塞周期？

教到什么程度：会找写后读相关；能画时空图并说清 sub 要等到 add 的哪一段之后；知道转发能省掉多少。

## co-mem　存储器扩展

用 2K × 4 位的 RAM 芯片构成 8K × 8 位的存储器（按字节编址，地址线 A12～A0）。要几片芯片？怎么连（位扩展、字扩展）？用 A12、A11 经 2-4 译码器做片选时，每组芯片的地址范围是什么？
（答案：8 片，每 2 片一组位扩展成 2K × 8，共 4 组字扩展；地址范围 0000H～07FFH、0800H～0FFFH、1000H～17FFH、1800H～1FFFH）

教到什么程度：会算芯片数和每片的地址线条数；分得清位扩展和字扩展；能由片选信号写出地址范围，或者反过来由地址判断落在哪一片。

## co-asm　机器级代码

C 函数：

```c
int sum(int a[], int n) {
    int s = 0;
    for (int i = 0; i < n; i++) s += a[i];
    return s;
}
```

对应的 x86 代码（Intel 格式，为简单起见没有保存 ebx）：

```
1   push ebp
2   mov  ebp, esp
3   mov  ecx, dword ptr [ebp+8]
4   mov  edx, dword ptr [ebp+12]
5   mov  eax, 0
6   mov  ebx, 0
7 L1: cmp ebx, edx
8   jge  L2
9   add  eax, dword ptr [ecx+ebx*4]
10  inc  ebx
11  jmp  L1
12 L2: pop ebp
13  ret
```

(1) 参数 a、n 为什么在 [ebp+8]、[ebp+12]？(2) 第 9 行访问的地址怎么算？哪个寄存器对应 s、哪个对应 i？(3) n = 3 时第 7 行执行几次？第 9 行呢？
（答案：(3) 第 7 行 4 次，第 9 行 3 次）

教到什么程度：说得清调用时栈里放了什么（参数、返回地址、旧的 ebp）；能把汇编和 C 一句句对上；会数循环里每条指令执行的次数。
