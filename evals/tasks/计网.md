# 验收题库 · 计算机网络

每题是一节「实时黑板」课（2～6 块板）要教会的东西。题面是 408 的典型题（王道口径），数都核对过。
「教到什么程度」写的是这节课结束时学生要能独立做到的事；用什么组件、怎么推进由老师自己定。

## cn-subnet　按主机数划分子网

某单位分到地址块 202.118.1.0/24，要分给三个部门，主机数分别是 120、60、20。按主机数从多到少分配，写出每个子网的网络地址、子网掩码、可分配的地址范围和广播地址。
（答案：202.118.1.0/25、202.118.1.128/26、202.118.1.192/27）

教到什么程度：会由主机数定主机位（别忘了减 2）；会从大到小切地址块；能写出广播地址和可分配范围。

## cn-cwnd　TCP 拥塞控制

TCP 的拥塞窗口从 1 开始，慢开始门限初值 16（单位：报文段）。第 12 轮收到 3 个重复确认（快重传、快恢复），第 16 轮发生超时。画出第 1～22 轮的拥塞窗口。

教到什么程度：分得清慢开始、拥塞避免、快恢复、超时后各自 cwnd 和 ssthresh 怎么变；能自己填出每一轮的 cwnd。

## cn-gbn　后退 N 帧

甲向乙用后退 N 帧协议（GBN）发送 0～6 号帧，发送窗口 4，2 号帧丢失，其余正常。甲要重传哪些帧？换成选择重传（SR，窗口也是 4）呢？

教到什么程度：能画出时序图；说清 GBN 的累积确认和 SR 的单独确认差在哪；知道窗口大小的上限（GBN ≤ 2ⁿ − 1，SR ≤ 2ⁿ⁻¹）为什么是这样。

## cn-crc　CRC 校验

生成多项式 G(x) = x⁴ + x + 1，要发送的数据 1101011011。求 CRC 校验码和实际发送的比特串。接收方收到后怎么判断有没有错？
（答案：校验码 1110，发送 11010110111110）

教到什么程度：会在数据后面补 r 个 0、做模 2 除法；知道余数为 0 表示没检测到错误。

## cn-dv　距离向量路由

四个路由器：A–B 代价 1，B–C 代价 2，A–C 代价 5，C–D 代价 1。开始时每个路由器只知道直接相连的邻居。所有路由器同时交换一次距离向量后，A 的路由表是什么？再交换一次呢？
（答案：第一次后 A 到 C 是 3（经 B）、到 D 是 6（经 C）；第二次后 A 到 D 是 4（经 B））

教到什么程度：会用 Bellman-Ford 式子 d(A,X) = min(c(A,N) + d(N,X)) 更新；知道每次交换只用邻居上一次的表；能说出「好消息传得快、坏消息传得慢」。

## cn-web　访问一个网页要几个 RTT

主机 H 的浏览器访问 http://www.example.com/index.html，页面里引用了同一台服务器上的 3 张小图片。忽略传输时延，DNS 已经解析好。
(1) 非持久 HTTP、串行请求，共需多少 RTT？(2) 持久连接、非流水线？(3) 持久连接、流水线？(4) 如果 DNS 没解析过、网关的 MAC 地址也不知道，发出第一个 HTTP 请求之前 H 还要做哪些事？
（答案：(1) 8；(2) 5；(3) 3）

教到什么程度：每个对象花了几个 RTT 能画出时序图来数；分清持久 / 非持久、流水线 / 非流水线；知道 ARP、DNS、TCP 三次握手的先后。
