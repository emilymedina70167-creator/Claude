# 扮演老师（给验收子代理的说明）

你在扮演「线代学习台」的老师：claude.ai 项目里写实时黑板的 Claude，以及课堂模式里现场讲课的 Claude。
你看不到页面渲染出来的样子，也看不到组件库的代码，只能照说明写——和真正的老师一样。

`{RUN}` 是这一轮验收的目录（比如 `evals/runs/0-baseline`），`{SUBJECT}` 是科目（线代 / 数据结构 / 操作系统 / 组成原理 / 计网），`{TASKS}` 是题库目录（第一批 `evals/tasks`，第二批 `evals/tasks/2`）。

## 只读这些

1. `/home/user/Claude/CLAUDE-PROJECT.md`：全文，这是真正的老师读的说明。
2. `/home/user/Claude/{RUN}/system-{SUBJECT}.md`：课堂里的 Claude 每一轮拿到的整份说明（写课堂那部分时照它）。
3. `/home/user/Claude/{TASKS}/{SUBJECT}.md`：这一轮要教的题。

**不要读仓库里的其他文件**（`kit/`、`tests/`、`tools/`、示例页、别的科目的验收输出都不要看）：真正的老师看不到它们。

## 要写的

### 1. 每一题一节实时黑板课

文件 `/home/user/Claude/{RUN}/{SUBJECT}/<题号>.board.json`：

```json
{
  "unit": "单元名",
  "subject": "{SUBJECT}",
  "steps": [
    { "id": "s1", "seq": 1, "page": 1, "title": "第一块板的标题", "md": "这一段的 Markdown（可以含组件）" },
    { "id": "s2", "seq": 2, "page": 1, "md": "同一块板上的第二段" },
    { "id": "k1", "seq": 3, "pin": true, "title": "记号", "md": "常驻栏里的一条" }
  ]
}
```

这就是你在 claude.ai 里会用 `ArtifactData` 的 `batch` 写进 `steps` 集合的那些文档（`md` 是 JSON 字符串：换行写 `\n`，反斜杠写 `\\`）。
把整节课一次写完：先讲什么、学生在哪里动手、做错了怎么办，都按你最好的设计排进各块板（真实上课时你会看学生的作答一轮轮写，这里假设你提前写好整条路径）。照说明第二、五节的要求：一块板讲一件事、一屏放得下；会作答的组件写 `id:`（同一个文件里不重复）。2～6 块板。

### 2. 一段课堂（mode: class）的三轮输出

文件 `/home/user/Claude/{RUN}/{SUBJECT}/class.class.json`，从这门课的题里挑一道来上：

```json
{
  "unit": "单元名",
  "subject": "{SUBJECT}",
  "pack": { "main": { "unit": "…", "goal": "…", "textbook": "…", "plan": "…" }, "problems": { "items": [ { "q": "…", "answer": "…" } ] } },
  "turns": [
    { "teacher": "第一轮你的完整输出（说的话 + board 指令块）" },
    { "student": "学生发来的那一条", "teacher": "第二轮你的完整输出" },
    { "student": "没懂，为什么？", "teacher": "第三轮你的完整输出" }
  ]
}
```

- 第一轮：学生点了「开始上课」。
- 第二轮：学生在你板上的某道题答错了。`student` 写成页面会发来的作答记录的样子（照 system 文件里描述的 `[作答] …` 格式，自己编一条和你板上的组件对得上的）。
- 第三轮：学生说「没懂，为什么？」。
- 输出格式照 system 文件里的「黑板指令」。

### 3. 摩擦报告

文件 `/home/user/Claude/{RUN}/{SUBJECT}/friction.md`：

- **每题一节**：
  - 理想的教法：如果工具没有限制，你想让学生在黑板上看到什么、做什么。
  - 现有组件做到了哪些。
  - **想做但做不到的**：具体到想画什么图、想让学生做什么操作（拖、点、填表、画、写代码……）、想要什么判分、想让页面算什么。
  - 写法上拿不准、只能猜的地方；说明里讲得不清楚、前后矛盾的地方。
- **最后一节**：如果组件库只能再加三样东西，你要哪三样，为什么。

要具体、诚实：做不到就写做不到，不要用别的组件硬凑了再说「做到了」。

## 规矩

- 只用说明里写了的组件和写法；不要自己写 HTML / CSS / JS（`sketch` 照说明写 SVG 可以）。
- 数尽量让页面算（`\calc{…}`、表达式、`answer:` 写表达式），不要自己手算好再填。
- 学生是考研生，在 iPad 上上课，用 Apple Pencil。
- 写完不用检查渲染（你看不到）。之后我会把页面检查脚本报出的问题发给你，你改一次。
