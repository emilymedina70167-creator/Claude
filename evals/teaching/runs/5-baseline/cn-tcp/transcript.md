````board new id=b1 title="首部的样子和前三行" cols=7/5
**第 1 行：两个端口**　源端口（source port）、目的端口（destination port）各 16 位，指出是两台主机上的哪个应用进程在通信。16 位能表示 $0\sim\calc{2^16-1}$。

**第 2 行：序号（sequence number），32 位**
TCP 面向字节流：要发的数据，**每个字节**都编了号。
==序号 = 本报文段所发送数据的第一个字节的编号==。
例：这段装的是第 $1000\sim\calc{1000+200-1}$ 号字节，序号就是 $1000$。

**第 3 行：确认号（acknowledgment number），32 位**
==确认号 = 期望收到对方下一个报文段数据的第一个字节的编号==，只有 ACK = 1 时才有效（ACK 是第 4 行里的一个控制位，下一块讲）。
例：B 收到了 $1000\sim\calc{1000+200-1}$，回给 A 的确认号是 $\calc{1000+200}$，意思是「$\calc{1000+200-1}$ 及以前都收到了，下一个要 $\calc{1000+200}$」。
=={red}确认号写的是「下一个要的」，不是「收到的最后一个」==。
````

````board add id=b5 title="六个控制位" col=1
控制位各占 1 位，置 1 才表示下面这件事：

```remember
title: 六个控制位（按首部里从左到右的顺序）
| 位 | 置 1 表示 |
|---|---|
| URG（urgent） | 紧急指针字段有效 |
| ACK（acknowledgment） | 确认号字段有效；连接建立以后的报文段都置 1 |
| PSH（push） | 接收方尽快交付给应用进程 |
| RST（reset） | 连接出了严重差错，要释放连接、再重新建立 |
| SYN（synchronize） | 建立连接时，用来同步序号 |
| FIN（finish） | 数据发完了，要求释放连接 |
```

注意前两个：URG、ACK 不是自己干一件事，而是==给某个字段「开开关」==：URG = 0，紧急指针写着什么都不算数；ACK = 0，确认号写着什么都不算数。
````

````board add id=b6 title="窗口、校验和、紧急指针" col=2
**窗口（window），16 位**
发这一段的一方，把**自己的接收窗口**写进来，告诉对方：现在允许你给我发多少字节。
````
